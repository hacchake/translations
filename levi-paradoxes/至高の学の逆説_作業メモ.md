# 至高の学の逆説（エリファス・レヴィ）　作業メモ

Éliphas Lévi『The Paradoxes of the Highest Science』（英訳1883年、第二版1922年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Global Grey の電子版（1922年第二版にもとづく）を章ごとに `src/c001.txt`〜`c140.txt` に置いた（`c013`〜`c140` は注一〜百二十八）。注をまとめたものを `src/notes.txt`、長い「総括」を三つに分けたものを `src/r1.txt`〜`r3.txt` とした。
- 電子版では、1883年の英訳者の序文に「Preface To The 1922 Second Edition」の見出しがついているが、本文の末尾は「訳者」の署名であり、内容から1883年の英訳者の序文と判断して「訳者序文（一八八三年の英訳者による）」とした。「C・J」の署名のものが第二版の序言である。
- 注は、本文中の番号の位置に（注n）として置き、おのおのの逆説と総括の三つの部分の終わりにまとめた。E・Oの注と英訳者（Trans.）の注とを区別した。
- 総括の「九」の番号は底本に見えない。四十六の一文（come only from matter）は文意が通りにくいが、原文のまま訳した。
- 下書き `draft/n0.md`〜`n10.md` と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿3本（第一回 n0〜n3、第二回 n4〜n7、第三回 n8〜n10）を生成した。
- 日本語訳の有無：2026年11月6日に extended 検索で調べた範囲では見つからなかった。
- 著作権：レヴィは1875年没。英訳（無署名）は1883年刊、第二版の序言は1922年刊。日本・英国・米国で保護期間満了。
