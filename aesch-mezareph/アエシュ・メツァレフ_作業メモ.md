# アエシュ・メツァレフ　作業メモ

『アエシュ・メツァレフ（浄化の火）』（ウェストコット編『ヘルメス文書集成』第4巻、1894年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の WestcottWWCollectaneaHermeticaVolume04 の OCR テキスト（_djvu.txt、2026年11月4日取得）を `src/aesch_ocr_raw.txt` に置き、柱とページ番号を除いて段落をつないだものを `src/aesch_clean.txt` とした。
- 本文中の注の番号（OCRでは語のあとに数字がまじっている）は、訳文では（注n）として示し、巻末のサペレ・アウデの注（章ごとの番号）に対応させた。読みとれない番号はいくつか補った。
- 方陣（カメア）の数表は OCR で崩れて読めない。第二章のもの（サペレ・アウデによれば「まことの太陽の方陣ではない」）は補えないのでそう断った。ほかは、アグリッパ以来の標準の方陣（土星3、木星4、火星5、太陽6、金星7、水星8、月9）をスクリプトで検算して補った（各行・列・対角線の和が本文の数と一致し、OCRに残る断片とも一致する）。
- 日本語訳の有無：検索した範囲では見つからなかった。
- 下書き `draft/k1.md`〜`k4.md` と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿1本を生成した。

## 訳の方針

- ヘブライ語の名は、本文ではカナ書き（ザハブ、ケテム、バルゼルなど）、注では原文の英字転写（ZHB、KTM、BRZLなど）を示した。
- 原文の聖書の章節はそのまま訳した。明らかなOCRの誤り（列王記下三十章三十節→九章三十節）だけ直した。
- 序文と注のウェストコットの言葉も、省略せず訳した。
