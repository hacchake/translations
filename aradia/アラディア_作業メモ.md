# アラディア、あるいは魔女の福音（C・G・リーランド）　作業メモ

Charles Godfrey Leland『Aradia, or the Gospel of the Witches』（ロンドン、David Nutt、1899年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Sacred Text Archive（archive.sacred-texts.com/pag/aradia/）の1899年版の翻刻（J・B・ヘア作成、ara00〜ara22）を `src/` に取得して底本にした（.gitignore で除外）。扉は Internet Archive の1899年版スキャン `aradiaorgospelof00lela` の n6 ページ（`images/title-1899.jpg`）。表紙（n0）も `images/cover-1899.jpg` に置いたが、記事では使っていない。
- 呪文と詩の多くは、原書ではイタリア語の原文とリーランドの英訳とが並んでいる。訳ではイタリア語の原文を省き、英訳から訳した。英訳がイタリア語と目だって食いちがう箇所（第二章「アラディアへの祈り」の「めあわせる」、第七章の祈りの後半）だけ〔　〕で注記した。巻頭の目次は省いた。
- 原注は〔注1〕〜〔注35〕として通し番号にし、各下書きの末尾にまとめた。
- 原文のままとして注記した主な箇所：第二章「粉の呪文」の flower（flour か）、第十章の地名 Cettardo（チェルタルド）、付録の lee（ice の誤植）。
- 草の名：rue はヘンルーダ、vervain／verbena はクマツヅラ、marroni d'India はマロニエの実とした。
- 下書き `draft/n1.md`（序・第一〜三章）、`n2.md`（第四〜八章）、`n3.md`（第九〜十二章）、`n4.md`（第十三〜十五章）、`n5.md`（付録・追加の三篇・付記）と解説 `draft/head.md` から、`_build.py` で全訳と note 用原稿3本を生成した。
- 日本語訳の有無：2026年11月10日に Web 検索（extended）で調べた範囲では、日本語訳は見つからなかった（日本語版ウィキペディアに項目があるが、邦訳の記載はない）。
- 著作権：リーランドは1903年没。日本・英国・米国で保護期間満了。
- 訳者表記：人工知能（Claude Fable 5.2）。
