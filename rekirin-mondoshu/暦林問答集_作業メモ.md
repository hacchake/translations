# 賀茂在方『暦林問答集』　作業メモ

## 0. 全体

- 原著：賀茂在方『暦林問答集』二巻。応永甲午（応永二十一年、一四一四年）孟春の序と跋がある。
- 底本：『群書類従』巻第五百六 雑部六十一（版本）。国立国会図書館デジタルコレクション info:ndljp/pid/2559255（「群書類従 第636-637冊（巻505-506）」）の57〜112コマ。
  - 作業の下地：NDLの全文テキスト（lab.ndl.go.jp の fulltext-json）。`src/ocr_2559255.txt` に該当コマだけ保存した。
  - 版面の画像（IIIF、幅1800px、割注の多いコマは3000px）と一字ずつ照らし合わせて本文を定めた。画像はリポジトリに入れていない。
  - 参考に、慶長期ごろの写本 pid 2533201 のOCRも `src/ocr_2533201.txt` に保存したが、手書きでOCRの崩れが大きく、校合には使っていない。
- ユーザーが示した pid 14488380（群書類從 卷506 の単冊）は全文テキストがなく、同じ版木の本なので、テキストのある 2559255 を使った。
- 構成：序・目録上・第一〜第二十四（上巻）・目録下・第二十五〜第六十四（下巻）・跋・奥書二つ。全訳。
- 体裁：各段に「原文（訳者が句読点を補い、通行の字体に改めた漢文）」「現代語訳（です・ます調）」「補足」。割注は〔　〕、または（　）で示した。
- 図版：群書類従版本の上巻巻頭（images/jo.jpg、57コマ）と下巻巻頭（images/gekan.jpg、93コマ）。江戸時代の版本で保護期間満了。NDLの蔵書印（東京書籍館）が写っている。
- 付録：暦注のしくみ・引用書目・用語集・読むうえでの注意（draft/fu.md、`暦林問答集_付録.md`）。

## 読みに自信のないところ

- 第五「歳星観察三□」の一字。
- 第十八 六十四卦の割注（小畜「小陰」、大有「保義」、恒「暦作常」など）と、注を読みとれなかった卦（豫・姤・無妄・困・噬嗑）。
- 第二十四「其星躔殊建、謂之乎」。
- 第五十七・第五十八の割注の切れ目と順序（とくに己の日の注、巳・午・未の日の注）。機械の文字起こしと版面を照らし合わせて、筋の通る並びをとった。
- 第六十 歳星の「作搪賊必敗」の「搪」。
- 第二十二「閉者名嘆星」の「嘆星」が何を指すか。
- 第一「鎮成」、第三・第四『定象紀』は人物・書名が確かめられなかった。
