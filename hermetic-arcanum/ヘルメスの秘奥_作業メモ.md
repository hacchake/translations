# ヘルメスの秘奥　作業メモ

ジャン・デスパニェ『ヘルメスの秘奥』（ウェストコット編『ヘルメス文書集成』第1巻、1893年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の WestcottWWCollectaneaHermeticaVolume01 の OCR テキスト（_djvu.txt、2026年11月4日取得）を `src/arcanum_ocr_raw.txt` に置き、柱とページ番号を除いて段落をつないだものを `src/arcanum_clean.txt` とした。
- 本文中の注の番号は（注n）として示し、巻末の注に対応させた。OCRで欠けた第131条の番号は補った。
- ウェルギリウス、アウグレルスなどのラテン語の詩句は、ウェストコット版に添えられた英訳（アシュモール以来のもの）から訳した。
- 日本語訳の有無：着手時の検索では見つからなかったが、2026年11月8日に、有田忠郎訳『自然哲学再興・ヘルメス哲学の秘法』（白水社「ヘルメス叢書」、1977年。ラテン語原典からの訳）に収められていることが判明した。ユーザーの判断で note の記事は公開のままとする。
- 下書き `draft/m1.md`〜`m5.md` と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿1本を生成した。

## 訳の方針

- 条文は「一、」「二、」の番号付きの段落とした。
- 「Sol」「Luna」は錬金術の用語としてソル、ルナとカナ書きにした（金・銀を指す）。
- Inceration は「インケラート〔蝋状に練る〕」とした（注55の定義による）。
- 注十五は電子テキストで途中が欠けているので、そう断った。
