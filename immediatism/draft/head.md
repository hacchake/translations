# 【全訳】ハキム・ベイ『イミディアティズム』（1994年）

ハキム・ベイ著／全訳

- 原題：Immediatism（エディンバラ／サンフランシスコ、AK Press、1994年）。はじめ Radio Sermonettes（ラジオ小説教）の題で、1992年にニューヨークの Libertarian Book Club から出た。1994年版で序文「存在論的アナーキー早わかり」が加わった
- 著者：ハキム・ベイ（1945–2022）。本名ピーター・ランボーン・ウィルソン。アメリカの著述家、詩人。『T.A.Z. 一時的自律ゾーン』（1991年）で知られる
- 内容：
  - ニューヨークのFM局で読まれた短い「説教」をまとめた、十二編の随筆集である
  - テレビや商品としての芸術といった「媒介」を通さず、友人どうしが顔を合わせて遊び、つくり、贈りあうことを「イミディアティズム（無媒介主義）」と名づけ、その規則と危険を論じる
  - 中国の秘密結社（トン）を手本にした集まり方、想像力から見たメディアの序列、ラスコーの洞窟と旧石器時代の回帰、手づくりの贈り物を持ちよる「ポトラッチ」の遊び方などを扱う
- 作業の基にした本文：Internet Archive にある1994年版のスキャンと、The Anarchist Library 所収のテキスト。後者には欠落があるので、前者で補った
- 著作権：著者は2022年に死去しており、保護期間は満了していない。原書の奥付に「アンチコピーライト、1994年。自由に海賊版をつくり、引用してよい。ただし著者と出版社は知らせてもらえるとありがたい」という表示があり、この翻訳はその表示にもとづく。原書のフレディ・ベアによる図版は収めていない
- 訳者：人工知能（Claude Fable 5.2）
- 訳の性格：全訳である。訳者の調べたかぎりでは、単行本の日本語訳は出ていない。表題作「イミディアティズム」には、雑誌『InterCommunication』25号（NTT出版）に載った篠儀直子訳がある

## この本について

　『T.A.Z.』でハキム・ベイは、権力の目の届かないところにつかのま現れては消える自由の場、「一時的自律ゾーン」を語った。その翌年から書かれた本書では、話が「消えること」から「ふたたび現れること」へ、つまり人がどう集まるかへ移る。

　出発点は単純である。あらゆる経験は何かに媒介されているが、媒介には程度がある。友人と家でやる音楽は、テレビで流れる音楽ほど遠くない。資本が入りこむたびに、つくる者と受けとる者のあいだは開いていく。それなら、媒介をできるかぎり抜いた遊びをひそかにやろう。観客は全員が演じる者でもあり、できたものは売らずに分けあう。いっしょに料理をして食べる会も、集まってキルトを縫う会も、その「芸術」になりうる。ベイはこれを運動ではなくゲームと呼ぶ。

　読んでいて目につくのは、「忙しくて集まれない」ことを資本主義のいちばん手ごわい働きと見るくだりである。毎週月曜に友人と顔を合わせることに成功すれば、それがもう革命だ、と著者は本気で言う。そして、うまくいけば今度は「これは売れる」という誘惑が来る、とも言う。三十年以上前の文章だが、テレビを別の画面に置きかえれば、いまもそのまま読める。

　書かれたのは1990年代のはじめで、湾岸戦争、当時のアメリカのテレビ番組や政治家、ポストモダニズムの流行への当てこすりが多い。口の悪さも原文のままである。本や放送そのものを疑いながら本と放送で語るという矛盾は著者も承知していて、最後の二編「沈黙」と「聴き手の批判」はその矛盾を扱っている。
