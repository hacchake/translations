## 各フォルダの構成（原則）

- 本体：訳文（節ごとに訳注）
- 用語集：主な用語・人名と訳語
- 作業メモ：原本との照合結果、判断が必要だった箇所（note本文には含めない）
- note用原稿：noteに投稿するための原稿
