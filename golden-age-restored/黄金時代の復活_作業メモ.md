# 黄金時代の復活　作業メモ

ヘンリクス・マダタヌス『The Golden Age Restored』（『ヘルメス博物館』英訳第一巻所収）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の `b24927363_0001`（The Hermetic Museum, vol. 1, 1893）の djvu.txt から、本篇（51〜67ページ）を `src/gar.txt` に切り出した。全体のテキストは `golden-tract/src/` で取得したもの（リポジトリには入れていない）。
- 扉（n66）を `images/title-1893.jpg` として切り出した。OCR で「DIRUSSDUASCU」となっていた語は、画像で見ると「PREFACE」だった。
- 下書き `draft/n1.md` と解説 `draft/head.md` から、`_build.py` で全訳と note 用原稿1本を生成した。
- 『雅歌』などの聖書の引用は英訳の語句に従って自分で訳した（既存の日本語訳聖書の本文は使っていない）。英訳が聖書と違う語（roses など）は〔原文 X〕と注した。
- 序の名前の数の謎は英訳のまま訳し、OCR の崩れもありうる旨を注記した。
- 日本語訳の有無：2026年11月8日に extended 検索と国立国会図書館サーチ（「マダタヌス」「ミンジヒト」「薔薇十字 秘密 象徴」など）で調べた範囲では見つからなかった。
- 著作権：原典は17世紀、ウェイトは1942年没。日本・英国・米国で保護期間満了。
