### 第55章　見かけの推論

**662**　判断は、われわれの通常の経験に現れるところでは、自明なものと、他の判断からの推論によってしか正当化されえないものとに分けることができる。したがってあるものは直接的な確実性をもつように見え、他のものは間接的な確実性しかもたないように見える。しかしすべての見かけの判断は実際には知覚であり、それらがもつどのような確実性も直接的である。しかし見かけの判断における一見したところの区別が単に誤っている――推論の現れの背後に何の実在もない――と想定することはほとんど不可能である。知覚の直接的な確実性を保ちながら、推論の現れについて合理的な説明を与えるような説明を見いだすことはできるであろうか。

　たしかにすべての知覚が、語のある意味で直接的な知覚であるわけではない。われわれは（第39章原書一二六ページ）、もし B が D についての C の知覚を直接に知覚するなら、彼は D を間接に知覚することを見た。D についての C の知覚についての情報を得ることにおいて、彼は D についての情報をも得ているからである。そしてもし彼が E についての D の知覚についての C の知覚を知覚するなら、彼は E を間接に知覚するであろう、以下同様である。

　しかしこれはここでわれわれの助けにはならない。いまわれわれが考察しているのは、あることを主張する判断が何か別のことを主張する判断に一見したところ依存していること――たとえばユークリッドのある命題が真であるというわれわれの判断が、とりわけ公理の一つが真であるというわれわれの判断に依存している場合や、すべての鉛は水に沈むというわれわれの判断が、とりわけある特定の鉛片が水に沈んだというわれわれの判断に依存している場合――だからである。そしてここでの間接性は、B が D についての C の知覚のうちに映された D を知覚するときにわれわれが得る間接性とは明らかにまったく異なる。

**663**　またさらに、B が C を鳥として知覚するとき、C が鳥であるという情報とその特性によって何が意味されているかという情報とは、鳥であるという特性のフェニックスであるという特性への関係についての情報――その知覚はそれも与えうる――よりも直接的に与えられる、と言われるかもしれない。そしてフェニックスであるという特性とヒッポグリフであるという特性との両立不可能性についてのさらなる情報――その知覚はそれも与えうる――は、なおいっそう間接的であると言われるかもしれない。

　しかしここでもまた、この種の間接性はここで必要とされるものではない。B が鳥であるという情報、「鳥」という特性の本性についての情報、その「フェニックス」という特性への関係についての情報、そして後者と「ヒッポグリフ」という特性との両立不可能性についての情報は、すべて同じ知覚において与えられる。これは、少なくとも一見したところ、一つの認識が一つあるいはそれ以上の他の認識に依存する場合である、われわれが考察している場合に関しては助けにならないであろう。

**664**　私には、求められる説明は難なく見いだされうるように思われる。まず、判断の内容――主張される事実――は、その判断が自明であるか推論されたものであるか、またもし推論されたものであるならア・プリオリに推論されたものか経験的に推論されたものか、という問いからまったく独立である、ということに注意しよう。これらは、何の事実が知られているかではなく、事実がどのように知られているかの問いである。

　このことは、同じ事実が異なるしかたで知られうることを考察するとき明白になる。自明に知られているものは推論によっても、ア・プリオリにも経験的にも知られうる。こうしてバルバラ式の特定の三段論法の妥当性は自明な真理であり、他の何ものにも言及することなしにそのようなものとして知られうる。しかしバルバラ式のすべての三段論法の妥当性という一般原理もまた自明な真理であり、この特定の三段論法の妥当性はそれから推論されうる。またさらに、二本の直線は空間を囲みえないというユークリッドの公理は自明な真理である。しかしそれが自明であることを見て取らない人は、それを経験的に推論するかもしれない。もし彼が多くのものの対を取り、各対のなかの各々のものが直線と見分けのつかない輪郭をもち、そして各場合にこれらの輪郭に空間を囲ませようと努めて失敗するなら、彼は、帰納によって得られた結果として、二本の直線は空間を囲みえないと信じるよい根拠をもつであろう。そして彼は、その真理の自明性を見て取る人とまったく同じ事実を信じていることになるであろう。

　またさらに、自明であるとは見て取られないが、ア・プリオリに推論されうる命題――たとえば三角形の二辺はつねに第三辺より長い――を取ろう。ほぼ三角形であるさまざまな図形の辺を、他の点でできるかぎり図形の本性を変えながら測る人は、帰納的に、三角形の二辺はつねに第三辺より長いという結論に達するかもしれない。そして帰納の結果として彼が信じている事実は、幾何学の学生が自明な公理からのア・プリオリな推論として信じているものとまったく同じ事実であろう。

**665**　私は、自明であるものと推論されるものとの区別、あるいはア・プリオリに推論されるものとア・ポステリオリに推論されるものとの区別が、主張される事実の本性と何の関係ももたず、特定の思考者がその事実についての自分の判断にどのように到達したかという問いにすぎない、と示唆したいのではない。一見したところそう見えるように、見かけの判断において主張されるとき自明として現れうるのはある事実だけであり、他の事実は推論されたものとしてしか現れえない、ということがあるかもしれないからである。そしてまた、ア・プリオリに推論されたものとして現れうるのはある事実だけであり、他の事実はア・ポステリオリに推論されたものとしてしか現れえない、ということがあるかもしれない。そしてこうして、自明とア・プリオリとは、「自明として知られうる」と「ア・プリオリに知られうる」という意味で、それらが知られるしかたとは独立に、事実の特性でありうるかもしれない。しかしその場合それらは判断において主張される事実の特性ではあろうが、その判断においてそれについて主張されてはいないであろう。もし私が自明な真理として X が Y であることを知るなら、その認識において私が自明に知っているのは X が Y であることである。私がその命題を自明に知っているという事実と、それが自明に知られうるという事実とは、他の事実についての他の判断である。そしてこのことは、上で述べたように、別の人が帰納の結果として、自明に知られうる、そして私がそのしかたで知っているこの同じ事実を知りうる、という考察によって明らかにされる。

**666**　この結果を目下の問題に適用しよう。推論によって到達された判断において与えられるように見える情報は、すでに見たように、知覚において与えられうる。見かけの判断においては、情報は間接的に与えられるように見えるが、実際には知覚において直接的に与えられている。しかしこの違いは、いま見たように、与えられる情報に影響せず、そうして一方のしかたで与えられるように見える情報は実際には他方のしかたで与えられうる。残るのは、判断がそこから推論される他の判断へのその判断の依存の現れに、実在において何が対応するかを説明することである。

　判断 P が判断 Q と R から推論された、と主張するとき、われわれは何を意味しているか。われわれは、思考者による判断 Q と R の下すことが、彼を続いて判断 P を下すよう決定した事実の群の一部であった、ということを意味している。それらが P の必要な先行条件であると言ってはならない。同じ結論が他のしかたで（たとえば他の前提から推論されることによって）到達されうるからである。またそれらがそれだけで判断 P を下すことを必然化する先行条件であると言ってもならない。結論を引き出すことなしに前提をいだくことは可能だからである。しかし、Q と R の生起がその一部をなすような事情の群があり、それが P のその後の生起を必然的にする、と言うことはできる。（他の事情には、結論を引き出すのに十分な関心と洞察、結論を引き出すのに十分なほど長い思考者の存在の継続、その他同様の本性のものが含まれるであろう。）

　しかし第二に、これ以上のことが必要とされる。たとえ Q と R の生起がその一部をなすような事情の組が P のその後の生起を必然的にするとしても、もし思考者が Q と R の真理が P の真理を含意するという信念をいだいていることもまた真でないなら、これは Q と R からの P の推論を構成しないであろう。

　そうするとこれが、P が事実として Q と R から推論された、と言うときに意味されていることである。しかしさらにその推論が妥当である、と言うとき、われわれはさらに、Q と R の真理が実際に P の真理を含意する、ということを意味している。

**667**　まずこれらの点の第三のものを考察しよう。Q と R の真理による P の真理の含意が、P の内容も Q と R の内容も実際には知覚によってわれわれに知られているという事実と少しも両立しなくはないことは、まったく明らかである。もし私が P の内容を知覚によって知るなら、私はそれを P が Q と R によって含意されていることから独立に知り、P が Q と R によって含意されていることを知ることなしにそれを知るかもしれない。しかしこのことは P が Q と R によって含意されているという事実と両立しなくはないであろう。もし私がバルバラ式の特定の三段論法を観照するなら、私はその妥当性を直接に、そうしてバルバラ式のすべての三段論法の妥当性という一般原理によってそれが含意されていることから独立に認めるかもしれないが、このことはそれがその一般原理によって含意されているという事実とまったく両立するであろう。

**668**　次に第一の点に戻ろう。一見したところの立場は、判断 P が判断 Q と R から推論された、というものである。実際にはこれらの見かけの判断は知覚であり、その内容は直接に知られている。しかしこのことは、それらが実在において、一見したところもつ関係を互いにもつことを妨げないであろう。その関係とは、認識 P は、出来事のある群がC系列においてそれに対して、時間において認識 P に先立つように見えるように関係していなかったなら、それがある場所に生じなかったであろうこと、そしてもしそれらの群の一つがそのように生じたなら、認識 P はそれがある場所に生じなければならないこと、そしてこれらの群の一つにとって、認識 Q と R の生起はその本質的な部分であること、だからである。これが、認識 P、Q、R が実際にはそうでない「判断」に、実際にそれらにあてはまるより一般的な語「認識」を代え、見かけの時間的関係に、時間的として現れる実在的関係を代えたときに、その関係が判明するところのものである。

　さてこのすべてのうちには、P の内容が知覚され、したがって直接に知られているという事実と両立しないものはまったく何もない。直接的な認識は、他のどのものとも同じく、因果法則によって他のものと結びつけられ、そのためその生起がそれらの他のものの生起によって決定され、あるいは部分的に決定される、ということがありうるからである。そしてそうして直接的な認識 P は直接的な認識 Q と R によって決定されうる。

**669**　第二の条件が残る。われわれは、その信念 Q と R によって信念 P へと決定された思考者が、Q と R の真理が P の真理を含意することをも信じているのでないかぎり、P は Q と R から推論されたとは言われないであろう、ということを見た。しかしここでも何の難点もない。私が、バルバラ式の特定の三段論法の妥当性を直接に認め、またその妥当性が、私が同じく直接に認める一般原理の妥当性のうちに含意されていることを知る場合のように、ある事実を直接に知り、またそれが直接に知られている別の事実によって含意されていることを知ることは可能だからである。そしてそうして、認識 P、Q、R の内容は実際には直接に知られているにもかかわらず、われわれは認識 Q と R の真理が認識 P の真理を含意することを知りうる。（もちろんこの含意についてのわれわれの認識は、実際には信念ではなく知覚であろう。）

　こうして P、Q、R は、P が Q と R から推論された、しかも真に推論された、と言われたときに主張されたそれらの関係のすべてを、実際に互いにもちうる。そしてしたがって推論はわれわれの理論に何の難点も示さない。
