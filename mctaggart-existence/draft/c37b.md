　第二の条件は、その関係が、各決定項が一つより多くの被決定項を決定しうるようなものでなければならない、ということである。そしてわれわれはこれを満たしている。多くの異なる自己が同じ自己、あるいは自己の部分を知覚することは可能であり、その場合、知覚されるものはそれを知覚する自己のそれぞれのうちに部分を決定するであろうからである。

　第三の条件は、B!C がただ一つの決定項 C に対応し、他方 C は一次全体 A の多くの部分の決定項でありうるけれども、B のうちに入る A の部分のうちではただ一つの決定項であるような関係でなければならない、ということである。この条件は満たされている。われわれの仮説は、B が C について別々の知覚を、しかもただ一つのそのような知覚をもつ、というものだったからである。したがって B の C の知覚は C 以外の何ものの知覚でもありえず、B のうちに C の知覚が一つより多くあることはありえない。他方、A のうちには C の他の知覚がありうる。A の部分である C 自身のうちにそのような知覚がありうるし、一次全体が二つより多くの一次部分に分かれている場合には、A の他の一次部分のうちにもそのような知覚がありうるからである。

　第四の条件は、決定的対応が少なくともある場合には相互的でなければならない、ということである。そして明らかに、もし一つの自己がそもそも別の自己を知覚しうるなら、自己の群のそれぞれが他のすべてを知覚してはならない理由はない。

　第五の条件は、対応が、全体が部分の部分へと無限に分割され、それらの部分のすべての十分な記述が、決定的対応によって、全体の十分な記述のうちに含意されている、ということが可能であるようなものでなければならない、ということである。そしてわれわれは、B と C がこのしかたで分割されていることを見た。A もまたそうである。A を、そのそれぞれが自分自身と他方とそれらの部分とを知覚するような部分の組 B と C をもつ一次全体、と十分に記述できるであろうからである。そしてこれは、求められるしかたでの A の分割を含意するであろう。

　そうすると、もしわれわれが記述したような自己の相互的な知覚があるなら、それは決定的対応に必要として定められた五つの条件のすべてを満たすであろう。そのような自己の相互的な知覚は可能であろうか。これを考察するにあたって、四つの問いを論じなければならないであろう。最初の三つは、原書八九ページで暫定的になした三つの想定にかかわる。第一に、自己が別の自己や別の自己の部分を知覚することは可能であろうか。第二に、知覚は知覚する自己の部分であろうか。第三に、全体の部分の知覚はその全体の知覚の部分でありうるか。第四の問いは、その部分の部分が無限に至るまでまた知覚であるような知覚の存在に何らかの難点があるかどうか、である。

**411**　前章でわれわれは、「この気づきに気づいている人」が排他的記述であるかどうかを探究し、それは必ずしも排他的ではない、という結論に達した（第36章、原書六五〜六八ページ）。そしてわれわれをこの結論に導いた理由は、一つの自己が別の自己とその部分とを知覚することに何の不可能性もないであろう、という結論にも導くであろう。したがって第一の問いは決着したものと考えてよい。

**412**　次に第二の問い――知覚は知覚する自己の部分であろうか――に移る。自然な見解、すべての人とは言わないまでもたいていの人がはじめてこの問いを問われたときに採るであろう見解は、思うに、それらはその部分である、というものである。しかしこれは否定されてきた。知覚は――そして他のすべての気づきも――状態ではなく関係である、と言われてきた。そうすると与件についての私の知覚は私自身と与件とのあいだの関係であり、知覚の状態であるような私自身の何らかの部分の存在を含まないであろう。

　もちろん、どの理論の上でも、自己とその自己が知覚するどの対象とのあいだにも特別な関係があるであろう。自己 B が M を知覚するなら、その事実は、知覚者とその知覚対象とのあいだにしか成り立たないような本性の、B と M のあいだの関係を含む。しかし問題は、そのような関係のほかに、知覚する自己の部分であるような知覚の状態があるかどうか、である。

　私の内観を信頼できるかぎり、私には、知覚する自己のうちに知覚の状態があるように思われる。しかし他の人々が自分の経験を異なって解釈しているという事実を考えると、私はこれにあまり重きを置けない。しかし知覚は知覚者の状態であるという結論に導くように思われる理由がいくつかある。

　第一に、私の知覚が、同時的であれ急速に継起するものであれ数多いとき、私自身の状態は、知覚が少ないときのその状態と比べて、より満ちている、という比喩によって適切に表現されるように思われるしかたで異なる。さてもしこれが適切な比喩であるなら、それは知覚が自己の部分であるからでしかありえない。あるものが別のものより満ちているのは、それがより多くの内容を、すなわちより多くの実体をもつ場合だけだからである。もし自己の状態の唯一の違いが、それがある種類の関係をより多くもつということであったなら、それをより満ちていると語ることはわれわれにはけっして思いつかなかったであろう。

　同じ考察を別のしかたで述べれば、私には、われわれが自分の思考作用、意欲、情動を観照するとき、それらはあわせてある意味で自己を尽くしており、自己は完全にそれらのうちに含まれている、と感じるように思われる。さて自己は、たとえそのすべての関係を考慮に入れても、その関係のうちに尽くされているとか含まれているとかは言えないであろう。ましてやその思考作用、意欲、情動の対象への関係のうちに尽くされているとは言えないであろう。それらはそれが立つ唯一の関係ではないからである。こうして、もし思考作用、意欲、情動が関係にすぎないなら、それらが何らかのしかたで自己を尽くすという見解を退けなければならない――そしてそれを退けるのは非常に難しいように思われる。他方、もしそれらが自己の状態であり、したがって部分であるなら、それらが自己を尽くすことは容易にわかる。実体はその部分の組のうちに尽くされている、という非常に実在的な意味があるからである。

　またさらに、B の C についての知識は C に対してよりも B に対してより直接的な違いをもたらす――C を知っている B と、もし C を知らなかったとしたらの B とのあいだの直接の違いは、B によって知られている C と、もし B に知られていなかったとしたらの C とのあいだの直接の違いより大きい――ということはほとんど普遍的に認められている。この見解は、知識の真理が知られる対象との対応にあると考えない人々のある者によって退けられるかもしれない――もっともそのすべてによって退けられるわけではない。しかし思うに、真理はそのような対応にあると考える思想家たち――第2章でわれわれが受け入れる理由を見いだした見解――によってはつねに受け入れられている。

　私は上で直接の違いについて語った。間接の違いを含めるなら、事柄はまったく異なるかもしれない。探偵がある男が殺人を犯したことを知っているなら、その知識は探偵の将来よりも殺人者の将来により大きな効果をもつであろう。ある人が自分の皿の上のじゃがいもが腐っていることを知っているなら、これはその人の運命よりもじゃがいもの運命により大きく影響するであろう。しかし知識の対象へのそのような間接の違いは、その知識が知る主体のうちに決定する行為に依存する。知識という単純な事実によって各項――知る者と知られるもの――に引き起こされる直接の違いを取るなら、上で述べたように、これは知られるものに対してより知る者に対してのほうが大きいことは真である。

　これは他の知識についてと同じく知覚についてもあてはまる。たしかに、もしその存在が知覚されることに依存するような知覚対象があるなら、知覚は知覚者に対してよりもそれらに対してより大きな違いをもたらすであろうことは明白である。知覚者の存在はある特定の知覚対象を知覚することに依存しないからである。しかしわれわれは、知覚される唯一のものは自己と自己の部分であると考える理由を見いだすであろう。そしてそれらはその存在を知覚されることに依存しない。

　さてもし知識が自己とその対象とのあいだの関係にすぎないなら、なぜこのより大きな違いがあるべきなのかを理解するのは非常に難しいように思われる。この場合、知識が知る自己について含むすべては、それが知るという関係の項であろう、ということであり、他方対象は知られるという関係の項であろう。そして私の見るかぎり、これら二つの特性のうちには、その一方がそれをもつ項に他方より大きな違いをもたらすことを説明しうるものは何もない。

　しかしもし私の知識が私自身の部分であるなら、難点は取り除かれる。その場合、知識は知られる対象のうちには知る自己への関係以外の何も含まないが、知る自己のうちには、知られる対象への関係だけでなく、ある特性をもつ部分の現前をも含むからである。そして知識は知る者に対しては関係の違いだけでなく部分の違いももたらし、知られる対象に対しては関係の違いしかもたらさないのだから、一方の場合には他方の場合より大きな違いをもたらすのである。

　もう一つの考察を付け加えてよいであろう。知覚を含む認識は自己の状態であることを否定するであろう思想家の多くは、快と苦は自己の部分であることを認めるであろう。これは少なくとも、自己は部分（あるいは少なくとも同時的な部分）をもちえないという理由で知覚が自己の部分であるという見解を退けるようないかなる議論とも両立しない。しかしわれわれはさらに進むことができる。快と苦はしばしば認識と非常に密接に結びついている。さてもしこれらの認識が自己の部分ではなく他のものへのその関係であるなら、認識と結びついた快や苦は、自己がある認識の関係にあるときに自己のうちにかき立てられる状態である、というしかたでしかそれと結びつきえない。関係はこれより緊密ではありえない。ここまではこの結果しか得られない。しかし第41章で見るように、快と苦についてのそのような見解は維持できず、したがってそれを含意する認識の見解を退けるさらなる理由を得るであろう。

　これらすべての理由は、認識、そのなかでも知覚は、自己の部分であるという理論を確証する傾向がある。また私はこれに対する妥当な議論を何も見いださない。たしかに、すでに見たように、認識は認識者と認識されるものとのあいだの関係を含意する。しかしそこから認識と関係とが同一であることは帰結せず、われわれの見解は、すでに指摘したように、関係がそこにあることを認めている。

　私は、認識は関係にすぎないという見解が、部分的にはこの点についての混同から生じたと信じている。そしてそれは部分的には、部分をもつことと実在的な統一であることとのあいだの想定上の両立不可能性のために、自己が部分をもつことを認めたがらないことから生じたと信じている。しかしそのような両立不可能性はない。そして第3部の終わりで見たように、すべての実体は部分をもたねばならず、したがってもし自己がそもそも存在するなら、その認識がその部分であろうとなかろうと、それは何らかの種類の部分をもたねばならない。そして実際、すでに述べたように、快と苦は自己の部分であることは一般に認められるであろうし、自己は時間のうちに存在し、時間の次元において部分をもつこともまた一般に認められるであろう。

　したがって私には、われわれの知覚はわれわれ自身の状態、すなわち部分であると結論する資格がわれわれにはあるように思われる。もちろんこのことは、私が M を知覚するとき私が直接に知っているのは知覚だけであり、M についての私の知識は M についての私の知覚についての私の知覚によって媒介されている、ということを含意しない。これはまったく正しくないであろう。M についての私の知識は直接的であり、M についての私の知覚にある。
