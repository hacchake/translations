### 第1章　序論

**1**　この著作で私は、存在するすべてのものに属する特性について、言い換えれば存在全体に属する特性について、何が決定できるかを考察しようと思う。また、これらの一般的な特性から、われわれが経験的に知っている存在するもののさまざまな部分について、理論的あるいは実践的な関心を引くどのような帰結が引き出せるかも考察する。

〔原注〕この探究のうち前者は、本巻に収める第2部・第3部・第4部が扱う。後者は、のちに刊行する第5部・第6部・第7部で追究する。

　存在するものは、思うに、一見したところ実在するものの一種である。存在するものはすべて実在しなければならない、ということは誰もが認めている。他方で、存在しない実在がある、という立場も主張されてきた。そこで、われわれがまず考察すべき問いは、実在、すなわち有ということで何が意味されているのか、である。この二つの語は、ふつう用いられるかぎりでは同じ意味である。

**2**　実在は定義できない。「何であれあるものは実在する」という命題は、真ではあるが、実在を定義する助けにも、それを他のしかたで規定する助けにもならない。「何であれあるもの」の「ある」がすでに有を含んでおり、有とは実在と同じものだからである。しかしこの命題は、同語反復ではあっても、無用ではないと私は思う。それは実在の外延がいかに広いかを目の前に示してくれるからである。

　そうすると、実在とは定義できない特性であって、それについては、何であれあるものは実在する、と言うことができる。したがって実在はその外延において普遍的だと言えるが、だからといって、非実在を述語づけることがすべて矛盾しているわけではない。それどころか、非実在の述語づけはしばしば正しい。どんな三角形であれその第四の角も、一九一九年のロンドン公爵も、どちらも実在しない。

〔原注〕これに対しては、たとえば三角形の第四の角について何かを真に述語づけることができるなら、その角は実在しなければならない、と反論されてきた。そうだとすれば、非実在の述語づけはすべて自己矛盾をきたすことになろう。しかしこれは誤りだと私には思われる。何かについて何かを述語づけるためには、私はそのものの観念をもたねばならず、その観念――私の心のなかの心的な出来事――は実在しなければならない。しかしそのような角の観念が実在するからといって、その角が実在することにはならない。この問題は第6部で論じる。

**3**　実在は多義的な語だ、と主張されてきた。つまり、何かが実在すると言うことは、さらに何かを言い足さないかぎり、何ひとつはっきりしたことを言っていない、というのである。ギャンプ夫人が実在するかしないかを言えるようになる前に、その問いがどの世界について問われているのかを決めねばならない。彼女はわれわれの日常生活の世界では実在しないかもしれないが、ディケンズの小説の世界では実在するかもしれないし、ひょっとすると私の夢の世界でも実在するかもしれない、と。

　もちろん誰でも、そうしたければ、実在という語を、その意味では何かが目覚めた生活の世界では実在せず、虚構や夢の世界では実在する、というような意味で用いることができる。この語のそうした用法と私の採った用法とのあいだには、真偽の問題はなく、便利か不便かの問題があるだけである。しかし私には、私が実在と呼んだような性質が存在すること、そしてふつうその名が当てられているのはまさにこの性質であることは明らかだと思われる。だからこの用法のほうが便利なのである。そしてこの意味では、ものは、但し書きとは無関係に、実在するか実在しないかのどちらかである。ギャンプ夫人についての私の夢は、もちろん実在する。特定の「世界」においてだけでなく、絶対的に実在する。しかしギャンプ夫人自身は夢のなかで実在するのではない。一人の人間が別の人間の夢の一部になることはできないからである。また、夢を見ているあいだ私が想定していたように、夢でない世界において彼女が実在するのでもない。夢を見ているあいだの私の想定は誤っていたからである。（もちろん、いま私が目覚めた生活だと思っているもののほうが夢であり、夢だと思われたものが目覚めた生活であったということが判明するかもしれない。その場合には、ギャンプ夫人が実在し、五分前に私が見たと思った男は実在しないことになろう。）

**4**　われわれの解する意味での実在は、程度を許す性質ではない。あるものが、同じく実在する別のものよりも、より多く実在したりより少なく実在したりすることはありえない。実在には程度がある、と言われてきた。しかしこれは、思うに、二つの混同のどちらかに由来するのであり、それを取り除けば、実在に程度がないことは明らかになると思われる。

　ときに実在は力と混同され、あるものは他のものにより多くの力を及ぼすのに比例してより実在的だ、と言われてきた。しかし力と実在とはまったく異なるものであり、より多くの力を及ぼすものが、より少ない力しか及ぼさないものよりも実在的であるわけではない。

　またときには、実在に程度がありうるという考えは、真理に程度がありうるということに基づいていたように思われる。A が X でないとしても、それを Y と呼ぶよりも X と呼ぶほうが、その実在の本性を偽り伝える度合いは少ないかもしれない。そしてその場合には、どちらも完全に真ではないにせよ、「A は X である」は「A は Y である」よりも真である、と言うのがふつうであり、またそう言うのは不適切でもないと思う。そうすると、「A は X である」が「A は Y である」よりも真であると言えるのだから、AX は AY よりも実在的だと言える、と考えられるのである。たとえば、宇宙は集積であると言うよりも有機体であると言うほうが真であるとすれば、有機的な宇宙は集積としての宇宙よりも実在的だと言える、と考えられる。しかしこれは誤りである。「A は X である」は「A は Y である」ほどには A の本性を偽り伝えないかもしれない。しかし A が X であることがまったく真であるのでないかぎり、A は X ではなく、AX はまったく実在しない。宇宙が有機体であることがまったく真であるのでないかぎり、いかなる実在性をもつ有機的な宇宙もないのである。

**5**　これで、実在という定義できない概念を同定することには成功したと思う。では存在についてはどうか。存在を実在によって定義できるのか、それとも存在もまた、実在と同じく定義できないのか。私は、それも定義できないと言わねばならないと思う。たしかにわれわれは、どのような場合に実在が存在を含むのかを言うことはできる。実体や出来事が実在するなら、それは存在する。人間も、机も、戦いも、くしゃみも、存在することによってしか実在しえない。さらに、存在する実体や出来事の性質や関係もまた存在する、そしてそれら存在する性質や関係の性質や関係もまた存在する、以下同様である、とも言うべきだと私には思われる。ソクラテスが実在するなら、ソクラテスが存在するだけでなく、その知恵という性質も存在し、ネロに対する道徳的優越という関係も存在し、さらにまた、彼の知恵がアリストテレスの知恵に対して立つ量的な関係も存在する。しかし他方で、知恵という性質や優越という関係は、それ自体として取られ、特定の存在するものに属したりそれらを結びつけたりするものとして取られないかぎり、たとえ実在するとしても、存在しない。また「ソクラテスは賢い」という命題も（一方では賢い人間ソクラテスから、他方ではソクラテスが賢いという私の知識という心的な出来事から区別されたものとしては）、たとえ実在するとしても、存在しない。

　存在するものの特性そのものを存在するものに分類すべきかどうかは、疑わしいと思われるかもしれない。しかしソクラテスが存在し、賢いのであれば、彼の知恵が存在することを否定するのは確かに理不尽であろう。そして彼の知恵とは、賢くあるという彼の性質にほかならない。同じように、ソクラテスのネロに対する道徳的優越も存在するのではないか。そしてこれは、ソクラテスがネロに対して立つ一つの関係にほかならない。

　これに対しては、そうだとすると実在する知恵は存在すると同時に存在しないことになる、と反論されるかもしれない。ソクラテスの性質としては存在するが、一般的な性質としては存在しない、と。しかし次章で見るように、いかなる性質や関係もその存在から離れて実在するかどうかは確かではない。また、たとえ性質や関係が、存在するものの性質や関係としては存在し、その一般的な面においては存在しない、ということが事実であるとしても、それがわれわれの見解への反論になるとは思わない。性質や関係は実体とは大いに異なるものであり、実体が存在すると同時に存在しないことはありえないという事実は、性質や関係――これらは実体のように個別的ではなく、普遍的である――がある面では存在し、別の面では存在しない、ということがありえないことを証明しはしない。

　このように、われわれはどのような場合に実在が存在を含むのかを知っているが、そのことは存在の定義を与えはしない。というのも、実体を定義する段になると、その定義の一部として存在の概念を持ち込む必要があることがわかるであろうからである。そして出来事は実体の一種であることがわかるであろうから、出来事の概念もまた、その定義の一部として存在の概念を必要とすることになる。さらに、存在するものの性質や関係の概念、またそれらの性質や関係の概念は、明らかに実体の概念を持ち込まずには定義できない。したがって、実体や出来事、およびそれらの性質や関係によって存在を定義しようとする試みは、悪循環に陥るであろう。

　しかし、実在が存在を含む場合を述べることは、定義としては悪循環であっても、説明としては価値がある。実体、出来事、特性、命題といった概念は、例を挙げるのがたやすく、存在というより抽象的な概念よりもわれわれにずっとなじみのある概念である。だから、存在は実在する実体と実在する出来事とその特性とに属するのであって、一般的な特性や命題には――一般的な特性や命題が実在するとしても――属さない、ということがわかれば、存在の本性はわれわれにとってより明らかになるのである。

〔原注〕私は「特性」という語を、性質と関係とに共通の名として用いる。両者に共通の名があると便利であり、ほかに使えそうな語は見当たらない。たしかに関係は、性質がそう呼ばれうるようには、何かの特性と正しく呼ぶことはできない。しかしのちに見るように、あらゆる関係は、その項のそれぞれについて、その項の特性である関係的性質を生み出す。したがって関係は、そのどちらの項の特性でもないにせよ、その項のそれぞれを特徴づけると言えるのであり、このことが関係を特性と呼ぶことを正当化するであろう。

**6**　しかし、存在しない実在するものはあるのだろうか。それとも、実在するものはすべて、その実在がその存在を含意するような種類のものだけなのだろうか。もし後者だとすれば、実在の領域と存在の領域とは一致することになろう。この点は次章で論じる。そこで私は、存在しない実在するものがあると考える理由はないこと、そして、たとえそのような存在しない実在があるとしても、それと存在との関係は、存在を研究することによって実在の全体を研究することになるようなものであることを主張しようと努めるであろう。

　しかし、たとえそうでないとしても――存在しない実在があり、しかもそれが、存在を研究しても実在のすべてを研究することにはならないような種類のものであるとしても――存在の本性はわれわれにとって特別な関心の対象であろう。というのも、われわれの実践的な関心の観点からすれば、存在するもの以外には何ひとつわれわれにとって重要ではないからである。存在するものには、われわれは皆なんらかの種類の実践的な関心をもっている。しかし、存在しない実在に対して、それ自体のために、それが存在するものに及ぼすかもしれない影響とは独立に、何らかの実践的な関心を感じうる人がいるとは、とても考えにくいように思われる。

〔原注〕われわれは存在するものだけでなく、存在の可能性にも実践的な関心をもっている、と言われるかもしれない。たしかに私は明日雨が降るかもしれないという可能性に実践的な関心をもっている。しかしそれは、私が明日の天気に関心をもっており、まだその特性のすべてを知らない、ということを意味するにすぎない。ところで明日の天気は存在する。存在は現在についてと同じく、未来や過去についても述語となるからである。他方、実際にはいま雨は降っていないのに、いま雨が降っていたかもしれないという可能性は、私にとって何の実践的な関心もない。この二種類の可能性の違いは次章（第35節）で論じる。

　純粋に理論的な関心については事情が異なる。多くの人は真理をそれとして知ることに強い関心をもっており、この理論的な関心は、存在する実在についてと同じく、存在しない実在についてもかき立てられうる。そしてこのことが、そのような実在があるとすれば、彼らに存在しない実在への関心を与える。ただしそれは、存在するものに向けられる関心とは種類の異なる関心である。存在しないものについては、われわれが望むことは、実在するものの本性が何であるかを知ることだけであろう。それが存在するものに影響を及ぼしうるかぎりを除けば、それがある本性をもつよりも別の本性をもつことを望むことはないであろう。もちろん、それが存在するものに影響を及ぼすかぎりでは、それがある本性をもつよりも別の本性をもつことを望むかもしれない。たとえば、その本性が、それについてのわれわれの知識を限られたもの、あるいは信頼できないものにするような本性でなければよい、という望みはどれもこの項目に入るであろう。知識は、実在するなら、存在するものだからである。

　そうすると、われわれは実在するものに、たとえそれが存在しないとしても、関心をもちうる。しかしそれは、知識をそれ自体のために求めるときにもつ関心だけである。それ以外のわれわれの関心――たとえば幸福への、徳への、あるいは愛への関心――はすべて、もっぱら存在するものにかかわる。だから存在するものの研究は、いずれにせよわれわれにとって特別な重要性をもつであろう。
