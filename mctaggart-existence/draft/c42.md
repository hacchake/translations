### 第42章　自己の非類似性

**482**　決定的対応が無限に至る部分の中の部分の系列を生み出しうるためには、もちろん、非類似的な一次部分から出発することが必要である。そしてわれわれはこれまで、宇宙の一次部分であると信じる理由を見いだした自己が、互いに非類似的であると想定してきた。しかしいまや、それらがどのようなしかたで非類似的でありうるかを探究すべき時である。

　三つのしかたが可能なものとして現れる。それらは本源的性質において、あるいは本源的性質の量において、あるいは関係において異なるかもしれない。これら三つすべて、あるいはそのどれか二つが結びついているかもしれない。

〔原注〕同じ本源的性質の異なる量は、それ自身異なる本源的性質であるが、それらを別に扱うほうが便利であろう。関係の違いは、もちろん、派生的性質の違いを含意する。

**483**　関係から始めるのが便利であろう。自己が互いに、決定的対応によって要求される関係に立つことをわれわれは知っている。各自己は二つ以上の自己をその決定する群としてもつ。そしてもし宇宙のうちに二つより多くの自己があるなら――これは経験的な根拠からありそうに思われる――、自己の数がいかに大きく、分化群がいかに小さくても、どの二つの自己も同じ分化群をもたない、ということは可能であろう。そしてその場合、どの自己についても、それはしかじかの自己をその分化群としてもつ自己である、ということがその排他的記述であろう。

　しかしもしこれを自己が非類似的であるべき唯一のしかたとして採ろうと努めるなら、その試みが悪しき無限を含むことを見いだすであろう。たとえば B と C との非類似性を、B の分化群が EF であり、C の分化群が FG であるという事実のうちに見いだすとしよう。しかしこれは、E、F、G の非類似性がすでに確立されているのでないかぎり、B と C を非類似的にしない。もしこれを、それらの分化群がそれぞれ HJ、KL、MN であることに頼ってなそうと試みるなら、これはこれら六つの自己の非類似性をあらかじめ確立していることを要求する。こうしてわれわれは悪しき無限系列のなかを進むことになろう。B と C との非類似性は、最終成員をもたない系列の最終成員の非類似性を確立することによってしか確立されえないからである。

　また関係する項が閉じた円環を形づくり、そのため――単純な例を取れば――B、C、D の分化群がそれぞれ CD、DB、BC であるとしても、われわれの立場がよりよくなるわけではないであろう。もし系列がそれ自身に戻り、そのため B が自分自身の分化群の成員の分化群の成員であるなら、B の非類似性を確立するには B の非類似性をあらかじめ確立することが必要となり、悪しき無限系列の代わりに悪循環があることになろう。

　この結果は第105節で到達した結論から帰結する。そこでわれわれは、すべての実体は十分な記述であるような排他的記述を少なくとも一つもたなければならず、十分な記述でない排他的記述によって実体を分化させようとする試みは悪しき無限に導くであろう、ということを見た。そしてもしわれわれが、実体がある関係に立つ相手の項の違いによって実体を分化させようとするなら、われわれは十分な記述でない排他的記述によってそれらを分化させようとしているのである。

**484**　しかし第104節でわれわれは、一つあるいはそれ以上の他の実体へのその関係による実体の記述が、ある事情のもとでは十分な記述でありうることを見た。第一に、もし B が C に対して関係 M をもつものとして排他的に記述され、C が本源的性質 XYZ をもつものとして十分に記述されうるなら、われわれは B の十分な記述を、性質 XYZ をもつ唯一の実体に対して関係 M をもつ唯一の実体として得る。しかしこれは、いま見たように、C が B とは異なり、それが関係する項の違いによって以外のしかたで識別されうることを要求する。したがってこれは、すべての自己をもっぱらその関係によって分化させることを可能にはしないであろう。しかし第二の選択肢が残る。関係の結合によって、きわめてまれであるため、ただ一つの実体だけが何らかの実体に対してその関係に立つような複合関係が形づくられうる。その場合、B は何らかの実体に対して関係 PQR に立つ唯一の実体である、と言うことが B の排他的記述であろう。そしてこの排他的記述は十分な記述であろう。それはまったく一般的特性から成るからである。

　さて、自己のその分化群への関係における、まったく一般的特性で表現しうるこれらの可能な変異は、任意の数の自己のための非類似的な記述を形づくるのに十分であろう。たとえば自己 B が、七つの成員の分化群をもつという事実によって他の多くの自己から識別されることは可能である。同じく七つの成員の分化群をもつ他の自己からは、彼の群が、それ自身六つの成員の分化群をもつ成員を一つ、それ自身十の成員の分化群をもつ成員を一つ含む、などという事実によって区別されるかもしれない。もしこれでもなお B を他のすべての自己から区別するのに不十分であるなら、彼は次の階の分化群における同様の変異によって区別されるかもしれず、以下、B にだけあてはまる記述に到達するまで続く。

　分化群の成員の数がこのしかたで変化することは不可能ではなく、したがって自己の非類似性がもっぱらこのしかたで生じることも不可能ではない。しかし不可能ではないにしても、それはきわめてありそうにないように思われる。もしそれが事実であるなら、他のすべての実体の分化がそれに依存するような自己のすべての分化は、それ自身、自己のうちのいかなる内的違いにも、彼が関係する他の自己のうちのいかなる内的違いにも、彼がそれらに対して立つ関係の種類にも依存しないことになろう。それはまったく、彼が直接にか間接にか結びついている群のなかの自己の数のような外在的特性に依存することになろう。

**485**　われわれの現在の経験における世界の現れは、究極的な分化は関係だけに依存するのではなく、少なくともある程度は本源的性質に依存することを、きわめて強く示唆している。絶対的実在は、われわれの現在の経験においてそう見えるものとは非常に異なることをわれわれはすでに見たのであり、これもまた違いの一点であるかもしれない、と言われるかもしれない。しかしそれなら、絶対的実在についてわれわれが見てきたことはすべて、自己の重要性を強調する傾向をもっていた。一次部分であるのは自己であり、そして第256節でわれわれは、一次部分は一次全体や宇宙よりも根本的に重要であるとみなされなければならないことを見たからである。したがって、一次部分のそれぞれが、それが関係する群の特性からその個体性を得ることは、きわめてありそうにないように思われる。

　またそれがそうする必要もない。自己の必要な分化は他のしかたで生じうるからである。それはその本源的性質に関して生じうる。各自己が、他のいかなる自己ももたない何らかの性質――単純であれ、複合であれ、複雑であれ――をもてば十分であろう。

　しかし、われわれは、異なる自己は質的にきわめてよく似ているという結論に達したことを思い起こさなければならない。そのそれぞれは自己と自己の部分とを知覚し、そのような知覚以外の内容をもたない。これらの知覚はすべてまた、知覚されるものへの同意の意欲である。そしてそのような知覚はすべて、愛、自己畏敬、情愛、満悦のどれかの状態である。

　さてこの一様性は、他の性質における多くの変異の可能性をほとんど残さないように思われる。たしかに前章でわれわれは、自己がもつかもしれないしもたないかもしれない他の情動があることは少なくとも可能であることを見た。しかしそれらの数は――少なくともいまわれわれに知られているものの数は――きわめて少ないので、それらの組み合わせは、われわれが存在すると信じる経験的根拠をもつ自己の数にとってさえ十分な分化を与えないであろう――そして自己の総数ははるかに大きいかもしれない。

　しかし非類似性は量的であるかもしれない。それは、すべての自己が共通にもつ性質の強さの変異にあるかもしれない。知覚は強さにおいて変化することが観察されうる。そして同意も、われわれが語ってきたすべての情動もそうである。そうするとここに非類似性のもう一つの源泉がある。たとえば、他のすべての自己によって知覚される唯一の自己として十分に記述されうる一つの自己があり、他のすべての自己は、彼らが彼に対して感じる愛の強さの変化によって十分に記述されうる、ということがあるかもしれない。これがそうであることを示唆するものは何もないが、それを特にありそうにないものにするものも私には何も見えない。そしてもちろん、自己が量的に分化されうる他のしかたは多くある。

　量的系列は、必要とされうるだけ多くの分化を与えることができるであろう。強さの度合いの系列は稠密であり、そのため無限個の度合いが見いだされうるかもしれないからである。そしてたとえそうでないとしても、度合いの数は自己の数に等しいほど大きいかもしれない。自己の数は無限であるかもしれないが、無限でないことも可能だからである。

**486**　もう一つの可能性もある。異なる自己が同じ知覚対象を知覚するしかたに、質的な違いがありうるであろうか。同じ言葉が異なる調子で発音されうる。同じ図案が異なる色で描かれうる。B が C と、調子や色に類比的な何らかの性質において異なることは可能ではないであろうか。そうすればわれわれはこれらの違いによって必要な分化を得るかもしれない。B と C が同じ分化群をもち、その群の成員あるいはそれらの成員の部分をもつものとして知覚する性質において異ならない、と想定しよう。そうすると B と C は、同じものを知覚し、それらを同じ性質をもつものとして知覚する以外の本性をもたないであろう。彼らは知覚するすべてのものに同意するであろう。そして彼らはそれらを同じ情動をもって見るかもしれない。しかし彼らの知覚は、同じ言葉の異なる調子での二度の繰り返しが異なりうるのと同じしかたで、質的に異なりうるであろう。そして知覚のこの質的な違いはその意欲的・情動的性質に影響するかもしれない。こうして B の D への愛と C の D への愛とのあいだに質的な違いがあるかもしれない。

　宇宙のうちにいかに多くの自己があろうとも、それらはすべてこのような手段によって互いに分化されうるであろう。そのような性質の変異が微細さにおいて何らかの限界をもつべき理由はなく、したがってその任意の数が異なる自己のうちに生じうるからである。そしてその性質は一種類より多くあるかもしれない。

　私はそのような調子の違いの存在の証明があると示唆しているのではない。何らかのしかたで各自己は残りのすべてから分化されなければならない。しかしこの章の前のほうで、それらは調子の違い以外の手段によって分化されうることを見たのであり、したがって調子の違いが存在しないことも可能である。

**487**　しかしそれらが存在することも可能である。そして可能性へのこの寄り道をもう少し先まで追うのもよいであろう。すでに見たように、すべての自己がすべての自己の分化群に含まれることは可能であるが、そうでなく、異なる自己が異なる分化群をもつことも可能である。たとえば D は B の分化群のうちにあり、C の分化群のうちにはないかもしれない。さて、もしそのような違いがあるなら、それはもちろん究極的であるかもしれない。何かが究極的でなければならず、これらの違いがそうであっても少しもおかしくない。しかし他方、それらが究極的である必要はない。そしてもしそのような調子の違いがあるなら、各自己の分化群は、その調子の性質が彼自身のそれに対してある関係にあるような他の自己から成る、ということがあるかもしれない。（これらの関係は、もちろん、特別な類似の関係である必要はない。それはたとえば相補的な違いの関係であるかもしれない。）

　もしそうであるなら、B が C を愛するとき、それは、C の調子の性質がある性質――それらを B の調子の性質に対してある関係に置く性質――をもつという事実によって引き起こされている。このうちには、愛に関してわれわれが到達した結論と両立しないものは何もない。前章で（原書一五一ページ）見たように、愛はけっして愛される者の性質に関してではないが、しばしば彼の性質のゆえにだからである。

　こうしてわれわれは、われわれの理論にとって本質的な自己の非類似性が、いくつかの異なるしかたで実現されうることを示した。したがって、そのような非類似性が必要であるという事実はわれわれの理論への反論ではない。しかしそれが実際にどの可能なしかたで実現されているかを決定する方法はないように思われる。
