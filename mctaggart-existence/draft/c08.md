### 第8章　関係

**78**　いまやわれわれは実体の多数性をもっている。したがって実体のあいだに関係があるであろうことは明白である。どのような関係があるであろうかは、本書の残りの多くの部分がささげられる問いであるが、何らかの関係があることは疑いを容れない。すべての実体は互いに類似しているであろう。どれも実体だからである。そしてすべての実体は互いに相異しているであろう。それらは別々の実体だからである。（相異ということで私は、ときに数的差異と呼ばれるものを意味しているのであって、非類似を意味しているのではない。非類似の相異に対する関係は第10章で考察する。）そして互いに類似していたり相異していたりする実体は、互いに類似と相異という関係に立つ。

　関係は、性質と同じく、定義できない。それで何を意味しているかは、例を挙げることによってしか示せない。A は B より大きい、B に等しい、B の父である、B の右にある、B を愛している、B を知らない、と言うとき、われわれは A が B に対して立つ関係を主張している。関係を、何かが何かに対して立つもの、あるいは何かと何かのあいだに成り立つもの、と定義することはできない。これらの言い回しに、関係について真となるような意味を与えるためには、それらを、ものが関係づけられているときに生じる種類の「立つこと」や「成り立つこと」として定義しなければならないであろうからである。そうすると関係の定義は循環的になるであろう。

**79**　関係は、A と B と C がすべて等しい場合のように、二つより多くの項をもつことができる。またさらに、少なくとも語の通常の意味では、関係がただ一つの項しかもたないこともありうる。主語はそれ自身に対して関係をもつことができるからである。すべての実体はそれ自身と同一性の関係をもつ。またある実体はそれ自身に等しく、それ自身を軽蔑し、自分自身の受託者や自分自身のいとこである。

　したがって、すべての関係は一つより多くの項をもつ、と言うことはできない。しかし関係に立つものは、たとえその関係がただ一つの項しかもたないとしても、ある種の多数性の側面をもつ。関係はつねに何かを何かと結びつけるからである。それが何かをそれ自身と結びつけるだけのときでさえ、そのようにそれ自身と結びつけられる項は――誤解を招かないと思う比喩を用いれば――関係の両端にあり、このことはある種の多数性の側面を含んでいる。もちろん実体の多数性ではないが。このことは、二つの項をもつか、一つの項を二度用いるかしなければ、いかなる関係も表現できないことに注意すれば、もっと明白になるかもしれない。A は自分自身以外の誰も愛さないということはありうるが、これは「A は A を愛する」か「A は自分自身を愛する」かと言って表現しなければならない。単に「A は愛する」と言っても表現できない。それは、誰をかを特定せずに、A が誰かを愛していることを意味するにすぎないからである。

　自己への関係を考察するにあたっては、項という語を別のしかたで用い、たとえば自己愛には、両方の項が同じ実体であるにもかかわらず二つの項がある、と言うようにすれば、簡単になる傾向があるかもしれない。しかし全体としては、一つのものをつねにただ一つの項と見なし、自己への関係をただ一つの項しかもたない関係として語るほうが便利であるように思われる。

**80**　関係と性質との違いは十分に明らかである。もっとも、どちらの語も定義できないのだから、両者の違いを定義することは不可能である。性質は何かの性質であるが、関係は何かの関係ではなく、何かと何かのあいだのものである、と言ってよいかもしれない。しかしこれは、違いを悟る助けにはなるかもしれないが、定義を与えはしないであろう。ここで用いられる「の」と「あいだ」は、性質と関係の概念の助けを借りなければ理解できないであろうからである。

　われわれの述べたことが正しいなら、関係は存在を記述するのに不可欠な概念であることになる。存在するものは関係をもち、関係の概念は定義できないのだから、それの同値物と見なしうるような他の概念でそれを置き換えることは不可能であろうからである。

　さまざまな哲学者が、存在についての理論において関係の概念なしで済ませようと懸命に努力してきた。そうした努力がとった最もふつうの形は、あらゆる場合に、関係の主張の代わりに性質の主張を置こうとする試みである。この目的のために提出された理論は、関係は存在について妥当ではあるが究極的ではなく、性質によって定義でき、したがって関係についての言明は性質についての言明に翻訳できる、と言うだけにとどまらなかった。それらは、関係の概念は積極的に妥当でない――どこにも正しくはあてはまらない概念である――と主張した。同時に、それらは、関係を主張する言明はすべて絶対的に、そして端的に偽である――たとえば、ロンドンはケンブリッジより大きいという言明は、ケンブリッジはロンドンより大きいという言明以上に真ではない――とまで言うことはしない。しかしそれらは、そのような言明は性質についての言明の混乱した不正確な形であり、性質についての真なる言明のそのような混乱した不正確な形は、性質についての偽なる言明の同様に混乱した不正確な形よりも真理に近い、と言う。性質についての言明は、ときには関係が主張された実体――この場合はケンブリッジとロンドン――のそれぞれのうちにある性質についてのものと見なされる。ときには両方の実体を含む何らかの全体の性質についてのものと見なされる。

　関係を退けるために挙げられてきた主な理由は、それがありうる場所がどこにもない、ということである。関係は、明らかに、一方の項のうちにあって他方のうちにないのではない。またそれは別々に取ったそれぞれの項のうちにあるのでもない。それは項のあいだにあるのであって、項のうちにあるのではない、と言われる。それならば、それがそのうちにありうるような何かがあるのか、と問われる。そしてこれに否定で答えると、関係は不可能だと結論されるのである。

〔原注〕これはロッツェの議論の筋であり、実質的にはライプニッツの議論の筋でもある。ブラッドリー氏の反論は異なっており、異なる結論に導く。彼はライプニッツやロッツェのように関係を性質に還元しようとはせず、性質と関係とを同様に退ける。（第88節参照。）

**81**　しかしこれは妥当ではない。それは、関係がそのうちにある、あるいは性質のようにそこに内属する何か一つのものが見いだされないかぎり、関係は不可能だ、と想定しているからである。それは関係の可能性の試金石として、関係が性質のふるまうのとまったく同じようにふるまえるかどうかという問いを取り、それができないことが認められると、関係は不可能であり、実在の真の見方においては関係の判断は性質の判断によって置き換えられるであろう、と結論するのである。

　しかし、関係が性質のように何かのうちに内属できないなら関係は不可能だ、という想定にはまったく正当な理由がない。「関係は何のうちにあるのか」という問いには、それは何のうちにもなく、二つ以上の項のあいだに、あるいはある項とそれ自身とのあいだにある、そして「あいだ」という概念は「うち」という概念と同じく究極的であり、妥当と見なされる資格を同じくらいもっている、と公正に答えることができる。どちらも究極的であり、どちらも矛盾を含まない。そして両方を用いることの正当化は、性質と関係との両方の実在を主張するか含意するかすることなしには、何ひとつ述べることが不可能だという事実にある。これが性質に関しても関係に関しても不可能であることは、すでに見た。われわれに直接かかわる場合、すなわち実体の実体に対する関係の場合で言えば、実体は存在するのだから、それはそれ自身と同一でなければならず、またすでに指摘したように、一つより多くの実体が存在するのだから、それらは互いに類似し、互いに相異していなければならない。

　そして、これらの関係を主張する命題は絶対的に真であろう、ということに注意しなければならない。それらを否定するよりも主張するほうが真理に近づく、というだけのことではない。いかなる実体も、それがそれ自身と同一であることが絶対的に真でないかぎりありえないし、一つより多くの実体は、それらが類似し相異していることが絶対的に真でないかぎりありえない。

**82**　そうすると、関係の概念は存在するものについて妥当なものとして受け入れなければならない。しかしそれが妥当であることは認めつつ、それが究極的で定義できないことは否定されるかもしれない。実体が関係のうちにあることは実際に真であるが、このしかたで表現される事実は、関係を持ち込まずに性質だけによって表現できる、と言われるかもしれない。しかしこれもまた偽である。実体のあいだの関係によって述べることのできるいかなる事実も、関係の概念を省いた言葉ではけっして述べることができない。（「実体のあいだの」という言い回しは、「ある実体とそれ自身とのあいだの」を含むものとして用いる。）

　この点についていくらか疑いを抱かせてきた事実が、思うに、三つある。第一に、関係はたしかにその項のそれぞれのうちにある性質に基づいていることがありうる。しかしこのことは、それがそれらの性質に還元できることを意味しない。A が B より大きいなら、この関係は、A が一平方マイルを覆い、B が一エーカーを覆うという事実に依存しているかもしれない。A が B をいらだたせるなら、この関係は A の政治的意見と B の感じやすさとに依存しているかもしれない。しかし A の大きさについての言明と B の大きさについての言明とは、A は B より大きいという言明と同値ではない。後者はそれらからの確かで直接の結論でありうるとしても。そして A の意見と B の感じやすさについての言明は、A は B をいらだたせるという言明と同値ではない。後者は人間性の法則によってそれらから帰結するかもしれないとしても。

　第二に、次章で見るように、二つの実体のあいだに何らかの関係が存在することは、それらの実体のそれぞれのうちに性質が存在することを含む、ということは真である。「A は B を賛嘆している」は A と B のあいだの関係の言明である。しかしその真理は、「A は B の賛嘆者である」と「B は A にとって賛嘆の対象である」という、A と B の性質を述べる言明の真理を含意する。しかしわれわれはこれらの性質を、関係の概念を省いた言葉で述べることはできない。前者は B を賛嘆する者であるという性質であり、後者は A によって賛嘆される者であるという性質であって、したがってそのどちらも、関係である賛嘆の概念を持ち込むことなしには述べられないからである。

　第三に、関係は、その関係のすべての項を含むどの全体についても、その性質を決定する。椅子 A と椅子 B を含み、そのうち A が B より大きい、ということは、この部屋の、あるいは宇宙の性質である、と言ってよいであろう。しかしその場合、この性質は「より大きい」という概念を用いなければ述べることができず、したがって関係を述べることなしには述べることができない。

**83**　そうすると、関係は性質によって置き換えることはできない。では性質は関係によって置き換えられるであろうか。私の知るかぎり、この見解が採られたことはない。もしそれが採られるとすれば、ラッセル氏が指摘しているように、「正確な類似」は、性質の共有に分析できない単純な関係であり、さまざまな種類の正確な類似がある、という見解を採る必要があるであろう。そうすれば、A と B がともに白さという性質をもつ、と言う代わりに、A と B は、ある特定の種類の正確な類似において互いに立つ項のうちの二つである、と言うことになろう。

〔原注〕『アリストテレス協会紀要』一九一一〜一二年、九ページ。

　しかし、性質があるという一見したところの見解から離れる理由はない。それを疑う理由はこれまで一つも挙げられたことがないからである。そして、正確な類似は単純な関係であって、いかなる性質の共有からも独立している、という見解は明らかに偽であるように思われる。したがってわれわれは、性質は関係によって置き換えられないという結論――すでに述べたように、これに異議が唱えられたことはないと思うが――にとどまらねばならない。

**84**　関係は、性質と同じく、単純か、複合的か、複雑かのどれかである。単純関係とは、分析ができず、したがって定義できないものである。複合関係とは、単純関係の集積に分析できるものである。複雑関係とは、他の関係の集積から成るのではないが、他の特性――性質であれ関係であれ両方であれ――によって分析され定義されうるものである。

　すべての関係はまた、性質のうちにそれに対応するものをもたない他の類にも分かれる。第一に、どの関係も、それに立つものがそれ自身に対してしかそれに立ちえないか、それ自身に対してはそれに立ちえないか、それ自身に対しても他のものに対してもそれに立ちうるか、のいずれかである。たとえば、実体はそれ自身としか同一でありえず、自分自身の父ではありえず、自分自身をも他のものをも賛嘆しうる。そうするとどの関係も、反射的か、非反射的か、あるいは単に反射的でないか、のいずれかである。

　第二に、どの関係も、A が B に対してそれに立つなら、B が A に対してそれに立たねばならないか、立ちえないか、立つかもしれないし立たないかもしれないか、のいずれかである。A が B に等しいなら、B は A に等しい。A が B の父なら、B は A の父ではありえない。A が B を愛しているなら、B は A を愛しているかもしれないし、いないかもしれない。こうしてわれわれは、対称的関係、非対称的関係、そして単に対称的でない関係の類をもつ。

　第三に、どの関係も、A が B に対してそれに立ち、B が C に対してそれに立つなら、A が C に対してそれに立たねばならないか、立ちえないか、立つかもしれないし立たないかもしれないか、のいずれかである。A が B の先祖であり、B が C の先祖なら、A は C の先祖である。しかし A が B の父であり、B が C の父なら、A は C の父ではありえない。そして A が B のいとこであり、B が C のいとこなら、A は C のいとこであるかもしれないし、ないかもしれない。こうしてわれわれは、推移的関係、非推移的関係、そして単に推移的でない関係の類をもつ。

　実体の関係のうちに、これらの類のそれぞれの例が生じることについて、いままでのところ何がわかっているであろうか。同一性、相異、類似の関係が実体について成り立つことはわかっている。そしてそれらに加えて、すべての実体は、それに内属する各性質に対して、またそれが項であるような各関係に対して関係をもつ。

　第一の群の三つの類がすべて例をもつことは明らかである。同一性は反射的であり、相異は非反射的であり、そして類似は、ものはそれ自身に類似していると言える、と考えるなら――私はそう考えねばならないと思うが――単に反射的でない。

　次の群では、相異も類似も対称的である。主語のその性質に対する関係は非対称的である。実体は性質に内属しえないからである。単に対称的でない関係が生じると考える理由はまだないが、のちに見るように、決定という関係は実際に生じ、この類に属する。

　第三の群では、類似は単に推移的でない。A が B に特性 X の点でのみ類似し、B が C に特性 Y の点で類似しているなら、A の B への類似と B の C への類似は、A の C への類似を含みもしないし排除もしないからである。しかし特定の点での類似は推移的である。A が X の点で B に類似し、B が X の点で C に類似しているなら、A は X の点で C に類似している。非推移的関係の事例にはまだ達していないが、次章で一つ生じるであろう。そこでは派生的特性の系列が得られ、そのなかで X は Y のすぐ上の項であり、Y は Z のすぐ上の項であるが、X はもちろん Z のすぐ上の項ではありえない。

〔原注〕実際には、A と C は、それが何であれ、類似しているであろう。どちらも実在し、存在し、実体であろうからである。しかしこのことは A の B への類似と B の C への類似からは帰結しない。
