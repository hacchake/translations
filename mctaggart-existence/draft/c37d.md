　そしてまた、二つの知覚対象は、異なる関係をもつものとして知覚されるなら、異なる性質をもつものとして知覚されているであろう、ということも思い起こさなければならない。その場合それらは異なる関係的性質をもつものとして知覚されているであろうからである。したがって、それらが互いに何らかの非反射的関係に立つものとして、あるいは第三のものに対して異なる関係に立つものとして知覚されれば十分であろう。

　これら二つの点に注意を払うなら、現在の経験のうちには、どの自己も、知覚対象を異なる性質をもつものとして知覚しないような二つの知覚を同時にもつことを示唆するものは何もないことは明らかである。

**416**　しかし、そのような別々の知覚があるという証拠はないけれども、そのようなものはありえないというわれわれの主張は誤謬だ、と反論されるかもしれない。知覚はその知覚対象の性質の知覚であるだけではないからである。実際、それは厳密にはまったく性質の知覚ではない。それは知覚対象――実体――の知覚である。C と D の知覚は、結局のところ C と D の知覚である、と言われるかもしれない。そして C と D は別々のものであるから、たとえ知覚がそれらを異なる性質をもつものとして知覚しなくても、このことはそれらの知覚を識別するのに十分であろう、と。

　しかしこれは誤りであろう。第95節で見たように、実体は、ヘーゲル的な意味での物自体、すなわちその性質から離れた個体性をもつものではないからである。それらは個体的であるが、その性質を通じて、その性質によってのみそうであり、したがってわれわれがそれらを知覚するとき、各実体の場合に異なる性質をもつものとしてそれらに気づいているかぎりにおいてのみ、それらに個体的に気づきうるのである。

**417**　しかしさらに、C と D のそれぞれを VW であるものとする B の知覚は、その知覚対象を異なる性質をもつものとして知覚することに依存しない知覚の性質によって分化されうるかもしれない、と反論されるかもしれない。たとえば C の知覚は D の知覚よりも強いかもしれない。これは、C と D の性質の何らかの違い――一方が X であり他方が Y であること――によって、それらが X や Y であるものとして知覚されていなくても、引き起こされるかもしれない。

　全体として私はこの反論が妥当だとは思わない。私には、知覚対象がそれをもつものとして知覚される性質のうちに違いがないことは、知覚の多数性がありえないことを積極的に含み、したがって強さの違いが起こる機会はない、と思われる。しかしこの問いはたしかに難しく、ひょっとするとその可能性は排除されるべきではないかもしれない。

**418**　しかし原書九八ページで述べたように、いままでのところわれわれは、知覚の一般的本性についてのみこの主題を論じてきたのであって、ここでわれわれが知覚の中の知覚の無限系列を扱っているというさらなる事実を考慮に入れてこなかった。そして、たとえある知覚が、その知覚対象を異なる性質をもつものとして知覚する以外のしかたで分化されうるとしても、決定的対応の無限系列のなかのすべての知覚にこれが起こることはありえないことは確かである。その理由は、第225節で見たように、もしどれかの実体が部分の部分へと無限に分割されているなら、それらの部分のどれもが決定的対応によって決定されたもの以外の性質をもつことは不可能である――もっとも任意の有限個の階の部分のすべてあるいはどれかがそのような他の性質をもつことは可能であるが――ということである。その有限個の最後の階 M より下のどの階の部分も、決定的対応によって決定されたもの以外の性質をもつことはできない。

　このことから、M より下の階のいかなる知覚も、原書一〇〇ページで示唆したしかたで、それ自身の強さや何か他の性質の違いによって互いに分化されえない、ということが帰結する。またそれらはC系列のなかの異なる点にあることによっても分化されえない。第51章原書二七五ページで見るように、決定的対応によって決定された知覚の体系全体はC系列のなかの同じ点にあるからである。そしてこれら二つの選択肢が排除されるのだから、結論は、それらはその知覚対象を異なる性質をもつものとして知覚することによってしか別々の知覚ではありえない、ということである。

　そうすると、そのような知覚の知覚対象はどのような性質をもつものとして知覚されなければならないか。これらの知覚対象はもちろんそれ自身知覚である。そして階 N、および階 M より低い他のすべての階のこれらの知覚は、決定的対応によって決定されたもの以外の性質をもちえない。どの知覚も、その知覚対象である別の知覚より一階低い。したがって、階 O およびそれより低いすべての階のすべての知覚は、その知覚対象を、その自己によって決定的対応の体系のうちで知覚される他のすべての知覚対象からそれらを分化させるような性質をもつものとして知覚しなければならない、ということが帰結する。こうしてもし C!D!E がそのような部分であるなら、それは B によって、性質 QR をもつ自己について性質 ST をもつ自己がもつ知覚について、性質 VW をもつ自己がもつ知覚として知覚されなければならない。ここで VW、ST、QR は、必ずしもそれぞれ C、D、E の十分な記述――すなわち、それらを他のすべての実体から区別する記述――ではないが、C、D、E を、B によって直接にか間接にか知覚される他のすべての実体から識別するのに十分な記述である。

　しかし C!D!E を特に知覚として知覚する必要があるのか、と問われるかもしれない。それは単に、性質 QR をもつ実体との決定的対応によって決定された、性質 ST をもつ実体の部分との決定的対応によって決定された、性質 VW をもつ実体の部分として知覚されるだけではいけないのか。これは、知覚が問題の決定的対応の特定の関係であるという事実を持ち込むことなしに、決定的対応によるその記述を与えるであろう。

　しかしこれは可能でないであろう。決定的対応はジョンソン氏が限定可能者と呼んだもの――それが生じるときはいつでも何らかの特定の形で生じなければならない類的特性――だからである。さて、ものがある限定可能者をもつと、それがその限定可能者のどの限定されたものをもつかを判断することなしに判断することは十分可能である。私は、初代ローマ司教の目が何らかの色をもっていたと、それがどの色であったかについて何の意見ももたずに判断できる。しかし知覚の場合は異なる。私は、ものを何らかの特定の色をもつものとして知覚することなしに、それを色をもつものとして知覚することはできない。そして同じように、もし私があるものを別のものとの決定的対応によって決定されたものとして知覚するなら、私はそれを、それが実際にもつその特定の種類の決定的対応をもつものとして知覚しなければならない。

〔原注〕私は知覚から知覚対象が色をもつことを知りながら、それが青か緑かを知ることができない、ということはありうる。しかしこれは、私がそれを色をもつものとして知覚しながら、何らかの特定の色をもつものとしては知覚しない、という意味ではないであろう。それは、私がそれがもつものとして実際に知覚した特定の色合いが、典型的な青の色合いと典型的な緑の色合いとの中間であった、という意味であろう。

**419**　そうすると、部分の無限系列のすべての成員を知覚することは、そのいくつか（そしてその無限に大多数）を、それらがそうであるもの、すなわち自己あるいは自己の部分についての自己による知覚として知覚するのでないかぎり不可能である。しかし上で述べたように、任意の有限個の階について、二次部分のすべてあるいはどれかが決定的対応によって決定されない性質をもつことは可能である。そしてこれらの性質によって、問題の二次部分が B に知られている他のすべてのものから識別されうる、ということも可能かもしれない。その場合、B は問題の部分をこれらの性質をもつものとして知覚し、他のいかなる性質をもつものとしても知覚せず、したがってそれをその知覚対象の知覚として知覚せず、さらにまったく知覚として知覚しない、ということはありえないのか、と問われるかもしれない。

　同じように、C は、自己であるという性質を含まない性質によって、B によって知覚される他のすべての自己から識別されうる、ということも可能ではないか。そしてその場合、B は C をまったく自己として知覚することなしに C を知覚しえないのか。

　自己を互いに識別し、しかも自己が自己として知覚されることなしにそれをもつものとして知覚されうるような性質を、自己がどのような性質としてもちうるかを考えるのは容易ではない。そして知覚を互いに識別し、しかも知覚が知覚として知覚されることなしにそれをもつものとして知覚されうるような性質を、知覚がどのような性質としてもちうるかを考えるのも同じく難しい。しかしこの仮説を退けるもっと積極的な理由がある。

　決定的対応によって決定されたもの以外の性質をもたない二次部分の階が、第一階より下のすべての階であると想定しよう。そうすると第二階の二次部分である C!D!E は、決定的対応によって決定されたもの以外の性質をもたないであろう。したがってそれは B によって、性質 QR をもつ自己について性質 ST をもつ自己がもつ知覚について、性質 VW をもつ自己がもつ知覚として知覚されなければならない。

〔原注〕もちろん、部分が決定的対応によって決定されたもの以外の性質をもたない最も早い階は、われわれの例のように二次部分の第二階ではなく、百万番目の階、あるいはその上に有限個の階をもつそれより低いどの階でもよい。しかし議論はその階が何であってもまったく同じであろうし、それを第二階として取るほうが単純に述べることができる。

　そうすると C!D!E は B に、とりわけ、その知覚者が性質 VW をもつ自己であるような知覚として知られている。もし B がこれを知っているなら、彼は性質 VW をもつ自己を知っており、それをこれらの性質をもつものとして知っている。（彼はそのような自己をただ一つしか知りえない。VW は、すでに見たように、C を B に知られている他のあらゆるものから識別する性質を含まねばならないからである。）しかし彼はこの自己を知覚によってでなければ知りえない。この章ののちに見るように、判断は部分の部分へと無限に分化されえないのだから、絶対的実在のうちには判断はありえないからである。したがって B は C を性質 VW をもつ自己として知覚しなければならない。

　こうして B!C は、性質 VW をもつ自己としての C についての B の知覚であろう。しかし B!C!D についてはどうか。これは、性質 ST をもつ自己について性質 VW をもつ自己がもつ知覚としての C!D についての B の知覚でなければならないか。これもまたそうでなければならない。原書九七ページで見たように、いずれにせよ B は C!D を C の部分として、また C!D!E がその部分であるような全体として知覚しなければならないからである。そして B は、いま見たように、C を自己として、C!D!E を知覚として知覚しなければならない。さて、何かを自己の部分として、また知覚をそれ自身の部分としてもつものとして知覚しながら、それをそれ自身知覚の本性をもつものとして知覚しないことは可能であろうか。

　私はこれは明らかに不可能であり、C!D は知覚の本性をもつものとして知覚されなければならないと思う。知覚の群や知覚の部分もまた知覚の本性をもつ。しかし C!D が、それがそうであるように、単一の知覚として知覚されることが必要であろう。何かをその知覚対象を知覚することなしに知覚として知覚することは可能でないからである。知覚であることはたしかに一つの性質である。しかしそれは関係的性質である――それは、第85節で述べたしかたで、その性質をもつものがその知覚対象に対して立つ関係性によって生み出される。そしてわれわれは、知覚の他方の項を知覚するのでないかぎり、それをこの関係に立つものとして知覚することはできない。したがってわれわれは、C!D がこの関係に立つ相手の D を知覚し、D は単一の対象であるから、C!D が単一の知覚であることを見るであろう。そしてこうしてわれわれは、決定的対応においては自己は自己として知覚されなければならず、知覚は知覚として知覚されなければならない、という原書九八ページでなされた言明を正当化した。

**420**　そうすると、知覚は決定的対応によって決定された部分の中の部分の無限系列を与えうる。一見したところ実際に生じる他の種類の精神的実在のどれかについてこれは可能であろうか。そしてまず、知覚以外の思考作用のどれかの形について可能であろうか。

　原書八七ページでそれらの形が何であるかを見た。第一は特性の気づきである。そのような気づきは求められる系列を与えることはできないであろう。部分の無限系列が悪しきものでないためには、そのような決定的対応におけるある決定項が、気づきを決定するだけでなく、気づきをその部分としてもつことが必要だからである。第201節で見たように、有効な無限系列が生じうるのはそのような相互的な決定によってだけである。さて、もし決定的対応が気づきであるなら、この要求は、それについての気づきがあるような対象が気づきをその部分としてもつ、という形をとる。したがってこれらの対象はすべて存在するものでなければならない。気づきは存在するものだからである。そしてしたがってそれらについての気づきは知覚であり、特性の気づきではないであろう。

　そしてまた、もし特性の気づきが無限に至る部分の中の部分の系列を生み出しうるなら、これは特性のそれぞれが無限に部分の中の部分をもつことを含むであろう。そして第64節で見たように、これは不可能であった。

**421**　判断もまた、決定的対応によって無限に至る部分の部分をわれわれに与えることができない。その場合、全体 W についての判断が、W の部分の組のそれぞれについての判断であるような部分の組から構成されうることが必要であろうからである。さて、すでに見たように、全体の知覚はその全体の部分の知覚の組から構成されうる。しかし判断についてはこれに対応することは何も起こりえない。一つの判断が別の判断の部分でありうる唯一の場合は、「すべての白鳥は白いという判断は偽である」と言うときのように、判断について何かが判断される場合である。そしてその場合、包括的な判断の部分のうち「である」「偽」「判断」は判断でも判断から構成されたものでもない。そうすると判断のすべての部分が判断であることは不可能であり、したがって無限に至る部分の部分の求められる系列は判断から成ることはできない。
