### 第37章　思考作用

〔訳注〕原書ではこの章の最初の節番号が405となっており、前章の最後の第399節とのあいだに番号が飛んでいる。原書どおりに残す。

**405**　これでわれわれは精神によって何が意味されるべきかを決定した。そしてここで、第一に精神が実際に存在するかどうか、第二にすべての実体が精神であると想定する理由が何かあるかどうか、という問いが生じる。

　一見したところ、精神は物質と同じく存在する。そして精神の存在の主張は物質のそれより強い。前章で示したように、われわれは何かを精神であるものとして確かに知覚するからである――われわれの各人が、さまざまなものを自分自身の部分として知覚することは認められており、また私が示そうと努めたように、何かを自分自身として知覚する。そしてもしこの知覚が正しいなら、存在するものは自己と自己の部分であり、したがって精神は、われわれの精神の定義によれば、存在する。

　しかしわれわれは、存在するどの実体も、決定的対応によって決定された、無限に至る部分の中の部分をもたねばならないことを見た。もし精神の本性をもついかなるものもこの要求を満たしえないという結論に達したなら、われわれは、精神の本性をもついかなるものも存在しえず、何かが精神として知覚されるときにはそれは誤って知覚されている、と考えざるをえないであろう。もしこの選択肢を採ることが不可能であるなら、われわれは望みのない二律背反とともに取り残されるであろう。

　しかし精神の本性を考察すると、ある仮説の上では、決定的対応によって決定された、無限に至る部分の部分の系列を与えうるような精神的実在の一つの類があることがわかる。

**406**　一見したところ自己のうちに生じる精神的実在は、知覚、特性の気づき、判断、想定、心像、意欲、情動に分類することができる。これらのうち最初の二つは、すでに述べたように、気づきとしていっしょに分類でき、気づきと判断とは認識としていっしょに分類できる。認識、想定、心像はまた思考作用としていっしょに分類できる。この章で私は、知覚は求められる型の無限系列を形づくりうるが、他のいかなる思考作用もそうできないことを証明しようと努めるであろう。意欲と情動の位置は第40章と第41章で考察する。

**407**　知覚の定義は第44節で与えた。第32章第299〜302節で、すべての知覚は実体の気づきであるが、知覚は知覚される実体の性質――他の実体とのその関係性から生じる関係的性質を含む――についての知識をわれわれに与える、ということを指摘した。たしかに、実体がしかじかの性質をもつことが知覚される、と言ってはならない。それは判断であって知覚ではないであろうからである。言わねばならないのは、実体が知覚され、それがしかじかの性質をもつものとして知覚される、ということである。

　実体を知覚するとき、それが実際にもつすべての性質をもつものとしてそれを知覚することは必要であろうか。その場合、すべての知覚は宇宙のあらゆる事実をわれわれに示すであろう。第221節で見たように、どの実体の完全な記述も他のすべての実体の記述を含むであろうからである。

　私の見るかぎり、実体を、それが実際にもつすべての性質をもつものとして知覚することなしに知覚することの可能性を疑う理由はない。またここで本源的性質と関係的性質とを区別し、実体が知覚されるとき、それは事実としてそれがもつすべての本源的性質をもつものとして知覚されねばならない、と考える理由も見当たらない。

　しかしさらに、ものが知覚されるとき、それがそのものの十分な記述を構成するのに十分な性質をもつものとして知覚されることは必要であろうか、と問われるかもしれない。これについても私は何の必然性も見いださない。宇宙のうちに性質 XYZ をもつ何か別のものがあるにもかかわらず、ものを性質 XYZ をもつものとして知覚し、それを他のいかなる性質をもつものとしても知覚しない、ということは可能であろうと思う。

　そこでさらなる問いが生じる。われわれの知覚は、それが及ぶかぎり正確でなければならないか。ものを性質 X をもつものとして知覚するとき、それが実際に性質 X をもつことは確かであろうか。われわれの絶対的実在の本性の理論は、ある知覚が誤っていなければならないことを含むのだから、どこかに誤った知覚の余地を認めなければならないことをわれわれは見た。しかし次の部でこの主題を考察するとき、決定的対応によって決定された部分の中の部分の無限系列を第一次的にわれわれに与える知覚のあいだには誤りの余地はない、と信じる理由を見いだすであろう。誤りはどこか他のところに見いだされねばならないであろう。

**408**　次に、知覚が、決定的対応によって決定された部分の中の部分のこの無限系列をどのようにしてもちうるかを考察しなければならない。

　三つの想定をなすことから始めよう。第一は、自己は別の自己と、別の自己の部分とを知覚しうる、ということである。第二は、知覚は知覚する自己の部分である、ということである。第三は、全体の部分の知覚はその全体の知覚の部分でありうる、ということである。この章ののちに私は、三つの命題すべてが真であることを示そうと努めるであろう。しかしこれらの命題の真理を論じる前にわれわれの見解の全体を説明しておくのが便利であろうから、さしあたりそれらを想定として扱うことにする。

　そうすると、そのすべての一次部分が自己であるような一次全体を想定しよう。そしてこれらの自己のそれぞれが、各自己と各自己の各部分とについて別々の知覚を、しかもただ一つのそのような知覚をもつと想定しよう。そして、いま可能であると想定したように、これらの知覚対象のどれか一つが別の知覚対象の部分であるとき、第一のもののどの知覚も第二のものの知覚の部分であろう、と想定しよう。そうするとわれわれは、決定的対応によって決定された、無限に至る部分の中の部分の系列をもつことになろう。簡単のため、自己である二つの一次部分 B と C から成る一次全体を取ろう。そうすると B は自分自身と C とを知覚し、彼と C とが自分自身と互いとについてもつ知覚と、彼らがこれらの知覚についてもつ知覚とを知覚し、以下無限に続くであろう。そしてこの知覚対象の無限系列についての B の知覚は知覚の無限系列を形づくるであろう。彼は各知覚対象について別々の知覚をもつからである。そして部分の知覚は全体の知覚の部分であろうから、その無限系列は部分の中の部分の系列であろう。同様の系列はもちろん C のうちにも生じるであろう。

**409**　そのような無限系列は、条件がいま取ったものといくらか異なっていても、なお得られうるであろう。第201節で決定的対応一般について述べたことを考えるなら、条件は三つの点で変更しうることが明らかであろう。第一に、各自己が一次全体のなかのすべての自己を知覚する必要はない。各自己が二つ以上の自己から成る分化群をもち、この群のなかの各自己とそのそれぞれの各部分とを知覚すれば十分である。第二に、ある自己が被決定項であるだけで決定項でない――すなわち、知覚されることなしに知覚する――ことも可能である。第三に、どの一次全体のなかのある自己が、自己の分化群の代わりに、ただ一つの決定する自己をもつ――すなわち、もう一つの自己とその部分以外の何ものも知覚しない自己がある――ことも可能である。しかし各一次全体のうちには、第201節で定義したしかたで決定が相互的であるような自己の群が少なくとも一つなければならないことはつねに必要であろう。

**410**　そうすると決定的対応の関係は、たとえば被決定項 B!C は決定項 C の知覚である、というものであろう。そしてわれわれは、この関係が、第229節で見た、決定的対応の関係が満たさねばならない五つの条件のすべてを満たすことを見いだすであろう。その第一は、C のある十分な記述（C が B の何らかの部分に対してその関係にあるという事実を含む）があって、それが問題の B の部分 B!C の十分な記述を内在的に決定しなければならない、ということである。さて、自己 C の十分な記述 XYZ で、それが B によって知覚されるという事実を含む（したがって、それなしには B による C の知覚が十分に記述されないであろう B の十分な記述 UVW を含む）ものは、B!C の十分な記述を内在的に決定するであろう。B!C のこの十分な記述は、「UVW である唯一の自己による、XYZ である唯一の自己の知覚」であろう。われわれの仮説によって、B は C についてただ一つの知覚しかもたず、したがってこの記述はただ一つの実体にしかあてはまらないであろうからである。同様の十分な記述は、より低い階の二次部分、たとえば B についての C の知覚についての B の知覚（B!C!B）についても見いだすことができる。
