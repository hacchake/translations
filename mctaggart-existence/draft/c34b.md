　第二に、部分の組の成員の空間的性質は、それらがその部分の組であるような全体の空間的性質を含意することは明らかである。A の部分の組のどの一つについてもその形と大きさを知り、互いに対するそれらの位置を知れば、A の大きさと形を知る。そしてこれに加えて、組の各部分の、何か外部のもの B に対する位置を知れば、B に対する A の位置を知る。他方、全体の大きさと形と位置は、それが大きさと形と位置をもつ部分をもつことを含意する――そうでなければそれはその空間的次元に関して部分へと分割されえないであろうからである。そしてもしそれがこれらの部分の大きさと形と位置が何であるかをも含意しないなら、それはそれらを前提とする。こうしてわれわれは、後続する項が先行する項を含意し、先行する項が後続する項を前提とするような項の無限系列をもつことになろう。そして第191節で示したように、そのような系列は矛盾を含むであろう。そのなかのどの項も前提をもちながら、全究極前提をもたないであろうからである。これを避ける唯一のしかたは、どの先行する項の空間的性質も後続するすべての項の空間的性質を含意することである。そしてこれは、系列が無限であるときには、決定的対応によってしかなされえない。

**357**　そうすると、物質の空間的部分の空間的性質を決定的対応によって決定することは可能であろうか。もしそうなら、物質の一つ以上の一次全体があり、どの全体 A も、その大きさと形と相対的位置とが究極的事実として与えられているような部分の組 B と C をもつのでなければならないであろう。（これらの一次部分はもちろん非空間的性質によっても互いに分化されていてよい。）そうすると対応の法則は、B と C がそれぞれ、その成員が形においても他の成員に対する位置においても A のすべての部分の組の成員と対応するような部分の組をもつ、というものでなければならないであろう。これは B と C のうちの部分の中の部分の形と位置とを無限に含意し、各部分の大きさは、B と C 自身の大きさとあわせて部分の形と位置とから帰結するであろう。

**358**　空間はときに相対的と考えられ、ときに絶対的と考えられるが、どちらの場合にも、各部分が非空間的性質によって分化されていないかぎり、空間的性質による決定的対応はありえないであろう。空間を相対的と取るなら、物質の空間的性質はすべて、物質の一片と別の一片との関係性から生じる関係的性質である。そして物質の諸片が他のしかたで互いに分化されていないかぎり、そのような関係性はありえない。M と N は、M の N に対する関係が N の M に対する関係と異なるという事実だけによっては、互いに分化されえない。また、第三の実体が M と N とに対して異なる関係に立つということ以外に分化の根拠をもたないなら、それらはその第三の実体に対する異なる関係によっても分化されえないであろう。

**359**　空間を絶対的と取るなら、事情はどうであろうか。絶対空間についての通常の理論は、それが分割できない点から成るというものである。その場合、物質が空間においてまったく無限に分割可能でありえないことは明らかである。分割できない各点を占める物質はそれ自身空間的に分割できないからである。

　しかしひょっとすると絶対空間の別の理論が可能かもしれない。そのような空間の単位は、分割できない点ではなく、そのそれぞれが究極的事実としてある大きさと形をもち、他のすべての領域に対してある関係に立つような領域であるかもしれない。物質の一次部分は、そのそれぞれがこれらの領域の一つを占めるようなものではありえないか。そうすれば、原書三七ページで示唆した対応の法則によって、各一次部分のうちに部分の中の部分の無限系列を決定することが可能ではないか。

　しかしこれは、部分の組の無限系列のなかの各部分がまたその非空間的性質によって分化されているのでないかぎり、なされえない。B と C が原書三七ページで述べたしかたでその空間的性質によって分化され、またその非空間的性質によっても分化されている――たとえば B は青く C は赤い――が、非空間的性質による分化はそこで止まり、したがって B のすべての部分は均質に青く、他のいかなる非空間的性質によっても分化されていない、と想定しよう。そうするとこの理論は、B のうちに、形と相対的位置においてそれぞれ B と C に対応する B!B と B!C があることを要求する。そしてこれらの部分は互いにいかなる非空間的性質によっても分化されていない。

　しかし、B と C に対するその関係によってのみ互いに分化されている二つのそのような部分がありうるであろうか。私には、それらが他のしかたで分化されていないなら、B!B と B!C という記述に合致する部分はありえないことが明らかに思われる。もしそれらが他のしかたで分化されていたなら――たとえば一方が菫色で他方が藍色であったなら、あるいは一方が硬く他方が柔らかかったなら――それらはそれぞれ B!B と B!C という記述に合致しえたであろうし、それらの記述はそれらの追加の十分な記述を与えるであろう。しかし仮説によって、B のすべてはその非空間的性質に関して均質である。そしてその場合、B!B、B!C という記述があてはまりうる部分はなく、したがって分化はないことは明白であるように思われる。

　しかし、この結論は誤謬でなければならないのではないか、と問われるかもしれない。もし部分を B!B と B!C として記述することがそれらの部分の十分な記述を与えるなら、それらの部分が他のしかたで分化されていないかぎりその記述があてはまりうる部分はない、とどうして言えるのか。それらの記述自体がそのような部分を区切るのではないか、と。

　これは一見したところ深刻な反論に思われる。そしてたしかに私の提出した見解は逆説的に思われる。しかし私は、空間の本性をもっと詳しく見るとき、この反論は妥当でないことがわかり、ついでに、私の擁護する見解がその真理にもかかわらずなぜ逆説的に見えるのかもわかるであろう、と信じている。

**360**　私の考えでは、空間的なものは、その部分の記述によってでなければ、その空間的性質に関して他のいかなるものからも識別されえない、ということが空間の本性に属する。全体をその部分の記述によって記述しない全体の記述は、それを他の空間から識別しないであろう。空間的全体をその部分の記述によって記述しうるしかたは二つあり、われわれが空間的全体を識別するのはつねにこの二つのしかたのどちらかによってである。

　そのしかたの第一は、そのすべての部分によってもたれ、全体と空間的に接しているいかなるものによってももたれない何らかの性質を指摘することによって、それを記述することである。こうしてわれわれは、ある特定の面を、そのすべての部分が青く、それに触れるすべてのものが赤い、という事実によって識別できる。均質な青い線の一区間を、目盛りのない棒に当てて測ることによって区切るときもそうである。そのときその区間のすべての部分は、その棒と接しているという性質――青い線の他のいかなる部分ももたない性質――をもつからである。これはもちろん、棒が識別されていないかぎり問題の区間を識別しないであろう。しかし棒は、そのすべての部分が、色と硬さに関して、それと接しているいかなるものももたない性質をもつ、という事実によって識別される。

　第二のしかたは、E のある部分の組の各部分 F、G、H が、それと接しているすべての空間的なものからそれ自身の識別をもち、したがってわれわれが E を F、G、H から成る部分の組をもつ実体として識別できる、というものである。このしかたで地図の上のイングランドの表示を識別することができるかもしれない。それは、ノーサンバーランドの表示、カンバーランドの表示、その他すべての州の表示をそのうちに含むかぎりの地図の部分であり、各州の表示は、そのすべての部分を通じて、それと接している地図のいかなる部分にも属さない何らかの色をもつという事実によって識別される、と言えるかもしれない。そしてこのしかたで、目盛りのある棒に当てて測るとき、われわれは青い線の一区間を識別する。そのときわれわれは、その区間は部分 F、G、H から成り、そのそれぞれは棒のある部分と接しており、棒の部分はさまざまな性質によって、その両側の棒の部分から、またその他の側を取り巻く空気から識別されている、と言うからである。

〔原注〕このしかたでイングランドの表示の十分な記述を与えようとするなら、州の表示の十分な記述を必要とするであろう。そしてそれらのうち互いに触れていない二つが同じ色であったなら、十分な記述を作り上げるために他の性質を加えなければならないであろう。しかし本文では、地図の残りの部分からのイングランドの表示の識別についてのみ語っている。そしてそのためには本文の条件で十分である。

　私の主張している見解が逆説的に見える理由は、思うに、われわれがこの第二の識別の方法が B!B と B!C の場合にあてはまるにちがいないと本能的に想定するからである。われわれは、B はこのしかたで互いに識別されうるような多くの部分へと分割されていて、B!B と B!C はそのどれも横切らず、そのそれぞれはまったく B!B か B!C のうちに入るにちがいない、と想定する。そうすれば B!B と B!C は、一方は部分 F、G、H 等々を、他方は部分 I、J、K 等々を含む B の部分として識別できるであろう、と。

　しかし第二の識別の方法が無限に至る部分の中の部分の識別にはあてはまりえないことは明らかである。このしかたで決定されるとき、どの全体の識別もその部分の識別に依存するからである。したがって識別が無限に及ぶときには、最後の項をもたない系列の最後の項から出発することによってでなければどの空間も識別されえず、したがってまったくどの空間も識別されえないであろう。

　したがって、われわれがいま考察している絶対空間の理論の上で、空間が部分の部分へと無限に識別されるべきなら――少なくともある有限個の階の後では――すべての識別は第一のしかたでなされなければならない、ということが帰結する。すなわち、各空間的部分 L について、L のすべての部分によって共有され、L と空間的に接しているいかなるものによっても共有されない何らかの性質がなければならない。そしてこの性質は非空間的でなければならない。すでに見たように、すべての空間的な違いはそのような識別を必要とし、それを与えることはできないからである。

　そうすると絶対空間のこの理論の上では、空間的性質による無限に至る空間的分割は、各部分がまた非空間的性質によって分化されている場合にのみ可能である。そしてわれわれは（原書三五ページ）、これが相対空間のどの理論の上でもまた事実であることを見たし、他方、絶対空間のより通常の理論は無限分割を不可能にする（原書三八ページ）。したがって、空間のどの理論の上でも、空間的性質による無限に至る空間的分割は、各部分がまた非空間的性質によって分化されている場合にのみ可能である、ということが帰結する。
