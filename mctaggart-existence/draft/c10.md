### 第10章　実体の非類似

**93**　次に、二つの実体がまったく同じ本性をもちうるのか、それとも、それらが二つの異なる実体であるという事実は、その本性に何らかの違いがなければならないことを含むのか、という問いが生じる。二つのものの本性のあいだに何の違いもなければ、それらは正確に類似しているであろう。したがってわれわれの問いは、相異は非類似を含意するか、という形で立てることができる――非類似は、正確な類似だけを排除し、部分的な類似とは両立するものとして用いる。

　まず注意してよいのは、もしそれらの本性に何らかの違いがあるとすれば、それらの一次的性質のうちに何らかの違いがなければならない、ということである。反復的性質の無限系列を生み出す公式は、一次的性質の何らかの違いから生じるのでないような反復的性質の違いはありえない、というようなものだからである。

　一次的性質は、本源的性質であるか、本源的関係性から直接に派生する性質であるかのどちらかである。二つの実体が、その本源的性質に何の違いもないまま相異していることが可能であることを否定する理由はないように思われる。もちろん、すべての実体がその本源的性質において異なるかもしれない。どの実体も、他のどの実体ももたない何らかの単純な本源的性質をもつことさえありうる。そしてもっとありそうに思われる想定を取れば、どの実体における本源的性質の集積も、他のどの実体における本源的性質の集積と、少なくともその構成要素のいくつかにおいて異なる、ということはありうる。しかしこれがそうでなければならないと想定する理由はない。もし相異が本性の違いを要求するとしても、その要求は、本源的関係性の違いによって引き起こされる関係的性質の違いによって満たされうるであろう。

　問題は正確な類似についてのものであり、正確な類似は、ふつうどれほど外的で無関係だと想定されている関係性であれ、どの関係性にも違いがないことを含む、ということを忘れてはならない。二つのものは、その一方が私に知られていて他方が知られていないなら、正確に類似していない。またその一方が、他方なしに私によって知覚されたり考えられたりすることがあるなら（たとえ別の時には両者を同時に知覚したり考えたりするとしても）、正確に類似していない。その場合、一方は特定の時に特定の人によって認知されるという性質をもち、他方はもたないからである。またそれらが、どれほど恣意的に当てられたものであれ、名前や番号によって区別されることがあるなら、正確に類似していない。その場合、一方は特定の時に特定の人によって P と呼ばれるという性質をもち、他方はその時に彼によって Q と呼ばれるという性質をもつであろうから。

**94**　では、正確に類似した二つのものはありうるであろうか。答えは、ありえない、でなければならないと私は思う。相異と非類似とのあいだの結びつきはたしかに総合的である。「A と B は二つのものである」と「A と B は非類似である」とは、同じ事実を述べる二つのしかたではない。しかし私には、相異が非類似を含意する――二つのものが同じ本性をもつことはできない――ことは明らかだと思われる。思考のなかで二つの実体から本性の違いをすべて取り除く実験をしてみると、それに成功したとき、われわれはもはや二つの実体ではなく一つの実体を考えていることに気づくであろう。そしてこれは、私の考えでは、われわれが二つの実体を区別できないことから来るのではなく――それは二つがないことを証明しはしないであろう――非類似なしの相異の不可能性を認めることから来るのである。実体の本性は、その実体が何であるかを完全に表現している。そして実体が何であるかの同じ完全な表現が、二つの実体のそれぞれについて真であることはありえない。実体はその本性によってこの実体にされるのであり、本性が同じなら、実体は同じである。

　相異する実体のあいだに存在しなければならない関係の非類似が一つあることは、誰も否定しないであろうと思う。A と B が相異する実体であるなら、A は A と同一であり B と相異しているが、B は A と同一でもなければそれ自身と相異してもいない。しかし前の段落でのわれわれの主張が正しいなら、相異する実体のあいだには、これとは別に何らかの非類似がなければならない。というのも、この非類似は先に確立された相異に依存しており、したがって相異を可能にするのに必要な非類似ではありえないからである。

**95**　相異はそれ自身に依存しない非類似を要求する、という見解は、思うに、大多数の哲学者によって採られてきた見解である。しかしそれは否定されてきたのであり、何がその否定を引き起こしたかを考察しなければならない。

　第一に、この否定はいくつかの場合には、多かれ少なかれ明示的に、物自体という誤った概念を採用したことによるように思われる。（私はこの言い回しをここで、カントの意味よりもむしろヘーゲルの意味で用いる。）実体はその本性から離れた別個の個体性をもち、したがって二つの実体は、同じ本性をもちながら、この別個の側面に関して相異しうる、と考えられる。ちょうど二つの頭に同じ帽子が合うのとほぼ同じように。しかしこれは支持しがたい。実体のこの別個の側面によって何を意味しているかを説明しようとするとき――いや、それが存在すると主張するときにさえ――われわれは実体の性質を主張することによってしかそうできないからである。そしてこれらの性質は実体の本性の部分であって、その本性から離れた別個のものではない。したがって、実体をその性質から、本性が同じでありながら実体が異なることを許すようなしかたで区別することは不可能である。

〔原注〕拙著『ヘーゲル論理学注解』第135節参照。

　これに対しては、実体がその本性から離れた個体性をもつという主張は、「これはあれの近くにある」というような判断が確定した意味をもちうるという事実によって証明される、と私に示唆されたことがある。そのような判断は、その項が、それぞれの記述が宇宙のなかのただ一つのものにしかあてはまらないほど精確に記述されることによって確定した意味を得るのでないことは確かである。実際、「これ」と「あれ」はそれぞれ宇宙のあらゆる対象にあてはまる。それでも、もし私が「これ」と「あれ」として指示する実体を知覚しているか、あるいはそれらを知覚したことがあって今それを覚えているなら、そのような判断には私にとって曖昧さはない。そこから、各実体のうちにはその性質から独立した個体性がなければならず、それはわれわれが実体を知覚するときにわれわれに明かされる――もちろん、実体が知覚されようとされまいと同じくそこにあるであろうが――と論じられるのである。

　しかしこの議論は妥当でないように私には思われる。たしかに私は A について、曖昧さのない知識――それを同定することを可能にする知識――を、知覚によってか記述によってかもつことができる。そして第一の場合には、A の性質についての私の知識に依存しない A についての曖昧さのない知識をもつであろう。ちょうど第二の場合には、A との私の直知に依存しない A についての曖昧さのない知識をもつであろうのと同じように。しかし私がその性質から独立に実体を知りうるという事実は、その個体性がその性質から独立しており、したがってそれが非類似でない他の実体から相異しうる、ということを証明しはしない。

〔原注〕われわれがある実体を、その性質のいくつかを知ることなしに知覚することがあるかどうか、私は疑わしいと思う。知覚の後には、われわれはつねに知覚したものの本性についていくつかの判断を下すことができるからである。（この主題は第5部で論じる。）しかし私は、実体の性質についての私の知識がその曖昧さのない記述にはるかに及ばなくても、知覚によってその実体について曖昧さのない知識をもつことができる。

　実体の個体性は、それを知ることなしに実体が曖昧さなく知られうるようなどの性質からも独立していなければならない、という見解は、不合理に導く。というのも、それを知ることなしに私が知覚によって実体を曖昧さなく知りうる性質のうちには、「どの性質からも独立した個体性をもつ」という性質が含まれるからである。したがって、もしこの見解が真なら、実体はどの性質からも独立した個体性をもち、その個体性はとりわけ、「どの性質からも独立した個体性をもつ」という性質をもつことからも独立していることになろう。そしてこれは不合理である。

　これを避けるために、実体は、それに含まれる性質――実体性、どの性質からも独立した個体性をもつこと、そしてそれに伴う非類似から独立した相異をもつこと――をもつのでないかぎり、そのような独立した個体性と相異とをもちえない、と認められるかもしれない。しかしそれでもなお、実体は、その性質のいくつかには依存しながらも、その性質に全面的には依存しない個体性をもち、この個体性は正確に類似した二つの実体において異なりうる、と主張されるかもしれない。しかしこの承認は議論の力を失わせるであろう。私は、ある実体が実体性をもつことも、どの性質からも独立した個体性をもつことも、非類似から独立した相異をもつことも知らずに、その実体を知覚することができる。そしてそれにもかかわらずその個体性がこれらの性質から独立していないのであれば、私がその他の性質を知らずに実体を知覚できるという理由だけで、その個体性が他のどの性質からも独立している、と論じることはできないからである。

**96**　したがって、われわれの理論を退けるこの根拠は不十分と見なさねばならない。他の場合には、われわれの理論は、それが何を意味するかについての誤解のために退けられるのだと思う。要求される非類似は、関係的性質を除いた、われわれが本源的性質と呼んだものの非類似でなければならない、としばしば想定されてきた。しかしこれは誤りである。主張されているのは、相異する実体はその本源的性質とその本源的関係の両方において正確に類似していることはありえない、ということだけだからである。

　われわれの理論に対して、正確に類似した二つの実体が異なる時点や場所に存在しうる、と主張されるのは、この誤解のためである。異なる時点や場所に、本源的性質において正確に類似した二つの実体があることは可能かもしれないが、それらは異なる関係性をもち、したがって異なる派生的性質をもつであろう。異なる時点にある二つの実体は互いに異なる関係をもつ。一方は他方より前であり、他方は前者より後であろうからである。そしてそれらは時間系列のなかの他のすべてのものに対して異なる関係性をもつであろう。また異なる場所にある二つの実体も異なる関係性をもつであろう。空間を絶対的なものと取るなら、一方の実体は空間の一つ以上の点を占め、それらの点は、別の場所にある他方によっては占められないであろう。そうすると A は点 M を占めるものであるという関係的性質をもち、この性質は B によって共有されないであろう。他方、空間を相対的なものと取るなら、二つの実体が空間内の他の実体に対するその関係性に何の違いもないなら、空間のなかで異なる位置を占めることはできないことは明らかである。

**97**　時間と空間の系列のほかにも項の系列はあり、同じようにして、相異する実体がそのような系列のなかで異なる位置を占めるなら、それらは正確に類似していながら相異しうる、と主張されてきた。実体が数えられたり番号を付けられたりするときにはいつでも、もちろんそのような系列がある。そしてわれわれの理論に対するこの反論は非常に重要と考えられてきたので、「数的に異なる」や「数的に相異する」という表現が、われわれが相異と呼んだものを表すのにしばしば用いられている。

　この反論も同じ誤解による。二つの実体がそのような系列のなかで異なる位置を占めるなら、その関係性は同じではない。A と B が系列のなかの異なる点にあるなら、それらは系列のなかの他のどの項 C に対しても異なる関係に立つであろう。C が系列のなかで A と同じ位置にあるなら、それは B と同じ位置にはないであろう。C が系列のなかで両者のあいだにあるなら、両者の一方は系列のなかで C より前にあり、他方は後にあるであろう。C が A と B の同じ側にあるなら、A が B よりそれに近いか、B が A よりそれに近いかでなければならない。こうして A と B の関係性と関係的性質とは異なるであろう。

　そして、系列の順序が、通常の言葉で言えばその項である実体には無関係と呼ばれるであろう何らかの考慮によって決定されているとしても、違いはない。私が今日フィールディング、メレディス、サッカレーをこの順に考えるのは、本棚を見ていて私の目が『トム・ジョーンズ』『エヴァン・ハリントン』『エズモンド』に次々にとまったからにすぎないかもしれない。しかしフィールディングについては、ある日にある人がメレディスを考える前に彼について考えた人である、ということが真であろうし、サッカレーについては、同じ日に同じ人がメレディスを考える前に彼について考えなかった人である、ということが真であろう。そしてこれはフィールディングとサッカレーの本性の重要な違いではないにせよ、実際の違いである。

　そうすると、われわれが考察した反論のどちらも妥当ではなく、相異は非類似を含意し、すべての実体は互いに非類似でなければならない、というわれわれの見解を堅持しなければならない。

**98**　すべての実体が互いに非類似でなければならないことは示したとしても、それらが本源的性質において、あるいは他の実体への関係において非類似でなければならないと想定してはならない、と言われるかもしれない。それらは、それらに属さない特性への関係においてだけ非類似であることはできないのか。たとえば、A と B が人間であるなら、その非類似はもっぱら、白さや剛性という特性への関係の何らかの違いにある、ということはありえないのか。

　しかしそのような非類似はどれも、A と B の他の実体への関係における非類似を含むであろう。A が特性 X に対して関係 Y をもち、B がそれに対してその関係をもたないなら、どれかの実体 C が特性 X をもつ場合、A と B は C に対して異なる関係にあるであろう。C は X に関係しており、したがって X に対して異なる関係に立つものに対して異なる間接的関係にあるであろうからである。そしてこれらの関係は間接的ではあろうが、実体のあいだの本源的関係であろう。他方、X がどの実体ももたない特性であるなら、すべての実体は非 X という特性をもつであろう。そして A と B が X に対して異なる関係をもつなら、非 X に対するそれらの関係は同じではなく、したがって非 X という特性が属する実体に対するそれらの関係も同じではないであろう。

**99**　われわれが達した結果は、歴史的に「不可識別者同一の原理」として知られている原理である。たしかに、この名を考案したライプニッツが、相異する実体は非類似の性質をもたねばならない、と主張したとき、彼は、われわれの採った用語法で言えば非類似の本源的性質と呼ばれるであろうものをもたねばならない、という意味で言っていた。しかし、ライプニッツは関係をまったく退け、本源的性質が実体の唯一の特性だと考えていたことを思い起こさなければならない。そして私には、不可識別者同一の原理を主張するにあたっての彼の主張の本質は、特性の非類似がある、という主張のうちにあったのであって、これが関係の違いから始まりうることを否定した点にあったのではないように思われる。

　しかしこの名はよい名ではない。この原理は、同一である不可識別者がある、と主張するのではなく、何ものも他の何ものからも識別不可能ではない、と主張するのだからである。「相異するものの非類似」と言うほうがよいであろう。
