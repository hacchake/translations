　これらの部分はすべて、われわれが知覚する自己の部分であり、そのような部分として知覚されるであろう（第37章原書九八〜一〇四ページ）。そして知覚される自己は愛されている。さて、現在の経験においてわれわれが、自分の愛する人格の生における状態や出来事をどのように見るかを考察すると、われわれはそれらを特別な種類の好感をもって見る傾向があることに気づく。この種の好感は愛とは呼ばれないであろう。愛という名は人格に対する情動のために取っておかれているからである。われわれはそれをひょっとすると満悦と呼んでもよいかもしれない――もっともその名は、しばしば感じられるものより穏やかな情動を示唆するが。

　現在の経験に関しては、上で述べたように、われわれはそれをこのように見る傾向がある、と言えるだけである。その傾向は、その状態を、われわれが愛する人格の状態として認めることから来る。しかしもしその状態が、それをわれわれにとって厭わしいものにする傾向のある他の性質をもつなら、われわれがそれを見る満悦は弱められるか、完全に妨げられることさえあるかもしれない。

　しかし絶対的実在においては、そのような状態が、それをわれわれにとって厭わしいものにする傾向のある何らかの性質をもちうるであろうか。私にはそうでありうるとは思われない。B によって知覚される C の状態はすべて、C 以外の自己あるいはその自己の部分、あるいは C 自身あるいは C の部分の知覚であろう。そのどれも満たされない意欲ではありえない。他の自己の知覚は愛の状態であろう。他の自己の状態についての C の知覚は、それ自身満悦の状態であろう――それがその知覚であるところの状態の何らかの性質によってこれが妨げられないかぎりは。そして同じ議論がこれら後者の状態にもあてはまり、以下無限に続くのだから、そのような性質が持ち込まれる余地はないであろう。

　C の状態が苦の状態であるかもしれず、それが B にとってそれを厭わしいものにするかもしれない、と言われるかもしれない。快と苦の問題は第7部で扱われる。そのとき（第67章原書四七一〜四七二ページで）、絶対的実在においてはどの状態の快もその状態の苦を無限に上回ることを見るであろう。したがって、その状態が全体として快楽的な根拠から嫌悪の対象でありうることは不可能であろう。

　他の自己とその部分についての C の知覚はすべて愛あるいは満悦の情動であろう。そしてのちに見るように、自分自身と自分の部分についての C の知覚は、それぞれ自己畏敬と満悦の情動であろう。そのような状態が、B――思い起こさなければならないが、B は C 自身を愛している――のうちに嫌悪を引き起こすべき何らかの性質をもちうるであろうか。私にはそれらがそうでありうるとは考えられない。もしそうなら、B が、自分の愛する C の部分であるがゆえにそれらを満悦をもって見る傾向を抑えるものは何もないであろう。そしてそうして彼はそれらを満悦をもって見るであろう。

**475**　C が B の分化群のうちにあり、D が C の分化群のうちにあるが B の分化群のうちにはない、ということは可能である。その場合 B は C を直接に知覚し、C は D を直接に知覚するであろうが、B は D を直接に知覚しないであろう。しかし彼は D についての C の知覚を知覚するであろうし、これが D の間接的知覚と呼ばれるのが適切であることをわれわれは見た（第39章原書一二六ページ）。この間接的知覚は D に対する何らかの情動的関係を与えるであろうか。私は与えると思う。B は C!D――すなわち D についての C の知覚であり、それはまた C の D への愛の状態でもある――を直接に知覚するであろう。B によるこの知覚（記号では B!C!D）は、すでに見たように、C!D に対する満悦の情動であるという性質をもつであろう。そして思うにそれはまた D に対する情動であるという性質ももつであろう――現在の経験において、われわれが自分では愛していないが、自分の愛する人々によって愛されている人々に対して感じる情動である。この種の情動が何か特別な名をもつかどうか私は知らない。しかしわれわれはその本性を知るのに困ることはない。それが現在の経験の一部をなさないような人はほとんどいないからである。われわれはひょっとすると、他の実体に対して感じられる好感とは区別された、人格に対して感じられる好感の種類を示すのに、情愛という語を用いてよいかもしれない。その場合、愛もこの情動も、ともに情愛の例であろう。

　同じように、B!C!D!E は、B が D を愛する C を愛し、D が E を愛するという事実から生じる、B が E に対して感じる情動であろう。そしてより低い階についても同様である。

**476**　これでわれわれは、自己に対する情動と自己の部分に対する情動について語った。自己の群に対するわれわれの情動について何か積極的なことが言えるであろうか。私は言えないと思う。もし私がある自己の群を直接に知るなら、私はその成員のすべてを愛するであろう。もし私がそれを間接に知るなら、私はその成員のすべてを情愛をもって見るであろう。そして私はこれらの事実と両立しないような情動をその群に対してもつことはできない。しかし私がその群に対してそもそも何らかの情動をもつことは帰結しない。ある人は学校時代の友人の一人一人を、大学時代の友人の一人一人を、自分の子どもの一人一人を愛するかもしれない。しかし彼が、学校時代の友人の一人、大学時代の友人の一人、子どもの一人から成る群――ひょっとするとその成員の誰も他の成員の誰にも会ったことのない群――に対して何らかの情動をもつことは帰結しない。

**477**　他の自己とその部分に対する情動についてはこれだけにしておく。しかし少なくともある自己は自分自身を知覚し、そうするなら自分自身の部分を知覚する。ここでの情動について何が言えるであろうか。

　自己と自分自身とのあいだの関係の緊密さが、自己のうちに自分自身に対する何らかの情動を決定するとは私は思わない。しかしそのような情動は絶対的実在において存在しなければならない。自分自身を直接に知覚するすべての人格は、少なくとも一つの他の人格をも直接に知覚しなければならない。したがって彼は少なくとも一人の人格を愛するであろう。さて愛は、愛する者のうちに、自己畏敬と呼んでよいような自分自身に対する情動を引き起こす。私は愛するのだから価値をもつ――最高善を所有しているのだから至高の価値をもつ。そして私は価値をもつのだから、自分自身を畏敬をもって見るであろう。そしてもし私が自分自身を畏敬するなら、私は自分の部分を、自分の愛する人格の部分を見るのと類比的な満悦の感情をもって見るであろう。

〔原注〕現在の経験においては、満悦への傾向があること、そしてひょっとすると自己畏敬への傾向があること以上のことは言えない。しかし原書一六一〜一六二ページにおけるものと類比的な議論によって、絶対的実在においてはその傾向が妨げられえないことを示すことができる。

　こうして、絶対的実在におけるわれわれの情動的態度の全体は、いまわれわれがそれを決定できるかぎりにおいて、愛に依存していることが見て取られるであろう。B が C の部分に対して満悦を、C が愛する D に対して情愛を、自分自身に対して畏敬を、自分自身の部分に対して満悦を感じるのは、B が C を愛するからである。そしてわれわれは（原書一六五ページで）、C と C の部分の存在だけでなく、D と自分自身と自分自身の部分の存在への彼の同意を決定するのは、彼の C への愛であることを見るであろう。自分自身に対する彼の情動も意欲も、ともに誰か他の人への彼の愛に依存している。しかしわれわれが生を、ここといまにおいてわれわれが見いだすとおりに考察してさえ、人が自分を畏敬に値するものと見いだし、自分の存在を望ましいものと見いだすのは、ただ自分が友人たちにいだく愛のためにすぎない、という見解のうちに驚くべきものは何も見いださないであろう。

**478**　いまわれわれは、前章の終わりで未解決のまま残した問いに戻ることができる。そこでわれわれは、絶対的実在においては知覚でないような意欲はありえず、満たされない意欲もありえないことを見た。しかしそのときには、すべての知覚が意欲であるかどうか、あるいはそのどれかがそうであるかどうかさえ決定することはできなかった。

　しかしいまやわれわれはこの問いに答えることができる。私は自分が直接に知覚する他のすべての自己を愛するであろう。そして同意は愛の必然的な帰結である。私は自分の愛する者から、あるいは彼への自分の愛から幸福を得ないかもしれない。私は彼を道徳的に是認しないかもしれない。私は彼の性質の多くが別様であればよかったと欲求するかもしれない。しかしもし私が彼を愛するなら、私が欲求しなければならないことが一つある。私は彼の存在を欲求する。私は彼がそこにいてほしいのである。

　たしかに現在の経験においては、彼が存在してほしいという私の欲求には、彼が異なる性質をもっていてほしい、あるいは彼が存在しなければよい、という同時的な欲求さえ伴うかもしれない。私自身のためには私は彼の存在を欲求する。しかし彼自身のためには、もし彼の生が惨めであるなら、あるいは他人のためにさえ、私は彼が存在しなければよいとも欲求するかもしれない。そして後者の欲求のほうが強いかもしれない。

　しかし絶対的実在においては満たされない意欲はない。すべての意欲は知覚だからである。したがって、彼は存在し、あるがままにあるのだから、私は彼が存在しなければよいとか、彼が異なっていればよいとかいう欲求をもちえないであろう。こうして彼の存在への欲求と衝突する欲求はなく、その欲求――すでに述べたように、愛が存在するときにはいつでも存在する――は、争う者のない支配力をもつであろう。

　そうすると他の自己についての私の直接的知覚はすべて満たされた意欲であろう。そして他の自己についての私の間接的知覚、私自身についての私の知覚、自己の部分についての私の知覚についても同じであろう。私はこれらを情愛、自己畏敬、あるいは満悦をもって見るであろうし、これらの情動のどれかをもって私が見るものは何であれ、私はそれが存在することを欲求するであろうからである。

　現在の経験においては、これらの欲求は、私が愛する自己の存在への欲求と同じく、同じ対象が異なる性質をもって存在してほしい、あるいはまったく存在しなければよい、という欲求を伴うかもしれない。しかし絶対的実在においては満たされない意欲はありえないのだから、絶対的実在においてはそのような対立する欲求はありえず、私は存在への満たされた欲求以外の欲求をもたないであろう。

　こうして私の知覚はすべて、意欲的側面においては、知覚される対象への同意の状態であろう。そして情動的側面においては、私の知覚はすべて、愛か、他の情愛か、自己畏敬か、満悦かの状態であろう。

**479**　これら四つのほかにどのような情動が絶対的実在において可能であるかを、いまわれわれは探究しなければならない。

　ある情動が生じえないことは明らかである。それらは、すでに見たように生じなければならない情動と両立しないからである。憎しみはありえない。私は自分が直接にか間接にか知っているすべての人格を、愛か他の種類の情愛かをもって見るからである。また他のいかなる種類の嫌悪もありえない。私が知っている唯一のものは、自己のほかには、自己の部分か自己の群だからである。自己の部分は、すでに見たように、すべて満悦をもって見られ、満悦は嫌悪を排除する。またわれわれは、ある自己の群の各成員を情愛をもって見るとき、その群を嫌悪をもって見ることはできない。

　悪意はより難しい問題を提示する。すでに見たように（原書一五〇ページ）、それは愛と両立しなくはないからである。しかし悪意が愛とともに見いだされるときには、それはつねに何らかの満たされない意欲（ふつうは、つねにではないが、性的な本性のもの）と結びつき、それに依存して見いだされるように思われる。この場合それは絶対的実在においては生じえないであろう。絶対的実在には満たされない意欲はないからである。

　この根拠からまた、満たされない意欲を含む他のさまざまな情動も退けなければならない。怒りはその一つである。嫉妬と羨望もまた、いかに分析されようとも、明らかに満たされない意欲に依存する。そして後悔と悔恨として知られる悲しみと謙遜の特別な変種もそうである。そうするとこれらのどれも絶対的実在のうちに場所を見いだしえない。

　第三に、絶対的実在は無時間的である。そしてこのことは、未来にのみかかわる希望と恐れを排除するであろう。それはまた、新しいもの、あるいは意外なものによってかき立てられる情動を意味する意味での驚異も排除するであろう。（偉大なもの、あるいは崇高なものによってかき立てられる情動という意味での驚異は是認の変種であり、それは下で考察される。）

　最後に、絶対的実在においては想定はありえない。われわれの思考作用はすべて知覚だからである。そしてどの問いも想定を含む。したがって絶対的実在においては問いはありえず、したがって答えられない問いもありえない。そしてこれは好奇心の存在と両立しない。

**480**　勇気と臆病はまったく不可能というわけではないように思われる。たしかにその領域はかなり狭められるであろう。それらは現在、勇気あるいは臆病がそれに関して示される悪が起こっていなければよい、あるいは将来起こらなければよい、という意欲とほとんどつねに結びついて生じるからである。この種の意欲は思考作用としては想定であり、したがって絶対的実在においては生じえない。それでも絶対的実在のうちには何らかの悪があり、したがって思うに勇気あるいは臆病の余地がある。しかしこの悪は、のちに見るように、善に比べて無限に小さくなければならないのだから、勇気と臆病の重要性は無限小である。

　残るのは、共感、是認、否認、誇り、謙遜、喜び、悲しみである。絶対的実在においてわれわれは、自分が愛する人々、あるいは情愛を感じる人々――われわれがそもそも知るであろう唯一の人格――に共感するであろう、という主張について何らかの証明を与えうるかどうか私は知らない。しかしわれわれが現在の経験から集めうるすべてのことは、われわれがそうするであろうという推定を与える。是認が欠けているとはほとんど想定できない。もし愛することが善であるなら、われわれは愛するものとして知覚する人格を、その愛に関して是認するであろう。そして存在することをわれわれが見た自己畏敬は誇りの一形態である。

　しかし否認と謙遜もまた生じることは可能である。是認は否認と、誇りは謙遜と、その両極的対立にもかかわらず両立しなくはない。四つすべてが、ある性質をもつことに関して人格に対して感じられるからである。こうして同じ実体が、是認をかき立てる性質と否認をかき立てる他の性質とをもつことがある。そして誇りと謙遜についても同じである。

　絶対的実在における自己の状態のうちに、謙遜あるいは否認をかき立てうるものは、あるとしてもほとんどないであろうことは確かであるように思われる。各自己は部分の組をもち、そのそれぞれは愛か自己畏敬かの状態であり、それらの部分のすべての部分は満悦の状態であろう。それでも少なくとも否認の余地はあるように思われる。否認は、もちろん、道徳的に悪いものによってだけでなく、悪いどの性質によってもかき立てられうる。絶対的実在のうちにある悪は、のちに見るように、苦の形をとるであろう。そして状態が苦しいものであるとき、そのかぎりでそれは否認をかき立てるであろう。

　またさらに、苦があるかぎり、おそらく悲しみの情動があるであろう。他方、各人格が、自分の知っている存在するすべてのものに同意する――しばしば情熱的に同意する――宇宙から、喜びが欠けていることはありえない。より特定的に言えば、愛は、満たされない意欲を引き起こさないかぎり喜びをもたらさなければならない。そして絶対的実在においてはそういうことはありえない。

　忠誠――私がその部分であるような共同体に対する情動という意味での――は、われわれの現在の経験においてきわめて重要であるから、絶対的実在におけるその位置について何かを知りうるかどうかを問わなければならない。それは、思うに、共同体に対する献身の情動――好感のより強い形の一つ――と、その共同体の部分としての私自身に対する自己畏敬の情動とが結びついたものにある。こうしてそれは、部分的には自己の群に対する情動にあり、部分的にはそれに依存する。そして上で（原書一六三ページ）、絶対的実在においてわれわれが自己の群に対して何らかの情動を感じるかどうかを決定する手段はないことを見た。

**481**　われわれはこれまで快と苦について何も語らなかった。それらは情動ではないが、快と苦がその成員であるような類――ときに感情の類と呼ばれる――は、情動と意欲に類比的である。快いことあるいは苦しいことは、思考作用の状態に、しかも思考作用の状態にだけ属しうる性質である。思考作用の状態が快いという性質をもつとき、それは快の状態であり、苦しいという性質をもつとき、それは苦の状態である。われわれの現在の経験においては、最も普通で典型的な快と苦は知覚――とりわけ感覚与件の知覚――である。しかし判断、想定、心像もまた快あるいは苦でありうる。

　絶対的実在における快と苦の位置について何か言えるであろうか。何らかの快があるであろうことは明白であるように思われる。誰もが愛するであろうからである。愛はたとえ苦が上回ることを含むとしても、つねに何らかの快を含む、とひょっとすると主張されるかもしれない。しかし愛が何らかの満たされない意欲と結びついていないときに快を含むことは疑いえない。そしてここではそうである。

　しかし、苦はないであろうとか、あるいは苦が快を上回らないであろうとさえ、ただちに結論することはできない。愛される人格の知覚は、快を与えると同時に苦を与えるかもしれず、しかも苦のほうが大きいかもしれないからである。また、満たされない意欲はありえないのだから苦もありえない、と論じることもできない。絶対的実在において満たされない意欲がありえない唯一の理由は、知覚以外の思考作用がないところでは、われわれは存在するものしか欲求できない、ということである。そしてこれは明らかに、存在するものの性質――それが別様であってほしいとけっして願われないという性質を除いて――について何の保証も与えることができない。われわれは、苦が、しかも多くの苦がある可能性を取り除いていない。もっとも、どのような苦があるにしても、われわれが無効な抗議と反抗という二次的な苦を免れるであろうことは確かであるが。

　快と苦の問題は第7部の終わり近くで再び考察される。そのときわれわれは、絶対的実在においては苦が快よりも無限に少ないであろうと信じる理由があることを見るであろう。
