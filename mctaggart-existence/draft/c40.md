### 第40章　意欲

**444**　自己は、その部分が決定的対応によって決定され、それ自身知覚であるなら、無限に至る部分の中の部分をもちうることをわれわれは見た。いまわれわれは、そのような自己が意欲をもちうるかどうかという問いを考察しなければならない。

　意欲という名はときにもっぱら意志の状態に用いられる。私はそれをより広い意味で――欲求と同義なものとして――用いることにしたい。こうして意欲でないような意志はないが、意志でない意欲は多くある。誰でも、明日ロンドンが地震で破壊されなければよいと欲したり、昨日自分がもっとよくふるまっていればよかったと欲したりするかもしれない。しかし誰も、自分が地震を制御したり過去を変えたりする力をもつと信じるのでないかぎり、そのどちらをも意志することはないであろう。

〔訳注〕volition を「意欲」、desire を「欲求」、will を「意志」と訳す。

　意欲は欲求する自己の部分である。この結論を支える考察は、知覚が知覚する自己の部分であるという結論のために上で（第37章原書九二〜九六ページ）与えた考察と類比的である。したがってここでそれを与える必要はない。

　欲求であるという性質を定義することはできるであろうか。私にはそれは単純かつ究極的であり、したがって定義できないように思われる。それを思考作用によって定義しようとする試みがなされてきた。それは自らを実現しようとする傾向をもつ観念である、と言われてきたし、またときに、何かが善である、あるいは快いという判断と混同されてきた。たしかにある意欲は自らを実現する傾向をもつ。もっとも、ロンドンが将来の地震から守られることへの意欲や、昨日自分がもっとよくふるまっていればよかったという意欲について、どうしてそうでありうるのか私にはわからないが。しかしたとえすべての意欲が自らを実現する傾向をもつとしても、意欲であるという性質は、自らの実現へと向かう観念であるという性質とは異なる性質であることは、私には明らかであるように思われる。そして何が善であるかについての判断はしばしば意欲と密接に結びついているけれども、判断と意欲とは異なるものである。

**445**　欲求は思考作用によって説明することはできないけれども、明らかに思考作用ときわめて密接に結びついている。すべての欲求は何かへの欲求である。たしかに、何を欲しているのかを知らずに何かを欲している状態として普通記述される欲求の状態がある。しかしこれらの場合に実際に起こっているのは、欲求の対象が広くて漠然としていること――それは、われわれが重苦しく感じる環境に何らかの変化が起こってほしいという欲求にすぎないかもしれない――、そしてどのような特定の変化がこの広く漠然とした欲求を実現するであろうかをわれわれが知らない、ということである。しかしそれは、いかに漠然としていようと、いかに否定的であろうと、つねに何かへの欲求である。

　そうすると私は、何かを欲求することなしに欲求することはできない。そして私は、欲求するものについて何らかの思考作用をもつのでないかぎり――それを知覚し、判断し、想定し、あるいは心像化するのでないかぎり――何かを欲求することができるであろうか。私にはそうできないこと、そして X についての私の欲求はそれについての私の思考作用を含むことは明白であるように思われる。

〔原注〕もちろん私は、私が X を欲していることを知るのでないかぎり X を欲求できない、と主張しているのではない。後者の知識はいずれにせよ論理的に欲求より後であり、しばしばまったく現前しない。われわれはしばしば欲求について反省することなしに欲求するからである。

　このことから、思考作用は意欲よりも独立した位置にあることが帰結する。いかなる意欲も思考作用とのある親密な関係においてでなければ存在しえないことは内在的に必然的であるが、すべての思考作用が意欲に対して対応する関係にあることは内在的に必然的ではないからである。少なくとも、われわれが何の欲求もいだかないものについて思考作用をもちうるという想定には、明白な不可能性はない。

　そうすると、欲求されるものはすべて思考作用の状態において与えられなければならない。しかし、二つの心的状態――欲求の状態でない思考作用の状態と、それに続くかそれに伴う、思考作用の状態でない欲求の状態――があれば十分であろうか。これは十分ではないであろう。その場合、欲求の状態のうちに、欲求されるものについての思考作用はないことになり、それがどうして他の何かではなくそれへの欲求の状態でありうるであろうか。

　それがその対象への欲求であるのは、欲求の状態と思考作用の状態とのあいだに存在する何らかの特別な関係のためである、と答えられるかもしれない。しかしこれは事実と両立しないように思われる。もしこの見解が正しいなら、X を欲求していることに加えて、私が X を欲求していることに気づいているとき、私は二つの状態 A と B とそれらのあいだの関係とに気づいていることになろう。A は X についての思考作用の状態であり、それがそうであるという事実は B へのその関係から独立しているであろう。その関係を捨象しても、A はなお X についての思考作用であろう。他方 B は、何かへの欲求であることなしに、ただの欲求であろう。さて、事情がそうでないことは明らかであるように思われる。X への欲求の状態は、X についての判断や想定が X についての判断や想定であるのと同じく直接にかつ無媒介に X への欲求である。それを X への欲求にするために、それ自身の外の何ものも必要としない。

**446**　そうするとわれわれは、われわれが到達した二つの結果をどのようにして調停できるであろうか。一方でわれわれは、欲求されるものについての思考作用なしにはいかなる欲求もありえない、と決定した。他方でわれわれは、この思考作用は欲求の状態から分かれた思考作用の状態ではありえない、と決定した。ただ一つの選択肢しかないように思われる。それを私は、それをはじめて私に示唆したムーア博士の言葉で述べよう。彼は、自分が採りたいと思う見解は「『基礎づける認識作用』はつねに、それに基づいて基礎づけられる作用と単に同時的であるだけでなくその構成要素であり、さらに、基礎づけられる作用の他の構成要素は、対象に異なる特定のしかたで向けられた別の完全な作用ではなく、単に認識作用の一つの性質にすぎない」というものだ、と言う。

〔原注〕『マインド』一九一〇年、四〇〇ページ、A・メッサー博士の『感覚と思考』の書評。「基礎づける認識作用」という表現はメッサー博士から取られている。

　この見解は私には正しいと思われる。欲求されるものについての思考作用とそれへの欲求とは同じ一つの心的状態であり、それは思考作用であるという性質と欲求であるという性質の両方をもつ。

　私の知るかぎり、この見解はムーア博士にはじまった。それは、思うに、この主題についての一般の意見に反している。しかしそれが示すかもしれない逆説の見かけはどれも、混同によるものと私は信じる。たいていの欲求の状態は、欲求の状態でない認識の状態と結びついており、これらの意欲的でない思考作用の状態が、欲求が要求する思考作用のすべてであると誤って想定されているのである。

　欲求の対象は欲求される前に思考されるのが一般である。われわれはまずそれが何であるかを認識し、それからそれを欲求するに至る。それを認識していてまだ欲求していないとき、まだ意欲の状態でない思考作用の状態がある。

　これは、あるものが、欲求される何か別のものの場合として欲求されるときにはつねにそうである。もし私が X であるものすべてを欲求することから出発し、それから Y を、それが X であるがゆえに欲求するなら、Y を欲求する前に、Y が X であることを私が知らなければならないことは明らかである。またもし私が X をそれ自身のために、Y を X への手段として欲求するなら、Y へのいかなる欲求にも、それが X への手段であるという知識が先立たなければならない。これらの場合、欲求でない思考作用が欲求に先立たなければならない。しかしあるものがそれ自身のために直接に欲求されるときでさえ、欲求されるものについての思考作用が欲求に先立つことは、必然的ではないが、可能であり、よくあることである。

　そうすると、欲求の状態ではなく、しかも欲求の状態と結びついた思考作用の状態がこれほどしばしばあるのだから、それらが関係する唯一の思考作用の状態であり、欲求の状態はそれ自身思考作用の状態ではない、と想定する誤りに陥りやすい。しかしその想定は誤っている。すでに見たように、つねに何かへの欲求である欲求の状態は、それ自身そのものについての思考作用でなければならないからである。

　そうするとわれわれは、思考作用のうちには欲求であるという追加の性質をもつものがある、と結論する。それはちょうど、欲求のうちに意志の状態であるという追加の性質をもつものがあるのと同じである。

　われわれの先の結論（原書一三三ページ）は、思考作用は意欲よりも独立した位置にある、というものであった。いかなる意欲も思考作用とのある親密な関係においてでなければ存在しえないことは内在的に必然的であるが、すべての思考作用が意欲に対して対応する関係にあることは内在的に必然的でないからである。しかしいまや、意欲に対する思考作用の独立性はさらにいっそう際立つ。すでに見たように、すべての意欲は思考作用でなければならないが、すべての思考作用が意欲であるという対応する必然性はないからである。

**447**　いまわれわれは意欲の状態についての他のさまざまな問いを考察しなければならない。その第一は、欲求されるものについて何か一般的なことが言えるかどうか、である。そのようなものの群は、欲求されているという性質や、それを欲求する自己によって思考されているという性質以外に、その成員に属する何らかの排他的共通性質をもつであろうか。私はもたないと思う。私は何かが自分に快を与えると信じるのでないかぎりそれを欲求できない、とときに考えられてきた。これにはふつう、私は何かが、それに代わる既知のどの選択肢が与えたであろうよりも大きな快を自分に与えると信じるのでないかぎり、それを意志できない、ということが付け加えられる。これが心理的快楽主義の説である。それに対するさまざまな議論をここで考察する必要はないと思う。今日の著作家によってそれが主張されることはまれだからである。

　もう一つのかなり似た見解は、人は自分が善であると信じるものしか欲求できない、というものである。これは私には心理的快楽主義と同じく事実と両立しないように思われる。私は自分自身の経験のうちに、また他の人々が自分の経験について私に与える説明のうちに、欲求されているその時に悪であると知られている対象が欲求されることを絶えず見いだす。

　そのような場合には欲求されるものの悪さが十分明晰に認識されていないのだ、とときに言われる。しかしそれが悪であるという判断は、完全な明晰さと完全な確実さとをもって下されている。それが十分に生き生きとしていないと言うことは、それが悪いと判断されたものをわれわれが欲求するのを妨げない、ということ以上の何ものにもならないように思われる。そしてこれは、ものは善であると判断される場合にだけ欲求されうる、という立場を放棄することである。

　またさらに、人が悪であると知っているものを欲求するなら、それは彼がそれを自分にとって悪であるとみなさないときだけだ、とときに言われる。言葉の厳密な意味では、あるものがある人にとって善であり別の人にとって悪であることは不可能である。善さは善いと判断されるものの性質であり、ものがある人にとって善であり別の人にとって悪であることは、二かける四がある人にとって八であり別の人にとって九であることができないのと同じく、ありえない。（ある人がそれを八であると信じ、別の人がそれを九であると信じることは十分可能であるが、そのことはそれを第二の人にとって九にするわけではない。起こっているのは、彼がそれを九であると信じており、しかも誤っている、ということだけである。）たしかに言葉のいくらかゆるやかな意味では、あるものが、全体としては善でないにもかかわらず、ある人にとって善である、と言うことは可能である。この場合意味されているのは、その結果のうち彼に影響するものは善であるが、そのすべての結果を合わせて取れば善より悪のほうが多い、ということである。しかしもし、誰も、自分自身へのその効果が善であると信じるのでないかぎり何も欲求できない、と主張されるなら、その理論はまたもや事実と衝突する。事実は、人が、義務のためにであれ盲目的な情念のためにであれ、自分の真の幸福であると信じるものを犠牲にしうることを明らかに示しているからである。

　そうするとわれわれは、一方の欲求と他方の快あるいは善さとのあいだに、いかなる共通の関係も確立されえない、と結論しなければならない。私の知るかぎり、欲求と他の何らかの性質とのあいだにそのような関係が確立されうると示唆されたことはない。したがってわれわれは第一の問いに否定的に答えなければならない。

〔原注〕また意志と、快あるいは善さとのあいだにも、そのような関係は確立されえない。人は自分が善である、あるいは自分にとって善であると信じるものしか意志できない、という見解は、人が、内在的に悪であり、それを欲求する自分自身にとっても悪であると知っているものを、単に欲求するだけでなく最終的に選択する多くの場合と両立しない。

**448**　第二の問いは、欲求が変化に対して何らかの必然的な関係をもつかどうかである。どの欲求も、何らかの変化が起こってほしいという欲求か、試みられている、あるいは試みられるかもしれない何らかの変化に抵抗したいという欲求かのどちらかでなければならない、とときに考えられている。しかし私は、これがすべての欲求について真であるとは思わない。それは多くの欲求について真であるが、欲求が変化に何の関係ももたない場合があるように思われる。神が存在すると信じる人の場合を取ろう。もし彼が神の存在についての通常の有神論的見解を受け入れるなら、彼は、神が存在しなくなることはありえないと信じるであろう。そのような人にとって、神の存在への欲求は変化への欲求ではありえない。彼は神が存在すると信じているからである。またそれは変化に抵抗したいという欲求でもありえない。神の存在という事実におけるいかなる変化も不可能であろうからである。しかしそのような人は神の存在への欲求をもちえないであろうか。私には彼は確かにもちうるように思われる。もし彼が神の存在を善である、あるいは自分にとって有利であると考え、そして善であるものは何であれ、あるいは自分の利益になるものは何であれ欲求するなら、彼は神の存在を欲求するであろう。あるいはまた、彼はそれを究極的に、理由なしに欲求するかもしれない。

　したがってわれわれは、欲求は必ずしも変化に向けられていない、と考えなければならない。それは第一次的には同意である。この語はまったく適切というわけではない。情熱的な欲求の場合には不適切に思われるからである。また私は、われわれが習慣的に欲求という語の代わりにそれを用いるべきだと示唆しているのでもない。しかしときにそれを同義語として用いるのは有益である。同意は変化への何の関係も含まないことは普遍的に認められており、こうしてわれわれは欲求がそのような関係を何も含まないことを明らかにするであろうからである。

**449**　われわれは、同意の否定的な相関物を何も持ち込まずに、欲求を同意として語ってきた。これはわれわれを第三の問いに導く。ある欲求は肯定的であるという性質をもち、ある欲求は否定的であるという性質をもつであろうか。ある欲求が否定的である――すなわち、何かがあらぬことへの欲求である――という意味があることは疑いない。そしてこの否定は単に欲求の帰結ではなく、その部分である。私が、事実として X と両立しない Y を欲求し、そのため私の欲求の満足が X が起こらないことを含む、というだけではない。もちろんこれはある場合には起こるが、他の場合には欲求は直接に何か否定的なものへ向けられている。私は A が X でないことを欲求し、それが私が欲求するすべてである。もし A が X でないなら、それは Y でなければならない、ということもあるかもしれない。しかし私はこれを知らないかもしれず、たとえ知っていても、私の欲求はそれに向けられていないかもしれない。それはもっぱら A が X でないことに向けられている。

　そうするとこの意味では、ある欲求は肯定的であり、ある欲求は否定的である。しかしより厳密には、否定的欲求というようなものはない、と言わなければならないと思う。欲求であるという性質は、一方は肯定的であるという性質をもち、他方は否定的であるという性質をもつ、二つの種をもつ類ではない。上で肯定的と否定的として区別した場合には、欲求そのものには何の違いもない。違いは欲求される対象のうちにだけある。一方は A が X であることへの欲求であり、他方は A が X でないことへの欲求である。欲求されるものの本性は異なるが、欲求の本性は同じである。

　この見解について私がもつ唯一の証拠は内観である。しかしそれが明示的に否定されたことがあるかどうか私は知らない。そして、欲求されるものは実際に否定的でありうることをわれわれが認めた、ということが思い起こされるなら、それは奇妙なもの、逆説的なものとはみなされないであろうと思う。

〔原注〕このことは、肯定と否定との違いは、より正確には、肯定的内容の肯定と否定的内容の肯定との違いとして記述される、ということを示唆する。そしてこれもまた内観によって支持されるように私には思われる。

　したがって、厳密に語るなら、欲求は肯定的でも否定的でもない、と言うべきである。しかしわれわれの結果は、すべての欲求が、肯定的欲求と否定的欲求の区別を受け入れる人なら誰でも肯定的と呼ぶであろう類に属することを含む、ということに注意すべきである。そのような人々は、肯定的欲求とは何かを受け入れるものであり、否定的欲求とは何かを拒むものである、と考えるであろうからである。そしてわれわれの見解は、すべての欲求は何かを受け入れる、というものである――もっとも、それが受け入れるものはしばしばそれ自身否定的な本性をもつが。

**450**　次に第四の問いに来る。上で（原書一三四ページ）、すべての欲求は思考作用の作用でもなければならないことを見た。すなわちそれは知覚、判断、想定、心像のどれかでなければならない。しかしこのことはなお、すべての欲求がそれらの類のうちの一つ、二つ、あるいは三つのうちに入り、その成員が欲求でありえないような類が一つあるいはそれ以上あるかもしれない、という可能性を残す。これがいまわれわれが考察しなければならない問いである。

　われわれの現在の経験においては、われわれの欲求のたいていは、命題で表現される何かへの欲求である。すなわち、欲求そのものは、思考作用としては判断か想定のどちらかでなければならない。そしてそのたいていは想定である。これは、私が存在すると信じていない何かを欲求するときにはそうでなければならない。もし私が明日晴れることを欲求したり、今日傘を忘れなければよかったと欲求したりするなら、これらの欲求は思考作用としては想定である。私は明日晴れるかどうか知らないし、今日傘を覚えていたことについては、それが起こらなかったことを知っており、それが起こったと信じることはできない。これらの欲求は想定でなければならない。そしてまた、私が一般的に善を、あるいは快いものを、あるいは自分にとって快いものを欲求するとき、私は、それが存在するかどうか私が知らないものの多くを欲求していることは明らかである。私は宇宙がどの程度善であり快いか、あるいは私自身の将来の生がどの程度快いかを知らない。そしてこれらの場合にもまた、欲求は想定でなければならない。

　欲求が思考作用として判断でありうるのは、人が自分の欲求するものがすでに実在すると信じている場合だけである。現在の経験においては、われわれの欲求のたいていはこの種のものではない。それらは、われわれが実在しないと信じている何かへの欲求か、それが実在するかどうか、あるいはどの程度実在するかをわれわれが知らない何かへの欲求かのどちらかである。そして人が自分の欲求するものがすでに実在すると信じているときでさえ、彼の欲求が思考作用として判断である必要はない。彼が、ものがそうであるという判断と、それがそうであるという想定との両方をもち、欲求であるのは後者であることも十分可能である。それにもかかわらず、現在の経験のうちには、「A は B である」という判断、あるいは「A が存在する」という判断が、A が B であるという事実、あるいは A が存在するという事実への同意であるという性質をももち、したがって欲求であるような場合があるように思われる。

**451**　欲求は知覚でありうるであろうか。私には、われわれの現在の経験においてさえ、そうでありうるように思われる。たしかに現在の経験においては、そのような欲求の例は数少ないであろう。現在の経験においては、私は感覚与件と私自身と私自身の部分以外の知覚をもたないからである。このことから、何か物質的なものであるか、それを含むような何かへのいかなる欲求も知覚ではありえない、ということが帰結する。また何か他の自己のうちにあるものであるか、それを含むような何かへのいかなる欲求も知覚ではありえない。また何らかの抽象的な結果――たとえば π が 3 であるべきか、あるべきでないか――へのいかなる欲求も知覚ではありえない。知覚でありうる唯一の欲求は、私自身、あるいは私自身の何らかの部分、あるいは何らかの感覚与件を、ある特性をもつものとして欲求するものである。そしてそれはもちろん、実体を、それがもつものとして知覚されている何らかの特性をもつものとして欲求するものでしかありえない。もしそれがその特性をもつものとして知覚されていないなら、その欲求は知覚ではありえず、何か他の思考作用的性格をもたなければならないであろう。

〔原注〕それは想定あるいは心像でありうるであろう。あるいは、もしその実体が、その特性をもつものとして知覚されてはいないが、それをもつと信じられているなら、判断でありうるであろう。

　そして欲求が、知覚対象がもつものとして知覚されている特性に向けられているときでさえ、それは知覚でありうるけれども、知覚である必要はない。私があるものを X であるものとして知覚するとき、同時に私がそれが存在すると判断したり、存在すると想定したりすることは可能であり、そのような場合には、欲求であるのは知覚ではなく判断あるいは想定であるかもしれない。

　こうして現在の経験におけるわれわれの欲求のたいていは知覚ではありえず、そのどれも知覚である必要はない。したがって、欲求であるような知覚の存在が容易に見過ごされうることは予想されることである。しかし注意深く見るなら、それらが存在すること――欲求であるような想定や判断のうちにわれわれが見いだすのと同じ、その内容への同意という性質をもつ知覚があること――を見ることができると思う。もちろんわれわれは、知覚に加えて知覚についての判断をもつのでないかぎり、自分がこれやあれを欲求していること、あるいはそもそも欲求していることを知らないであろう。知覚についての判断によらないかぎり、われわれは知覚について何らかの事実が真であることを知ることはできない。しかしそのことは、知覚が知覚であることを妨げないのと同じく、知覚が欲求であることも妨げない。

　同じように私には、心像が欲求であるという特性をもちうるし、ときに実際にもつ、と思われる。こうして現在の経験においては、欲求は思考作用の四つの種のどれにも属しうる。それは想定、判断、知覚、心像のどれでもありうる。

**452**　欲求は、欲求されるものが事実であるかないかに応じて、満たされているか満たされていないかのどちらかである。思考作用として想定であるような欲求は、満たされていることも満たされていないこともありうる。そして心像であるような欲求についても同じである。

　もし真なる判断が欲求であるなら、それは満たされている欲求でなければならない。もし「A は X である」という判断が欲求でもあるなら、欲求されているのは A が X であることである。そしてもしその判断が真であるなら、A は X であり、欲求は満たされている。もしその判断が偽であるなら、欲求は満たされていないが、満たされていると信じられている。もしのちに A が X でないことが見て取られるなら、もちろん、それが X であるという判断はもはや下されない。判断の代わりに、「A が X であること」という想定があり、それが欲求である。そしてその欲求は満たされていないことが知られている。

　欲求が思考作用として知覚であるとき、もしその知覚が正しいなら、それは満たされていなければならない。A を X であるものとしてとらえる知覚は、A を X であるものとして欲求するものであり、もしその知覚が正しいなら A は X だからである。しかしもしそれが誤った知覚であるなら、ひょっとすると A は X でなく、欲求は満たされていない。われわれはある知覚が誤った知覚であることを認めなければならないことを見た。したがって、知覚であるような欲求は、判断であるような欲求と同じく、満たされていないことがありうる、という可能性がある。

**453**　こうしてわれわれは意欲の本性についてある結果に到達した。そしていまわれわれは、これらの結果をわれわれの当面の問題――絶対的実在における意欲の位置――に適用しなければならない。絶対的実在においては、すでに見たように、すべての自己は、決定的対応によって無限に決定された部分の中の部分をもち、これらの部分はすべて知覚でなければならない。そうすると、もし絶対的実在のうちに何らかの欲求があるなら、それらは知覚でなければならない。そして知覚が欲求でありうることをわれわれは見た。

　しかしそれらが満たされていない欲求であることは可能でないであろう。すでに見たように、満たされていない欲求は、思考作用として、想定、心像、偽なる判断、あるいは誤った知覚であるような知覚のどれかでなければならないからである。われわれは（第47章原書二二八〜二三二ページで）、決定的対応の体系における部分である知覚は誤った知覚ではないことを見るであろう。したがってそれらは満たされていない欲求ではありえない。

　正しい知覚は満たされていない欲求ではありえないけれども、われわれの現在の経験においては、それは満たされていない欲求の対象でありうる。私は、ある事情のもとで性質 X をもつ知覚をもちたいという欲求をもつかもしれない。もしこれらの事情のもとで私がその性質をもたない知覚をもったなら、その知覚は欲求が満たされていないことを含むであろう。そしてもし私が自分の知覚は性質 X をもたないと判断したなら、私は自分の欲求が満たされていないことを知るであろう。しかしそのような場合、欲求そのものは想定であって正しい知覚ではないであろう――その対象である知覚は正しいかもしれないが。そして決定的対応の体系は正しい知覚以外のいかなる思考作用も含まないのだから、絶対的実在のうちのいかなるものも、満たされていない欲求でも満たされていない欲求の対象でもない、ということが帰結する。

**454**　しかし絶対的実在のうちにそもそも欲求はあるのであろうか。そしてもしあるなら、絶対的実在のうちのすべての知覚が欲求なのか、それともそのいくつかだけがそうであることが可能なのか。

　私には、この時点でわれわれがこれらの問いのどちらにも答えられるとは思われない。知覚のいくつか、あるいはすべてが欲求であることを妨げるものは何もない。知覚は欲求でありうるし、決定的対応の体系のなかのすべての知覚が欲求であることに何の難点もないからである。他方、私にはいままでのところ、その体系のなかの知覚のどれも欲求でない可能性を排除するものも何も見えない。たしかにその体系のなかの知覚は私自身の内容全体を尽くしており、私は確かに欲求をもつように見える。しかしわれわれの本性について真であるように見えることの多くは実際には真でないことを、われわれはすでに見た。欲求の現れについてもそうでないことを確信できるであろうか。

　しかし考察すべきさらなる事実がある。われわれは、各自己によって知覚されるものについて、それが一次部分とその二次部分とから成るという事実以上のことを知っている。すべての一次部分は自己であり、すべての二次部分は知覚だからである。こうしてわれわれは、自己によって知覚されるものは自己とその知覚であることを知っている。このことが情動に及ぼす結果は次章で考察され、それらの結果が、決定的対応の体系のなかのすべての知覚は欲求でもある、と決定する根拠をわれわれに与えることをわれわれは見るであろう。
