　さらに、判断は意味をもつ。そして意味をもつものが、その要素が意味をもつような複合体であるとき、その複合体の意味は要素の意味に依存する。したがって判断の意味は、究極的には、その項のうちそれ自身意味をもち、しかも意味をもつ部分をもたないような項の意味に依存する。そしてもし判断が判断の中の判断から無限に成るとしたら、その意味は、最終項をもたない系列の最終項の意味に依存することになろう。こうしてそれは意味をもたず、判断ではありえないであろう。

　想定もまた決定的対応の関係を与えないであろう。想定の内的構造は判断のそれと同じである。唯一の違いは、判断が主張であるのに対して想定はそうでない、ということである。判断がすべて判断であるような部分の組をもちえないのとちょうど同じく、想定もすべて想定であるような部分の組をもちえない。そして判断についてと同じく想定についても、それは意味をもつ、ということが真である。したがって判断にあてはまったのと類比的な理由から、想定が、そのすべてが想定であるような部分の部分へと無限に分割されることは不可能である。

**422**　残るのは心像である。私は、いま知覚していないもの、かつて知覚したことのないもの、あるいは存在しないものを思い描く――この言い回しはゆるやかだが役に立つ――ことができる。私は白地の上の赤い円盤を思い描くことができる。私は、過去に私が感じた歯痛――それは存在した――を思い描くこともできるし、現在私が感じている歯痛――それは存在しない――を思い描くこともできる。私は、クロムウェルのチャールズ一世への不信――それはおそらく存在した――を思い描くこともできるし、クロムウェルの若僭王への軽蔑――それは確かに存在しなかった――を思い描くこともできる。

〔訳注〕「若僭王」（Young Pretender）はチャールズ・エドワード・ステュアート（1720〜1788年）のこと。クロムウェル（1599〜1658年）の死後に生まれた人物であり、クロムウェルが彼を軽蔑したことはありえない。

　私はこれを行う過程を心像化と呼び、そこに含まれる心的状態を心像、あるいは心像の状態と語ることにしたい。心像化されるものを私は心像対象と呼ぶことにする。

〔訳注〕原語は imaging（心像化・心像）と imaginatum（心像対象）。perception／perceptum（知覚／知覚対象）に対応させた造語である。

　私が imagining（想像）の代わりに imaging を用いるのは、前者の語が曖昧だからである。たとえば、うぬぼれた人について、彼は自分がシェイクスピアに匹敵すると想像している、と言われるであろうが、意味されているのは、彼がそれを信じているが、誤って信じている、ということである。他の場合には、想像と呼ばれるものは実際には想定である。ある人が百万長者になったら何をするかを想像する、と言われるとき、しばしば意味されているのは、彼が百万長者になったという想定が真であったならどのような命題が真にされるかを考えている、ということである。そしてまた、これらの場合には心像化のないところで想像について語るが、他方われわれが想像とは呼ばないような心像化の場合もある。私は昨日見た猫を思い出すかもしれず、この記憶はその要素として猫の心像化をもつかもしれない。しかし私が猫を想像したとは言われないであろう。

　私は image（像）の使用も避けてきた。それもまた曖昧だからである。それはときに心像化の状態に、ときに心像対象に用いられる。実際それはしばしば同時に両方に用いられる。両者の区別が無視されているからであり、それは知覚と知覚対象とがきわめてしばしば互いに区別されてこなかったのと同じである。

　心像は、その内的構造において知覚に似ており、判断や想定とは似ていない。判断や想定は、第45節で与えた意味での命題である。われわれは何かについて何かが真であると判断し、あるいは想定する。しかし心像化には、知覚と同じく、「〜ということ」はない。心像対象は、知覚対象と同じく実体であり、われわれが心像化するのはその実体である。しかし心像対象は、知覚対象が特性をもつものとして知覚されるのとちょうど同じく、特性をもつものとして心像化される。このことは、われわれがそれらの特性の現前を主張する判断を下しうるという事実によって証明される。たとえば私は、いま私が心像化しているものは白地の上の赤い円盤であるという特性をもつ、と判断することができる。

　そして、われわれの現在の経験において心像化されうるのは、われわれの現在の経験において知覚されうる種類のものだけである。すなわち、感覚与件と、内観によって知覚されうる種類の心的実在とである。たしかにわれわれは普通ウェストミンスター寺院を心像化すると語るが、それは知覚されえない。しかしそれならわれわれは、ウェストミンスター寺院は見られえないにもかかわらず、同じく普通にそれを見ると語る。一方の場合にわれわれが心像化し、他方の場合に知覚するのは感覚与件である。もし私がタワー・ブリッジの上でのジョージ三世の処刑を心像化すると言うなら、意味されているのは、私がある感覚与件を心像化しており、それは、それを（私のようにただ心像化するのではなく）知覚する人が、少なくとも現象的にはそのような処刑が行われているということが真である、と普通は判断するようなものだ、ということである。

〔原注〕心像化と知覚とのもう一つの結びつきは、われわれの現在の経験においては、誰も、以前に知覚したことのないような単純な特性をもつものとして何かを心像化することはできない、ということである。

　しかし別の点で心像化は知覚や判断と根本的に異なり、想定に似ている。知覚と判断は認識である。それらは知識を与えると称し、誤っていないかぎり実際に知識を与える。しかし心像化は知識を与えると称さない。もし私が何かを「クロムウェルの若僭王への軽蔑」という記述にあてはまるものとして心像化するなら、その心像化の行為は、「クロムウェルが若僭王を軽蔑した」という想定が偽と呼ばれうるのと同じ原理で、ひょっとすると偽と呼ばれうるかもしれない。しかし私が一方を想定することにおいて誤っていないのと同じく、他方を心像化することにおいても誤ってはいない。知識を与えるという主張がないところでは、誤りはありえない。

**423**　心像化は、決定的対応によって決定された、無限に至る部分の中の部分の系列をわれわれに与えうるであろうか。判断と想定がそのような系列を与えることを妨げた二つの障害は、ここにはあてはまらない。知覚の部分が知覚でありうるとわれわれに信じさせたのと同じ考察が、心像の部分が心像でありうるとわれわれに信じさせるであろうからである。そして心像は、知覚と同じく、意味をもたない（もちろん、そのどちらの記述も意味をもつであろうが）。したがって心像は、そのすべてが心像であるような部分の中の部分の無限系列をもちうるであろう。その系列は悪しきものではないであろうからである。

　たとえば、B と C が自分自身と互いとそのすべての部分とを心像化すると想定しよう。そうすると B は、C を、C による B と C の心像を、B と C の心像についての C による B と C の心像を、以下無限に、心像化するであろう。そして B はまた、自分自身の心像についての同様の心像の系列をもつであろう。

　しかし、心像化の本性についてのわれわれの見解を修正せざるをえなくするような難点が生じる。そしてこの難点は心像対象の本性と結びついている。心像対象――それを心像化する心的状態とは区別された、心像化される何か――があることは明らかであるように思われる。これは、思うに、内観から明白である。私の心像化の状態は、それ自身以外の何かを心像化する。そしてこのことは知覚の類比によって確証される。知覚においては、知覚とは区別された知覚対象が確かにあるからである。心像化とは区別された心像対象の実在がつねに認識されてきたわけではないとしても、驚くにはあたらない。比較的最近まで、知覚対象を知覚から区別することを認識するのは例外的なことであったからである――この場合のほうが心像化の場合よりもその区別は認めやすいにもかかわらず。

　そうすると、心像化があるところにはどこでも心像対象がある。しかし心像対象はどのような本性のものであり、何の部分なのであろうか。

　ある場合には、私が何かをそれをもつものとして心像化している性質をもつものが何も存在しないことは確かである。過去にも現在にも未来にも、クロムウェルが若僭王に対していだいた軽蔑であるという性質をもつものは何も存在しない。また、それを知覚する人に、ジョージ三世がタワー・ブリッジの上で処刑されていると普通は示唆するであろうような感覚与件の群であるという性質をもつものも、何も存在しない。

　またこの難点は、そのようなものは存在することなしに実在しうる、という示唆によって取り除くこともできないであろう。すべての心像対象は、すでに見たように、実体である。そして実体は存在することによってのみ実在しうることは明らかである。もしヘンリー八世と私の机とが実在するなら、それらは存在する。もしアーサー王と円卓とが存在しないなら、それらは実在しない。

　ときに、心像対象を心像化する自己の心のうちに置くことによってこの難点を取り除こうとする試みがなされてきた。しかし難点はこのようにして取り除くことはできない。第一に、もしものがまったく存在しないなら、それは自己のうちにも存在しえない。そして第二に、ものが心像化する自己の外に存在しうる多くの場合に、それがその自己のうちには存在しえないことは明らかである。私はクロムウェルと、彼のチャールズ一世への不信とを心像化できる。そしてクロムウェルと彼の不信とが私の外に存在したことは十分ありうる。しかしクロムウェルも、彼のチャールズ一世への不信も、彼の若僭王への軽蔑も、私の部分として存在しえないことはまったく確かである。また私は、敵の飛行船を撃破したとしたらいだいたであろう私の誇りを心像化できる。しかし私は一度もそれを撃破したことがないのだから、問題の誇りは私の部分ではありえない。

**424**　どのような解決が残っているか。私は、ただ一つの解決しか可能でないと思う。それは、心像対象はつねに存在するが、つねにそれがもつものとして心像化される性質をもって存在するわけではない、ということ、そして心像化は実際には知覚であって、それは第一に、それ自身ときに誤っており、第二に、今度は内観において誤って知覚され、そのため実際には知覚であるのに心像化であるように現れるのだ、ということである。第一の誤り――状態のうちの誤り――は、何かが、実際にはその軽蔑でないにもかかわらずクロムウェルの軽蔑として現れることを許すであろう。第二の誤り――状態についての誤り――は、実際には知覚であるものが心像化として現れることを許すであろう。

　この見解は一見したところ逆説的に見えるかもしれない。しかしほかにどのような見解が可能であろうか。心像対象がなければならない（すなわち、心像化の状態として現れる状態の対象がなければならない）。心像対象の本性は実体であるという性質を含む。もしそれが存在する心像化の状態の心像対象であるなら、それは実在しなければならない。そして実体は存在しないかぎり実在しえない。心像化の状態はその心像対象の気づきであり、存在する実体の気づきは知覚でないとすれば何であろうか。もしそれが知覚であるなら、それはある場合には誤った知覚でなければならない。ある場合にはそれは、その知覚対象を、それが確かにもたない性質をもつものとして知覚するからである。そしてもしその状態が、実際には知覚であるのに心像化として知覚されるなら、それ自身誤って知覚されているのでなければならない。

　われわれの立場は、第56章で見いだすように、誤って知覚された知覚がどのようにして心像化として現れうるかを詳細に説明することが可能であると見いだすときに、強められるであろう。そしてそれはまた、第44章で、知覚として現れる知覚でさえ多くの場合誤った知覚であることを見、第45章で、誤った知覚の存在を疑いの目で見る理由はないことを見るときに、付随的に強められるであろう。

　そしてそれはまた、一見したところ判断、想定、あるいは特性の気づきであるような状態が実際には知覚であり、それらが何か異なるものとして現れるのはそれらが誤って知覚されているためである、ということを見ることによっても、付随的に強められるであろう。しかしこれら三つについての議論の筋道は、心像化についての議論とは異なることに注意しなければならない。結論はそれぞれの場合に同じ――その状態は実際には誤って知覚された知覚である――であるが、それは異なるしかたで到達される。判断、想定、特性の気づきの場合には、それらが現れるとおりのものでないと想定する理由は、この著作で以前に到達した結果に依存する理由以外にはない。いかなる実体も、無限に至る部分の中の部分をもたないかぎり存在しえない、とわれわれは決定した。そしてこの章で、実際に判断、想定、あるいは特性の気づきであるようないかなるものも、無限に至る部分の中の部分をもちえないことを見た。これは心像にはあてはまらない。実際に心像化であるような状態も無限に至る部分の中の部分をもちうることを見たからである。心像化として現れるものが実際には知覚でなければならない理由は、いま与えたものである。

　それにもかかわらず、われわれはクロムウェルの若僭王への軽蔑の実在を取り除いていない、と反論されるかもしれない。私が、その軽蔑であるという性質をもたない何かを誤って知覚し、それをその軽蔑であるものとして誤って知覚する、ということを認めるとしても、私は結局その軽蔑について考えているのだからである。そして私は実在しないものについて考えることができるであろうか。これは誤った知覚一般についての問いであって、特に心像化として現れるものについての問いではない。それは第52章で論じられ、そのような知覚はそのような軽蔑の実在を含まないであろうことをわれわれは見いだすであろう。

**425**　記憶については何と言うべきであろうか。私は、記憶がわれわれのすでに考察していない要素を何か含むとは思わない。私には、記憶は、心像対象として現れる何か別のものについての判断として現れる認識であるように思われる。それが認識であることは明らかである。それは過去についての知識を与えると称し、忠実であるときには実際に与えるからである。そしてそれは明らかに知覚であるようには現れない。われわれの現在の経験において知覚であるように現れるすべてのものは、それ自身と同時的なものについての情報しか与えないが、記憶はそれ自身より早いものについての情報を与えるからである。

　それは知覚として現れることなしに存在するものの認識として現れるのだから、判断としてしか現れえない。そして内観においてそうであることは明らかであるように思われる。それは、現在の心像対象が過去に知覚されたという判断として現れる。

　しかしそのような判断のすべてが記憶であるわけではない。私は自分が子どもの頃に何かをしているのを心像化し、自分がそれを実際にしたと信じるかもしれず、この信念は真でありかつ十分な根拠をもつかもしれない。しかしもし私がそれを、もっぱら自分がそれをしたと誰か別の人に言われたという根拠で信じているなら、記憶はない。何が記憶の判断をこのような判断から区別するのかという問いは興味深く重要であるが、われわれの現在の目的にはかかわらない。もし記憶が判断であるなら、それが無限に至る部分の中の部分の求められる系列をわれわれに与ええないことは明らかだからである。

**426**　これでわれわれは、一見したところ自己のうちに存在する思考作用のさまざまな形のすべてについて語った。しかし意欲と情動についてはどうか。これらについて私は、第40章と第41章で、意欲と情動の状態は実際には思考作用の状態であり、それはある追加の性質をもつことによって他の思考作用の状態から区別される、ということを示そうと努めるであろう。

　この章の結論は、精神は、物質や感覚与件とは異なり、実際に存在しうる、ということである。しかしそれがそうしうるのは、それが知覚と知覚の群以外のいかなる部分も含まない場合だけである。いま述べたように、意欲と情動は思考作用であることが見いだされるであろうからである。そして、一見したところ精神のうちに見いだされる、知覚以外の四種の思考作用のうち、判断、想定、特性の気づきは無限に至る部分の部分をもちえないことを見た。したがってこれらの種類のどれかであるように現れるものは、実際には他のもののどれかでなければならない。これは知覚と心像とを自己の唯一の可能な状態として残す。そして心像として現れるものは実際には知覚であることが示されたのだから、知覚が唯一の可能な状態として残されるのである。
