### 第11章　十分な記述

**100**　実体はもちろん定義できない。それは個別的だからである。定義は普遍者である特性にしかあてはまらず、しかも単純でない特性にしかあてはまらない。定義とは、定義される特性が分析されうるより単純な特性――究極的には絶対的に単純な特性――を述べることである。しかし実体は定義できないにせよ、記述することはできる。それは、その実体がもつすべての性質――その実体が立つ関係から派生する性質を含む――によって、多かれ少なかれ記述される。（特性もまた、定義できるにせよできないにせよ、それがもつ性質によって記述できる。）

　記述は、そのどちらによっても、それが適用されるものを他のあらゆるものから区別できるようになる、という点で定義に似ている。単純でなく、したがってそもそも定義を許すすべての特性は、それ自身以外の何ものの定義でもない完全な定義をもつ。実際、完全な定義以外のものはふつう定義とは呼ばれない。「直線図形」が三角形の不完全な定義であるとは言わないであろう。それは定義の一部である、と言うだけであろう。

　他方、不完全な記述も記述と呼ばれる。ヘンリー七世をイングランドの君主として語るとき、われわれは彼を記述している。もっともそれは彼をリチャード二世やエリザベスから区別しない特性であるが。したがってわれわれは、記述と排他的記述とを区別しなければならない。

**101**　排他的記述とは、ただ一つの実体にしかあてはまらず、したがってその実体がその記述によって絶対的に同定されるような記述を意味する。さらにまた、排他的記述と完全な記述とを区別しなければならない。実体の完全な記述は、その性質のすべて――一次的性質と反復的性質の両方――から成り、したがってもちろん無限に多くの性質から成るであろう。前章で達した結果から、完全な記述は排他的でなければならないことが帰結する。二つの実体がその本性において完全に同じであることはなく、したがって一つの実体の本性の完全な説明が別の実体の本性について真であることはけっしてありえないからである。しかし排他的記述は完全である必要はない。「あらゆる存在者のうち最も有徳な者」は、いかなる可能な存在者の完全な記述でもありえないであろうが、それが真であるどの存在者についても排他的記述であろう。それは一つより多くのものについて真ではありえないからである。

　記述は性質による。しかし関係から派生する性質による記述は、ときに実体を持ち込む。ヘンリー七世を君主の父と記述するなら、私は彼をまったく特性によって記述している。しかし彼をヘンリー八世の父と記述するなら、記述のなかに実体――ヘンリー八世という実体――が入ってくる。そしてそれは記述にとって本質的である。「ヘンリー八世の父」は「君主の父」とはまったく異なる記述である。後者は、前者によって記述されない多くの実体を記述するからである。

　部分的に実体によって表現された記述は、その記述のなかで挙げられた各実体がそれ自身記述されていないかぎり、記述される実体についてのわれわれの知識を増すのに何の効果ももたないように思われるかもしれない。というのも、実体が記述なしに知られうるなら、記述はまったく必要ないからである。実体が記述なしに知られえないなら、記述の一部をなす記述されていない実体は知られていない。そして未知のものによって何かを記述しても役に立たない。

　しかしこれは、私が知覚によって気づいている実体がいくつかあり、それらによって他の実体を記述することは、私が気づいていないものを、私が気づいているものによって記述することでありうる、という事実を見落としている。たとえば私は自分の机に気づいているのではない。そして私がそれを「これらの視覚的感覚与件の原因」――記述をしているあいだに私が知覚している感覚与件という意味で――と記述するとき、私はそれを、実体も特性も含めてそのすべてに私が気づいているものによって記述している。だからこの記述は、感覚与件の排他的記述を含んでいないにもかかわらず、排他的でありうる。

**102**　記述されていない実体を含む排他的記述と、まったく特性による排他的記述とを区別するために、後者を十分な記述と呼ぶことにしたい。

　十分な記述は、ただ一つの単純性質から成ることもありうる。ただ一つの実体しかその性質をもたないなら、それをもつ実体は、それをもつものとして十分に記述されるであろうからである。それはただ一つの複雑性質から成ることもありうる。あるいはいくつかの別々の性質から成ることもありうる。その場合、それ自身は、他の性質をその部分とするただ一つの複合性質であろう。

　ただ一つの単純性質ではない十分な記述も、「あらゆる存在者のうち最も有徳な者」のように比較的単純でありうる。しかしそれは単純さから無限に隔たっていることもありうる。それはいかなる心もそれを把握できないからといって十分な記述であることをやめはしないからである。この章ののちに見るように、ある場合には、単純さからのそのような無限の隔たりは、悪しき無限を持ち込むことによって記述の十分さを壊すであろう。しかし記述が「A は性質 X、性質 Y、性質 Z……をもつ」という型のものであるなら、A 以外のあらゆるものを排除するのに必要な性質の一覧は、悪しきものとなることなく無限でありうるであろう。

　一つの実体は一つより多くの十分な記述をもちうる。たとえば「あらゆる存在者のうち最も有徳な者」と「あらゆる存在者のうち最も力ある者」とが同じ人の記述である、ということもありうるであろう。

**103**　すべての実体は十分な記述をもつであろうか。ある特定の記述が何らかの存在する実体の十分な記述であることをわれわれが知りうる場合は、ごくわずかしかない。しかし、それらの一つが何らかの実体の記述であるなら、それがその実体の十分な記述であるような記述は多くある。たとえば「あらゆる存在者のうち最も有徳な者」はそうである。それはただ一つの実体にしかあてはまりえないからである。しかしそれが何らかの実体にあてはまることは確かではない。有徳な存在者が存在することは、たしかに自信をもって肯定できるかもしれない。しかし二つの存在者が他のどれよりも有徳で、しかも徳において互いに正確に等しい、ということは絶対的に不可能ではない。その場合、あらゆる存在者のうち最も有徳な者は誰もいないであろう。そしてそれが誰かを記述していることを確信していたとしても、それが誰を記述しているかはわからないであろう。たとえ私がたまたまあらゆる存在者のうち最も有徳な人に会ったことがあると想定しても、自分自身の調査によってか信頼できる報告によってか、他のすべての有徳な存在者の徳の限界を知るのでないかぎり、彼がそうであることを知りえないであろう。

　それが何かにあてはまるならそれの十分な記述であろうような比較的単純な記述のほとんどは、この型のものである。それらは「性質 X を最も多く（あるいは最も少なく）もつもの」という形をしている。そして前の段落で述べた難点は、そのそれぞれの場合に生じる。

　空間と時間による記述は十分であるように見える。「一五〇〇年のイングランド王」はヘンリー七世の十分な記述と間違えられるかもしれない。しかし「イングランド」をある特定の実体の固有名と取るなら、その記述は、排他的ではあっても十分ではないであろう。唯一の他の選択肢は、「イングランド」を記述的なもの――公式の称号がイングランドである国、あるいはその名で習慣的に呼ばれる国、という意味――と取ることである。しかしその場合、宇宙のどこかの時と場所に――ひょっとすると別の惑星に――同じしかたでイングランドと呼ばれる別の国がないとは確信できない。そしてもしそうなら、ヘンリー七世がその王であった国の十分な記述は得られておらず、したがって彼についてのわれわれの記述も十分ではないであろう。そして時間についても同様の難点が生じる。暦の起点となる出来事から一五〇〇年というのは、同じしかたで記述されうる他の出来事がかつて起こったことも今後起こることもないと確信できないかぎり、十分な記述ではないからである。たとえばローマ建国から年を数えることは曖昧さがないとは言えないであろう。宇宙の歩みのなかで、その名をもつ都市がいくつも建設されないとは確信できないからである。

　ついでに述べておけば、多くの暦は、それを定めた人々の信念が真であるなら、日付の十分な記述を与えるであろう。われわれの現在の暦は、その暦を定めた人々が神の受肉であり、時間の歩みのなかでの唯一の神の受肉であると信じた出来事から始まる。もしこれが真なら、「受肉から一五〇〇年後」は日付の十分な記述であろう。イスラム暦の場合も同じであろう。その宗教は、思うに、その創始者に宇宙における唯一無二の位置を帰し、その暦を彼の生涯のある出来事から数えているからである。

　さらに、同じ信念が真であるなら、場所の十分な記述を作ることも可能であろう。メッカ、メディナ、エルサレム、ターイフは、ムハンマドの生涯へのそれらの関係によって十分に記述でき、ムハンマド自身は神への彼の唯一無二の関係によって十分に記述できるであろう。そして他のどの場所も、これら四つへのその関係によって十分に記述できるであろう。

　しかし、ある人物や出来事の唯一無二の性格についてのこれらの見解のどれも受け入れないなら、空間と時間によっては十分な記述は得られない。たしかに、時間に限界があるなら、日付はそれらの限界への関係によって十分に記述できるであろう。しかし、たとえ時間がこのしかたで限られているとしても、われわれの現在の知識では、そのような十分な記述を知ることは不可能であろう。

　もちろん、空間と時間によるかなり単純な排他的記述は多くある。たとえば、ヘンリー七世を、私がこの記述をしている惑星において、私がそれをしている時点より四一九年前のイングランド王、と記述するのがそうであろう。しかしこれは十分な記述ではない。それは私が記述をしているという出来事を十分に記述しておらず、それについての私の直接の知覚に頼っているからである。

**104**　こうして、与えられた記述がある特定の実体の十分な記述であることをわれわれが知りうる場合はごくわずかしかない。すべての実体が十分な記述をもつことは確かであろうか。すべての実体は排他的記述をもたねばならない。いかなる実体も他のどの実体ともまったく同じ本性をもつことはできないからである。しかし、A は B に対して関係 X をもつ、という事実を持ち込まなければ A を排他的に記述できない、ということはありえないであろうか。そしてこれは、そのままでは十分な記述に入ることはできない。それは特定の実体を持ち込むからである。しかもそれなしには何ものも十分な記述ではありえないであろう。すべての十分な記述は排他的でなければならないからである。

　しかし、A が B に対して関係 X をもつという事実は、十分な記述に入りうるようなしかたで述べることができるかもしれない。まず、A が B に対して関係 X にある唯一の実体であるだけでなく、何に対してであれ関係 X にある唯一の実体である、ということがありうる。その場合には「B に対して関係 X をもつ」を「何らかの実体に対して関係 X をもつ」で置き換えることができ、それはこの仮説の上では同じく排他的であり、特定の実体を持ち込まないので十分であろう。

　しかし A 以外の実体が B 以外の実体に対して関係 X をもつなら、この置き換えはできない。しかしもし B の十分な記述――たとえば「性質 P と Q をもつ」――を見いだせるなら、「B に対して関係 X をもつ」を「性質 P と Q をもつ唯一の実体に対して関係 X をもつ」で置き換えることによって、A の十分な記述を得ることができる。

　さらにまた、特定の実体を持ち込まない B の排他的記述が見いだせない――たとえば「C に対して関係 R をもつ」――としても、A の十分な記述はなお可能である。これは二つのしかたで起こりうる。たとえ A 以外のある実体が B 以外の実体に対して関係 X をもち、たとえ B 以外の実体が C 以外の実体に対して関係 R をもつとしても、A 以外のいかなる実体も、何らかの実体に対して関係 R をもつどの実体に対しても関係 X をもたない、ということがありうる。この場合には、「B に対して関係 X をもつ」を「別の実体に対して関係 R をもつ何らかの実体に対して関係 X をもつ」で置き換えることによって、われわれの記述を十分なものにすることができる。

　あるいは第二に、もし C の十分な記述――たとえば「性質 S と T をもつ」――を見いだせるなら、A の十分な記述に達するであろう。その場合、A の排他的記述に「性質 S と T をもつ唯一の実体に対して関係 R に立つ唯一の実体に対して関係 X に立つ」を含めることによって、A の排他的記述が得られるであろうから。そしてこの記述は十分であろう。

　さらにまた、別の特定の実体を持ち込むことなしには――たとえば、それが D に対して関係 U をもつ、と言うことなしには――C を排他的に記述できないとしても、A の十分な記述に達する同じ見込みがふたたび生じるであろう。二つのことのどちらかが起こるときにはいつでも、A の十分な記述を見いだすであろう――実体 B、C、D 等々の系列のなかで、十分な記述をもつものに達するときか、あるいは「関係 U をもつ実体に対して関係 R をもつ実体に対して関係 X をもつ……」という複雑な関係が非常にまれになって、A 以外の何ものも何かに対してそれに立たなくなるときかである。

**105**　しかし、そのどちらもけっして起こらず、A の排他的記述に含まれる実体の系列がけっして終わらない、と想定したらどうか。その場合には、十分な記述をもたない実体の事例を得ることになるのではないか。

　しかしこの事例は起こりえない。そのような無限系列は悪しきものであろうからである。前章の結果によって、A は他のすべての実体と非類似でなければならない。このことの可能性は B の存在に依存し、B の存在は他のすべての実体とのその非類似に依存する。そしてこれは C の存在に依存し、これは他のすべての実体とのその非類似に依存し、以下同様である。この系列が無限であるなら、それは悪しきものである。A の存在から出発して、前の各項は後のすべての項を要求し、したがって系列が完結することを要求するが、それは完結しえないからである。したがって、系列が無限であるなら、A は他のすべての実体と非類似であることはできない――言い換えれば、排他的記述をもつことはできない――したがって存在しえない。それゆえ、A が実際に存在するなら、系列は無限ではありえない。そして系列が無限でないなら、A は十分な記述をもつ。したがってすべての実体は十分な記述をもたねばならない。

　注意すべきは、実体が十分な記述をもたねばならないことの証明の基礎とした、実体が排他的記述をもたねばならないという必然性は、排他的記述なしには誰もそれを他の実体から区別するようには知りえないであろう、という根拠に基づくのではない、ということである。そのような議論は三つの根拠で妥当でないであろう。第一に、すべての実体が他の実体から区別されるようなしかたで知られうるものでなければならない必然性はないように思われる。それらは異なると知られることなしに異なる実体でありうるからである。第二に、排他的記述は、すでに見たように、無限に多くの性質から成ることがあり、その場合にはわれわれのような心には知りえないであろう。第三に、実体は直接に知覚されるときには、それの何らかの記述を必要とすることなく、他の実体から区別されたものとして知られる。実体が排他的記述をもたねばならないという必然性は、二つの実体は完全に類似することはできず、他のどの実体とも完全に類似していない実体は必然的に排他的記述をもつ、という事実から生じるのである。
