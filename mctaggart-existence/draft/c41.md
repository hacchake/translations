### 第41章　情動

**455**　いまわれわれは、決定的対応によって決定された知覚の系列が情動に対してどのような関係に立つかを考察しなければならない。情動とは何か。注意すべき第一の点は、情動が多くの種をもつということである。これは、そのような種をもたない意欲との際立った違いである。たしかに思考作用は種に分けられる――特性の気づき、知覚、判断、想定、心像。しかしそれらは五つしかなく、私の知るかぎり、それらが思考作用の全範囲を覆わないとか、そのどれかが根本的でないとか示唆する人は誰もいないであろう。情動の場合にはわれわれははるかに多くの種をもち、またそのどれを根本的なものとして取るべきか、どれを他のものの変種として扱いうるかも必ずしも明らかではない。しかし、体系的な完全さを装うことはないが重要な脱落を含まないような一覧を作ることはできる。そのような一覧として私は次のものを提案する。好感と嫌悪、愛と憎しみ、共感と悪意、是認と否認、誇りと謙遜、喜びと悲しみ、希望と恐れ、勇気と臆病、怒り、驚異、好奇心。これらのたいていは、すべてではないが、両極的に対立する対にまとめられていることに気づかれるであろう。

〔原注〕愛と憎しみは好感と嫌悪の変種であるが、この章の経過のなかで明らかになる理由から、それらを別に挙げるのが便利である。是認と否認は、それらが性質に向けられる、あるいはそれらの性質をもつことに関して実体に向けられるという事実によって、好感と嫌悪から区別される。他方、好感と嫌悪は、実体の性質によって決定されうるとはいえ、全体としての特定の実体に向けられる。後悔は、思うに、悲しみの変種として取るべきであり、悔恨は謙遜の一種――特定の種類の原因によって決定されるもの――である。忠誠の問題はのちに考察する。

　情動そのものは、思うに、定義できない。思考作用や意欲と同じく、それは究極的な概念である。しかしこれほど多くの例があれば、何が意味されているかを同定するのに何の難しさもない。

**456**　すべての情動は何かに向けられている。私は自分自身を誇り、誰かを愛し、何かを希望し、何かについて心配する。そして私は、情動が向けられているものについて何らかの思考作用をもつのでないかぎり、情動をもつことはできない。

〔原注〕全般的な高揚や沈鬱の状態において、われわれは何にも向けられていない喜びや悲しみの情動をもつ、と反論されるかもしれない。しかし思うに、そのような状態においては、情動はその瞬間にわれわれの思考作用のうちに入るすべてのもの、あるいはほとんどすべてのものに向けられている。その現前はものの何らかの特別な特性によるのではなく、その時の自己がもつ特別な特性によるのである。

　こうして思考作用の情動に対する関係は、意欲に対するその関係と類比的である。思考作用は情動よりも独立した位置にある。いかなる情動も思考作用とのある親密な関係においてでなければ存在しえないことは内在的に必然的であるが、すべての思考作用が情動に対して対応する関係にあることは内在的に必然的でないからである。少なくとも、われわれが何の情動もかき立てない何かを思考しうるという想定に明白な不可能性はない。

　しかしここでも、欲求の場合と同じく、さらに進まなければならない。二つの心的状態――情動の状態でない思考作用の状態と、それに続くかそれに伴う、思考作用の状態でない情動の状態――があるだけでは十分でないであろう。もしそうなら、情動の状態のうちに、情動がそれに向けて感じられるものについての思考作用はないことになろう。そうするとそれは、どうして他の何かではなくそれに向けられた情動でありうるであろうか。

　それがそれに向けられた情動であるのは、情動の状態と思考作用の状態とのあいだに存在する何らかの特別な関係のためである、と答えられるかもしれない。しかしここで、意欲についての類比的な理論を退けることをわれわれに強いたのと同様の反論が生じる。この理論の上では、私が X を愛し、しかもそうしていることに気づいているとき、私は二つの状態 A と B とそれらのあいだの関係とに気づいていることになろう。A は X についての思考作用の状態であり、それがそのような状態であるという事実は B へのその関係から独立しているであろう。他方 B は愛の状態であり、それが X への愛の状態であるのは A へのその関係のためにすぎないであろう。もしその関係を捨象するなら、A はなお X についての思考作用であろうが、B は愛の状態ではあっても誰への愛の状態でもないであろう。さて、事情がそうでないことは明らかであるように思われる。X への愛の状態は、X についての判断や想定が X についての判断や想定であるのと同じく、直接にかつ無媒介に X への愛である。それを X への愛にするために、それ自身の外の何ものも必要としない。

　したがってわれわれは、情動について、ムーア博士の意欲の理論と類比的な理論を採らなければならない。情動が向けられているものについての思考作用とそれへの情動とは同じ心的状態であり、それはそれについての思考作用であるという性質とそれに向けられた情動であるという性質の両方をもつ、と考えなければならない。

**457**　情動でもある思考作用は、その思考作用的側面においては、知覚、判断、想定、心像のどれでもありうる。われわれの現在の経験においては、情動は意欲よりもしばしば知覚や判断である。われわれの現在の意欲は、存在するものとして思考されるものよりも、存在しないものとして思考されるものに向けられることのほうが多いからである。そして前者の類の意欲は想定か心像でなければならない。しかしわれわれの情動は、存在しないものとして思考されるものによってと少なくとも同じだけ、存在するものとして思考されるものによってかき立てられる。

　思考作用は、意欲であるという性質と情動であるという性質の両方をもちうる。私は何らかの将来の出来事を同時に希望し欲求することができ、あるいは X を愛しその存在に同意することができる。そしてそのような場合に、その出来事について、あるいは X について、二つの別々の思考作用がなければならないと想定する理由はないように思われる。

　絶対的実在においては、すでに見たように、知覚以外の思考作用はない。したがってわれわれの情動はすべて思考作用としては知覚であり、われわれは存在するもの以外に対しては情動をもたないであろう。そして絶対的実在においては、自己、自己の部分、自己の群以外の何も存在せず、それらはそのようなものとして知覚されるのだから、われわれが情動を感じうるのは、そのようなものとして知覚される自己、自己の部分、自己の群に対してだけである。われわれがどのような情動を感じるかを決定することはできるであろうか。

**458**　誰もが一つより多くの自己を知覚しなければならないのだから、彼は少なくとも一つの他の自己を知覚しなければならないことが帰結する。絶対的実在においてわれわれは他の自己に対してどのような情動を感じるのか。われわれの現在の経験においては、他の自己に対して感じられうる情動は多くの異なる種類のものである。しかしそれなら、現在の経験における他の自己についてのわれわれの認識は、間接的であるという点で絶対的実在におけるそれと異なる。現在の経験においては誰も他のいかなる自己も知覚しない。彼はその自己を記述によって――しかじかの性質と関係をもつものとして――知るにすぎず、しかも他の自己のこれらの性質と関係さえ直接には知られず、知る者による感覚与件の知覚を媒介としてしか知られない。こうして他の自己についての知識は二重に間接的である。そして他の自己の部分についてのわれわれの知識も同じしかたで二重に間接的である。

　他方、絶対的実在においては、他の自己とその部分についてのわれわれの知識は直接的である。われわれは自己とその部分の両方を知覚するからである。この点において、絶対的実在において各自己が他の自己についてもつ知識は、現在の経験において彼が自分自身についてもつ知識にある程度似ている。自己は自分自身を知覚でき、自分の部分を知覚できるからである。しかし現在の経験においては、自己の自分自身とその部分についての知識は、知覚でありうるけれども、知覚である必要はない。それは判断でもありうる。しかし絶対的実在においては知覚以外の知識はなく、われわれは他の自己とその部分について判断することはできず、ただそれらを知覚しうるだけである。

　こうして、私自身と私の部分についての私の現在の知識は、絶対的実在における他の自己とその部分についての私の知識の型としてある程度役立つけれども、それは結局不完全な型である。他の自己についての私の現在の知識は、絶対的実在における他の自己についての私の知識から、私自身の自己についての私の現在の知識からよりも大きく異なる。

　われわれの現在の経験における他の自己の知識と絶対的実在におけるそれとのあいだの大きな違いは、一方の情動的性質から他方の情動的性質を論じることを危うくする。こうして、現在の経験における自己についてのわれわれの知識がしばしば何の情動的性質ももたず、またしばしば非常に多様な情動を示すという事実は、絶対的実在においても同じであろうと結論する資格をわれわれに与えない。

**459**　私は、絶対的実在においては他の自己についての知識はつねに一つの情動的性質をもつであろう、と信じる（それがつねに、あるいはそもそも、他の性質ももつかどうかは、のちに考察される問いである）。そしてつねに現前するであろうと私が信じる情動は愛である。

　愛によって何が意味されているか。私はこの語を好感の一種に用いることにしたい。好感は、上で述べたように（原書一四四ページ原注1）、実体に対してしか感じられえない情動である。愛という名を実体に対してしか感じられない情動に限定するにあたって、私は用法に従っていると思う。たしかに、人が勇気や慈愛をある強さで賛嘆するなら、彼は勇気や慈愛を愛している、と言うのは珍しくない。しかしこれは、思うに、比喩であると一般に認められるであろう。

　しかし愛は他の種類の好感からどのように区別されるべきか。私はこの語を、第一に、人格に対して感じられる好感に限定することにしたい。ここでは、ひょっとすると通常の用法がこの限定を支持するかどうかはより疑わしいかもしれない。ある人がアルプスを愛していると言うとき、彼が正義を愛していると言うときほど比喩的に語っていることは明らかでない。ましてや彼が自分の学校や祖国を愛していると言うとき、比喩的に語っていることはなおさら明らかでない。しかし人格に対してだけ感じられる好感のための別の名をもつことは重要であり、そしてこの語の通常の使用がどこまで及ぶにせよ、その中心的で典型的な使用が人格に対して感じられる情動のためのものであることは、思うに疑いない。したがって、それをもっぱらその情動に用いても、われわれは通常の使用から、そもそも外れるとしても、大きくは外れないであろう。

　また私はこの語を、強く情熱的な好感にだけ用いることにしたい。これは過去の用法ではないが現在の一般的な用法に一致している。

〔原注〕好感という語はしばしば強く情熱的な情動を除外するのに用いられる。人が「私は A に好感をもってはいない。彼を愛しているのだ」と言うのは珍しくないであろう。しかしこの種の情動をその強さに言及せずに含むための何らかの一般的な語が必要である。そして好感よりよい語は手に入らないように思われる。

〔原注〕たとえばスピノザもヒュームも、私に快を与える何らかの性質をもつ他の人格に対する好感のあらゆる情動に「愛」を用いている。（『エチカ』第3部定理13備考、『人間本性論』第2巻第2部参照。）しかしこの語のこれほど広い用法は十九世紀の初期に廃れたように思われる。

**460**　そうすると愛は、人格に対して感じられ、強く情熱的であるような好感である。愛が慈愛からも共感からも注意深く区別されなければならないことは明らかである。慈愛との違いは根本的である。慈愛はまったく情動ではなく欲求――ある人格に、あるいはすべての人格に善をなしたいという欲求――だからである。それにもかかわらず、それはときに愛と混同されてきた。たしかにわれわれは、自分が愛するどの人格にも一般に善をなしたいと欲求するであろう。しかし情動と欲求とはまったく別のものである。そしてわれわれはしばしば、自分が愛していない人々に、さらには自分が憎んでいる人々にさえ善をなしたいと欲求する。

〔訳注〕benevolence を「慈愛」、sympathy を「共感」と訳す。

　共感は愛とより密接に結びついている。それは情動だからである。しかしそれは異なる情動――他人の快においてわれわれを快く、その苦においてわれわれを苦しく動かす情動――である。もしわれわれがある人格を愛するなら、一般に彼に共感するであろう。しかしわれわれは愛していない人々に共感することができる。憎んでいる人々に共感することさえ――少なくともその憎しみがあまり強くなければ――可能である。

**461**　われわれはこの語の使用を強く情熱的な情動に限定している。このことによって、それと性的欲求との関係の密接さを誇張するよう誤導されてはならない。それはしばしばその欲求と結びついて見いだされる。しかしそれはまた、他の結合の絆――血縁、幼いころからの親しさ、気質や意見の類似、感謝など――と結びついても見いだされる。そしてまた、そのような結びつきなしに、二人の人が互いに属し合っているとしか言えないような場合にも見いだされる――『新生』や『イン・メモリアム』に記録されたような愛である。

〔訳注〕『新生』（Vita Nuova）はダンテがベアトリーチェへの愛を記した作品。『イン・メモリアム』はテニスンが亡友アーサー・ハラムを悼んだ長詩。

**462**　われわれの現在の経験において、B が C を愛するとき（B のうちにであれ、C のうちにであれ、両者のあいだの関係としてであれ）つねに現前する何らかの特性を見いだすことはできるであろうか。B が C を愛するとき、その愛はつねに、C の行為あるいは存在が B に快を与えてきた、あるいは与えているという事実に依存している、と主張されてきた。しかしこれは事実と両立しない。愛はしばしばそのような快なしに生じる。そしてそのような快があるとき、B が自分の愛する C に負う快は、自分の愛していない D に負う快よりもはるかに少ない、ということもしばしばある。

　そうすると愛はつねに快によって引き起こされるわけではない。また愛が生じたとき、それがつねに快を引き起こすわけでもない。それが快よりもはるかに多くの苦を生み出す場合は多くあり、それが苦だけを生み出すような場合が生じることも不可能ではないように思われる。嫉妬に導く愛は苦が快を大きく上回る結果を生み出すかもしれない。そしてたとえ嫉妬に導く愛は最高の種類の愛ではないと言われるとしても、それがまったく愛でないと主張するのはばかげているであろう。そして報われない愛は、たとえ嫉妬を免れていても、快よりもはるかに多くの苦を生み出すかもしれない。愛は快いものでなければならないという見解は、思うに、心理的快楽主義の妥当性を受け入れるか想定し、そのうえで、もし愛する者が愛することをやめたがらないなら、それは彼が愛を快いと思うからでしかありえない、と論じた人々によるものである。

**463**　また B の C への愛が、B による C の道徳的是認を含むということもない。道徳的是認なしの愛はありえない、とまでは言わないにしても、それが起こるのは愛が性的欲求によって、あるいはそれを歪めるとみなされる何か他の影響によって迷わされたときだけであり、愛はそれ自身に任されるなら「最も高きものを見るとき、それを愛さずにはいられない」、と主張されてきた。これは私にはまったく誤っているように思われる。道徳的是認が愛に対して何か特別な関係に立つとは私には思われない。もちろんそれは愛とともに見いだされることがあり、愛を引き起こすこともある。B が C を愛するようになったのは、C が有徳だったからかもしれないし、美しかったからかもしれない。しかし B が C を醜いと知りながら愛することは可能であり、邪悪であると知りながら愛することも可能である。そして徳は美より重要であるけれども、邪悪であると知られている人格への愛は、有徳であると知られている人格への愛とまったく同じく真に愛である（そしてついでに言えば、まったく同じく善である）と私には思われる。

〔訳注〕「最も高きものを…」はテニスン『国王牧歌』中「ランスロットとエレイン」の一句。

　また慈愛と共感がつねに愛とともに見いだされるとも言えない。人々が、自分が真に愛している人々の不幸を喜び、それを促進したいと欲した場合がある。そのような場合はおそらくまれであり、確かに悪しきものであり、ひょっとするとつねに病的と呼びうる影響によって引き起こされるのかもしれない。しかしそれは起こる。そしてそのような例外的な場合について何と言われようと、慈愛と共感は、たとえ愛が現前するときにけっして欠けていないとしても、愛が欠けているときにもしばしば現前することは明らかである。実際、上で述べたように、それらはときに憎しみとともに現前する。

**464**　そうすると、快も、是認も、慈愛も、共感も、つねに愛とともに見いだされるわけではない。つねにそうであるものは何かあるであろうか。私は一つあると思う。B が C を愛するとき、彼は、自分が特別な強さと親密さの絆――二つの自己を結びつけうる他のいかなる絆よりも強く親密な絆――によって彼と結びつけられていると感じる。現在の経験においては、上で述べたように、他のいかなる自己についてのわれわれの知識もけっして知覚ではなく、二重の媒介を通じて到達される。しかしそれでも、愛における関係の親密さが、人の自分自身の自己との関係の親密さにほとんど劣らないと感じられる時がある。

〔原注〕現在の経験において「ほとんど劣らない」より先に進めるかどうか私は疑う。親密さの程度における何らかの違いが、現在の経験においてはつねに残っているように見える。原書一五六ページ参照。

　そしてこれが私には愛の本質であるように思われる。愛は、他の自己との合一の感覚から生じる情動である。合一の感覚は本質的である――それなしには愛はない。そしてそれは十分である――十分に緊密な合一の感覚があるときにはいつでも、愛する者と愛される者の性質が何であれ、またそのあいだの他の関係が何であれ、愛がある。

**465**　このことは愛についてのもう一つの考察――愛は、他のいかなる情動よりも、それが向けて感じられる実体の性質から独立している、ということ――にわれわれを導く。私は、愛が、われわれの現在の経験において、愛される者がもつ、あるいはもつと信じられている性質を媒介として到達されるのではない、と言っているのではない。もし B が C を愛し D を愛さないなら、それはしばしば、C が D のもたない何らかの性質をもつという事実によって説明できる。そして、B も他の誰も、なぜ彼が C を愛し D を愛さないのかを説明できない場合のいくつかにおいても、発見されていないとはいえ、そのような説明があるかもしれない。私が言わんとしているのは、愛はそれらの性質のゆえにであるかもしれないが、それらの性質に関してではない、ということである。

　情動が性質のゆえに生じることと、性質に関して生じることとの違いは、他人の是認の場合を取ればより明らかに見て取ることができる。是認は、原書一四四ページ原注1で述べたように、つねに性質に関してのものである。そしてそれはまたつねに性質のゆえにである。しかし私が彼を是認する際にそれに関して是認する性質は、私が彼を是認するそのゆえんの性質と異なることがある。たとえば私はクロムウェルをその勇気に関して是認するとしよう。しかし何が私の是認を引き起こすのか。その直接の原因は、彼が勇敢であったという私の信念である。これをクロムウェルの性質によって述べるなら、原因は、彼が私によって勇敢であると信じられているという性質をもつことである。そうすると私の是認は一つの性質に関してであり、まったく異なる性質のゆえにである。勇敢であることと、私によって勇敢であると信じられていることとはまったく異なる性質だからである。もちろん、彼が勇敢であったという私の信念は、彼が勇敢であったという事実によって決定されているかもしれず、その場合このもう一つの事実――彼の勇気――は私の是認の遠因である。しかし私の是認は、直接に、いかなる中間段階もなしに、彼の勇気に関してである。また私は、彼が実際には勇敢でなかったのに勇敢であると信じていたかもしれない。あるいは私は、彼がワーテルローで近衛兵を率いたと信じていたがゆえに、彼を勇敢であると信じていたかもしれない。これらの場合、彼の勇気は私の是認をまったく決定しなかったであろうが、私の是認は彼の勇気に関してであろう。

　また私は、クロムウェルについて一度も聞いたことがなかったなら、彼を是認することはできなかったであろう。したがって、彼が生まれる前に私が死ななかったこと、そして私が歴史を少し読んだことは、私の彼の是認の原因における要因である。もっとも私は確かに、私の死より前に彼が生まれたこと、あるいは私によって歴史のなかで読まれたことに関して彼を是認しているのではないが。

　そうするとこれが、情動が性質のゆえにであることと性質に関してであることとの違いである。そして私の主張は、愛は性質のゆえにであるかもしれないが、けっして性質に関してではない、ということである。
