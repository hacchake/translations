### 第26章　決定的対応（二）

**224**　次に、決定的対応についてのさらなるいくつかの問いの考察に進まなければならない。C が B の何らかの部分に対して関係 X にあるという事実を含む B の十分な記述から、B!C の十分な記述が帰結することをわれわれは見た。しかしさらに進んで、B のこの十分な記述のうちには、B!C の十分な記述だけでなく、B!C の本性の全体が含意されている、と言うことはできるであろうか。それとも反対に、B!C が、B のこの十分な記述のうちにいかなるしかたでも含意されていない性質をもつことは可能であろうか。

　もし B!C のある性質がそのこの十分な記述によって含意されていないなら、その性質はこの記述によって前提とされている。排中律によって、S を任意の性質として、B!C は S か非 S かでなければならないからである。したがってそれが B!C であることは、それが「S または非 S」であることを含意し、それがさらに一方であって他方でないことを含意しないなら、それは、実際にどちらであるにせよ、それが S であることか非 S であることかを前提とするであろう。

　第184節で、どの項 N も、N が含意するものによって前提とされるものを何であれ前提とすることを見た。そして B のある十分な記述は、無限系列を通じて B のすべての部分の十分な記述を含意する。したがって、もし B の部分のこれらの十分な記述のそれぞれがその部分の何か他の性質を前提とするなら、B の十分な記述は前提の無限系列をもつであろう。これは矛盾を含むであろうか。

**225**　第191節で、そのとき考察した前提の無限系列から矛盾が生じるであろうと結論するに至った理由によっては、それが矛盾を含むと決めることはできない。系列の後続する項における前提の固定は、先行する項における前提の固定を含意する必要はないからである。たとえば、B!C を構成する第二階の二次部分において、それらの十分な記述によって前提とされるそれらの部分の他の性質を固定したとしても、それは B!C 自体において、その十分な記述によって前提とされる性質を必ずしも固定しないであろう。そしてその場合、B の全究極前提を考察するにあたって、これらの前提のどれも、同じ系列のより低い項のうちに含意されているという理由でそこから消えることはないであろうし、したがって矛盾は生じないであろう。

　他方、第190節で提起された反論はこの場合にもあてはまるであろう。決定的対応によって決定される実体の無限系列のそれぞれが、決定的対応によって含意されていない各性質に関してその前提を固定されるためには、随伴の無限系列がなければならないであろうからである。そして第190節で、このような無限系列は受け入れられないという結論にわれわれは達した。

　もしこれが正しいなら、B のすべての部分が無限に至るまで、決定的対応によって決定された性質以外の性質をもつことは不可能であろう、ということが帰結するであろう。しかしこの結果は系列の無限性からのみ帰結する。任意の有限個の階の部分のすべて、あるいはどれかが、決定的対応によって決定されていない性質をもつことは可能であろう。そしてそのような部分のなかには、もちろん、観察の力が無限でないどの観察者によってでさえ観察されうるすべての実体――すなわち、現在われわれにとって何らかの実践的関心をもつすべての実体――が含まれるであろう。

**226**　ここで当然、宇宙のうちに実際に生じる決定的対応の関係が何であるかを見いだすことができるかどうか、という問いが生じる。もし、決定的対応の関係であるような関係はただ一つしかない、あるいは存在するものの本性についてわれわれが達した他の結果とその生起が両立する関係はただ一つしかない、とアプリオリに示すことができれば、その関係が宇宙のうちに実際に生じ、実際に生じる決定的対応の唯一の関係であることがわかるであろう。しかし私は、これをアプリオリに示すことは可能だとは思わない。第5部で経験的な性質の考察を導入するとき、思うに、宇宙のうちに生じ、実際に生じる唯一のものであるようなある決定的対応の関係があると信じる十分な理由を与えることが可能になるであろう。しかしそれまでは、この点は未決定のままでなければならない。

**227**　またわれわれは、私の見るかぎり、実際に生じるどの決定的対応の関係も満たさねばならないさらなる条件を、現在のところ定めることもできない。とりわけ、排除できない二つの重要な可能性がある。第一に、同じ種類の決定的対応が至るところに生じることが必要であると示しうるとは私には思われない。一つより多くの一次全体があるなら、その関係はそのそれぞれにおいて異なるものであるかもしれない、ということは十分可能であるように私には思われる。そして一つの一次全体のうちでさえ、B が C の部分ともつ決定的対応の種類が、D が E の部分ともつそれとも、あるいは B 自身が F の部分ともつそれとも、あるいはさらに G が B の部分ともつそれとも異なりうることを否定する理由はないように思われる。

　しかし、後続する部分の組の無限系列の決定において、最初の段階より後のどの段階にも新しい種類の決定的対応を導入することはできないであろう。最初の段階で、これらの後続する部分の組のすべての成員の十分な記述が含意されていなければならないからである。そしてもし最初の段階で述べられていない新しい種類の対応が後続するどこかの段階で効力をもつなら、そうではないであろう。もちろん、A が、さらなる後続する組の無限系列を生み出すという特性を除いて決定的対応のあらゆる特性をもつ関係によって、後続する組を決定するような部分の組をもつことは可能である。そしてそのようにして決定された組が、そのような系列を生み出すという特性を除いて決定的対応のあらゆる特性をもつ別の関係によって、さらに別の組を決定するかもしれない。これは任意の有限個の組について続くかもしれない。しかしそれは決定的対応ではないであろう。どの関係も組の無限系列を生み出すという特性をもたないであろうからである。最終的には、もとの矛盾が避けられるべきなら、そのような無限系列を生み出す決定的対応の関係に達しなければならない。そしてそのとき、上に挙げた理由から、そのような系列において最初の段階の後に新しい種類の決定的対応を導入することはできない。

**228**　第二に、宇宙全体に、あるいはその一部に及ぶ決定的対応の種が一つより多くありうる可能性を、現在のところ排除することはできない。われわれがまだ見るかぎりでは、宇宙が、どちらの成員も決定的対応によって直接に決定されておらず、しかもどちらかの組のすべての成員の十分な記述から、決定的対応によって、すべての後続する組の成員の十分な記述が帰結するような、二つの部分の組をもつことは可能であるかもしれない。その場合、宇宙は、そのそれぞれがわれわれの定義によって一次部分の組であり、そのそれぞれが宇宙全体に及ぶ決定的対応の体系を始めるような、二つの部分の組をもつであろう。そしてそのような部分の組の数は二つに限られる必要はない。

〔原注〕全体は、どちらも他方に対して後続的でない二つの部分の組に分割されうることを思い起こされたい。たとえばケンブリッジの卒業生の群は、博士の群、修士の群、学士の群から成る一つの部分の組をもつ。それはまた、神学の卒業生の群、法学の卒業生の群などから成る別の組をもつ。これらの組のどちらも他方に対して後続的ではない。

　第5部で経験的な考察を導入するとき、思うに、これら二つの可能性をどちらも退ける十分な理由を見るであろう。上で述べたように、宇宙のうちに実際に生じる決定的対応の関係はただ一つしかないと結論する根拠を見いだすであろうし、また一次部分の組はただ一つしかないと信じる根拠も見いだすであろう。しかし現在のところ、この点についてそれ以上先に進むことはできない。

**229**　その間に、われわれの経験が告げるある種の対応の形を考察し、それらがどこまで決定的対応に必要な条件を満たし、どこまで満たさないかを探究するのは有用かもしれない。そのような議論は、決定的対応の本性をより明らかに悟る助けになるかもしれない。

　まず、決定的対応に属することがわかったある特性を列挙することから始めよう。（1）実体 C と実体 B の部分とのあいだの関係が決定的対応の関係であるのは、C がその関係において B の何らかの部分に立つという事実を含む C のある十分な記述が、問題の B の部分 B!C の十分な記述を内在的に決定するようなものであるときである。（2）決定的対応の関係は、一つの決定項が一つより多くの被決定項を決定しうるような関係である。（3）それは、B!C がただ一つの決定項 C によって決定され、他方 C は、A の多くの部分の直接の決定項でありうるが、B のうちに入る A の部分のうちではただ一つの直接の決定項であるような関係である。（4）それは、少なくともある場合には相互的である。（5）それは、全体が部分の組に分割され、そのそれぞれがまた部分の組に分割され、以下無限に続き、しかもこれらすべての部分の十分な記述が、決定的対応によって、全体の十分な記述によって決定される、ということが可能であるようなものである。

**230**　まず、透明な面に描かれた模様が、その面に対して異なる角度に立つ――どの二枚も同じ角度には立たない――いくつかの板の上にその影を投げかける場合を考察しよう。模様と影とのあいだの関係は、決定的対応に必要な条件のいくつかに実際に合致する。それは第一の条件に合致する。模様の形と、各板が透明な面に対して立つ角度とを知れば、各板の上の影の形を含意する所与をもつことになるからである。それは第二の条件に合致するであろう。一つの模様は異なる板の上に多くの影をもちうるからである。そしてそれは第三の条件に合致するであろう。各影は（模様に対してその角度に置かれた板の上では）ただ一つの模様の影でしかありえず、模様は各板の上にただ一つの影しかもちえないからである。

　しかしそれは第四の条件には合致しないであろう。相互的な決定の可能性はない。模様の部分は模様の影の影ではありえないからである。したがってそれは第五の条件に合致しえない。もし影が無限に部分の中の部分をもつとすれば、それは、模様が、模様と影とのあいだの関係から独立した事実として、無限に部分の中の部分をもつからでしかありえないであろう。そうすると模様は部分の組の無限系列をもち、そのそれぞれはそれに後続するものを前提としつつ、それ自身はそれらによって含意されていたであろう。こうして第23章で説明したしかたで矛盾が生じるであろう。

**231**　あるいはまた、詩集の蔵書が相互参照を排除するある方式で目録化され、目録が何部かあって、各部が異なる色の紙に刷られていると想定しよう。そうすると、ここでもまた最初の三つの条件は満たされるであろう。C の十分な記述は、その巻が B――赤い紙に刷られた目録の部として十分に記述されるであろう――に記載されているという事実を含む、巻の一つのどんな十分な記述でもよいであろう。そしてこれは、目録のその部におけるその本の記載項目の十分な記述 B!C を与える。こうして第一の条件は満たされる。第二の条件は満たされる。一冊の本は目録の多くの部に記載されうるからである。そして各記載項目はただ一冊の本にしか言及せず、各本は各目録にただ一つの記載項目しかもたないであろうから、第三の条件も満たされる。

　しかし第四の条件は満たされない。目録化された本の部分が、目録を目録化する目録の記載項目から成ることはありえないからである。これは不可能である。そのような記載項目から成る本は詩集ではないであろうからである。したがって第五の条件もまた満たされない。一方、本だけが目録化され、その部分は目録化されないなら、目録の記載項目は、目録化されるもののうちの何かに対応する、無限に至る部分の中の部分をもつことはできない。他方、本の部分が目録化されるなら、記載項目のうちにそのような無限系列がありうるのは、目録化される本が独立の事実としてそのような部分の無限系列をもつ場合だけであろう。そしてこれは、前の場合と同じく矛盾に導くであろう。

**232**　しかし場合を変えて、それぞれがそれ自身と、他の目録と、それ自身および他の目録のなかの記載項目とを目録化するような、ある数の目録を取ると想定しよう。最初の三つの条件は前と同じく満たされるであろう。そして第四の条件も満たされるであろう。青い本の記載項目は赤い本の部分であり、赤い本の記載項目は青い本の部分であろうからである。また記載項目の無限系列の十分な記述も含意されるであろう。赤と青の二つの目録があるなら、赤はそれ自身と青の記載項目を含むであろう。それはまた、それ自身のなかのそれ自身と青の記載項目の記載項目、そして青のなかの両方の記載項目の記載項目も含むであろう。そして以下無限に続く。

　しかしそれでも第五の条件は満たされないであろう。青い本の記載項目は、いま述べたように赤い本の部分である。そして青い本のなかの青い本と赤い本の記載項目を記録するさらなる記載項目もまた赤い本の部分である。しかしそれらは赤い本のなかの青い本の記載項目の部分ではない。「青い本」という記載項目が、「青い本のなかの赤い本の記載項目」と「青い本のなかの青い本の記載項目」とをその部分としてもちえないことは明らかである。したがって記載項目の無限系列は、無限に部分へと分割された部分の系列ではなく、第五の条件を満たしたことにはならないであろう。

**233**　次に、B が正であり C が負であって、それらがこの点で自分たちに似るように、それら自身と互いとの部分を決定し、したがって B!C は A の正の部分の負の部分である、と想定しよう。この場合、第一の条件は満たされるであろう。B!C はこのしかたで十分に記述されるであろうからである。第二の条件も満たされるであろう。C は B!C だけでなく C!C をも決定するであろうからである。第三の条件もそうである。B!C は C 以外の何ものにも対応せず、C は B のうちに入る A の部分のうちではただ一つの直接の決定項であるからである。第四の条件も満たされるであろう。B は C の部分を決定し、C は B の部分を決定するであろうからである。最後に、第五の条件も満たされるであろう。第一階の二次部分は四つあるであろう――正の部分の正の部分、正の部分の負の部分、負の部分の正の部分、負の部分の負の部分である。そのそれぞれがまた正と負の部分をもち、以下無限に続く。こうしてすべての条件が満たされる。

　同じ結果は、正と負以外の性質についても起こりうるであろう。そしてこのように組み合わされる性質の数は二つより多くてもよく、したがって一次全体は二つより多くの一次部分を含んでもよいであろう。またそれらのいくつかが相互的に決定する群を形づくるなら、すべての一次部分が他のすべての一次部分を決定する必要もないであろう。

　しかしこのような決定的対応のためには、性質がある特性をもつことが必要である。第一に、それらは互いに両立しないものでなければならない。そうでなければ、B の部分の一方について正であると言い、他方について負であると言うことによって、それらの十分な記述は与えられないであろう。両方の記述が同じ部分に属するかもしれないからである。第二に、それらは全体とその部分が同じ性質をもちうるようなものでなければならない。正の部分が正の部分をもち、負の部分が負の部分をもちうるのでなければ、無限系列は生じないであろうからである。第三に、それらは全体とその部分が異なる性質をもちうるようなものでなければならない。負の部分の正の部分と、正の部分の負の部分とをもつこともまた必要だからである。そしてこれらの特性は、問題の全体が一次部分であれ、第一階の二次部分であれ、他のどの階の二次部分であれ、無限の過程のどの段階においても真でなければならない。

　これらの特性をもつ性質の組が何かあるかどうかは、いまのわれわれにはかかわらない問いである。私は、そのような組があるとも、あるとしても正と負がそのような組であるとも主張しない。

**234**　精神の世界のうちに決定的対応の例を見いだすことはできるであろうか。知識はそのような対応の項でありうるであろうか。まず判断から成る知識を取ろう。真なる判断だけが知識の部分である。真なる判断とは事実に対応する判断であり、判断は知る存在者の心の状態であって実体であり、知られるものはときに実体であるから、実体のあいだの対応であるような知識の場合がある。

〔原注〕すべての真なる判断が知識の部分であると主張するつもりはない。一九一九年のピーターハウス学寮の視察者が司教であったということは真なる判断であるが、もしある人が、その視察者はジブラルタル司教であると信じたためにその判断を下したのなら、彼がこれを知っていると正しく言えるかどうかは、少なくとも疑わしい。

　B は、十分な記述 XYZ をもつ実体が存在することを知っている。十分な記述 XYZ を含み、また B が C についてこの知識をもつという事実も含むこの実体 C の十分な記述は、B の C についての知識の十分な記述を与えるであろうか。

　第一に、それはそうしないであろう。人は同じ事実を二つの異なる時点に知ることが可能だからである。そのとき彼の心の二つの状態があり、そのそれぞれについて「十分な記述 XYZ をもつ実体が存在するという B の知識」という記述が真であろう。したがってこの記述はどちらの状態の十分な記述でもないであろう。それは両方について真だからである。その帰結として、上に定めた第一と第三の条件は満たされないであろう。

　しかし、知る存在者のそれぞれが、そもそも知っているどの実体についてもただ一つの知識の行為しかもたない、という想定がなされるなら、それらは満たされるであろう。そうすると実体は、RST として十分に記述される実体である B の、XYZ として十分に記述される別の実体が存在するという知識、として記述されるなら、十分に記述されるであろう。

　しかしこの予備的な難点が取り除かれても、他の難点が見いだされるであろう。第一に、知識のすべての行為は知る者の部分である――私はこれが真であると信じている――ことを認めるとしても、多くの場合、第四の条件は満たされえないであろう。その場合、B の部分は C によって決定されるであろう。しかし C がそれ自身知る存在者でないなら、この決定は相互的でありえない。私が大ピラミッドを知っているなら、私の心の部分は大ピラミッドについての知識であることによって決定される。しかし大ピラミッドのどの部分も、私の心についての知識であることによって決定されることはありえない。そして第四の条件が満たされないのだから、第五の条件も満たされないにちがいない。

　第二に、B と C が互いを知りうる場合にさえ、第五の条件は満たされないであろう。そのどちらかが一つより多くの実体を知ることは想定の一部ではないからである。またこれでさえ、知識が相互的であると想定し、さらに各知る存在者が自分の知るすべてのものの部分を知ると想定しないかぎり、第五の条件を与えはしないであろう。

　第三に、どの知る存在者の知識の行為もその存在者の完全な部分の組を形づくり、したがって B のすべての部分について決定的対応が与えられることを保証する、ということは想定の一部ではない。

**235**　われわれが考察している知識の種類をさらに特定することによって、これらの難点を避けることはできるであろうか。一次全体の一次部分のそれぞれが知る存在者であり、そのそれぞれが他の一次部分とその部分とを知り、その知識を除いてはまったく何の部分ももたない、としよう。そうすると決定は相互的でありうる。知られる一次部分はまた知ることができ、知られる二次部分は知識の行為でありうるからである。こうして第四の条件は満たされる。そうしてわれわれは B のうちに決定された部分の終わりのない系列をもつ。まず彼自身と C についての彼の知識があるであろう。次に、彼自身と C についての彼の知識についての彼の知識と、彼自身と C についての C の知識についての彼の知識とがある。そして以下無限系列を通じて続く。

　しかしそれでも第五の条件は満たされていない。たしかに一次部分の十分な記述は、そのそれぞれが一次全体の部分であり、また一次部分の一つの部分でもあるような実体の終わりのない系列の十分な記述を内在的に決定する。しかしこの点を越えると、決定される部分は先に決定された部分の部分ではない。それらはすべて判断であり、部分についての判断は全体についての判断の部分ではありえない。したがって相互的な決定は、終わりのない系列を生み出しはするが、部分の中の部分の終わりのない系列を生み出しはしない。

　たとえば上に挙げた場合、BkC（ここで k は「〜についての知識」を表す）は BkCkB と BkCkC を含意する。C のうちには CkB と CkC があり、B は自分の知るすべてのものの部分を知るからである。しかし BkCkB は BkC の部分ではない。両方とも B の部分であり、CkB は C の部分であるにもかかわらず。判断は部分をもつ（もっとも無限に至る部分の中の部分はもたないが）が、判断の部分の組がすべて判断であることはけっしてない。したがって全体についての判断の部分の組が、全体の部分についての判断であることはけっしてありえない。たとえば、私が連合王国について何かを知っているなら、連合王国についての私の判断は、グレートブリテンとアイルランドそれぞれについての二つの判断に分割することはできないであろう。たとえ連合王国についての私の判断が、それはグレートブリテンとアイルランドという二つの部分から成る、というものであっても、その判断は、グレートブリテンについての判断とアイルランドについての判断という二つの判断から成るのではないであろう。

**236**　こうして、知識が判断に限られると取られるなら、知識は決定的対応の例を与えることはできない。しかし判断のほかに、知識と呼ばれる資格をもつものがある。それは知覚である。そして知覚の場合には、いま考察した難点は生じない。部分の知覚が全体の知覚の部分でありうることは、思うに、認めなければならないからである。私が鏡板の表面を全体として知覚し、同時に表面の彫刻の細部を知覚するなら、各特定の細部の知覚は全体としての鏡板の知覚の部分である。

〔原注〕厳密に言えば、もちろん、私は鏡板やその細部を知覚するのではない。私は感覚与件を知覚し、そこから鏡板と細部とを信じるよう導かれるのである。このように細部に関係づけられた感覚与件は、明らかに、このように鏡板に関係づけられた感覚与件の部分であると思われる。そして私の主張は、細部に関係づけられた感覚与件についての私の知覚は、鏡板に関係づけられた感覚与件についての私の知覚の部分である、ということである。（この主題は第5部で論じる。）

　こうして、思うに、一次部分のそれぞれが、他の一次部分とその部分とを知覚し、それ自身はそれらの知覚以外の部分をもたない知覚する存在者であるような一次全体を取ることによって、決定的対応がどのようなものであろうかの例を得ることができる。（われわれはまた、知覚は少なくともある場合には相互的であり、どの知覚者もどの知覚対象についても一つより多くの知覚をもたない、と想定しなければならない。）最初の四つの条件は、判断による知識の場合と同じく満たされるであろう。そして第五の条件もまた満たされるであろう。B についての C の知覚についての B の知覚は、C についての B の知覚の部分であろうから、われわれは部分の中の部分の無限系列をもつことになろうからである。

　このような知覚の経験をわれわれはもたない。われわれの経験は、思うに、正しく分析されるなら、自己は自分自身を知覚することができ、しばしばそうしていることを示す。しかし、ある自己が別の自己を知覚する経験も、したがって自己の相互的な知覚の経験も、われわれはもたない。そしてまた、知覚以外の活動をもたず、知覚以外の部分をもたない知覚する存在者の経験もわれわれはもたない。

　それでもわれわれは知覚がどのようなものかを知っており、このようにして自分自身と互いとその部分とを知覚する自己の社会の概念を形づくることは不可能ではないように思われる。したがって、もしこれが生じたなら、そこに決定的対応の関係が得られるであろう、という結論に達したことは無駄ではない。そしてこの問題は、第5部でふたたび取り上げるまで、ここに置いておかねばならない。
