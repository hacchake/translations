## この作品について

　ジョン・マクタガート・エリス・マクタガート（一八六六〜一九二五）は、ケンブリッジ大学トリニティ・カレッジで教えたイギリスの哲学者で、ヘーゲル研究から出発し、独自の観念論の形而上学を築いた。一九〇八年の論文「時間の非実在性」で示したA系列・B系列の区別と、時間は実在しないという論証とは、今日の時間の哲学でもなお出発点として論じられている。『存在の本性』はその主著であり、第1巻は一九二一年に刊行され、第2巻は著者の死後、弟子の C・D・ブロードの編集で一九二七年に刊行された。

　本書の前半（第1巻）は、経験的な前提をほとんど使わずに、存在するものはすべて「実体」であり、どの実体も部分の中の部分へと無限に分割され、その分割は「決定的対応」と呼ばれる関係によって決定されていなければならない、ということを論証する。後半（第2巻）は、この結論を私たちの経験に当てはめる。物質も感覚与件も時間も実在せず、存在するのは互いを知覚し合う自己（精神）だけであり、自己の内容は知覚だけから成る、という観念論がそこから導かれる。続いて、それにもかかわらずなぜ世界が物質と時間のうちにあるように見えるのか、という誤りの理論（「C系列」と「包含系列」の理論）が展開され、最後に、不死、先在と輪廻、そして宇宙における善と悪の割合という実践的な帰結が論じられる。結論は、時間の相のもとでは、あらゆる自己は有限な時間ののちに、互いへの愛を本質とする終わりのない最終段階に達し、その価値は他のすべての段階の悪を無限に上回る、というものである。

　この翻訳では全体を部ごとに七つの記事に分けた。第2巻の編者ブロードの序文と注（保護期間内）、第1巻巻頭の詳細目次、索引は訳していない。訳文中の〔原注〕は著者の注、〔訳注〕は訳者の注である。第2巻で原書のページを参照している箇所は「原書〇ページ」のまま残した。

## 第3部　群

### 第14章　実体の類似

**117**　次に、実体が互いに対してもつ関係のさらなる考察に進まなければならない。前の部でわれわれは、実体の多数性があること、それらが互いに関係に立つこと、どの実体も他のどの実体とも非類似であること、そしてどの実体も（理念的には――人間の知識にとってはつねにではないにせよ）一般的な言葉で、他のどの実体にもあてはまらないような記述によって記述されうることを学んだ。それらのあいだに成り立つものとして、ほかにどのような関係を決定できるであろうか。

　すべての実体は非類似である。どの二つも同じ本性をもつことはできない。しかしどの実体の本性も多くの性質に分析できる。さて、A の本性が B の本性と部分的に同一であり、したがってそれらが何らかの性質を共有している、ということを妨げるものは何もない。この場合、A と B そのものは、非類似であるとともに類似しているであろう。そしてわれわれは、これが可能であるだけでなく現実であることを見ることができる。たとえば実体性、存在、性質をもつこと、という性質は、一つより多くの実体に属する性質だからである。そして、のちに見るように二つより多くの実体があるなら、A との非類似という性質は少なくとも二つの実体に共通であろう。それは A を除くすべての実体に属するからである。

**118**　そうすると、性質はいくつかの実体に共通でありうるし、いくつかの性質がそうであることをわれわれは知っている。しかし、ある性質と結びついた実体の多数性は、ある実体と結びついた性質の多数性と完全には類比的ではない。というのも、われわれはすべての実体が性質の多数性――いや、無限に多くの性質――をもつことを知っているからである。たしかに、実体の本性を構成するそれらの性質のすべては、ただ一つの性質としても取ることができるが、その場合その性質は無限に多くの部分を含む複合性質である。

　他方、ある性質が一つより多くの実体に実際に属することはわかっているが、すべての性質についてそうであるかどうかはわからない。まず、どの実体にも属さない性質がある――たとえば一九一九年のイングランド共和国大統領であるという性質がそうである。次に、いま述べたように、各実体の本性はただ一つの性質であり、それが他のどの実体にも属しえないことをわれわれは知っている。しかし、これら後者とは違って単純であるか、有限にしか複合的あるいは複雑でない性質についてさえ、それが一つの実体にあてはまるとしても、そのそれぞれについて、それが一つより多くの実体にあてはまるとは知らない。

　さらに、そのような性質のいくつかの場合には、それが一つより多くの実体にあてはまりえないことをわれわれは知っている。単純性質のどれについても、思うにわれわれはこのことを知らない。しかしそれでもそれらについてそれが真であるかもしれない。ただ一つの実体に、そしてただ一つの実体だけにあてはまる単純性質はない、と確信できるとは私には思われない。

　そして有限に複合的および複雑な性質の場合には、一つより多くの実体にあてはまりえないものを多く知っている。第18章で見るように、宇宙であるという性質は、単純ではないが無限に複合的でも複雑でもない性質である。そしてまた、それがただ一つの存在する実体に実際にあてはまり、一つより多くのものにはあてはまりえないことも見るであろう。また「あらゆる犬のうち最も有徳な犬」は、無限に複合的でも複雑でもない性質であり、明らかに一つより多くの実体にはあてはまりえない。もっとも、犬が徳をもちえないなら、あるいは等しく有徳な二匹の犬がその性質において他のすべての犬にまさるなら、どれにもあてはまらないかもしれないが。

**119**　そうすると、ある実体はある他の実体と類似している。そしてこれを証明したのと同じ考察が、どの実体も他のどの実体とも類似していることを証明するであろう。実体性、存在、性質をもつこと、という性質はすべての実体に共通であり、このことは、どの実体も他のどの実体とも類似していることを証明するのに十分だからである。

　そしてわれわれはまた、二つの実体に共通であるがすべての実体には共通でない性質があることを見ることができる。（二つより多くの実体があるなら）A が存在する実体であるとして「A と非類似である」はそのような性質である。いくつかの実体だけに限られるそのような類似について、何が言えるであろうか。この問いはわれわれを群の考察へと導く。

〔原注〕この性質は、「A」の代わりに同値の言い回し「性質 X、Y、Z をもつ実体」――ここで X、Y、Z は A の十分な記述をなす――を置くことによって、まったく一般的な言葉で表現できる。

### 第15章　群

**120**　群とは、実体から、あるいは実体の集まりから、あるいはその両方から形づくられるどんな集まりをも意味する。その集まりを形づくる実体や集まりは、群の成員と呼ばれる。

　群は類から区別しなければならない。類は類概念によって決定される。この概念は一つ以上の性質から成り、これらの性質をもつものはすべてその類の成員である。したがって「類 P の成員である」という性質は定義でき、その定義は「性質 X、Y、Z をもつ」である。そしてこの定義によって、ある特定のものがその類の成員であるかどうかを決定できる。しかし群の成員は外延的指示によって決定される。L とは A と B と C から成る群である。したがって、ある特定の群の成員が何であるかを定義によって決定することはできない。たしかに、L の成員であるという性質は、性質 RST か、性質 UVW か、性質 XYZ かのいずれかをもつという性質――ここでこれらの性質はそれぞれ A、B、C の十分な記述をなす――として定義できるかもしれない。しかしわれわれは群の成員が何であるかを知るまではこの定義を知りえず、したがってこの定義によってそれらが何であるかを決定することはできない。

〔原注〕もう一つの違いは、群はわれわれの定義によれば実体か実体の集まりかから成らねばならないが、類は実体や実体の集まりの類だけでなく、性質や関係の類もありうる、ということである。

　群が定義によって決定されないという事実は見落とされやすいかもしれない。というのも、のちに見るように、どの群についても、その群のすべての成員に属し、その外の何ものにも属さないある性質があるからである。そしてこれらの性質が「その群の成員である」という性質を定義すると想定されるかもしれない。しかしそれは誤りであろう。実体がその群に属するのは、それらが性質を共有しているからではなく、この特定の群がそれらの特定の実体から成る群だからである。実際、のちに見るように、群のすべての成員に見いだされ、群の外の何ものにも見いだされないと確信できる唯一の性質は、特定の実体が群に含まれていることに依存する性質であり、したがってどの実体がそれに含まれるかを決定するのに用いることはできないであろう。

**121**　群と類の違いはいくつかの重要な帰結を生む。第一に、類は成員を含まないことがありうる――たとえば、一九一九年のイングランド共和国大統領たちは一つの類である――と主張されてきた。そして同じように、類はただ一つの成員しか含まないことがありうる――たとえば、一九一九年の連合王国の君主たちは一つの類である――と主張されてきた。しかし群はそれが含む成員によってのみ決定されるのであり、したがって成員なしであることは不可能である。そして群は成員の集まりとして定義されたのだから、それは一つより多くの成員をもたねばならない。

　第二に、自分自身の成員である類について生じる難点を根拠に、類の概念に対していくつかの批判がなされてきた。そのような批判は群の概念にはあてはまりえない。いかなる群も自分自身の成員ではありえないことは明らかだからである。群 L は A と B と C から構成されている。A、B、C が何であれ、そのどれも L ではありえないことは明らかである。L はその三つ全部だからである。たしかに、すでに見たように、群はその一つ以上が群であるような成員から構成されうる。たとえば C はそれ自身群であるかもしれない。しかしそれは群 L ではありえない。そうだとすれば C は、それ自身と A と B との群と同一であることになり、それは不可能だからである。またさらに、L は A、B、C とともに群にされうる。しかしこの四つの成員をもつ群 M は、その部分である L と同じ群ではないであろう。

　第三に、二つの異なる類の内容は外延が一致しうる。一九一九年に学寮長の任命権がフェローにないケンブリッジのカレッジは一つの類である。一五一五年から一五五〇年のあいだに設立されたケンブリッジのカレッジは別の類である。どちらの類もただ同じ二つの成員――モードリン・カレッジとトリニティ・カレッジ――を含む。しかし類は異なる。他方、二つのカレッジはただ一つの群を形づくるにすぎない。一組の成員をもつ群はただ一つしかありえないからである。

〔原注〕ラッセル氏ならこの二つの類を同じ類として扱うであろう。（「われわれは、二つの異なる類がまったく同じ成員をもつことのないような類を望む。」『数理哲学入門』一八四ページ。）ラッセル氏は数学を扱うにあたってこの用法を採っているのだから、それは疑いなく彼の目的にとって最善である。しかしそれが通常の用法だとは思わないし、哲学にとって便利ではないように思われる。

　類が一つより多くの成員をもつときはいつでも、その成員が群を形づくることは明白である――もっとも、いま述べたように、多くの異なる類の場合にそれが同じ群であることもありうるが。どの群の成員も少なくとも一つの類を形づくるかどうかという問いは、第17章で論じる。

　群の成員は、何らかの関係の体系の成員となるように結びつけられていることがある。そしてそれらは一つより多くのそのような体系の成員となるように結びつけられていることもある。A と B は夫と妻であり、C と D はその息子と娘であるかもしれない。そしてある特定の日に、A と C は B と D を相手にホイストの組になっているかもしれない。そうするとここには関係の二つの別々の体系があり、そのそれぞれが四人のそれぞれを他の三人と結びつけている。しかしそれらのあいだにそのような関係の体系がいくつ成り立とうとも、それらはただ一つの群を形づくるにすぎない。

**122**　注意すべきは、われわれの定義によれば、実体や群のどんな組み合わせも群である、ということである。群はたしかに、われわれにとっての重要性においても、それを観照することの有用性においても大いに異なる。たとえばイングランドの人々の群や、合衆国大統領の群や、すべての象の群は、私がいま書いている机と、現在オーストラリアにいる最も年老いたウサギと、ルイ十五世が最後に飲んだ薬とから形づくられる群よりも、はるかに重要であり、観照するのにはるかに有用である。それでも後者もまったく同じく真に群である。その三つの成員はすべて実体である。それらはある種の統一として取ることができる――このことは、それらが三つあることが真であるという事実によって証明される。もしそれらがともに結びつけられ、他のすべてのものから分けられていなければ、それらは三つではないであろうからである。三であるのはそのそれぞれではなく、全部いっしょであり、したがってそれらが三であることは、それらが結びつけられていることを証明する。そしてもしそれらが他のすべてのものから分けられていなければ、数はただ三ではないであろう。（たとえば、それらがウェストミンスター寺院から分けられていなければ、数は四より少なくはないであろう。）したがってそれらは群である。

〔原注〕つまり、それらが存在するならそれらは実体であり、一見したところそれらは存在する。これらのうち一つ以上が存在しないという結論に、のちに達する可能性はある。

　思うに、これら三つの実体は、それらをいっしょに観照するよう導かれたどんな観察者によっても群として取ることができる、ということは認めつつ、そのような観察を離れてはそれは群ではない、と否定する傾向があるであろう。イングランドの人々のような群が客観的に存在することは認められるかもしれない。しかし上に挙げたような突飛な群については、それはそれを構成する実体がそうであるようには独立に存在するのではなく、観察されるときに、観察される場合にだけ存在する、と言われるかもしれない。

　しかしこれは誤っている。机とウサギと薬が三つの実体であるという事実は、それらが三つとして観察されることに依存しない。もし誰もそれらをいっしょに考えなかったとしても、誰もそれらが三つの実体であることを知らないだけで、それらはやはり三つの実体であろう。そしてすでに見たように、それらが三つであるという事実は、それらが群であることを証明する。

　私は上で、イングランドの人々の群、すべての象の群などについて語った。しかし「イングランドの人々」や「すべての象」は類の名であって、群の名ではない。それらの内容は定義によって決定できる。私が意味したことの正確な表現は、たとえば「象の類に入るすべての実体を、そしてそれだけを成員とする群」であったであろう。しかしこの表現は不便なほど長かったであろう。そしてこれでさえ定義の試みと間違えられたかもしれない。実際にはそれは、その外延に基づく群の記述なのであるが。

**123**　群の成員と群の部分とを区別しなければならない。グレートブリテンのすべての州の群を取るなら、イングランドもホワイトチャペルもその群の成員ではないが、それらは部分であり、群はその全体である。群のすべての成員はまたその部分でもある。そしてそれらに加えて、ホワイトチャペルのように成員の部分であるか、イングランドのように成員の群であるかするような部分もある。さらに、イーリー司教区のように、異なる成員にまたがる部分もある。

〔原注〕全体と部分の関係は、私には究極的で定義できないものに思われる。

〔原注〕成員のそのような群は、もとの群の下位群と呼ぶと便利であろう。

　部分の全体に対する関係はもちろん推移的である。A が B の部分であり、B が C の部分であるなら、A は C の部分である。しかし成員の群に対する関係は推移的ではない。L が群 M の成員であり、それ自身が A をその成員とする群であるなら、A は M の部分ではあっても M の成員ではない。

**124**　全体はそのすべての部分から成る、とよく言われる。しかしこれは厳密には正確でない。たとえばグレートブリテンはイングランドとスコットランドとウェールズから成る。そしてそれはイングランドとスコットランドとウェールズ以外の何ものからも成らない。しかしこれらはグレートブリテンのすべての部分ではない。サリーもまたその部分だからである。

　われわれはさらなる概念――私が部分の組と呼びたい概念――を必要とする。どんな全体の部分の組とは、ともにその全体を構成し、しかもそれを構成する以上のことはしない、つまりそれらの部分やその部分のどれかが取り去られたなら全体が構成されないであろうような、その部分の集まりのことである。こうしてイングランドとスコットランドとウェールズはグレートブリテンの部分の組である。グレートブリテンのすべての州もそうである。そしてイングランドとスコットランドとウェールズ内の諸州もそうである。しかしスコットランドとウェールズはグレートブリテンの部分の組ではない。それらは全体を構成しないからである。イングランドとスコットランドとウェールズとサリーも組ではない。サリーが取り去られても全体はなお構成されるであろうからである。イングランドとウェールズとヨーク以北の地域も組ではない。ヨーク以北の地域のうち国境より南にある部分が取り去られても全体はなお構成されるであろうからである。このように一つの全体は多くの部分の組をもつことができ、二つの単純で分割できない部分から成る全体を除けば、どの全体も一つより多くの部分の組をもつであろう。

〔原注〕ホワイトヘッド博士の感覚対象の合成の定義を参照。（『思考の組織』一五九ページ。「二つの感覚対象の両方の部分であるような第三の感覚対象がないとき、それらを『分離している』と呼ぶ。そのとき、対象 A が二つの対象 B と C から合成されているのは、（1）B と C がともに A の部分であり、（2）B と C が分離しており、（3）B からも C からも分離している A の部分がないときである。」）

〔原注〕したがって二つの単純観念から成る合成観念は、ただ一つの部分の組しかもたないであろう。しかし第22章で見るように、単一で分割できない実体はない。したがってどの群も一つより多くの部分の組をもち、実際、そのような組を無限にもつであろう。

　全体とその部分の組とのあいだの関係は推移的である。イングランドとスコットランドとウェールズがグレートブリテンの部分の組であり、州のある集まりがイングランドの部分の組であり、第二の集まりがスコットランドの部分の組であり、第三の集まりがウェールズの部分の組であるなら、三つの集積をあわせたものはグレートブリテンの部分の組であろう。

　群の成員はその群の部分の組である。それらはいっしょに取られるとき群を構成し、そのどれか、あるいはその部分のどれかが取り去られたなら群は構成されないであろうからである。

**125**　群は、成員と部分のほかに、私が内容と呼びたいものをもつ。内容とは、群の異なる部分の組のうちで同一であるような多数性を意味する。イングランドとスコットランドとウェールズはグレートブリテンの部分の一つの組であり、州は別の組であり、教区と教区外地は別の組である。それらは別々の部分の組であるだけでなく、これら三つの組の場合、一つの組に見いだされるどの部分も他のどちらの組にも見いだされない。それでもわれわれは、それらのあいだにある同一性があり、州の組を取るときと教区の組を取るときに、二つの実在を取っているのではなく、同じ実在をもう一度取っているのだ、ということを悟る。これこそ私が内容によって意味するものである。

〔原注〕群が二つの単純で分割できない成員から成るなら、それはただ一つの部分の組しかもたず、その内容はその組と区別できないであろう。しかし前の注で述べたように、単純実体はないことがわかるであろうから、この場合は実体については不可能である。

　二つの群が同じ内容をもつことがある。グレートブリテンの州を成員とする群と、グレートブリテンの教区と教区外地を成員とする群とは、同じ成員をもたないのだから異なる群である。二つの群は、一方の部分で他方の部分でもないものがないとき、同じ内容をもつであろう。そして次章で見るように、ある場合には、一方の部分で他方の部分でないものがあっても、それらは同じ内容をもちうる。一方の部分で他方の部分であるものがないとき、それらは完全に異なる内容をもつであろう。他のすべての場合には、それらは部分的に同一の内容をもつであろう。

**126**　一方が他方の部分であるような二つの成員から群が形づくられることはありうるであろうか。ありうることは明らかだと思われる。たしかに、全体である実体のうちにすべての内容が取られているのだから、その一部を二度目に繰り返しても、追加の内容は何も加わらない。しかし内容の部分的同一性にもかかわらず、別個の群がある。庶民院の厨房委員会は庶民院議員の群の部分である群である。委員会にいる者で院にもいない者はいないからである。しかしそれらは異なる性質をもつ別個の群である。院の群の成員は税を議決できる団体を形づくるが、委員会の群の成員はそうではない。委員会の群の成員は院によって選ばれた団体を形づくるが、院の群の成員はそうではない。そしてそれらは別個の群なのだから、それらを成員とするさらなる群がある。

　そのような群は、内容の一部を反復するのだから、反復群と呼んでよいであろう。そのような群の数は無限である。第7章で見たように、二つより少ない実体はありえないからである。そして二つの実体 A と B があるなら、A と B を成員とする群 L があるであろう。そしてそうすると、A と B と L を成員とする別の群 M があり、以下限りなく続くであろう。

　この無限系列をたどっていくと、たいていの場合、群はすぐに実践的にはほとんど重要でなくなる。庶民院と厨房委員会から成る群を観照することにはいくらか有用性があるかもしれない。ある事柄について権限をもつ唯一の二つの団体として、それらをいっしょに観照することはしばしば価値があるかもしれないからである。しかしこの群と厨房委員会とを成員とする群は、何の実践的重要性ももちえないであろう。そして系列のさらに先の群は、もし可能なら、いっそう重要でないであろう。しかし重要でないものもそれでも実在的なのである。

　反復群は、そのそれぞれが同じ部分を一度より多く含むような部分の組をいくつかもつであろう。群 L が A と B を成員としてもち、群 M が L と A を成員としてもつなら、A と B は L の部分の組であり、L と A は M の部分の組であろう。全体とその部分の組とのあいだの関係は推移的なのだから、M は A と B と A から成る部分の組をもつであろう。これらはともに M を構成し、それを構成する以上のことはしない。B か、A の二回の出現のどちらかが取り去られたなら、M は構成されないであろうからである。一つの部分が同じ組のなかに一度より多く現れうるのは、反復群においてだけである。

### 第16章　複合実体

**127**　どの群も性質をもち、関係に立つ。第14章で見たように、すべての群に共通のある性質がある。そして少なくともいくつかの群が、それ自身に特有の性質をもち、特有の関係に立つことは明白である。一九一九年に生きているすべてのフランス人を成員とする群は、国民であるとか共和国であるとかいった性質をもつ。そしてそれは一八九九年に生きていたすべてのフランス人を成員とする群に対して、ある類似と非類似の関係性に、またある因果関係に立っている。群は性質をもち関係に立ち、それ自身は性質でも関係でもないのだから、それは実体である。

　実体は群の部分である。したがって、ある実体は実体をその部分としてもつ。実体をその部分としてもつ実体を複合実体と呼んでよいであろう。そうするとわれわれの現在の立場は、少なくともある実体は複合的である、ということである。のちに、すべての実体が複合的であると考える理由を見るであろう。

**128**　そうすると、どの群も実体である。しかし異なる群はどれも異なる実体であろうか。グレートブリテンの州の群とグレートブリテンの教区の群は異なる群である。しかしすでに見たように、それらは同じ内容をもつ。それらは異なる群であるから異なる実体である、と言うべきか、それとも同じ内容をもつから同じ実体である、と言うべきか。

　私には、同じ実体であると言うべきであることは明らかだと思われる。それらのあいだにはただ一つの違いしかない――両方がもつ二つの部分の組のうち、一方の組は一方の群の成員の組であり、他方の組は他方の群の成員の組である、ということである。この違いは群としてのそれらの本性にのみかかわり、それを越えない。そしてそれは確かにそれらが一つの群であることを妨げるが、それらが一つの実体であるかどうかという問いには影響しない。他方、実体の同一性は内容の同一性と結びついているように思われる。

　また一つの実体がいくつかの群であることにも何の難点もない。「X と Y を成員とする群である」は一つの性質である。「T と U と V と W を成員とする群である」は別の性質である。どの実体も多くの性質をもつのであり、X と Y の内容が T と U と V と W の内容と同一であるなら、それがこの両方をもってはならない理由はない。

　そうすると、複合実体は、それがもつ部分の組と同じ数だけの群であろう。その部分の組のそれぞれが一つの群の成員の組であろうからである。それは、それについて、それがその実体の成員の組である、と言えるような部分の組をもたないであろう。一つの部分の組は、特定の群に言及することによってしか、成員の組として他の組から区別できないからである。そして実体は、これらの群のどれか一つであるのが、他のどれかであるより特にそうであるわけではない。

　そしてさらに、どの複合実体もまた無限に多くの反復群である。複合実体は二つ以上の実体をその部分としてもつからである。そして前章で見たように、二つ以上の実体のどんな群も反復群の無限系列を生み出す。そしてこれらの反復群はすべて、それらを生み出す非反復群と同じ内容をもつのだから、すべて同じ複合実体と同一であろう。

〔原注〕第126節。

　前章で、ある場合には二つの群は、一方の部分で他方の部分でないものがあっても同じ内容をもつであろう、と述べた。たとえば、L が A と B を成員としてもち、M が L と A を成員としてもち、N が M と A をもつなら、L と N は同じ内容をもつが、N は L の部分でない部分 M をもつ。内容の同一性の一般的な公式は、二つの群は、そのそれぞれについて、一方の組の部分で他方の組の部分でもないものがないような部分の組が見いだせるなら、同じ内容をもつ、と言えば得られる。たとえば N は部分の組として A、B、A、A をもち、L は部分の組として A、B をもつ。そしてこれらの組のどちらにも、他方の組の部分でもないような部分はない。

〔原注〕第125節。

　そうすると、複合実体は無限に多くの反復群と同一であり、そのそれぞれには同じ部分を一度より多く含む部分の組がある。しかしながら、複合実体が、そのそれぞれが同じ部分を一度より多く含むような部分の組をもつ、と言ってはならない。たとえば A、B、A、A は N の部分の組である。四つの部分のどれかが取り去られたなら N は構成されないであろうからである。しかしそれは N が反復群だからである。A の出現のうち二つが取り去られても、内容は何も取り去られないであろう。そして実体をなすのは内容の同一性なのだから、実体は完全に構成されているであろう。実体は、その部分の組として、それと同一であるすべての非反復群の部分の組をもつが、反復群の部分の組はもたない。

　複合実体は、その部分であってまったくそのうちに入る他の実体をもつであろう――庶民院と厨房委員会の場合のように。しかしまた、部分的にそのうちに入り、それと共通の部分と、その外に出る部分とをもつ他の実体もあるであろう。たとえば庶民院と枢密院はこのしかたで重なり合っている。

**129**　同じ内容を、全部であれ一部であれ含まない二つ以上の実体はどれも、一つの複合実体を形づくる。したがって複合実体の数は、ただ一つの仮説を除いて無限である。有限個の単純実体が宇宙の部分の組を形づくるなら、複合実体の数は有限であろう。他のどの場合にもそれは無限であろう。そしてのちに見るように、宇宙は有限個の単純実体から成ってはいないので、複合実体の数は実際に無限であろう。

　異なる内容の二つ以上の実体はどれも別の実体を形づくるという結論は、多くの場合逆説的に見えるであろう。他の場合にはごく自然に見えるであろう。現時点のフランス市民の群が一つの実体であると言っても、何の驚きもない。現時点のフランス市民の群は現時点のフランス国民だからである。そして国民はあまりにも緊密で重要な統一なので、それを実体と呼ぶのに何の奇妙さもないことは一般に認められるであろう。しかし先に挙げた、いまケンブリッジにある机と、いまオーストラリアにいるウサギと、十八世紀のフランスでの一服の薬とから成る群のようなものに来ると、統一はあまりにもわずかなので、そのような群を実体と呼ぶのはばかげている、と言われるかもしれない。

　この反論に対する答えは、われわれの実体の定義は統一の緊密さや重要性について何も言っていない、ということである。実体とは、それ自身は性質でも関係でもないのに、性質をもち関係に立つもの、と定義された。そして最も突飛な群もこの定義に合致するのだから、それは実体と呼ばれねばならない。

　またそれが逆説的な結果に導くということも、われわれの実体の定義に対する公正な反論ではないであろう。実体という語は日常の言説ではあまりにも不整合に用いられているので、どんな定義も、一貫して守られるなら、逆説的に見えるほど奇妙な結果に導くであろうからである。そのうえ、もし実体という名を緊密な、あるいは重要な統一のためにとっておくとしたら、それは体系のずっと後になるまで用いることができなかったであろう。緊密な統一ということで何が意味されるかを決定する立場に、われわれはまだないからである。そして何が本当に重要かを決定することが可能になるのは、さらに後の地点になってからであろう。体系の後のほうでしか到達できない概念によって実体を定義することは、われわれの採った道筋が生み出すどんなことにも劣らず、通常の用法からの大きな逸脱であろう。さらに、われわれは、性質や関係であることなしに性質をもち関係に立つものについて多くを語ってきたし、これからもっと語るであろう。それには何らかの名がなければならない。そしてそれに実体という名を拒むなら、別の名を見つけるのは容易ではない。

**130**　さらにまた、われわれのこの名の用法は、ある場合には、いま論じたもののように問題の特定の群がそれ自体で重要でないからではなく、それ自身の成員と比べて重要でないために、不適切とみなされるかもしれない。たとえば、ブリッジの一座と、その一座を構成する人々との両方に実体という名を与えるのは理不尽だ、と言われるかもしれない。ブリッジの一座は、机とウサギと薬から成る群のような突飛な群ではない。その成員はさまざまな性質を共有していなければならず、それらのあいだの関係は直接的で明白でなければならない。しかし人々のほうがはるかに重要であり、はるかに持続的であり（たとえ彼らが不死でないと考えられるとしても）、ブリッジの一座が彼らに依存するよりもはるかに少なくしかブリッジの一座に依存していないので、人々とブリッジの一座の両方を実体と呼ぶのは不適切だ、と考えられるかもしれない。

　この反論に対する答えは前の反論に対するものと同じである。われわれの採った実体の定義は重要性や持続性や独立性について何も言っておらず、ブリッジの一座は人々と同じだけそれに合致する。

　あるいはまた、複合実体はその部分と比べて重要でなさすぎるので実体ではありえない、という反論ではなく、その部分と比べて重要すぎるので、それから合成されたものと見なすことはできない、という反論がなされるかもしれない。たとえば、人が時間のうちのその継起する状態に対して全体がその部分に対するように立つとみなされ、人の内容がすべて時間のうちに入るなら、彼は実体としてだけでなく、時間のうちの彼の状態――それもまた実体とみなされねばならない――から合成された実体として考えられねばならない。そしてこれは理不尽だ、と言われるかもしれない。たとえ人の内容の全体が時間のうちに入ると想定しても、人の本性のうちには彼の状態のどれにも見いだされないものが多くあるからである。それならどうして彼が状態から合成されていることがありえようか、と。

　ここでの答えは、実体から構成され、したがって群である実体は、その部分のどれにも見いだされない多くの性質（とりわけ、それらがその部分であるところの全体であるという性質）をもたねばならず、それらの性質のなかには最も重要なものもありうる、ということである。たとえば、フランスは個々のフランス人から構成されている。フランスという実体のうちには、あれやこれやのフランス人のうちに入らない内容は何もない。それでもフランスは国民であり共和国であって、どのフランス人もそのどちらでもない。そして同じように、ジョン・スミスのうちには、時間のうちの彼の状態のあれやこれやのうちに入らない内容は何もないかもしれない。それでも彼は、それらの状態のどれの性質でもない多くの性質をもつであろうし、それらのなかに、彼自身にとっても彼の友人たちにとっても最も重要な彼の性質が含まれている、ということも十分ありうるであろう。

### 第17章　群における排他的共通性質

**131**　ある群には、そのすべての成員に共通の性質があることをわれわれは見た。それらを群における共通性質と呼んでよいであろう。（成員のそれぞれの性質である群における共通性質は、群の性質から区別しなければならない。多くの場合、群において共通である性質は、群そのものの性質ではない。たとえば「象である」が群における共通性質であるとき、それはその群の性質ではない。象の群はけっして象ではないからである。）

　どの群にも共通性質はあるであろうか。（共通性質のうちには、もちろん、群の各成員が何かに対して同じ関係に立つなら生じるであろう共通の派生的性質も含まれる。）どの群にも共通性質があることは明らかである。どの群のすべての成員によってもたれ、したがってどの群においても共通であるような性質――存在、実体性、性質をもつこと――があるからである。

　しかしさらなる問いがある。われわれは、ある群には、その群の成員以外の何ものとも共有されない共通性質があることを見る。たとえば、すべての象を成員として含み、象でない成員をもたない群における「象である」がそうである。それらを排他的共通性質と呼んでよいであろう。どの群も一つ以上の排他的共通性質をもつであろうか。

**132**　ここでも答えは肯定でなければならない。第一に、どの群 L も A と B と C を成員としてもつなら、各成員が A と B と C を成員とする群の成員である、ということはその群における排他的共通性質であろう。これは実際ほとんど同語反復にすぎないが、排他的共通性質を与えはする。

　そしてさらに、L の成員でない実体が少なくとも一つある。さて、それらの実体のどれか一つ D について、群のすべての成員がそれと相異しているであろう、ということが真であろう。そしてそれと相異しているのだから、すでに見たように、それと非類似でなければならない。したがって群のすべての成員は「D と相異し非類似である」という性質をもち、これはしたがって L における共通性質であり、D によってはもたれない。

### 第19章　普遍的決定

**137**　前章の終わりに達した結果は、外在的決定の問題に重要なかかわりをもつ。外在的決定がそう呼ばれたのは、それがある実体の別の実体による決定だからではなく、二つの性質が同じ実体に対して立つ関係のおかげでそれらのあいだに成り立つ決定だからであった。他方、内在的決定は二つの性質そのもののあいだに成り立つ決定であった。

　しかし実際には何の難点もない。一般法則において表現される命題は、第一次的には、現実のものであれ可能なものであれ、いかなる個体についての言明でもないからである。それは第一次的には二つの特性のあいだの関係の言明である。問題の関係はたしかに、存在のうちに生じる特性を扱う一般法則の場合には、特性 X が生じるすべての場合に特性 Y もまた生じるであろう、と推論できるような本性のものである。しかしこれは法則の本質ではない。それは特性の結びつきにある。そしてこの結びつきは、存在するものが何もこれらの特性をもたないときにも存在しうる。

〔原注〕第2章で見たように、このことは、存在するもの以外には何も実在しないという見解と両立しないわけではない。

**142**　われわれがいま証明した、存在するすべての特性の相互依存は、もちろん、すべての特性が一般法則によって決定されていることと同値ではない。特性が一般法則によって決定されるとは、何か他の特性 Y の生起が X の生起を内在的に決定する、ということを意味する。すべての特性が一般法則によって決定されているという主張は、どの特性 X のどの生起についても、Y が X を内在的に決定するような特性 Y の生起が見いだせる、ということを意味するであろう。そしてわれわれが証明したのは、特性が互いに外在的に決定し合っている、ということだけである。

　ここでわれわれは内在的な決定、あるいは一般法則によって働く決定を考察しているのではないのだから、因果性を扱っているのではない。この語にどのような意味を与えるべきかはのちに考察するであろう。しかし因果性の通常の見方は、他の要素とともに、確かに一般法則の現前を含む。X は何らかの一般法則によって Y と結びついているのでないかぎり、Y の結果とは見なされない。そしてわれわれはこの見方を正しいものとして受け入れる理由を見いだすであろう。したがって外在的決定は因果性ではない。

　しかしわれわれが達した結果は、ヘーゲルが因果性と相互作用のカテゴリーにおいて確立したと考えた結果とほとんど同じであるように思われる。それらのカテゴリーにおいて彼は、すべてのものは他のすべてのものによって決定されている、という結論に達しており、彼が、その決定が一般法則によって起こる、という意味で言っているはずはない。彼は、弁証法のさらに先にある普遍的判断のカテゴリーに来るまで、一般法則の観念を持ち込んでいないことは明らかと思われるからである。

〔原注〕しかし因果性についてのヘーゲルの扱いの細部は、われわれが達した結論とは非常に異なる。とりわけ、原因と結果は同一であるという彼の途方もない見解がそうである。

**143**　実在についてのある理論に対しては、それは宇宙を、すべての部分が他のすべての部分と硬直的に結びついている「塊」の宇宙にしてしまう、という反論が提起されてきた。この反論は一般に、宇宙のすべての部分が一般法則によって他のすべての部分と結びついているとみなす理論に対して提起される。その場合には確かに、すべての部分は他のすべての部分と硬直的に結びついているであろう。しかし反論の向けられている硬直性は、一般法則による決定が完全でなかったとしても生じるであろう。いま見たように、どの実体のどの特性も他のどれに対しても外在的に偶然的ではなく、したがって、A が特性 Y をもつことや B が特性 Z をもつことに影響することなく、A が特性 X の代わりに特性 W をもちえたであろう、と言うのは正当ではないからである。そしてここでの結びつきは、一般法則による結びつきとまったく同じく硬直的である。

　「塊」の宇宙に対する反論は、私の知るかぎり、まったく価値判断に基づいている。そのような硬直的な宇宙は非常に不快であろうとか、道徳を破壊するであろうとか主張され、したがってそのような本性の宇宙は悪として断罪されるべきだと言われ、さらにときには、実用主義的な根拠から、偽として退けられるべきだと付け加えられる。偶然性の価値は意見の分かれる点であり、ここではわれわれにかかわらない。われわれが注意すべきことは、偶然性の不在が悪であるなら、それは避けがたく普遍的な悪だ、ということだけである。

### 第20章　有機的統一

**144**　第13章で見たように、実体の性質は、その実体の本性がそれから合成される部分としてだけでなく、全体として取られたその本性の顕現としても取ることができる。また前章で見たように、各実体の存在は宇宙のある性質――その実体をその部分の一つとしてもつという性質――の存在を含む。このことは宇宙以外の全体についても真である。どの実体 A も、その本性が性質 XYZ から成る部分 B をもつなら、本性が XYZ である部分をもつことは A の性質であろう。そして A のこの性質は、第13章で達した結果によって、A の本性の部分の一つとしてだけでなく、その本性の顕現としても考えることができる。

　A と B の性質のこの関係から、A と B そのもののあいだの関係が帰結する。全体である実体は、その部分から合成されたものと考えることができる。そして一見したところ、われわれはそのように考えている。しかし、いま見たように、そのような本性の部分をもつという事実は A の本性の顕現と考えることができるのだから、部分の存在は全体の存在に依存しているものと取ることができる。部分を全体を構成するものと考える代わりに、われわれは――より真にではないが、まったく同じく真に――全体が部分となって現れ出るもの、と取ることができる。そうしてわれわれは、部分は全体の顕現である、と言うことができる。

　全体の顕現と全体の本性の顕現とを区別しなければならない。A は A の部分である実体のうちに顕現しており、A の本性は、その本性の部分である A の性質（もちろん、B とその部分である他の実体をその部分としてもつという性質を含む）のうちに顕現している。というのも、われわれが顕現という語を用いている意味では、何ものもそれ自身の部分のうちにしか顕現しえず、実体の部分は実体であり、実体の本性の部分は性質であることは明白だからである。

　A の各部分には A の性質――その部分をもつという性質――が対応するであろう。しかし A のすべての性質に対応する部分があるわけではない。どの実体も、それがもつ部分をもつという性質のほかに、他の性質をもつからである。

　第13章で見たように、どの実体についても「しかじかの性質のうちに顕現している本性は何か」という問いには、それはそれらの性質のうちに顕現している本性である、と言うことによってしか答えられない。実体の本性は、それが顕現している性質以外の何ものからも成らないからである。しかし「しかじかの部分のうちに顕現しているその実体の本性は何か」という問いには、部分のどれにも言及しない答えを返すことが可能である。部分に言及しない性質によって答えることができるからである。スミス、ブラウン、およびその同胞市民はイギリス国民の部分であり、その国民は、スミスを市民としてもつという性質、そしてブラウンやその他についても同様の性質を含めなければ完全には記述できないであろう。しかしイギリス国民について、それは大国であり、制限君主制であり、二つの国教会を含む、等々と言うことはでき、こうして、特定の部分をもつという性質であるような性質を一つも含めずに十分な記述を形づくることが可能かもしれない。

〔原注〕これが同語反復になるのは、問いのなかで実体の一次的性質がすべて列挙されている場合だけであろう――そしてその数は無限である。実体の数、したがって各実体の他の実体への関係の数は無限だからである。「X のうちに顕現している B の本性は何か」という問いには、「YZ のうちにも顕現している本性である」と答えることができる。

**145**　この段階で達する全体のその部分に対する新しい関係は、部分どうしの新たな関係を含む。前章で見たように、宇宙のなかのすべての実体は相互に依存しており、その結論に達した根拠は、宇宙以外のどの全体についても、その部分が相互に依存していると結論することを同じく正当化するであろう。どれかの部分が異なっていたなら、それはもはや同じ全体ではないであろうし、同じ全体でなければ、他の部分のどれかが存在するであろうと考える理由はないであろう。しかしいまやわれわれはさらに進むことができる。部分はいまや、統一として取られた全体を顕現するものと見られるからである。どの部分も、他の部分がそうしないなら、これをなしえないであろう。どれかの部分が欠けていたなら、その部分を含む全体はまったく顕現しえないであろうからである。したがってどの部分も、他の部分もそうしないなら、全体を顕現しえないであろう。こうして部分は全体を顕現することにおいて協働している、と言うことができる。

　相互依存は以前より完全になったわけではないが、より積極的になった。われわれはもはや、部分の一つが異なっていたなら全体は異なっていたであろうし、他の部分が残るであろうと想定する根拠はないであろう、と言うだけではない。部分には果たすべき共通の機能――全体の顕現――があり、それらのそれぞれが異なるしかたでそれを果たしながら、他の部分もそれを果たしているのでなければ、どれもそれを果たしえない、とも言うのである。相互的な不可欠性の観念に、いまや相互的な協働というより積極的な観念が加わる。

**146**　いま達した、全体の部分に対する、そして部分どうしのより積極的な関係は、ときに、全体はすべての部分のうちにある、と言うことによって表現される。この言い回しは不幸なものと私には思われる。哲学においては、文字どおりの意味では偽である言い回しを、それが比喩としてのみ用いられていることがまったく明白でないかぎり、用いるのは望ましくない。この場合、この言い回しが比喩としてのみ用いられていることはまったく明白とは思われない。そして比喩として用いられていないなら、それは偽である。いかなる全体も、文字どおりの意味では、その部分のどれか一つのうちにありえないからである。

〔原注〕私は「文字どおり」を「空間的」と同値には取らない。うち、そと、全体、部分、より大きい、より小さい、といった語は、空間的なものについてと同じく文字どおりに、非空間的なものについても用いることができると私には思われる。私の思考は私の心のうちにある、メレディスはメリット勲章受章者のうちにあった、という言明は、ネルソンの墓はセント・ポール大聖堂のうちにある、という言明と同じく文字どおりに真であると私には思われる。

　そしてこの言い回しは、思うに、混乱に導く。その部分が意識ある存在者であって、そのそれぞれが全体を知覚する、あるいは全体が存在すると判断するような全体の場合には、全体の観念はすべての部分のうちにある、と言えるかもしれず、これは（もしこの言明を意識ある存在者である一つの部分の組に限るなら）文字どおりに真であろう。そして全体は部分のそれぞれのうちにある――これは比喩としてしか真でありえない――と言われるとき、このことが比喩的に言えるすべての全体は、全体の観念がすべての部分のうちにあることが文字どおりに真であるような全体である、とときに想定されているのだと思う。そしてこれは誤りに導く。この比喩は、その部分が意識ある存在者でない多くの全体にも適用されるが、全体の観念がそのそれぞれのうちにありうるのは、部分が意識ある存在者である場合だけだからである。

　しかし、全体は部分のうちにあるという表現は不幸なものであるが、それが生じたことが不自然でないことは認めなければならない。全体はそれぞれの特定の部分のうちに顕現しないかぎりまったく顕現しえないことが悟られるとき、各部分は全体との関係において唯一無二の機能を果たしていると見られる。たしかに、それは全体にとって他のすべての部分以上に本質的であるわけではない。しかしそれがちょうどそれがあるところのものであって、他の何ものでもないことは、全体にとって本質的である。そしてこの部分の特別な本性がそれにとって本質的であるような全体は統一として取られているのだから、その関係を、全体は各部分のうちにある、と言うことによって表現しようとする試みがなされたことは驚くにあたらない。

〔原注〕「汝の声は弱く思われた。それがやむと／創造の合唱はとだえた。」ブラウニング「少年と天使」。

**147**　またさらに、このような全体においては、全体の本性は各部分のうちに表現されている、とときに言われる。これもまた文字どおりには真ではない。全体の本性は、いっしょに取られたすべての部分のうちに表現されている――あるいはわれわれがそう呼んできたように、顕現している――が、別々のそれぞれのうちにではない。そしてこの場合にもまた、比喩としてでさえこの表現を用いるのは望ましくないように思われる。しかしこの場合にもまた、この表現が採られたことにはいくらかの言い訳がある。全体の顕現を助けることにおける各部分の唯一無二の機能が、その部分だけによる全体の本性の表現と混同されたのは不自然ではなかったかもしれないからである。

〔原注〕のちに（第286節）見るように、単なる有機的統一についてよりも、全体はすべての部分のうちにある、あるいは各部分は全体の本性を表現している、と言うのがより適切であるような統一の可能な形がある。しかしこのさらなる統一についてさえ、これらの表現は文字どおりには真ではないであろう。

**148**　部分をもつどの実体も、このしかたでその部分のうちに顕現している。突飛な実体の例に戻れば、その実体の本性は、オーストラリアで最も年老いたウサギをその部分の一つとしてもつという性質を含む。したがってその実体そのものはそのウサギのうちに顕現している。これは、私の身体が全体として私の心臓のうちに顕現しているとか、絵が全体としてそのさまざまな細部のうちに顕現しているとか言う場合ほど自然な表現には思われないが、顕現は最初の場合にも他の二つの場合と同じくそこにある。（第二と第三の場合に表現がより自然に思われる理由は、この章ののちに考察する。）

　全体である実体は互いに重なり合うのだから、同じ実体がさまざまな重なり合う全体の顕現であろう。一八〇〇年のウィリアム・ピットは、一八〇〇年の枢密院と一八〇〇年の庶民院の両方の顕現である。ピットを成員としてもつことはその両方の性質だからである。

**149**　私はこの章に「有機的統一」という題をつけた。われわれの現在の立場は、哲学者たちによって一般に有機的統一、あるいは内的目的論という名を与えられてきたものに非常によく似ていると思われるからである。これらの名――両方が用いられるときは同義語と見なされる――によってつねに指されているのは、全体の部分に対する位置が単に機械的な統一におけるよりも強く、部分どうしの関係が機械的な統一の場合よりも部分をより緊密に結びつけるような、分化した統一であることは疑いないと思う。

〔原注〕ヘーゲルは目的論を一つのカテゴリーの名として、生命を目的論のすぐ後に続く別のカテゴリーの名として用いている。有機的統一の概念は生命のカテゴリーのもとで導入される。しかし内的目的論の完全な概念は目的論の最後の下位区分まで達せられず、他方、有機的統一の概念は生命の最初の下位区分で入ってくる。そしてこれらの下位区分の一方から他方への移行は、ヘーゲルの方法によれば「直接性への崩落」であり、新たな結果には達せず、先に達した結果を言い直すだけである。

　この概念に有機的統一という名が与えられたのは、それが生物学で研究される有機的生命に固有のものと考えられたからではなく、その有機的生命のうちでとりわけ際立って明白だと考えられたからである。これは真だと思う。われわれの議論が正しかったなら、すべての全体はこの意味で有機的統一である。しかしある全体は他の全体よりもはるかに明白に有機的統一の特別な特性を示す。これらの特性がとりわけ明白な統一のほとんどは二つの類に入る――生物学的有機体と、美しいと認められる対象とである。なぜそうなのか。なぜ一頭の馬や一枚のペルシア絨毯や美しい夕焼けのあいだの空が、石の山や一ヤードの無地のキャンバスや特に美しくない空よりも、明白に有機的統一に見えるのか。思うに、その理由は、第一の類の場合には、小さな変更が、われわれが高い重要性――観察者のその時の個人的な必要にとっての重要性だけでなく、価値の客観的基準によって判断して高い位置を占める重要性――を帰する対象の特性を変えるであろう、ということである。石の山がわずかに大きくなっても、それは異なるであろうが、その違いは、何か特別な目的のためでなければ、われわれが重要と見なすような違いではない。しかし生きている身体のごくわずかな変化はそれを病気にしたり殺したりするかもしれず、美しいもののごくわずかな変化はそれを醜くするかもしれない。そしてこれらは、われわれが――正しくにせよ誤ってにせよ、ここでは問題ではない――客観的な立場から判断して重要と見なす性質である。

　さて有機的統一の本質的な特徴は、部分が全体を顕現すること――統一としての全体がそれがあるところのものであるから、部分はそれがあるところのものでなければならない――ということである。これは、すでに見たように、実際にはすべての全体についてそうであり、したがってすべての全体は実際には有機的統一である。しかしそれらの有機的本性が明白になるのは、ほんのわずかだけ異なる部分の組が、ある重要な特性において異なるであろう全体の本性の顕現であろう、ということが明白になるときだけである。石の山の場合はそうではない――石の一つを加えたり除いたり、二つの石を入れ替えたりすれば、それは異なる全体になるであろうが、何か重要な特性において異なるわけではない。しかし生命と美はわれわれによって重要な特性と見なされており、部分のわずかな変化がそれらを破壊するかもしれない。こうして、生きている全体や美しい全体については、部分が全体の本性の顕現であることが明白である。異なる部分は全体が同じであることとあまりにも明白に両立しないであろうからである。

　たしかに、全体が生命も美ももたないのにその有機的本性が明白である場合もほかにある。しかし生物学的有機体と美しい対象の類を除いて、有機的統一が明白であるような全体の大きくてはっきりと区切られた類はない。

**150**　これが、そうすると、有機的統一という名の正当化である。しかしこの名には不便もないわけではない。同じ名を用いることによって哲学的概念と生物学的概念とが結びつけられたために、ある哲学者たちは、一方についてしか正当に主張できない命題を他方について主張するようになったからである。

　第一に、生物学的事実を、ときに「機械論的」原理と呼ばれる物理科学の通常の原理によって説明することは、無機物にかかわる事実の説明ほどには進んでいない。こうして科学においては、有機的本性は、少なくとも当面は、機械論的説明の失敗と結びつくようになった。そこでときに、有機的統一という哲学的概念を宇宙の説明における根本原理として提出することは、宇宙は機械論的説明ができないと主張することだ、あるいは少なくとも、存在が有機的統一によってうまく記述されるかぎり、それは機械論的決定によってはうまく記述できない、と主張することだ、と想定されてきた。そしてこれは、すでに見たように誤りである。全体を部分から合成されたものとみなすことは、部分を全体の顕現とみなすことに劣らず正しい。両方が真である。有機的統一に達したときのわれわれの立場の優越は、最後に達したものの優越にあるのではなく、われわれが両方に達したという事実にある。

　第二に、生物学との類比は、別の方向で概念の範囲を不当に限るよう導くかもしれない。たとえそれがすべての存在にあてはまること――つまり、すべての実体的内容が何らかの有機的統一のうちに入ること――が認められるとしても、すべての実体が有機的であることはしばしば否定されるであろう――たとえば、先に挙げた、机とウサギと一服の薬とから成る実体である。そしてこれは、思うに、生物学によって示唆されている。羊は生物学的有機体であり、羊飼いもそうであるが、羊の群れや、羊とその羊飼い、あるいはすべての羊の左脚から形づくられる群は生物学的有機体ではないからである。しかしこの制限は、われわれの概念に適用されるときには正当化されない。これらの群はすべて部分をもつ実体であり、部分をもつどの実体も有機的統一であることをわれわれは見たからである。

**151**　第三に、生物学によって考えられる有機体は、われわれの現在の概念のもとで観照される有機的統一よりも完全でない統一である、ということに注意しなければならない。これらの有機的統一においては全体はその部分と同じく根本的であると見られるが、生物学においては全体はその部分ほど根本的ではないからである。

　生物学的有機体を構成する物質の単位は、その有機体の外に存在することができ、どの場合にも存在したことがあり、また存在するであろう。もし実際、それらが他の有機体の部分としてしか存在しえないのであれば、同じ一片の物質が次々に多くの有機体のうちにありうるという事実は、同じ有機体のうちで一片の物質が別の物質に引き継がれうるという事実と釣り合うだけかもしれない。しかし、有機体のうちに存在する同じ物質が、どの有機体の部分でもなく存在することができ、他の時には実際にそうしているのに対し、有機体は何らかの物質片をその部分としてもつことなしには存在しえない、という事実は、生物学的有機体を、その部分が有機体に依存しているよりも多くその部分に依存しているものにする、と思われる。

　物質的な単位が、それが構成する生物学的有機体よりも根本的である点がもう一つある。生物学は時間のうちの出来事を扱う。さて、高等な有機体は、その誕生からある時間のうちにその死と解体とを含む本性をもっており、たとえ死がある下等な有機体にとっては避けがたくないとしても、それらは死にうるし、多くの場合実際に死ぬ。有機体を構成する物質については事情が異なる。それは必然的に存在をやめるのではないだけでなく、その存在を終わらせうる既知の原因は何もない。

　この場合に結びつきによって生じる混乱は、第一と第二の場合と同じしかたでは働かない。それらの場合には、結果は、生物学的概念からの要素が哲学的概念のうちに不当に持ち込まれる、ということであった。他方ここで一般に起こるのは、思うに、哲学者たちが、哲学的な有機的統一の概念によれば部分は全体より根本的ではないのだから、生物学的有機体においても部分は全体より根本的ではない、と誤って結論するよう導かれてきた、ということである。

　実際、これはしばしばさらに先まで進んできた。多くの哲学者は、哲学的な有機的統一の概念によれば全体はその部分より根本的であるとみなし、このことが彼らに、生物学的有機体においても全体は部分より根本的であると考えさせたのである。哲学的概念において全体が部分より根本的であると彼らが想定した理由は、思うに、大部分、すでに述べたようにしばしば有機的統一の同義語として用いられる内的目的論という名に結びついた誤解を招く連想によるものであった。

**152**　これらの連想は、内的目的論と、内的目的論から区別するためにときに外的と呼ばれる通常の意味での目的論との混同へと向かいがちである。たしかに、内的目的論について語る著者たちは一般に、それと外的目的論との違いを述べ、さらには強調することから始める。しかし議論の途中で、名詞によって呼び起こされる連想が形容詞よりもしばしば強すぎたのである。外的目的論においては、目的論的に説明される事実の生起は、何らかの意識ある存在者が採った目的のための手段としてのその位置によって説明される。この場合、目的――その意識ある存在者の意図――は、その手段である事実とはまったく別個のものとして存在する。それ自体が別個の事実――意図を抱く意識ある存在者の心のうちの意欲――である。さて、内的目的論においては多数性を説明し統一する別個の事実はないことが悟られているときでさえ、統一の側面――概念が内的目的論として語られるときには目的として語られるもの――は、その目的を実現する別々の事実の多数性によって形づくられる全体の統一にほかならない、ということを忘れる傾向がしばしばある。それはしばしば、まさにこの統一以上の何か、ただし別個のものよりは少ない何かであると想定される。このような条件のもとでそれが何でありうるのかは容易にはわからないし、その立場の支持者たちによってもあまり明らかにされていない。しかしそれはときに、それによって統一される多数性を構成する事実の本性がなんらかのしかたでそこから演繹されうるような原理と見なされているように思われる。そしてもしそれがそういうものと考えられるなら、それは当然、それから演繹される部分の多数性よりも根本的なものと考えられる。

### 第21章　結果の要約

**155**　これでわれわれは全体と部分の関係をいくらか詳しく論じた。われわれが達した結果は宇宙の全体を通じてあてはまる。宇宙そのものが一つの全体であり、他のすべての実体は部分であり、しかもこれらの他の実体の多くは、すべてではないにせよ、全体でもあり部分でもあるからである。したがってわれわれの結果はすべての実体にあてはまる。

　しかしそれらが生み出す効果は限られている。第一に、宇宙のうちに、正当に秩序と呼べるようなものの存在を、われわれは証明していない。

　全体は多かれ少なかれ秩序づけられていることがある。そして、思うに、どの全体も、三つの特性――そのそれぞれは他の二つと両立する――のどれか一つをもつ程度に応じて秩序づけられている、と言うべきであろう。その第一は、その部分が一般法則にしたがって互いを決定し合うことである。これを因果的秩序と呼んでよいであろう。第二は、その部分が、問題の部分がただ一つの系列を形づくるような関係によって互いに結びついていることである。これを系列的秩序と呼んでよいであろう。

　第三は分類の秩序と呼んでよいであろう。これを定義するためには、まず私が分類体系と呼びたいものを定義する必要がある。全体の部分が分類体系を形づくると言えるのは、全体における各部分の位置を他の部分との関係で定めるような、部分の中の部分の配置があり、しかもその配置によって形づくられる部分の各群が、その外延から生じるもの以外の何らかの排他的共通性質をもつときである。そして全体が分類の秩序をもつと言えるのは、その部分が分類体系のうちに配置でき、その体系が、それをもつ部分にとって根本的な重要性をもつ共通性質に基づくような本性をもつときである。体系が分類を推し進める程度が大きければ大きいほど、秩序はより完全であろう。

　普遍的決定を扱ったときに見たように、事実が一般法則によって決定されている程度についてはまだ何の結論にも達していなかった。したがって因果的秩序についてはいまのところ何も言えない。またすべての、あるいはほとんどの実体のあいだに、それによってそれらがただ一つの系列に配置されうるような関係があると想定する理由も見いだしていない。したがって系列的秩序は、少なくとも現在のところ、宇宙について主張されるべきではない。

**156**　分類による秩序が残る。これは動物界において、その成員が種・属・科などへと群分けされるときに形づくられる種類の秩序であり、また図書館の主題別目録においても形づくられる。いかなる全体も分類の秩序だけによって完全に秩序づけられることはありえない。たとえば分類の秩序は種を属へと群分けしうるが、亜属を導入するのでなければ、種に属のうちでの確定した位置を与えることはできない。たとえ亜属を導入するとしても、それらが分類による秩序の確立に役立つためには、そのそれぞれが一つより多くの種を含まなければならない。そして分類の秩序は各亜属のうちでの種の相互の位置を決定できないであろう。それらのあいだに系列的秩序が存在することがわかるのでないかぎり、それらの相互の位置は秩序づけられないままであろう。しかし動物界や良い主題別目録と同じくらいの分類の秩序をもつ全体は、秩序が完全でないとしても、確かに秩序づけられた全体と呼ばれるであろう。

　全体は、すでに述べたように、分類が根本的に重要な性質に基づいているのでないかぎり、分類による体系を形づくっているからといって秩序づけられているとは見なされないであろう。図書館が本の装丁に使われた材料にしたがって分けられ、これらの群が各巻のページ数にしたがってさらに分けられたなら、分類体系は得られるであろうが、その存在は、図書館を秩序づけられた全体と呼ぶことを正当化するとは思われないであろう。

**157**　全体が分類によって秩序づけられていると見なされるのは、分類がものを似ているかぎりで結びつけ、似ていないかぎりで分けるときだけである。そしてこれは、根本的に重要な性質が、それを基準とすることによってかなり確定した体系が確立できるようなしかたで全体の部分のうちに生じるときにしか起こりえない。さて、われわれには、そのような性質が、それによってかなり確定した体系を確立するようなしかたで宇宙の部分のうちに生じると信じる理由はまだない。たしかに、従属的な全体を観察するとき、ある可能な基準による群分けが、他の基準による群分けよりもはるかに理にかない有益に見えることがしばしばある。人類を分類する原理として性別や宗教を採るほうが、頭髪の数が偶数である人とそうでない人とに分けるよりもはるかに賢明である。性別や宗教による区分は、理にかなった人が実践的あるいは理論的な関心を感じうる多くの問いにかかわりうるが、髪の数による区分は、見るかぎり、理にかなった人がわずかでも関心をもちうるいかなる問いともまったく関係をもちえない。

　しかしこのことから、宇宙に秩序を持ち込むであろう体系の断片にでさえ達した、ということは帰結しない。第一に、性別や宗教をもつ実体が宇宙の完全な部分の組を形づくっていると主張する理由はないであろう。そしてもしそうでないなら、この分類体系は宇宙全体には及ばないであろうし、残りの部分を配置するような補完的な分類体系があると信じる理由もないであろう。

　そして第二に、ある体系は理にかなった人が何らかの実践的関心をもちうる問いにかかわり、別の体系はかかわらない、という事実は、理にかなった人が実践的関心をもつ問いが宇宙の本性において根本的に重要な事柄である、ということが確立されないかぎり、われわれの助けにはならないであろう。そしてたとえこれが真であるとしても、われわれはまだそれを証明していない。たしかにわれわれの理論的関心は、主として宇宙の本性において根本的に重要なものに向けられていると言えるかもしれない。しかしわれわれの知識はきわめて不完全であり、ある体系が別の体系よりも根本的に重要な性質に基づいているようにわれわれに見えるという事実は、われわれの無知によるかもしれない。知識がイングランドの地図に限られている観察者は、ケンブリッジをイーリーよりもオックスフォードの近くに置くようなイングランドの町の分類を、気まぐれで役に立たないと非難するかもしれない。しかしより大きな知識があれば、そのような分類がかなりの意義をもつことがわかるかもしれない。

　そうすると、われわれはいままでのところ――比喩を許していただけるなら――実体のうちにいかなる木目も見いだしていない。それは、実体の可能な組み合わせがあるのと同じだけ多くのしかたで分けたり結びつけたりできる。その数は、次章で無限と見なす理由を見るであろう。そしてそれが配置されうるこれらすべてのしかたのうち、どれか一つが他のどれよりもよくその本性を表現していると想定する理由はわれわれにはない。

**158**　そしてこれに加えて、いくらか似た本性の第二の問題があり、それについてわれわれはまだ何の光も得ていない。経験的にわれわれに知られている宇宙の部分を見ると、合成の統一という概念のほうが顕現の統一という概念よりもはるかに適切に思われる場合があることに気づく。先に考察した突飛な全体の場合、机とウサギと薬が全体の顕現であると言うのも、全体が机とウサギと薬から合成されていると言うのも、たしかにひとしく真である。しかし後者の言明のほうが全体の実際の本性をはるかによく表しているように思われる。そして実在がわれわれの観点からそれほど恣意的でない場合でさえ、合成の統一のほうがより自然に用いられる概念に思われることがしばしばある。石の山については、石を山の顕現としてよりも、山を石から合成されたものとして考えるであろうことは確かである。他方、たとえば人間の意識の継起する状態のような場合には、それを全体――この場合には人間――の顕現と取るのが、人間をそれらから合成されたものと取るのと少なくとも同じくらい自然に思われる。

〔原注〕この最後の場合には、合成よりも顕現のほうが適切だと主張する哲学者もいるであろう。しかし上に挙げた場合に合成のほうがすぐれて適切であることが普遍的に認められるのと同じほど、顕現のほうがすぐれて適切であることが普遍的に認められるような場合を私は思いつけない。このように合成が顕現より強い位置をもつように見えるという事実は、ひょっとすると第23章で論じる全体とその部分のあいだの関係と結びついているのかもしれない。

**159**　このような例は、たとえ二つの類の場合が入る範囲を定義できないとしても、分化した統一の本性が顕現によってよりも合成によってよりよく表現される場合があることを非常に強く示唆する。しかしそうであると確信する権利はわれわれにはない。たしかに、上で述べたように、ある場合には顕現は合成よりもはるかに適切でないように思われる。しかし、問題の全体についてもっと知れば、顕現がひとしく適切に思われないかどうか、われわれはけっして確信できない。統一は、われわれにそう見えるからといって必ずしも些細なものでも表面的なものでもない。すでに見たように、群は外延によって決定されるのであり、群がどの成員から成るかを知りながら、その成員のあいだの最も重要な関係について無知であることは十分にありうるからである。

　ここから、統一がわれわれに些細で表面的に見えるとき、その判断はわれわれの無知によるのであって、群のうちの実際の些細さや表面性によるのではない、ということが十分にありうることになる。ロンドンのある八百屋の店員と、リヴァプールのある巡回区域の警官と、メルボルンのあるクラブの門衛とを成員とする群は、このように記述されると、ごく表面的な重要性しかもたない群であり、顕現の概念はまったく不適切であろう群に見える。そしてそのような記述が、群を完全に同定する排他的記述でないと考える理由もないであろう。それが含む各人の記述がその人の排他的記述であることは十分ありうるし、その場合にはそれ自体が群の排他的記述であろうからである。それでも、記述は排他的であっても、統一を表面的とはほど遠いものにする成員の関係をまったく無視しているかもしれない。三人はみな兄弟であるかもしれず、彼らの互いの愛情や、各人が他の二人に及ぼす影響は、彼らの相互の関係をそれぞれの生涯において最も重要で意義深い特性にするようなものであるかもしれない。

**160**　こうして、実体の本性についていままでに達した情報は、二つの点で不足している。存在する内容は多くの実体のうちに入り、それらの大部分（実際、のちに見るように、そのすべて）は、きわめて複雑に互いに重なり合う群であって、そのそれぞれは合成の統一としても顕現の統一としても取ることができる。さて第一に、これらの区分のどれも他より根本的でないなら、存在が秩序づけられた全体であると信じる理由はない。そしてそのいくつかは確かにわれわれには他より根本的に見えるが、そのどれかが実際にそうであると信じる理由はない。そして第二に、ある群は合成の統一としてのほうが適切に表現され、ある群は顕現の統一としてもひとしくよく表現される、ということを示唆するものは多いが、これが実際にそうであることの証明は見いだせない。

　このすべての複雑さのうちに何か固定点を見いだせるであろうか。現在のところ、思うに、ただ一つしか見いだせない――宇宙である。もし単純実体があるなら、それはもちろん群ではないであろうから、それもまた固定点であろう。しかし単純実体の存在は証明されておらず、次章で見るように、それを信じない理由がある。しかし宇宙は実際に存在し、実体のなかでのその位置は唯一無二で重要である。それはすべての内容を含み、それ自身以外のすべての実体を含むからである。したがってそれは、単にわれわれの関心の観点からではなく客観的に、すべての実体とまでは言わないにしても、ほとんどの実体よりもはるかに根本的な位置をもつ。

　そしてわれわれ自身の関心の観点からもまた、全体としての宇宙の本性を決定することは重要でなくはない。たとえば、宇宙は実体なのだから、いまやわれわれはそれが有機的統一であることを知っている。そして有機的統一のカテゴリーが神秘主義にとって主要な重要性をもつのは、それが全体としての宇宙にあてはまるからである。神秘主義の本質は統一を強調することにあり、それは合成の統一に基づくこともでき、実際に基づいてきたが、有機的統一のカテゴリーにおいて達せられるより緊密な統一は、それにより好都合な基礎を与える。そして有機的統一の概念がその十全な重要性に達するのは、宇宙がそのような統一を含むだけでなく、それ自体がそのような統一でもあることを認めるときだけである。したがって、有機的統一の概念が全体としての宇宙に適用されるときにはじめて、その概念は神秘主義にとって本当に重要になる。たとえば、上で示唆したように、スピノザの第三種の認識とそれに伴う神への知的愛との説明が有機的統一と合成の統一との違いのうちに求められるべきであるなら、その説明が見いだされるのは、有機的統一の概念を全体としての宇宙に適用することのうちにだけである。

　しかし宇宙というこのただ一つの固定点は、すでに述べたようにそれ自体としては重要であるが、その部分であるさまざまな実体のあいだに秩序を持ち込むことには何の役にも立たない。何らかの秩序を見いだそうとするなら、さらに先を見なければならない。

### 第22章　実体の無限分割可能性

**161**　前章の終わりに、われわれは、宇宙の部分は途方もない複雑さで――ひょっとすると無限の複雑さで――互いに重なり合う全体のうちに組み合わされている、という結果をもって取り残された。実体的内容のそのようなすべての組み合わせのうち、どれかが他より入り組んでいるとか根本的であるとか主張することを可能にするような原理は何も見いだされていなかった。たしかに宇宙そのものは唯一無二の位置にあることがわかった。しかしこれは存在するもののうちに秩序を持ち込むにはごくわずかしか役立たない。

　いま別の問いが生じる。宇宙を除くどの実体も別の実体の部分である。そして多くの実体は、他の実体の部分でもあり、また他の実体がその部分であるような全体でもある。しかしこれはすべての実体について真であろうか、それとも全体であることなしに部分であるような実体があるのであろうか。言い換えれば、単純実体はあるのであろうか。

　いかなる実体も単純でないなら、どの実体も内容をもつ。内容は全体の異なる部分の組のうちで同一である多数性として定義されたからである。そして逆に、実体が内容をもつなら、それは部分をもち、したがって単純ではないであろう。したがってわれわれの問いは、すべての実体は内容をもつか、と立てることもできる。

**162**　実体は、たとえそれが分割できないあるしかたがあるとしても、少しでも分割可能であるなら単純ではないことは明らかである。言い換えれば、それはあらゆる次元において分割不可能でなければならない。

　次元の概念は、空間においてだけでなく、系列が見いだされるところならどこにでもあてはまる。どんな系列の項も一次元の場を形づくる。その成員のそれぞれがまた系列であるような系列があるところでは、二次元の場が得られる。この場の成員はそれぞれ、一方の系列のなかのある一つの位置と、他方の系列のなかのある一つの位置とにある。これらの成員のそれぞれがまた系列であるなら、三次元の場が得られ、以下同様である。

　実体がある次元において系列を形づくるか、系列の項であるかするところではどこでも、その実体はその次元をもつ、と言うことにしよう。したがって、線は長さの次元だけでなく幅と厚さの次元をももち、時間系列のなかの個々の瞬間は時間の次元をもつ、と言うことにする。これは幾何学の通常の用法からの逸脱である。幾何学なら、線は長さを除いていかなる空間的次元ももたない、と言うであろう。

　次元がこのように定義されると、それは空間の次元にあてはまるが、他のところにもあてはまることは明らかである。空間において三次元であるものがまた時間のうちにもあるなら、それは第四の次元として時間をもつ。というのも、空間の三次元の場のどの成員――三つの空間系列のそれぞれのなかのある一つの位置を占めるもの――を得たときにも、時間の異なる瞬間におけるそのものの状態は別の系列を形づくるからである。

　またさらに、快は少なくとも二つの次元をもつ、と言えるかもしれない。快はある時間続き、その時間の各瞬間にある強さ――同じであれ異なるのであれ――をもつからである。したがって、われわれの次元の定義によれば、それは、水平にある長さをもち、その各点である特定の高さ――同じであれ異なるのであれ――をもつ図形とまったく同じく二つの次元をもつ。

**163**　どれかの実体は単純であろうか。探究を始めるにあたって、この問いはわれわれの知覚から引き出された議論によっては決定できない、ということに注意しなければならない。われわれが知覚するものは何であれ実体であり、もし単純だと知っている何かを知覚したなら、単純実体があることを知るであろう。もっとも、すべての複合実体が単純実体から成ることは確かではないであろうが。しかし実際には、知覚されるものは何ひとつ単純ではない。

　まずわれわれは感覚与件を知覚する。それは外的感覚によって把握される。そしてわれわれはまた、内観によって自分の心のうちの出来事を知覚する。それらをわれわれは感覚与件とともに知覚与件というより一般的な名のもとに分類した。さて第一に、どの知覚与件も、広がりと呼ばれてきたものの形で外延量をもつ、と考える理由があるように思われる。この場合、どの知覚与件も部分をもつであろう。しかしすべての知覚与件の広がりは否定されてきた。またそれらの広がりは、われわれの現在の主張を証明するのに必要でもない。

〔原注〕量をもつものは何であれ部分をもつ、と言うのではない。ある関係は量をもつが、より小さな関係へと分割できない。私の主張は、外延量をもつすべての実体は部分をもつ、ということである。

　というのも、すでに見たように、時間は時間のうちに存在するもの何であれの次元だからである。そして時間のいくつかの部分を通じて存在するものはすべて、それ自身の部分として、時間のそれらの部分のそれぞれにおいて存在するものとしてのそれ自身をもつであろう。「十九世紀のセント・ポール大聖堂」と「一八〇一年のセント・ポール大聖堂」とは、どちらも実体の名である。しかしそれらは異なる実体の名である。十九世紀のセント・ポールについて真である多くの主張が一八〇一年のセント・ポールについては真でなく、その逆も同様だからである。そして第二の実体は第一の実体の部分である。「一八〇一年のセント・ポール」「一八〇二年のセント・ポール」と名づけられる実体を一九〇〇年のセント・ポールまで取るなら、それらはあわせて、「十九世紀のセント・ポール」に含まれるすべての内容を含むであろう。

　さて、私が知覚するどの知覚与件も有限の時間続く。ある速さで互いに続く刺激は、別々の継起する感覚与件についての別々の知覚をわれわれに与える。しかしそれらがもっと速く互いに続くなら、それらはわれわれに、別々の感覚与件であるような継起する部分をもたない、ただ一つの感覚与件を与える。したがって感覚与件には最小の持続があり、すべての感覚与件はある時間の幅を通じて続く。感覚与件でない知覚与件もそうである。さて、知覚与件がある時間の幅を通じて続くなら、それは時間の次元において分割可能である。時間が単純な部分をもたないなら、知覚与件も単純な部分をもたないであろう。時間のどの幅も無限に多くの単純な部分をもつなら、知覚与件は、この次元ではそれ以上分割できない無限に多くの部分をもつであろう。時間の幅が有限個の単純な部分をもつなら、与件は、この次元ではそれ以上分割できない有限個の部分をもつであろう。しかしいずれの場合にも、時間のどの幅も部分へと分割可能であり、したがってどの知覚与件も部分へと分割可能であろう。

**164**　知覚与件は知覚されているあいだつねに変化するわけではなく、変化がなければ継起する部分もないであろう、と反論されるかもしれない。しかしこれは正しくないであろう。時間を通じて存在するものの本性は、時間の二つの異なる瞬間においてまったく同じではありえないからである。後の瞬間には、過去と未来のさまざまな出来事に対するその時間的関係は、前の瞬間にそうであったのと多かれ少なかれ異なるであろう。そして関係の違いは関係的性質の違いを含む。

　また、実体は、何か特定の点でそれ自身と同じ本性をもつ部分へと分割できないからといって、必ずしも単純ではない、ということも思い起こさなければならない。たとえばカレッジは、カレッジから成るのではないという事実にもかかわらず、単純実体ではない。それは人間から成るからである。日常生活ではこの区別ははっきり認められている。しかし哲学的な議論では、たとえば感覚与件は感覚与件へと分析できなければ単純である、と想定し、可能なかぎり最も短い感覚与件も、それが成るさらに短い部分に関しては複合的である、という事実を無視する傾向がときにある。

**165**　われわれの各人が感覚与件を知覚し、また内観によって自分自身のうちで起こるさまざまな出来事を知覚することは、普遍的に認められるであろう。思うに、これに加えて、人は自分自身を知覚することが可能であり、たいていの人は、つねにではないにせよしばしばそうしている。この見解の正しさは本書の後の部分で論じる。現在のところは、人が自分自身を知覚するとしても、そうすることによって単純な何かを知覚するのではない、と指摘すれば十分である。第一に、各自己は同時的な多くの部分をもつ。すべての瞬間にではないにせよ多くの瞬間に、意識の場は分化している。そしてもし私がそうであると信じているように、自己の知覚や判断や意欲がその自己の部分であるなら、このことは自己が単純でないことを証明するであろう。

〔原注〕知覚される自己が、時間のうちのその持続のために単純でありえないなら、ましてや全体としての自己は単純でありえない。それは、どれか一つの知覚において知覚される自己の持続がその一部にすぎないような持続を通じて存在するからである。自己の単純性をわれわれが否定することの意義を誇張しないために、A が B と C をその部分としてもつと主張することによって、A が B や C よりも統一の度合いが低いとか重要でないとか主張しているのではない、ということを思い起こさなければならない。われわれのあらゆる関心――理論的なものも実践的なものも――にとって、重要なのは全体であって部分ではないかもしれない。そしてもし宇宙のなかの実体のどれかが他より究極的で根本的であることが示されうるなら、この点で最も高い位置を占めるのは B や C ではなく A であるかもしれない。また、自己が部分をもつと主張するとき、われわれはその部分が、人体や他の物質的な合成物の部分のように、ときにはその自己の部分として、ときにはその部分でなく存在しうる、と主張しているのではない、ということも思い起こさなければならない。そして自己が部分をもつという主張に対してなされる反論は、ときにこのことを見ないことによる。

**166**　いままでのところ、われわれの結果は単に否定的なものにすぎない。実体についてのわれわれの知覚のうちには、単純実体があると信じる理由を与えるものは何もない。しかしこれは、われわれが知覚する実体でさえ、われわれが知覚しない単純実体から成っている、という可能性を残している。すべての複合実体が――ましてや、ある複合実体が――単純実体から成る、ということは依然として事実でありうる。

**167**　そうするとわれわれは主要な問いに戻る。実体は内容なしに存在し、したがって単純でありうるであろうか。私にはそれはありえないように思われる――内容なしの実体はありえず、したがって部分なしの実体はありえず、したがって単純実体はありえない、と。

　こうして達した結果は非常に重要である。単純実体の不可能性は、それ自体としてかなりの理論的関心の対象である。しかしその帰結は、私には、さらに大きな関心――理論的なだけでなく実践的な関心――の対象であるように思われる。（本書の残りは大部分これらの帰結の演繹から成るであろう。）したがってこの点についてのわれわれの決定は、最も注意深い考察を必要とする。

　いかなる実体も内容なしには存在しえない、という命題は明らかに総合的である。われわれは実体によって内容をもたないものを意味しているのではない。われわれはそれを、それ自身は性質でも関係でもないのに性質をもち関係に立つもの、と定義した。それが内容をもつと言うとき、われわれはそれが実体であることをもう一度主張しているのではなく、実体についての事実を主張しているのである。

　そしてこの命題は、思うに、自明で究極的である。それが自明であるのは証明を必要としないからであり、それが究極的であるのは、より明らかに自明な何らかの命題からは証明できないからである。われわれの各人にできることは、それを注意深く眺め、自分がそれを自明なものとして受け入れるかどうかを見ることだけである。だからといって説明や議論が無用であることにはならない。それらは誤解を取り除き、命題の意味をより明らかにし、その真偽をより明らかにするかもしれないその真偽の帰結を示唆するかもしれない。しかし積極的な証明は不可能である。

**168**　認めねばならないが、すべての実体は内容と部分をもたねばならないという見解を受け入れる前にわれわれをためらわせるべきいくつかの考慮がある。第一に、この命題は、いま述べたように自明で究極的なものとして提出されているが、確かに普遍的にそのようなものとして受け入れられてはいない。実際、私の知るかぎり、それが自明で究極的であるという主張はこれまでなされたことがない。このことはその主張が誤っていることを示すものではない。自明で究極的な命題のなかには――たとえば排中律のように――実際あまりにも明白なので、普遍的に自明で究極的なものとして受け入れられているものもある。しかしその自明さと究極的な真理とが、まったく同じく実在的であるにもかかわらず、経験の事実を長く注意深く吟味し分析したのちでなければ思い浮かばないものもある。したがってわれわれの主張は、新しいからといって誤っている必要はない。しかし他方、命題を軽率に自明で究極的なものとして受け入れることは、誤りの豊かな源となってきた。そして人類の普遍的な同意なしに、ある命題について、それは証明できないが疑われるべきではない、と主張するとき、われわれが非常に重い知的責任を負うことは疑いない。

**169**　注意深く気をつけるべき第二の誤りの危険がある。単純実体が、ふつうの言い回しで言えば「どのようなものであるか」――つまり、実体であることと内容なしであることのうちに含意されている性質を除いて、それがほかにどのような性質をもつであろうか、あるいはもちうるか――をわれわれが知らないことは明らかだと思われる。というのも、上で示したように、われわれはけっして単純実体を知覚しないし、私の見るかぎり、単純実体を想像することはまったく不可能だからである。しかしわれわれの想像力の限界は可能性の限界ではない。したがって、単純実体を想像することの不可能性から、その存在の不可能性へと論じることはできない。そしてわれわれは、二つの不可能性を混同する誤り、実際にはわれわれが見ているのは単純実体を想像できないことにすぎないのに、単純実体の不可能性をはっきりと見ていると想定する誤りを犯さないよう警戒しなければならない。

**170**　第三の誤りの危険があり、それが私自身に影響するかぎりでのその危険を、私は深く自覚している。いま論じている結果の助けを借りれば、本書の後の部で説明するように、少なくとも私には非常に望ましく思われる結論に達することが可能だと私は信じている。この結果なしには、それほど望ましい結論にはとうてい達しえないと私には思われる。哲学の歴史は、うんざりするほど繰り返して、ある命題の真理が望ましいとされるなら、その正しさが望まれていなかったなら十分とはけっして考えられなかったであろう証拠に基づいて、それを真として受け入れることがいかにたやすいかを示している。私に言えることは、私はこの危険をけっして忘れたことがなく、それに対して身を守るためにできるかぎりのことをしてきた、ということだけである。

**171**　しかし、ためらいのこれらすべての根拠を考慮に入れたうえで、やはり私には、実体は内容と部分をもたねばならないという命題を受け入れなければならないと思われる。私の見るかぎり、二つの性質――実体であるという性質と、内容と部分をもつという性質――のあいだには積極的な結びつきがある。排中律へのわれわれの信念が、真でも偽でもない言明を想像することの不可能性にではなく、言明であるものは何であれ真か偽かでなければならないという積極的な必然性の認識に基づいているのと同じく、この場合にもわれわれは想像力の失敗に依存しているのではなく、一方の性質による他方の性質の直接的な含意の認識に依存しているのである。

　この事柄はさまざまなしかたで言い表すことができ、それらはわれわれの主張の証明――それが証明できないことはすでに認めた――を与えはしないけれども、事柄をより明らかにするかもしれない。実体は何らかの詰め物なしに作られうるか、そして実体にとって部分の組以外に何か詰め物がありうるか、と自問してもよい。あるいは、もし実体が部分をもたなければその内側には何もないであろうと反省し、内側のない実体という概念は支持できるか、と自問してもよい。

　われわれの問題を眺めるもう一つのしかた――そして思うに、それを実際により明らかにするしかた――は、内部構造に関してである。内部構造ということで私は、何か高い程度の組織化や統一を含意するものを意味しているのではなく、部分から成るどの全体にも避けがたく属する性質を意味している。そのような全体の部分は必然的に互いに何らかの関係をもつであろう。そしてそれがこれらの関係づけられた部分をもつという事実こそ、それが内部構造をもつということで私が意味するものである。単純実体はもちろん内部構造をもちえないであろう。そして私には、実体性と内部構造という二つの性質を切り離そうと努めると、それらは、第二のものの除去が第一のものの除去を含意するので切り離しが不可能であるようなしかたで結びついていることに気づくように思われる。実体がそもそも実在的であろうとするならもたねばならない特有の種類の実在性は、内部構造をもつことに依存しているのである。

**172**　忘れてはならないもう一つの点は、単純実体は歴史ももちえず持続ももちえないであろう、ということである。それはどの次元においても分割されていてはならず、時間のうちに存在するものにとっては、時間は一つの次元だからである。思うに、単純実体の可能性を受け入れるのに何の困難も感じないように見える著者たちのなかには、この点を無視して、同時的な分化の不在に注意を集中しながら、継起的な分化を排除しようとまったくしない人々がいる。もし彼らが、自分たちの実体は同時的な部分をもたないことに加えて、時間のただ一つの単純で分割できない瞬間にしか存在しえないことを悟ったなら、彼らは単純実体の可能性についての判断を考え直すかもしれない。

**173**　またわれわれは、問題は単純実体――すなわち部分をまったくもたないもの――の可能性についてのものである、ということも思い起こさなければならない。何らかの部分をもつ実体は、たとえその部分が互いにきわめて緊密に結びついていて、それらを引き離しうる既知の力が何もないとしても、単純ではない。またその部分の本性が、そのどれもがその全体の部分としてでなければ存在しえないこと、あるいは全体がそのどれか一つなしに存在しえないことがアプリオリに見てとれるようなものであるとしても、それは単純でさえない。これらのことが真であるなら、全体は、そうでなかった場合よりも緊密に統一されているであろうが、それでもなお複合的であって単純ではないであろう。

　さて、ある場合にはこれが忘れられ、思索者の心のうちの概念が実際には単純実体の概念ではなく緊密に統一された複合実体の概念であったときに、単純実体は可能だと主張されてきた、と私は思う。

**174**　そうすると私には、すべての実体は内容と部分をもたねばならず、単純実体はない、ということは自明かつ究極的に真であるように思われる。しかしこれは、たとえば排中律やユークリッドの第一公理の自明で究極的な真理ほどには決して確実でないことは認めてきた。そしてもしこの命題がそもそも真であることに対して強い推定を引き起こすような事情を何か見いだせるなら、それが自明かつ究極的に真であるというわれわれの結論を疑う理由を見いだすかもしれない。そのような推定を引き起こすものを何か見いだせるであろうか。

第一に、この命題が真であるという仮説が矛盾を含むと想定する理由が何かあるであろうか。一つを除いて、それが矛盾を含むと想定されうるしかたは私には見当たらない。どの実体も部分をもつなら、どの実体も部分の組の終わりのない系列をもつ。どの組のなかの各部分も部分をもつ実体であり、部分の部分はもとの全体の新しい部分の組を形づくるであろうからである。この無限系列は悪しきものだ、と言われるかもしれない。この点は次の二つの章で論じる。

**175**　第二に、単純な特性があるという事実によって、われわれの見解に対する推定が何か生じるであろうか。単純な特性があることは疑いを容れない。たとえば赤は単純性質である。そしてさらに、単純な特性から合成されたもの以外の複合的特性がないことも疑いを容れない。どの性質もどの関係も何かを意味しなければならず、何かがその性質をもつ、あるいは何かに対してその関係に立つ、と主張されるとき、その主張が有意味でありうるようでなければならない。そして複合的特性の意味はその部分の意味に依存する。したがって単純な部分をもたない複合的特性は、悪しき無限後退を含むであろう。その意味はその部分のある組の意味に依存するであろう。しかしどの組を取るにせよ、そのなかの各項の意味はその部分の組の意味に依存し、以下無限に続くであろう。もとの特性の意味は、系列の終わりに達し、それ自身を越えた何ものにも意味が依存しない項が見いだされたときにはじめて固定されうるであろう。そして系列には終わりがないであろうから、そのなかにそのような項はないであろう。したがってそのような複合的特性は意味をもたず、したがって実在的でありえないであろう。

　しかし単純な特性の生起は、単純実体を支持する推定を何も与えない。単純実体があるとしても、それらと複合実体とのあいだの関係は、単純な特性と複合的特性とのあいだの関係とは非常に異なるであろうことは明白だからである。われわれは複合的特性を、それが成る単純な特性に気づくことなしに気づくことはできない。これは上で述べたことから帰結する。特性に気づくとはその意味を知ることだからである。しかしわれわれは複合実体を、それを合成する単純実体に気づくことなしに気づくことができる。実体の気づきは知覚であり、われわれは単純実体をその部分として知覚することなしに複合実体を知覚することができるからである。実際、上で示したように、われわれはけっして単純実体を知覚しないし、したがって、それらが存在するにせよしないにせよ、われわれはそれらに気づいていない。そうすると単純実体は、もし存在するとしても、単純な特性と複合的特性とのあいだに成り立つ関係とはあまりにも異なる関係に複合実体に対して立つであろうから、単純な特性の実在は単純実体の存在を支持する推定を何も与えない。

〔原注〕もちろん、複合的特性を合成する単純な特性に気づくことなしに、その複合的特性の排他的記述をもつことはできる。たとえば人間性は複合性質である。そしてもし私が人間性について、それはある著者がその第一巻第二十章で論じた主要な主題である、ということしか知らないなら、私は人間性を合成するどの性質にも気づくことなしに、人間性の排他的記述をもつであろう。しかしその場合、私は人間性に気づいてはいないであろう。私はほかの何ものにもあてはまらないその記述をもつであろうが、それに気づいてはいないであろう。それが何を意味するかを知らないであろうからである。

　実際、私は、単純な特性の考察はむしろ、単純実体の不可能性を自明な真理とみなしたことでわれわれが正しく判断した、という信念を強めるはずだと思う。というのも、私には、特性が実在的でかつ単純でありうることの可能性は、それが特性であること――言い換えれば、普遍者であること、あるいは有意味であること――に依存することが見てとれるように思われるからである。それが実在的で単純な特性でありうることの可能性がそれが特性であることに依存する――それは同語反復であろう――と言うのではなく、それが実在的で単純でありうることの可能性がそれが特性であることに依存する、と言うのである。このことは、実体は実在的でかつ単純ではありえない、という見解を支持するであろう。それはわれわれのもとの命題の新しい表現以上のものではほとんどない。しかしすでに述べたように、ある命題が究極的に真であるという主張に光を投げかけることを望みうるのは、このような言い直しによってである。

**176**　第三に、科学がわれわれに教えるもののうちに、単純実体を支持する推定を与えうるものが何か見いだされるであろうか。もし科学において一般に受け入れられている見解が単純実体の存在を含むと想定するなら、われわれはそれらの見解の正確な形而上学的意義を探究し、単純実体を退けることによって、われわれが本当に科学と衝突するのか、それとも科学者たちの無批判な形而上学と衝突するだけなのかを考察しなければならないであろう。しかしこの問いを考察する必要はない。科学のどの教えのうちにも、単純実体の存在を含むものは何もないからである。

　心理学という科学のなかの何かが、われわれがこの言い回しを用いた意味での単純実体の存在をありそうなものにする、と示唆されたことはないと思う。したがってもしどれかの科学がそれを要求するとすれば、それは物理科学でなければならず、単純実体は物質であるか、物質として現れるかでなければならない。すでに見たように、空間において広がりをもつなら何ものも単純ではありえない。そのとき、それは空間的に分割可能でなければならないからである。物理科学は、空間的に分割できない何かが存在することを示唆するであろうか。

　物理科学は、幾何学の真理が空間のうちの存在する物質にあてはまると主張し、このことは、空間的に分割できない点という概念がそれについて真であるような何かが存在することを含む、と言われるかもしれない。

　しかしこのことは、空間的に分割できない実体が単純実体であることを示しはしないであろう。それは何か他の次元において分割可能であるかもしれないからである。物理科学の対象は空間の次元とともに時間の次元をもつ。そして時間の次元においてはすべての部分が他の部分へと無限に分割可能である、と考えることを困難にするようなものが科学のうちに何かあるとは、私は知らない。

　しかし私はこの点を強調したくはない。上で述べたように、私は時間系列は単純な部分から合成されていると信じているからである。しかし他の次元において分化がありうるかもしれない。たとえば、ひょっとすると心のあいだに空間的関係が存在することに内在的な不可能性はなく、もしそのような関係があるなら、どの心の部分のあいだにも空間的関係はなく、したがって心は空間的関係をもちながら空間的には分割可能でない、ということもまた事実であるかもしれない。そのような心は、したがって、他の性質とともに幾何学的な点であるという性質をもつであろう。しかしそれは単純実体ではないであろう。それは非空間的な部分をもつであろうからである。そしてその部分のどれもこの次元において単純でない、という可能性は残るであろう。

　もちろん科学はこれがそうであると主張するのではないが、この仮説のうちには科学のどの結果とも両立しないものは何もない。そしてもしこれが単純実体を避けるであろう唯一の選択肢であるなら、われわれはそれを受け入れる資格があるであろう。単純実体は不可能だと信じる理由をわれわれは見いだしたからである。

　前提は推移的な関係である。X が Y か Z かを前提とし、Y が T か S かを前提とし、Z が U か V かを前提とするなら、X は T か S か U か V かを前提とする。また、X が Y を内在的に決定し、Y が U か V かを前提とするなら、X は U か V かを前提とすることは明らかである――ただし、X が直接にか間接にかそのどちらかを決定し、したがって他方を排除する、ということがたまたまあるのでないかぎり。X は明らかに、X が必要とするものが必要とするものを何であれ必要とし、したがってそれを供給するのでないかぎり――すなわち、それを内在的に決定するのでないかぎり――それを前提としなければならないからである。

**185**　X が W を内在的に決定し、ある特定の W を前提とするとき、X と R とをあわせれば、ある特定の W を内在的に決定する、ということがあるかもしれない。その場合、X とともに R も生じるなら、それらが両方とも生じるという事実は、ある特定の W を前提とはしないであろう。それはその特定の W の存在を内在的に決定するであろうからである。あるいはまた、X によって前提とされる W がある特定の W であってほかのどれでもないことを、事実としてわれわれが知っているかもしれない。これらのどちらかのしかたで、X によって前提とされる特定の W が何であるかがわかるとき、その W は固定されている、と言ってよいであろう。

　X がある特定の V を前提とし、またある特定の W を前提とすると想定すると、V の固定が W の固定を含む、ということがありうる。たとえば、何かが三角形であるなら、その事実は、それが正三角形であるか、二等辺三角形であるか、不等辺三角形であるかを前提とする。それはまた、その三つの角の大きさが互いに対して立つある確定した関係をも前提とする。しかし角の相対的な大きさが与えられれば、最初の場合の前提は固定される。三つの角がすべて互いに等しいなら三角形は正三角形であり、二つが等しいなら二等辺三角形であり、どの二つも等しくないなら不等辺三角形である。

　前提のあいだのこの関係は相互的であることもそうでないこともある。V の固定が W の固定を含むとき、W の固定が V の固定を含むこともあれば、含まないこともあるからである。何かがある特定の図書館の書架の本であるなら、これはそれがある特定の主題をもつことと、図書館のなかのある特定の場所をもつこととを前提とする。その図書館の本が主題にしたがって並べられているなら、それがしかじかの主題をもつという事実は、それが図書館のなかのしかじかの場所にあることを含意するであろう。そしてそれがしかじかの場所にあるという事実は、それがしかじかの主題をもつことを含意するであろう。したがってこの関係は相互的である。他方、何かについて、それが動物学の認める種であることを、どの種であるかを知らずに知っているなら、これはそれがある特定の属に属することと、ある特定の目に属することとを前提とする。そしてここでは属の固定は目の固定を含むが、目の固定は属の固定を含まない。

〔原注〕また、ある場合には V と W は、V がその可能な場合の一つに固定されれば W の場合が何であるかを固定するが、その可能な場合の他のものに固定されてもそうしない、というように関係しうることにも注意してよい。三角形の角の相対的な大きさの固定が、それが正三角形か二等辺三角形か不等辺三角形かの決定を含むことはすでに見た。この関係はすべての場合に相互的なのではない。三角形が二等辺三角形や不等辺三角形であるという事実から、その角の正確な相対的大きさを推論することはできないからである。しかし三角形が正三角形であるなら、そのすべての角が等しいことを推論できる。

**186**　二つの前提がこのように関係しているとき、実際には二つの別々の前提はない、と主張されるかもしれない。何かが種であるという事実は、実際には属と目の両方を、それらを供給することなしに必要とするのではない。属が与えられれば、その事実によって目が供給されるからである、と言われるかもしれない。しかし私は、それらは両方とも前提であるが、両方が全究極前提の部分をなすのではない、と言うほうが正確だと思う。私は X の全究極前提を、X のすべての前提の集積から、残るもののどれかの固定のうちにその固定が含意されているようなものをすべて取り除いた後のもの、と定義したい。（二つの前提のどちらの固定も相互に他方の固定を含意する場合には、二つのどちらを除くかはどちらでもよい。）

　そもそも前提をもつものはすべて全究極前提をもつ。たとえそれがただ一つの前提しかもたないとしても、あるいはその前提のどれも、その一つの固定が他のどれかの固定を含意するようなものでないとしても、それはなお上で定義したような全究極前提をもつであろう。もっとも第一の場合にはその全究極前提はただ一つの前提から成るであろうし、どちらの場合にもその部分をなさない前提はないであろうが。

**187**　こうして前提の本性を論じたので、次に、われわれが得た結果を、単純実体の不可能性がいずれにせよ矛盾を生み出すかどうかという問題の考察に適用しなければならない。

　実体 A が部分の組 B と C をもつとしよう。そうすると、B と C の十分な記述をもつなら、A の十分な記述をもつことになる――すなわち、それぞれ B と C の十分な記述をもつ二つの部分の組をもつ全体、である。（簡潔のため、今後これを「B と C から合成された全体」と書くことにする。）これは A の十分な記述である。それは A にあてはまり、A 以外の何ものにもあてはまらないからである。同じ部分の組をもつ二つの全体はありえないからである。そしてこれは、B と C のどんな十分な記述を取ろうとも真である。それらが十分な記述でありさえすれば、それらを構成する性質がどれほど些細で取るに足りないものであってもかまわない。

〔原注〕われわれの「全体」の用法によれば、同じ部分は、たとえ関係の二つの異なる体系によって結びつけられていても同じ全体を形づくる、ということを思い起こされたい。B と C が父と息子として結びつけられ、また同じ事業の共同経営者であることによっても結びつけられているなら、それらは二つの全体を形づくるとは言わず、その部分が関係の二つの体系によって結びつけられている一つの全体である、と言うであろう。

　他方、A の十分な記述は、必ずしも B と C の十分な記述を含まない。A のすべての部分の十分な記述を含むような A の何らかの十分な記述がつねにある、ということはありうる。（のちに見るように、これは実際に事実である。）しかし A のすべての十分な記述が、そのすべての部分の十分な記述を含むわけではない。たとえば、ある特定のカレッジの十分な記述で、その部分のどの組を合成する成員の数さえ決定することを可能にせず、したがってましてやそれらの成員のそれぞれの十分な記述を決定することを可能にしないようなものを見いだすことは十分可能であろう。

**188**　A は実体であり、実体であるというこの性質は、それが単純でなく、したがって無限に多くの部分の組をもつことを含意する。これらの組のそれぞれの各成員は、もちろん十分な記述をもたねばならない。そうすると A の本性は、実体であるという性質を含むのだから、これらすべての組の成員の十分な記述を必要とする。もし A の本性のうちにこれらの記述を供給するものが何もないなら、それはそれらを前提とするであろう。

　A の本性がその部分のどれかの組 M の成員の十分な記述を前提とするなら、それは M に対して後続的なその部分のどの組 N の成員の十分な記述をも前提とするであろう。というのも、もしそれがそれらを前提としないなら、それはそれらを供給しなければならないからである。それはそれらを必要とし、それらを供給することによってしかそれらを前提とすることを免れないからである。しかし N の成員の十分な記述は M の成員の十分な記述を含意するであろう。M の各成員は、それ自身 N の成員であるか、N の成員から構成された全体であるかのどちらかであり、すでに見たように、部分の十分な記述は全体の十分な記述を与えるからである。したがって、もし A の本性が M の成員の十分な記述を前提とし、したがってそれらを供給しないなら、それは N の成員の十分な記述を供給することはできない。後者を供給することによって、それはそれらが含意するもの――すなわち M の成員の十分な記述――を供給することになろうからである。

　A は単純な部分をもたないのだから、与えられたどの組に対しても後続的な部分の組を無限に多くもつであろう。したがって、もしその本性がその部分のどれかの組の成員の十分な記述を前提とするなら、それは無限に多くの前提をもつであろう。

　A が無限に多くの前提をもつという事実は何の矛盾も含まないかもしれない。しかしこれらの特定の前提の本性を考察すると、矛盾が含まれていることがわかる。

**189**　どの実体の十分な記述も、その部分のどれかの組のすべての成員の十分な記述が与えられれば与えられる、ということをわれわれは見た。さて第一に、もしこれが実体の十分な記述が与えられうる唯一のしかたであるなら、矛盾があるであろう。A が実体であるという事実は、その部分のある組 M の成員の十分な記述を前提とする。そして M の成員のこれらの十分な記述は、われわれの現在の仮説の上では、それらの部分の組の成員の十分な記述を与えることによってしか与えられえないであろう。M の成員の部分の組のこれらの成員はまた、A の部分の組――組 N――を形づくるであろう。そして同じように、N の成員の十分な記述は、それらの部分の組の成員の十分な記述を与えることによってしか与えられえず、それらの成員は A の部分の別の組――組 P――を形づくるであろう。そしてこの過程は無限に続くであろう。

〔原注〕N がこの議論に入ってくるのは A の部分の組としてではなく、M の成員の部分の組の集積としてであることがわかるであろう。同じように P は、N の成員の部分の組の集積としてのみ議論に入ってくる。他方、第191節の議論では、N と P は A の部分の組として入ってくるであろう。

　そのような無限系列は悪しきものであろう。M の成員の十分な記述は N の成員の十分な記述によってしか十分にされえず、それらは P の成員の十分な記述によってしか十分にされえず、以下無限に続くからである。したがって M の成員の十分な記述は、終わりのない系列の最後の段階によってしか十分にされえない――すなわち、まったく十分にされえない。しかし M の成員の十分な記述を前提とする A の存在は、そのような十分な記述があることを含意する。したがってそのような十分な記述がありえないという事実は矛盾を含意する。

**190**　しかし、われわれが論じてきた仮説は正しくない、と答えられるかもしれない。実体は、その部分の組の成員を十分に記述することなしに十分に記述されうる。たとえば連合王国は、大国であり、君主国であり、二つの国教会をもつ国民であり、等々と、記述が十分になるまで、その部分のどれの十分な記述も持ち込まずに記述されうるかもしれない。したがって、A の各部分は、その無限に多くの部分の組のそれぞれにおいて、しかじかの部分をもつことから成るのではない何らかの性質で、宇宙のなかの他の無限に多くの実体のそれぞれからそれを区別するようなものをもっていた、という可能性がある、と言われる。（M の成員の十分な記述がその部分の組の十分な記述による以外のしかたで与えられるとき、A によるこれらの十分な記述の前提は独立に固定されている、と言ってよいであろう。）この場合、悪しき無限系列はないであろう、と言われるかもしれない。A の存在は、すべての組におけるその部分のそれぞれの十分な記述を前提とするであろうが、これらの前提のそれぞれは、この部分がしかじかの十分な記述をもつという究極的な事実によって独立に固定されるであろう。終わりのない系列の終わりに達することによって各十分な記述に確定性を与えようと求める必要はもはやないであろう、と。

　しかしこれが可能な選択肢であるかどうかは疑わしいように思われる。A が存在するのだから、われわれは、無限に多くの実体が存在し、そのそれぞれが、十分にではないにせよ、そのような実体の系列のなかでのその位置によって――すなわち、A の部分のある特定の組の成員であり、先行する組のある特定の成員の部分である、ということによって――記述されることを知っている。想定は、これらの実体のそれぞれがまた、それだけで、あるいは前の文で挙げたものとあわせて、その十分な記述を形づくるような一つ以上の性質をもつであろう、ということである。さてこれらの追加の性質は、系列のなかでの実体の位置から独立していなければならない。それらは系列のなかの後続する項に関するその位置に依存することはできない。そうであれば前節で論じた悪しき無限に導くであろうからである。またそれらは系列の先行する項に関するその位置に依存することもできない。そうであれば、それらの先行する項は後続する項の十分な記述を含意し、それを前提とはしないであろうからである。そしてわれわれの現在の仮説は、それらがそれを前提とする、というものである。

　そうすると、これらの追加の性質と、系列のなかでの実体の位置から生じる性質との随伴は、究極的で未決定でなければならない。そしてわれわれは、この種の究極的な随伴が無限にある――単純実体の不在によって要求される無限に多くの実体のそれぞれについて、十分な記述を与えるような一つ以上の性質が生じる――と想定できるであろうか。

　私には、この想定を受け入れることはできないように思われる。その場合、無限分割可能性に含まれる矛盾を避けようとするこの試みは破綻するであろう。しかし、たとえそうでないとしても、系列のなかでのその位置から独立した、項のそのような十分な記述が存在しても、矛盾を取り除くことはできないであろう。

**191**　もし各部分がそのような十分な記述をもつなら、それはたしかに、それが成る部分に言及することなしに十分に記述されるであろう。しかしこのことは、それがまた、その部分のどれかの組のすべての成員の十分な記述によっても十分に記述されるであろう、という事実には影響しないであろう――これは、すでに見たように、どの全体についても真である。

　さてこれは A の全究極前提にどう影響するであろうか。組 M の成員の十分な記述の前提（これを前提 μ と呼ぼう）は、A によって前提とされる全究極前提の部分ではないであろう。というのも、前提 ν――組 N の成員の十分な記述の前提――が固定されるとき、それは前提 μ を固定するからである。こうして全究極前提の定義によって、二つの前提の一方はその部分をなさない。そして μ の固定は ν の固定を含まないであろうから、二つのどちらを除くかはどちらでもよいわけではない。除かれねばならないのは μ である。

　しかし N に対して後続的などの部分の組 P を取っても、A による新たな前提――組 P の成員の十分な記述の前提 π――に達するであろう。そして π の固定は ν を固定するであろうから、ν もまた全究極前提から除かれねばならない。そして同じ運命が π にも降りかかり、以下終わりなく続く。この系列のどの前提も、それが言及する部分の組がそれに対して後続的な組をもたないのでないかぎり、全究極前提のうちに残ることはできないであろう。したがって A によって前提とされる全究極前提は、μ も、その固定が μ の固定を含意するようないかなる前提も含まないであろう。

　しかしこれは不可能である。全究極前提は、すべての前提の集積から、残るもののどれかの固定によってその固定が含意されるようなものを取り除いた後のもの、と定義されたからである。したがって A によって前提とされる全究極前提が、μ も、その固定が μ の固定を含意するようないかなる前提も含まない、ということは不可能である。

　この考察を別の言葉で述べよう。第189節で見たように、系列のどの前提も独立に固定されていないなら矛盾が生じる。したがって――それらは何らかのしかたで固定されねばならないのだから――前提の少なくとも一つは独立に固定されていることが必要である。しかしすでに見たように、どれかの前提に対して先行的な前提のどれも独立に固定されている必要はない。それはどの後続する前提の固定によっても固定されるであろうからである。そしてどの前提も何らかの前提に対して先行的である。したがって、どの前提も独立に固定されている必要はない。こうしてわれわれは矛盾をもつ。

〔原注〕いかなる前提も独立に固定されていない、と言うのではない。第190節で提起された難点――それは現在の議論のために不問にしてきた――を別にすれば、それらがすべて独立に固定されていてはならない理由は私には見当たらない。矛盾は、系列のどの項も独立以外のしかたで固定されうるのであり、したがってどの項も独立に固定されている必要はない、ということと、同時に、本文のように、何らかの項が独立に固定されていることが必要だと示しうる、ということとのあいだにある。

　そうすると A の前提の無限系列は、前提が独立に固定されうるにせよされえないにせよ、矛盾を含むであろう。すべての無限系列は矛盾を含む、とときに主張されるので、繰り返しておくのがよいであろう。系列が無限でなければ矛盾は生じないであろうが、それは単にそれが無限であるという事実から生じるのではなく、各項がそれに後続する項に対して立つ関係から生じるのである。

**192**　そうすると、どの実体の本性も、その部分のどれかの組の成員の十分な記述を前提とすることはできない。そしてそれは確かにそれらを必要とするのだから、それらを供給しなければならない。さて、何かの本性が他のものの十分な記述を供給しうるしかたは二つある。それはそれらを包含するか含意するかしうる。まず包含を考察しよう。

　一見したところ、これについてはまったく難点がないように思われるかもしれない。A の本性は確かにそのすべての部分の十分な記述を包含しているからである。B を十分に記述する記述をもつ部分をもつこと、C を十分に記述する記述をもつ部分をもつこと、そしてすべての組における他のすべての部分についても同様であることは、A の本性の一部である。そのような記述は無限に多くの部分を含むであろう。A は無限に多くの部分をもち、そのそれぞれがこの A の記述のなかで別々に記述されねばならないからである。しかし記述は、無限に多くの部分を含むからといって必ずしも悪しきものではない。そしてもしこの記述が A の本性の一部であるなら、その本性は A のすべての部分の十分な記述を、必要とするだけでなく供給もする。

　しかしさらに見ていくと、そのような記述は、A の本性のうちに、部分の終わりのない系列の十分な記述を、それらの記述を包含することなしに含意する何かがあるのでないかぎり、矛盾を含むであろうことがわかるであろう。したがってわれわれは、矛盾を避けうる唯一のしかたとして、含意――必要とされるものが供給されうるもう一つのしかた――へと追いやられるのである。

**193**　というのも、これがなければ、記述の無限に多くの部分は、追加の性質と系列のなかでの部分の位置から生じる性質とのあいだの無限に多くの究極的な随伴を必要とするであろうからである。そして第190節で述べたように、そのような無限に多くの究極的な随伴を受け入れることはできないように思われる。

**194**　そしてまた、第191節で論じたものに類比的な理由からも矛盾が生じるであろう。A のすべての部分の十分な記述を包含する A の記述は、ある目的――それらの十分な記述を与えるという目的――には十分である。さて、与えられた目的に十分な記述が、その目的にとって十分以上でありうることは明らかである――つまり、それはその一部が省かれてもなお十分であったようなものでありうる。こうしてわれわれは、どの目的についても最小十分記述――その目的に十分であって、十分以上ではない記述――という概念を得る。

　どの目的についてのどの十分な記述にも、その目的にとって余分な要素を省くことによってそれと異なるか、もとの記述のどの要素も余分でなければそれと同一であるような、少なくとも一つの最小十分記述がなければならないことは明らかである。

〔原注〕一つの十分な記述が一つより多くの最小十分記述をもつこともありうる。十分な記述を与えるという目的のための十分さの場合を取ろう。そうすると「人々のうち最も親切で最も善い人」は二つの最小十分記述をもつ。「人々のうち最も親切な人」も「人々のうち最も善い人」もどちらも十分な記述であろうからである。またさらに、二つの十分な記述が同じ最小十分記述をもつこともありうる――たとえば「人々のうち最も親切な人で宮廷官吏」と「人々のうち最も親切な人でイギリスの貴族」は、十分な記述を与えるという目的のためには、それぞれ「人々のうち最も親切な人」をその最小十分記述としてもつであろう。

　さて、われわれがここで考察している場合の最小十分記述は何であろうか。それは、部分のどれかの組 M の成員である部分の十分な記述を含むことはできない。それらの部分の十分な記述は、どれかの後続する部分の組 N の成員である部分の十分な記述によって含意されているからである。したがってわれわれの目的にとって両方を保持するのは余分であり、後者を保持するのは余分ではない。したがって前者は去らねばならない。しかし同じように、後者もまた今度は去らねばならない。それらはそれらに後続するどの部分の組 P の十分な記述によっても含意されているからである。そして以下終わりなく続く。こうして最小十分記述はないであろう。唯一可能な最小十分記述は、それに後続する組をもたない部分の組の成員である A の部分の十分な記述から成るであろう。そして A は単純な部分をもたないのだから、そのような組はありえない。

　こうして矛盾がある。問題の記述には最小十分記述がなければならず、しかもありえない。これを避けうるしかたはただ一つしかない。先行する組の成員の十分な記述が後続する組の成員の十分な記述を含意するような、先行する組から後続する組へと下っていく含意の連鎖がなければならない。この場合、先行する組の記述を包含することは、後続する組の記述を包含することを不要にするであろう。それらはそこから演繹できるからである。こうして、そのすべての部分の十分な記述を与えるのに十分な A の最小記述は、含意の連鎖がそこから始まる先行する組の部分の記述であろう。

　A の本性がその部分の十分な記述を供給しうる二つのしかたのうち、含意なしの包含は矛盾を含むであろうことを、われわれはいま見た。したがってわれわれには含意しか望みが残っていない。われわれは、その部分の一つ以上の組の成員の十分な記述を包含してもよいが、それらの最後のものに後続する無限に多くの部分の組の成員の十分な記述を含意するような A の記述を見いださねばならない。

　そのような記述を見いだすことができるであろうか。部分の組の成員のどの十分な記述も全体の十分な記述を含意し、したがって後続する部分の組の成員のどの十分な記述も先行する部分の組の成員の十分な記述を含意する、ということをわれわれは見た。しかし逆は真ではない。全体の多くの十分な記述は、その部分のどれか一つの組の成員の十分な記述を含意しないし、ましてやそのような組の無限の数の成員の十分な記述を含意しない。しかし矛盾が避けられるべきなら、どの実体についても、部分の組のその無限系列全体を通じてのすべての部分の十分な記述を実際に含意するような何らかの記述がなければならない。そのような記述が何でありうるかを見いだすことが、次の部でのわれわれの最初の仕事であろう。
