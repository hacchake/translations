## この作品について

　ジョン・マクタガート・エリス・マクタガート（一八六六〜一九二五）は、ケンブリッジ大学トリニティ・カレッジで教えたイギリスの哲学者で、ヘーゲル研究から出発し、独自の観念論の形而上学を築いた。一九〇八年の論文「時間の非実在性」で示したA系列・B系列の区別と、時間は実在しないという論証とは、今日の時間の哲学でもなお出発点として論じられている。『存在の本性』はその主著であり、第1巻は一九二一年に刊行され、第2巻は著者の死後、弟子の C・D・ブロードの編集で一九二七年に刊行された。

　本書の前半（第1巻）は、経験的な前提をほとんど使わずに、存在するものはすべて「実体」であり、どの実体も部分の中の部分へと無限に分割され、その分割は「決定的対応」と呼ばれる関係によって決定されていなければならない、ということを論証する。後半（第2巻）は、この結論を私たちの経験に当てはめる。物質も感覚与件も時間も実在せず、存在するのは互いを知覚し合う自己（精神）だけであり、自己の内容は知覚だけから成る、という観念論がそこから導かれる。続いて、それにもかかわらずなぜ世界が物質と時間のうちにあるように見えるのか、という誤りの理論（「C系列」と「包含系列」の理論）が展開され、最後に、不死、先在と輪廻、そして宇宙における善と悪の割合という実践的な帰結が論じられる。結論は、時間の相のもとでは、あらゆる自己は有限な時間ののちに、互いへの愛を本質とする終わりのない最終段階に達し、その価値は他のすべての段階の悪を無限に上回る、というものである。

　この翻訳では全体を部ごとに七つの記事に分けた。第2巻の編者ブロードの序文と注（保護期間内）、第1巻巻頭の詳細目次、索引は訳していない。訳文中の〔原注〕は著者の注、〔訳注〕は訳者の注である。第2巻で原書のページを参照している箇所は「原書〇ページ」のまま残した。

## 第4部　決定的対応

### 第24章　決定的対応（一）

**195**　前章でわれわれは、いかなる実体も単純ではありえないという事実から、ある事情のもとでは、実体の本性が矛盾を含み、したがっていかなる実体も存在しえない、ということが帰結するであろうことを見た。この矛盾は、どの実体 A の本性も、無限に至るまでその部分の後続する組の十分な記述を前提とするなら生じるであろう、ということがわかった。この条件は二つの要素に分析できる――第一に、A が実体であるという事実は、それが無限に部分の中の部分をもち、それらの部分が十分な記述をもつことを含意する、ということ、そして第二に、A のいかなる記述も、その部分のそれぞれについての何らかの十分な記述を含意しない、ということである。

　これらの第一は、いかなる実体も単純ではありえないなら明らかに真である。その場合、何かが実体であるという事実は、それが無限に部分の中の部分をもつことを含意し、そのそれぞれが十分な記述をもたねばならないからである。したがって、A のいかなる記述も、その部分のそれぞれについての何らかの十分な記述を含意しないなら、A の本性は矛盾を含む。

　しかし実体が実際に存在することをわれわれは見たし、存在する実体の本性は矛盾を含みえない。そうするとわれわれは、存在する各実体について、A のすべての部分の十分な記述を実際に含意するような何らかの記述がなければならない、と確信できる。たとえこれをなすような A の記述を何も知らないとしても、そう主張する資格がある。そしてもし、ある型の記述だけがこれをなしうるという結論に達するなら、その型の記述が A について真でなければならない、と主張する資格があるであろう。問題の記述の型について何らかの結論に達することはできるであろうか。

〔原注〕A のそのような記述はありえないことを証明するために、われわれがどこにも誤りを見いだせない議論が提出されたなら、すべての結論をあわせると矛盾を生み出すのだから、どこかに何らかの誤りがあることは明らかであろう。その場合、他の議論の一つを疑うよりもむしろ最後の議論を疑う理由はないかもしれない。しかし他の命題は確実なものとして受け入れられてきており、A のそのような記述はありえないことを証明する議論がこれまで提出されたことはないのだから、退けるべきはこの最後の命題である。

　前章の終わりで見たように、その記述は、その部分の一つ以上の組の成員の十分な記述を包含するものであってもよい。ただし、それは、記述に包含された最後の組に後続する無限に多くの部分の組の成員の十分な記述を、包含することなしに含意しなければならない。そのような含意はどのようなしかたで決定されうるであろうか。

**196**　実体以外のある実在で、そのそれぞれが他の実在の無限系列を実際に含意するものがある。A の各部分が、そのような無限系列の各項とある一対一の対応にあり、その対応の本性は、A の部分が与えられた本性をもつ実在にこのしかたで対応するという事実のうちに、A のその部分の十分な記述が含意されるようなものである、と主張する法則によって、われわれの求めるものを得ることは可能であろうか。

　この種の無限系列にはどのようなものがあるか。命題についてそのような系列が得られる。たとえば「M は N である」は「M は N であるということは真である」を含意し、さらに「M は N であるということは真であるということは真である」を含意し、以下無限に続く。しかしこのような系列の項との一対一の対応は、A の部分の系列をけっして与えないであろう。実体の場合の無限系列は部分の組の無限系列であり、各組の成員の数は、先行する組から後続する組へ進むにつれて増していくからである。この命題の系列のような系列との一対一の対応は、後の部分の組に必要な増大する多数性を与えることはできず、したがってそのような系列はわれわれの助けにならない。

　またさらに、第9章で論じた派生的特性の無限系列がある。そしてここでは後の項において増大する多数性を得ることができる。M が N に等しい場合を取ろう。この関係性は、まず、さらに二つの関係性を含む。M と N はともに、それらがその項である相等の関係性に対して関係性をもつからである。次の段階ではさらに四つの関係性が含まれる。M と、N に対するその相等の関係性とのあいだの関係性は、M に対しても相等の関係性に対しても関係性をもち、N と相等の関係性とのあいだの関係性についても対応する事実が真だからである。第三の段階では八つの新しい項が含まれ、以下無限に続く。

　任意の二つの項の関係によってこのしかたで生み出される関係性の系列への対応によって、A の部分を決定することは可能であろうか。しかしこの場合にも、前の場合と同じく、そのような系列の項と A の部分とのあいだに成り立ちうる一様な種類の対応はない。この系列では、各段階で生み出される新しい項は上の段階の項の部分ではなく、前のすべての段階で生み出されたすべての項のあいだに挿入されるからである。他方、A の部分については、各段階――すなわち、この場合には各部分の組――で導入される新しい項は、上の段階の項の部分であり、それらのあいだの位置を占めるのではない。したがって、第一の系列の項との一対一の対応のいかなる原理も、A の部分の系列を決定することはできない。

　もちろん命題や、単純でない特性は部分をもち、そのうちのあるものは部分の部分をもつ。しかしそれらへのいかなる対応によっても、実体の部分の組の無限系列を得ることは不可能であろう。命題や特性のすべての部分がまた部分をもつ、ということは事実ではないからである。反対に、それ自身単純でないすべての特性は単純な部分から成り、すべての命題はそれ以上分析できない成員へと分析できる。

　A の部分の組の系列を、何か他の実体の無限系列と対応させることによって、われわれの求めるものを得ることを望めるであろうか。しかし、もしそれが対応すべき系列が無限に至る部分の中の部分の系列でないなら、それへの対応はけっしてわれわれの求めるものを与えないであろう。そしてもしそれが無限に至る部分の中の部分の系列であるなら、それについても A について生じたのと同じ難点が生じるのではないか。

**197**　私は、この難点から抜け出す道が一つあり、しかもただ一つしかない、と信じる。

　A が部分の組 B と C をもつとしよう。（組のなかの部分の数は、有限であれ無限であれ、どんな数でもよい。）第一に、これらの部分のそれぞれが、A の各部分に対応する部分の組をもつ、ということが真であるとしよう。第二に、その対応は全体を通じて同じ種類のものであり、部分の組の成員のあいだの一対一の関係であり、そして、C がこの関係において B の何らかの部分に立つという事実を含む C のある十分な記述が、問題の B の部分の十分な記述を決定する、というようなものである、ということが真であるとしよう。そして第三に、その対応は、一つの決定項が別の決定項の部分であるとき、第一のものによって決定されるどの部分も、第二のものによって決定される部分の部分であろう、というようなものである、ということが真であるとしよう。

　簡潔のため、C に対応する B の部分を B!C と書き、D に対応する C の部分に対応する B の部分を B!C!D と書き、以下同様とする。このような対応を決定的対応と呼ぶことにする。それによって、B と C の十分な記述の助けを借りて、B!C の十分な記述を決定できるからである。C を B!C の決定項と呼び、B!C を C の被決定項、あるいは C によって決定されるもの、と呼ぶことにする。B!C!D は C!D によって直接に決定され、その決定項の決定項である D によって間接に決定される、と言うことにする。A を一次全体と呼び、B を一次部分と呼ぶことにする。B!C、B!C!D、B!C!D!E 等々を二次部分と呼ぶことにする。B!C を第一階の二次部分、B!C!D を第二階の二次部分、等々と呼ぶことにする。

〔原注〕この段落で用いた語はここでは定義しない。それらの意味は、いまわれわれの前にある場合を覆うのに必要なよりもかなり広いことがわかるであろうからである。定義は第202節で与える。

**198**　前の前の段落で述べた条件が満たされるなら、一次部分の十分な記述が、無限系列を通じて A の部分の中の部分の十分な記述を決定するであろう、ということが帰結する。というのも、B のうちには B!B と B!C があり、C のうちには C!B と C!C があるからである。そしてこれら四つはすべて A の部分であり、B と C の両方のうちにそれらに対応する部分をもつであろう。そうすると B のうちには B!B!B、B!B!C、B!C!B、B!C!C があるであろう。C のうちには C!B!B、C!B!C、C!C!B、C!C!C があるであろう。これら八つのそれぞれがまた、B と C の両方のうちにそれに対応する部分をもち、以下終わりなく続く。

　こうしてわれわれは、各部分の組の十分な記述がその下の部分の組の十分な記述を含意するような、A の部分の部分の無限系列を得た。したがって無限系列はもはや悪しきものではない。前章で見たように、それが以前悪しきものであったのは、系列の各段階の十分な記述がより低い段階の十分な記述によって含意される一方、より高い段階の十分な記述がより低い段階の十分な記述を前提とする――すなわち、そのような記述があることを含意しながら、それが何であるかを含意しない――からであった。そしてこのことが、すでに見たように、前提が全究極前提をもつことを不可能にしたが、他方でそれはそれなしではありえなかった。

　しかしいまやわれわれは、すべてのより低い組の十分な記述を含意するような、一つの部分の組の十分な記述を見いだした。それはそれらの記述を含意するのだから、それらを前提とはしない。こうして全究極前提についての難点は取り除かれる。

　そしてまた、系列は無限に多くの究極的な随伴を含むために悪しきものとなることもないであろう。各二次部分の十分な記述も、系列のなかでのその位置も、どちらも一次部分の十分な記述から帰結するであろうからである。

**199**　第三の条件は不可欠である。それが挿入されなければ、決定的対応は A のすべての一次部分のうちに無限に多くの部分を決定するであろうが、A のすべての部分の部分を決定することは必要でなくなるであろうからである。第三の条件がなければ、たとえば上に挙げた場合に、第三の組の部分のうち七つが第二の組の部分のうちの三つのうちに入り、他方、第二の組の残りの部分がそれ自身第三の組の八番目の部分であって、第一の組の部分とも第二の組の部分とも対応している、ということがありうるであろう。たとえば同じ部分について、それが B!C でもあり B!C!D でもある、あるいは B!C でもあり B!B!B でもある、あるいは他のどんな組み合わせでもある、ということが真でありうるであろう。それはまた第四の部分の組の成員でもあり、すべての後続する部分の組の成員でもあるかもしれない。その場合、決定的対応はその部分のいかなる部分も決定しないであろうが、同時に、それは実体なのだから、無限に部分の中の部分をもたねばならない。こうしてその部分の場合には、悪しき前提は避けられないであろう。しかし第三の条件を挿入することがこの可能性を取り除く。

**200**　このように A の部分の部分のこの無限系列のそれぞれの十分な記述を含意する十分な記述は、A のすべての部分の十分な記述を含意する。たしかに、A のある部分は無限系列のうちに見いだされないであろう。たとえば B!C と B!B!C から成る部分はそこには見いだされないであろうし、A が三つの一次部分 B、C、D をもつなら、B と C から成る部分もそこには見いだされないであろう。しかしたとえば系列のなかで B!C と B!B!C の十分な記述に達したなら、それらはこれらの部分から成る部分の十分な記述を含意するであろう。そしてもし、部分の組の無限系列は決定的対応によって決定されていないかぎり矛盾を含む、というわれわれの結論が正しいなら、決定的対応の系列のうちにないどの実体も、その系列のうちにある実体へと分割できる、とわれわれは確信している。というのも、もしそのように分割できないような実体があれば、どの実体も無限に部分の部分へと分割されるのだから、決定的対応によって決定されていない部分の組の無限系列があることになり、これは矛盾であろうからである。

　A の一次部分の組の成員の十分な記述は、もちろん A の十分な記述を与えるであろう。前章で見たように、全体のどの部分の組の成員の十分な記述も全体の十分な記述を与えるからである。

**201**　A のすべての後続する部分の組の十分な記述を含意するためには、A の一次部分を究極的な事実として取る必要があるのか、と問われるかもしれない。A と結びついた別の実体によって同じ結果が生み出されることはできないのか。A のほかに G があり、それらのあいだの関係が、A と G がそれぞれ、A と G から合成された複合実体のすべての部分の組に対応する部分の組をもつようなものであった、と想定しよう。これは確かに、A のすべての部分を決定するのに必要な含意の無限系列を生み出すであろう。しかしその場合、一次全体であるのは A と G から合成された複合実体であり、A と G はその一次部分であろうから、もとの定式はなおあてはまるであろう。

　条件が第197節で与えたものと異なりながら、それでも対応が悪しき無限系列を避けるようなものでありうる点が三つある。第一に、われわれはいままで、A の各一次部分が A の各部分の組に対応する部分の組をもつ場合を取ってきた。しかしこれは必要ではない。各一次部分が、A の二つ以上の一次部分から成る分化群をもち、その群の各部分の組に対応する部分の組をもつなら十分である。A が一次部分 B、C、D をもつなら、B が B と C およびそれらの部分に対応する部分をもち、C が C と D およびそれらの部分に対応する部分をもち、最後に D が D と B およびそれらの部分に対応する部分をもつなら、A のうちの部分の中の部分の組の無限系列の十分な記述が決定されるであろう。また一次部分がそれ自身の分化群の成員である必要もない。B の分化群が C と D であり、C と D の分化群がそれぞれ D と B、B と C であってもよい。

　そうすると、すべての一次部分が A の他のすべての一次部分のうちの部分の決定項である必要はない。そして第二に、すべての一次部分がそもそも決定項である必要もない。B と C がそれぞれ B と C をその分化群としてもつとしよう。そうすると B と C のすべての部分は、B と C のあいだの関係によって決定された十分な記述をもつ。さて D の部分が B と C およびそれらの部分によって決定されるなら、D のすべての部分は決定された十分な記述をもつであろう。こうして、D が A のいかなる部分の決定項でもないにもかかわらず、A のすべての部分の十分な記述に達するであろう。

　第三に、ある一次部分の場合には、分化群の位置をただ一つの一次部分が占めることがありうる。いま挙げた場合に、D の部分が B とその部分以外に決定項をもたないとしても、B のうちには部分の部分の無限系列があるのだから、D の部分の組の無限系列はその十分な記述が決定されているであろう。

〔原注〕この場合、決定的対応によって決定されるであろう D の部分の組の最も高い系列は、D!B!B と D!B!C から成るであろう。これらは一次部分によってではなく第一階の二次部分（B!B と B!C）によって直接に決定され、それ自身は第二階の二次部分であろう。したがって D は第一階の二次部分をもたないであろう。同じように、D が E にとって分化群の位置を占めるなら、決定的対応によって決定される E の最も高い部分の組は E!D!B!B と E!D!B!C から成り、これらは第三階の二次部分であろう。

　これが起こるためには、B の部分の組の無限系列の十分な記述が決定されていなければならない。したがって、各一次全体のうちには、決定的対応が相互的であるような一次部分の群が少なくとも一つなければならない。（私は、一次部分のどの群においても、その群の各成員が直接にか間接にか他の各成員の二次部分を決定し、どの成員のどの二次部分も群の外のいかなる一次部分によっても決定されないとき、決定的対応はその群において相互的である、と言う。）十分な記述の含意の無限系列が最初に確立されうるのは、そのような相互性によってだけである。もっとも、そのような無限系列は、ひとたび確立されると、相互的な決定なしに別の無限系列を確立しうるが。

**202**　いまやわれわれは、第197節でその用例を挙げた語の定義を与える立場にある。決定的対応は次のように定義できる。実体 C と実体 B の部分とのあいだの関係が決定的対応の関係であるのは、C がその関係において B の何らかの部分に立つという事実を含む C のある十分な記述が、（1）問題の B の部分 B!C の十分な記述を内在的に決定し、かつ（2）B!C の部分の組の各成員の十分な記述、およびそのような成員のそれぞれの部分の組の各成員の十分な記述、以下無限に至るまでの十分な記述を内在的に決定するときである。

〔原注〕決定的対応は二つの実体のあいだの関係であって、もちろん、二つの実体のある十分な記述のあいだの関係である内在的決定の関係と混同してはならない。

　そのような無限系列は、（3）C の十分な記述がまた、C の部分の組の各成員が、B の部分が C 自身に対してそうであるように、それが決定的対応の関係に立つ何らかの実体をもつ、という言明を含むのでないかぎり、（4）B と C が、決定が相互的である群あるいはその一部を形づくるか、さもなければそれらのそれぞれがそれ自身、互いにそのような相互的な関係にある実体への決定的対応の関係によって、直接にか間接にか決定されているのでないかぎり、そして（5）一つの決定項が別の決定項の部分であるとき、第一のものによって決定されるどの部分も他方によって決定される部分の部分であるのでないかぎり、決定されえないことをわれわれは見た。しかしこれら三つの条件は定義の一部をなすのではなく、そこから演繹できる。いま述べたように、定義の第二の条項は、これら三つの条件も真である場合にしか真でありえないからである。

　定義を続けよう。一次全体とは、（1）その部分のどれかを十分に記述するために、その部分の他のもの以外の何ものとの決定的対応も持ち込む必要がなく、（2）その外のどの実体を十分に記述するためにも、その部分のどれとの決定的対応も持ち込む必要がなく、（3）前の条項（1）と（2）の両方が真であるような部分をもたない、そのような実体である。

　これらの後続する組のどれかの成員はどれも二次部分と呼ばれる。それが一次部分との決定的対応によって直接に決定されているなら、それは第一階の二次部分と呼ばれる。それが第一階の二次部分との決定的対応によって直接に決定されているなら、それは第二階の二次部分と呼ばれ、以下同様である。

　どの一次部分 B の分化群も、B の部分がそれに対応する一次部分、およびその二次部分から成る。

**203**　一次全体のなかのすべての一次部分が、その全体のなかのすべての一次部分によって直接に決定される部分をもつ必要はないことをわれわれは見た。それがこれらすべての一次部分によって間接に決定される部分をもつ必要はあるであろうか。そうでないことは明らかである。すでに見たように、ある一次部分はそもそも決定項でないことがありうるからである。そしてたとえば D が何も決定しないなら、それは何か別のものを決定する何かを決定することはできない。

　しかし、たとえある一次全体のなかのすべての一次部分が何かの直接の決定項であったとしても、これらすべての一次部分が直接にか間接にか他のすべての一次部分の部分を決定する、ということは帰結しないであろう。四つの一次部分 B、C、D、E のうち、B の分化群も C の分化群も B と C であり、D の分化群も E の分化群も B と D と E であったと想定しよう。そうすると四つの部分のそれぞれが決定項であろう。そしてそれらはすべて同じ一次全体のうちに入るであろう。B は C と同じ一次全体のうちに、また D と E と同じ一次全体のうちになければならないからである。それでも、B の部分も C の部分も、直接にも間接にも D や E によって決定されないであろう。B と C は、その部分がその体系の外の何ものによっても決定されないような体系を形づくる。

　しかしそれらの部分は D や E によって直接にも間接にも決定されないけれども、それらはどちらも D と E の部分を決定する。B はそれらを直接に決定し、C は B を通じて間接に決定する。そして同じ一次全体のなかのどの二つの一次部分についても、そのそれぞれが他方の部分を決定するか、それ自身他方によって決定される部分をもつか、その両方かでなければならない。そうでなければ、二つの一次部分は二つの一次全体に属し、同じ一つの一次全体には属さないであろうからである。

**204**　前章で見たように、後続する組の成員の十分な記述は、先行する組の成員の十分な記述をつねに与えるであろう。先行する組のなかの部分は、後続する組のより多数の成員から構成された全体だからである。決定的対応は、先行する組の成員の十分な記述が後続する組の成員の十分な記述を与えることを保証する。しかし二つの場合のあいだには違いがある。後続する組の成員のどんな十分な記述も先行する組の成員の十分な記述を与えるであろうが、決定的対応が含むのは、先行する組の成員の何らかの十分な記述が後続する組の成員の十分な記述を与えるであろう、ということだけだからである。先行する組の成員は、これをなさないような他の十分な記述をもつかもしれない。しかしこの結果は、すでに見たように、矛盾を取り除くのに十分である。

**205**　われわれは一次全体をその名で呼んできた。それは決定的対応に関するかぎり自己完結的だからである。しかし宇宙全体が単一の一次全体を形づくるのでないかぎり、一次全体はまた部分でもあろう。まずそれは宇宙の部分であろうし、宇宙のうちに二つより多くの一次全体があるなら、そのそれぞれは一次全体のさまざまな群の成員であり、その群のそれぞれが別個の実体であろう。そしてまた、一つ以上の一次全体と、他の一次全体の一つ以上の部分とから成る実体もあるであろう。一次全体がその部分であるような全体を超一次全体と呼んでよいであろう。

　そのような全体とその部分とのあいだには決定的対応の関係はないであろう。したがって、部分のどんな十分な記述も全体の十分な記述を含意するであろうが、全体のどんな十分な記述も部分の十分な記述を含意することを保証するものは何もないであろう。したがって超一次全体の本性がそのすべての部分の十分な記述を前提とすることはありうる。しかしそれは矛盾を生み出さないであろう。生み出される前提の系列は無限ではないであろうからである。超一次全体はある場合には他の超一次全体に分割されうる。しかし有限の段階で、それはすべてが一次部分か二次部分であるような部分の組に分析されるであろう。これらはもちろんそれぞれが部分の中の部分の無限系列をもつであろうが、これらの系列は悪しきものではないであろう。一次部分のうちにあるのだから、各系列の項は決定的対応によって関係づけられているであろうからである。

**206**　この章の結果を要約すると――単純実体の不在は、宇宙がわれわれの一次部分の定義に合致する部分の組をもつなら、矛盾を含まない。（これらの一次部分は一つの一次全体を形づくってもよいし、任意の数の一次全体に分かれていてもよい。）宇宙がそのような部分の組をもつという理論を、私は実体の決定的対応の理論と呼ぶことにする。

　この理論を証明されたものとして受け入れる資格がわれわれにはあるであろうか。われわれは単純実体がないことを見いだした。したがって存在するものの本性は、単純実体の不在が矛盾を含むことを防ぐようなものでなければならない。そのためには、すでに見たように、部分の終わりのない系列の十分な記述がその全体の十分な記述のうちに含意されていることが必要である。そしてわれわれは、実体の決定的対応の理論が真であるなら、そうであろうことを見た。

　しかしこれ以外のしかたで、部分の十分な記述をその全体の十分な記述によって含意することは可能であろうか。もしそうなら、決定的対応の理論が真であることは確信できない。しかしなされねばならないことは、各段階が前の段階より多くの成員をもつような段階の無限系列を含意すること、しかも、すでに見たように、それ自身はそのような無限系列を含まない何かのうちにそれを含意することである。そしてそれが――不適切でない比喩を用いれば――それぞれが前のものより多くの成員を含む無限に多くの段階を実際に含意するような、多数性のそれ自身への反映による以外に、いったいどのようにしてなされうるであろうか。そして起こらねばならない反映の種類を特定しようとすると、十分な記述を与えるためには、この反映はわれわれが決定的対応と呼んだ形をとらねばならないことがわかる。

　したがって私の考えでは、この章とそれに先立つ二つの章からの正当な結論として、われわれは決定的対応の理論を証明されたものとして採用する資格がある。

### 第25章　因果的なものとしての決定的対応

**207**　いまやわれわれは、さまざまな実体のあいだに決定的対応の関係が成り立つことを確立した。そしてこの時点で、この関係は因果性の関係と呼ばれるべきかどうかを探究しておくのがよいであろう。この問いは、ある意味では言葉の問題にすぎない。ここでは決定的対応の関係の新たな特性を見いだそうとするのではなく、それがすでにもつことが知られている特性が、因果性という名をそれにふさわしいものにするようなものであるかどうかを決めようとするのである。しかしこの問いは、この意味で言葉の問題であっても、だからといって些細なものではない。因果性は、ほとんどすべての哲学体系において――因果の妥当性を否定する体系においても、それを主張する体系に劣らず――目立った位置を占めてきた語である。したがってこの点でわれわれの体系がこれら他の体系に対してどのような関係にあるかを見いだすことは、重要でなくはない。もし決定的対応が因果性の一事例であるなら、因果性はある存在するもののあいだに実際に成り立つ。決定的対応はある存在するもののあいだに成り立つことが示されたからである。

　では因果性によって何が意味されているのか。因果性がまったく退けられるのでないかぎり、チャールズ一世の斬首は彼の死を引き起こしたと考えられねばならないが、彼の誕生やヘンリー八世の死を引き起こしたのではない、ということについては一般の合意があるであろう。またさらに、チャールズ一世の妻への溺愛は彼を軽蔑すべき者にしたが、彼をイングランド王や合衆国大統領にしたのではない。このように、チャールズ一世の斬首と彼の死とのあいだに成り立つと考えられている関係とは何であろうか。

**208**　この関係に必要であることが普遍的に認められるであろうことが三つある。第一は、それが決定の関係、しかもわれわれが内在的決定と呼んだものの関係である、ということである。チャールズ一世の斬首の生起は彼の死の生起を決定する。そしてその決定は明らかに内在的であって、すでに見たように宇宙のなかの各事実と他のすべての事実とのあいだに成り立つ単なる外在的決定ではない。因果性は A と B のあいだには成り立ち、A と C のあいだには成り立たないことのありうる関係だからである。チャールズ一世の処刑とヴェスヴィオ山の最後の噴火とのあいだには何の因果関係もないかもしれない。そして「チャールズ一世は斬首された」という命題は「チャールズ一世は死んでいる」という命題を含意する。このことはその決定が内在的であることを示している。

　第二に、因果性の関係は存在するもののあいだにしか成り立たない。ユークリッドの定義と公理が、三角形の二辺の和が残りの一辺より長いことの原因である、とは言わないであろう。それらはそれが長いことを決定してはいるが。また潮の法則が部分的に重力の法則によって引き起こされた、とは言わないであろう。もっとも、ある特定の時と場所における海の高さは月の引力をその原因の一部としてもっていた、とは言うであろうが。

　またさらに、十八世紀のイングランド王の斬首は、その王の死を内在的に決定する。しかしそれがそれを引き起こしたとは言わないであろう。実際には、十八世紀に斬首されたイングランド王はいなかったのであり、したがって決定の関係は存在するもののあいだにはないからである。言えることは、もしイングランド王が十八世紀に斬首されていたなら、それは彼の死を引き起こしたであろう――すなわち、もし項が存在していたなら、因果性の関係がそれらのあいだに成り立ったであろう――ということだけである。

　第三に、因果性の関係はつねに性質（関係的性質を含む）のあいだの関係である。たしかにわれわれの日常の言葉はこのことを隠している。われわれはルターを宗教改革の部分的原因として語り、チャールズ一世の斬首を彼の死の原因として語る。そしてルターも三つの出来事も性質ではなく実体であり、そのそれぞれが多くの性質をもっている。実際、斬首が死を引き起こした、と言う代わりに、実体を他の性質によって記述して、覆面の男による行為が白薔薇同盟によって嘆かれる出来事を引き起こした、と言うこともできるであろう。

　しかしこの事柄をもっと詳しく見ると、その関係は実際には二つの性質のあいだにあることがわかる。前の出来事のなかのただ一つの性質だけが、後の出来事のなかのただ一つの性質を決定すると考えられている。前のものがチャールズ一世の斬首であったことは、後のものがチャールズ一世の死であったことを決定する。しかし前のものが覆面の男による行為であったことは、後のものが白薔薇同盟によって嘆かれる出来事であったことを決定しない。内在的決定、したがって因果性は、各実体のなかのただ一つの性質だけを結びつけ、他の性質は結びつけない関係である。

　そしてまた、チャールズ一世の溺愛が彼が軽蔑すべき者であることの原因だと言われるとき、その関係は性質のあいだのものでなければならないことは明らかである。この場合には両方の性質が同じ実体に属するからである。そして何ものもそれ自身の原因ではありえない。

**209**　因果性の本性についてのこれら三つの点は、思うに、議論の余地がない。第四に、関係の二つの項はそれぞれ原因と結果として互いに区別でき、原因は結果より後ではありえず、したがって二つの項が時間を超えているか時間において同時であるかの場合を除いて、前の項が原因である、と一般に考えられている。

　もしこれがすべてなら、この点は単に名称にかかわるだけであろう。前の項が原因と呼ばれ、後の項が結果と呼ばれるであろう。しかし二つの項が時間を超えているか同時である場合には、原因と結果のあいだに違いはないであろう。そして時間を超えた、あるいは同時の因果の可能性は、つねにではないにせよしばしば認められている。

　しかしここで、ときにすべての原因を結果から区別すると考えられる三つの特徴に来る。そしてこれらの区別の主張は、原因はその結果より後ではありえない、という主張と結びついている。これらの特徴によって、もしそれを受け入れるなら、時間を超えた同時の因果の場合にさえ原因と結果を区別できるであろう。そしてそのとき原因と結果の区別は名称の問題以上のものとなる。存在する性質のあいだの内在的決定のすべての場合に、二つの項の一方がこれらの特徴のどれかをもち他方がもたないかどうか、そしてもしそうであり、二つの項が異なる時点に生じるなら、それらをもつのはつねに前の項であるかどうかは、事実の問題だからである。

　ときに原因を結果から区別すると考えられるこれらの特徴の第一は、原因は結果が原因を決定しないようなしかたで結果を決定する、ということである。たとえば、誘惑に抗うか屈するかのわれわれの選択は、たとえそれ自身ある結果の避けがたい原因であるとしても、それが引き起こされたのでなければ決定されていないであろう、としばしば考えられている。

　第二に、原因は結果が原因を説明しないようなしかたで結果を説明する、とときに考えられている。

　第三に、原因は結果にある活動を及ぼす、とときに考えられている。たとえ A の生起が B の生起を内在的に決定するとしても、活動もまた現前しているのでないかぎり、これは因果を構成するのに十分ではない、と言われる。

　さて私には、さまざまな思想家によって原因を結果から区別すると考えられてきたこれらの特徴はすべて退けられねばならないように思われる――第一のものは、一方の項による他方の項のそのような非相互的な決定が後のものによる前のものの決定に限られないという根拠で、第二と第三のものは、そのような説明もそのような活動も因果関係のうちにまったく見いだされないという根拠で。

**210**　まず非相互的な決定を考察しよう。もちろん、因果的に結びついた二つの性質の決定が相互的でないことはしばしばある。斬首は死の原因である。そして斬首は死を決定するが、死は斬首を決定しない。死が生じうるしかたはほかにも多くあるからである。そうするとここでは、前のものが後のものを、後のものが前のものを決定しないようなしかたで決定している。しかし他の場合には非相互的な決定は逆に向かう。アルコールを飲むことは酩酊に先立たねばならない。そしてここでは後のものが前のものを決定する。アルコールを飲まずに酔うことはできないが、酔わずにアルコールを飲むことはできるからである。

**219**　因果性について述べておくのがよいさらなる点が三つある。第一に、因果の普遍性によって何が意味されるであろうかについてのわれわれの言明は、相互的な決定を含意しない、ということに注意しなければならない。G のどの生起についても見いだされうる H は、H のすべての生起が G のある生起に対して関係 M に立つようなものでなければならないが、G のすべての生起がそれに対して関係 M に立つ H の生起をもつであろう、とは言われていない。G の異なる生起がそれぞれ H、J、L の生起に関係 M、N、O によって関係している、ということは十分ありうるし、したがって H のすべての生起は G のある生起に対して関係 M に立つが、G のすべての生起がそれに対して関係 M に立つ H の生起をもつわけではない。こうして先の例では、身体の斬首はその死を決定するが、死は斬首を決定しない。死は絞首や毒殺によって引き起こされうるからである。

〔原注〕もちろん、G が H を相互的に決定しないなら、自然の斉一性の法則が真であるとすれば、H は、それが生じるときはいつでも何か他の性質によって決定されていることが必要であろう。たとえば、身体の死はその身体の先立つ斬首を含意しないのだから、自然の斉一性の法則が真であるなら、どの機会にもその生起、あるいはその一つの生起が身体の斬首を含意するような何か他の一つ以上の性質がなければならない。この性質はもちろん斬首される身体の性質である必要はない。たとえば、イングランドの王妃がある特定のしかたで夫を誤らせるという性質をもつときはいつでも、彼女の夫の身体が斬首されるという性質をもつであろう、という法則があるかもしれない。

　同じように、G の各生起について見いだされるべき K は、G が生じる各場合に、それに対して関係 P に立つ K の生起をそれがもつようなものでなければならないが、K のすべての生起が G のある生起に対して関係 P に立つであろう、とは言われていない。こうして先の例では、身体の死は交わりの停止を決定するが、交わりの停止は死を決定しない。人は、その身体の死によってだけでなく、その麻痺によっても、この惑星の他の人々との交わりから隔離されうるからである。

　そうすると因果性の普遍性は、相互的な因果性の普遍性を含まない。しかし後者もまた存在すると主張されてきた。これによって何が意味されているかを考察しよう。

　まず第一に、すべての因果的決定は相互的であると主張するどんな法則も偽であろうことは明らかである。酩酊がアルコールを飲むことを決定することをわれわれは知っており、アルコールを飲むことが酩酊を決定しないことも知っている。人がアルコールを飲んでも酔わなかった場合があるからである。そうするとここには、相互的でない因果的決定の場合が少なくとも一つある。

　そうすると、普遍的な相互的決定が、ある性質による別の性質のすべての決定が相互的であることを意味すると取られるなら、相互的決定が普遍的に成り立たないことは明らかである。そしてすべての因果的決定は相互的であると言われるとき、思うに、これほど広く及ばない何か別のことが意味されてきた。性質のすべての決定が相互的であることではなく、すべての性質が少なくとも一つの相互的な決定をもつ、ということが意味されてきたのである。斬首は死を決定し、死は斬首を決定しない、ということは認められるであろうが、斬首によるすべての死は、他のどの種類の死にも見いだされない何らかの特有の性質をもち、この特有の性質と斬首されるという性質とは互いに相互的に決定し合う、と主張されるであろう。またさらに、死という性質が生じるときにはいつでも、そしてそのときだけ生じ、したがって死と相互的な決定のうちに立つ何か他の性質がある、と主張されるであろう。

　もしそのような相互的決定が普遍的であるなら、それを主張する法則は次のように表現できるかもしれない。G を生じる任意の性質としよう。そうすると、G が生じる各場合に、G のその生起に対して関係 M において生じ、かつ H が生じる各場合にそれが G のある生起に対して関係 M に立ち、G が生じる各場合に H のある生起がそれに対して関係 M に立つであろうような性質 H が見いだされる。

**220**　このような相互的決定が普遍的であることはありうる。それは何の矛盾も含まず、それが事実でないことを経験的に証明することは不可能である。われわれがその決定項を見いだせる性質のなかにさえ、他の性質との相互的決定を何も見いだせないものが多くあるかもしれない。しかしそのそれぞれについて、決定が相互的であるような、われわれに知られていない決定項があるかもしれない。しかし他方、相互的決定の普遍性を証明することは不可能であるように思われる。それは、たとえ因果的決定の普遍性がそれ自身確立されたとしても、それから証明することはできないであろう。相互的でない決定に何の矛盾もないことは明らかだからである。すでに見たように、多くの決定――たとえば斬首による死の決定――は相互的でないからである。

**221**　第二に、すべての性質が因果的に決定されているなら、どの実体についての完全な知識も宇宙のなかの他のすべての実体についての完全な知識を含意するであろうが、因果的に決定されていない性質があるならこの結果は必ずしも帰結しないであろう、とときに言われてきた。しかしこれは私には誤りであるように思われる。「どの実体についての完全な知識」という言い回しのある意味では、すべての性質が因果的に決定されていなくても、この結果は帰結するであろう。この言い回しの別の意味では、それらがすべて因果的に決定されていても、それは帰結しないであろう。

　宇宙のなかのすべての実体は宇宙のなかの他のすべての実体に関係している。そしてどの実体 A についても真であるすべてのことについての完全な知識は、他のすべての実体に対するそのすべての関係についての知識を含むであろう。これはもちろん、それらすべての実体の十分な記述についての知識を含む。それが関係 P に立つ相手の実体 B を同定できなければ、私は A を完全には知らないからである。しかしさらに、B の十分な記述に加えて、B について真である他のすべての事実が A についての私の知識を増す。それは、A がこの事実が真であるような実体に対して関係 P にあることを私に告げるからである。したがって A の完全な記述は、A について真であるすべての事実を含むのだから、他のすべての実体の完全な記述を含むであろう。したがって、A についての完全な知識をもつなら、すべての性質が因果的に決定されていようといまいと、B についての、そして他のすべての実体についての完全な知識をもつであろう、ということは真であろう。

　しかし A の知識のうちに他のすべての実体についての知識がこのように含まれることは、われわれが論じている理論によって意味されていることではない。意味されているのは、B についての完全な知識を含まない A についての知識から、ある性質が別の性質を因果的に決定する法則について十分な知識をもち、必要な論証を遂行する十分な推論の力をもつ人なら誰でも、B についての完全な知識を推論できるであろう、ということである。そして、これが真であることがすべての性質の因果的決定によって含まれるであろうと信じる理由はないように思われる。

　すべての性質の因果的決定のうちには、宇宙のなかに、どちらのどの性質も他方のどの性質によっても直接にも間接にも因果的に決定されていないような二つの実体があるという可能性を排除するものは何もない。また、私の見るかぎり、その可能性を排除するものはほかにも何もない。因果性に関しては互いにまったく関係していない二つの実体が宇宙のうちに存在することは完全に可能である。もちろん、宇宙のうちに何らかのしかたで関係していない二つの実体があることは不可能であるが、このことから、因果的に関係していない二つの実体がありえないことは帰結しない。

〔原注〕われわれが存在することを証明した唯一の種類の因果的決定は、決定的対応による決定である。そして宇宙が二つ以上の一次全体に分かれ、そのどの一つのどの部分も他方のどの部分とも決定的対応によって結びついていない、ということは可能であることをわれわれは見た。もちろん二つの一次全体の部分が何か他の種類の因果的決定によって結びついていることは可能であろうが、これは単なる可能性にとどまる。

　そしてたとえ宇宙のなかのすべての実体が宇宙のなかの他のすべての実体と因果的に関係していたとしても、われわれが考察している理論は証明されないであろう。B のある性質は A の性質によって因果的に決定されているとしても、B の他の性質は A の性質によって直接にも間接にも因果的に決定されていない、ということがなおありうるであろうからである。そしてこの場合、A についてのいかなる知識も B のすべての性質を推論することを可能にしないであろう。

**222**　なぜ、すべての性質が因果的に決定されているなら、どれか一つの実体の本性から他のどの実体の本性へのそのような推論がなされうる、と想定されてきたのであろうか。私は、それが部分的には、われわれが外在的決定と内在的決定として区別したものの混同によるのではないかと考えがちである。何かがそれがあるのと異なっていたなら他の何かがそれがあるのと同じであろう、と信じる権利はわれわれにないことは、多かれ少なかれはっきりと認められていた。そしてこの否定的で一般的な外在的決定が、積極的で特殊な内在的決定と混同されたのである。割れた壁の花のどれかがそれがあったのと異なっていたなら、シェイクスピアは『ハムレット』を書いたであろう、と信じる権利はわれわれにない。しかし、テニスンが示唆しているように見えるように、その花についての最も完全な知識が、シェイクスピアが『ハムレット』を実際に書いたことを推論するのを可能にするであろう、ということは帰結しない。

　こうして、たとえすべての性質が因果的に決定されているとしても、どれか一つの実体についての完全な知識からすべての実体についての完全な知識が推論されうると考える資格はわれわれにないであろう。そしてたとえそうであるとしても、そのような推論をなしうる可能性は実践的には何の重要性ももたないであろう。宇宙のなかの実体の数は無限であり、その関係は無限に込み入っており、したがって、無限の長さと複雑さの論証を遂行する力をもつ思索者によってでなければ、ある特定の B の本性が A の本性から推論されうるという保証はないであろう。これがわれわれ自身のように力が有限でしかない存在者の知識に関しては何の重要性ももたないことは明白である。そしてたとえ宇宙のうちに、推論の力が無限であり、どれか一つの実体についての完全な知識を獲得できる存在者が存在するとしても、その存在者がまた直接に全知であるなら、そのような推論をなしうる可能性はその存在者にとって何の重要性ももたないであろう。その場合その存在者はすべての実体についての完全な直接の知識をもち、それに推論によって達する必要はないであろうからである。

**223**　第三に、すべての性質が因果的に決定されていないという可能性が、通常の意味での非決定論者――すなわち、少なくともある場合には人間の意欲は完全には決定されていない、と主張する人々――に何らかの満足を与えるかどうかを考察することが残っている。それが彼らに何らかの満足を与えるかどうかは、彼らが何を真だと主張し、あるいは真であることを望むかにかかっているが、それが何であるかはあまり明らかではないように思われる。

　ときに非決定論者が要求しているのは、意欲が、それに先立つ出来事との関係においては――それに続く出来事との関係においてではないにせよ――内在的にも外在的にも偶然的であるべきだ、ということであるように思われる。求められているのは、もし意欲がそれがあったのと異なっていたとしても、このことは、先立つ出来事がそれがあったとおりであったであろうことを疑う理由をわれわれに何も与えないであろう、と言えることであるように見える。非決定論者によってときに提出される「塊」の宇宙への抗議は、このことを意味しているように見える。それらが完全な内在的決定の不在によってなだめられうるとは思われない。

　もしこれが求められていることなら、われわれが達したいかなる結果もそのような要求を正当化することには何の役にも立たないであろう。その正当化は、宇宙から完全な内在的決定だけでなく完全な外在的決定もまた欠けていることを必要とするであろうからである。そしてすでに見たように、宇宙の外在的決定は完全である。

　またときに、非決定論者によって求められているのは、意欲が他のものより決定されていないことであるかのように思われる。私が引き金を引こうと意志し、引き金が引かれ、人が撃たれるなら、非決定論者は、意欲が内在的に完全には決定されていなかったことを確立するだけでは、引き金を引くことと人の死とが内在的に完全に決定されていたこともまた確立されないかぎり、満足しないであろうように思われる。われわれが自分の行為に責任をもちうるためには、それが部分的に決定されていないことだけでなく、他の何ものもそうでないことが必要だと考えられているらしい。われわれの結果はこの要求を正当化するのに何の役にも立たないであろう。すべての性質が内在的に決定されていないという、まだ開かれていることをわれわれが見た可能性は、意欲である実体の性質に限られないからである。しかしひょっとすると非決定論者は、あるいは少なくともある非決定論者は、われわれの意欲が内在的に完全には決定されていなければ満足するかもしれない。そしてその可能性は排除されていないことをわれわれは見た。われわれの意欲がそのすべての性質に関して完全には決定されておらず、決定されていない性質のなかに、倫理的な意義をもつもの、あるいはそのいくつかが含まれている、ということはありうる。この場合それらが倫理的な意義を得るか失うかは、倫理学の問題である。

### 第26章　決定的対応（二）

**224**　次に、決定的対応についてのさらなるいくつかの問いの考察に進まなければならない。C が B の何らかの部分に対して関係 X にあるという事実を含む B の十分な記述から、B!C の十分な記述が帰結することをわれわれは見た。しかしさらに進んで、B のこの十分な記述のうちには、B!C の十分な記述だけでなく、B!C の本性の全体が含意されている、と言うことはできるであろうか。それとも反対に、B!C が、B のこの十分な記述のうちにいかなるしかたでも含意されていない性質をもつことは可能であろうか。

　もし B!C のある性質がそのこの十分な記述によって含意されていないなら、その性質はこの記述によって前提とされている。排中律によって、S を任意の性質として、B!C は S か非 S かでなければならないからである。したがってそれが B!C であることは、それが「S または非 S」であることを含意し、それがさらに一方であって他方でないことを含意しないなら、それは、実際にどちらであるにせよ、それが S であることか非 S であることかを前提とするであろう。

　第184節で、どの項 N も、N が含意するものによって前提とされるものを何であれ前提とすることを見た。そして B のある十分な記述は、無限系列を通じて B のすべての部分の十分な記述を含意する。したがって、もし B の部分のこれらの十分な記述のそれぞれがその部分の何か他の性質を前提とするなら、B の十分な記述は前提の無限系列をもつであろう。これは矛盾を含むであろうか。

**225**　第191節で、そのとき考察した前提の無限系列から矛盾が生じるであろうと結論するに至った理由によっては、それが矛盾を含むと決めることはできない。系列の後続する項における前提の固定は、先行する項における前提の固定を含意する必要はないからである。たとえば、B!C を構成する第二階の二次部分において、それらの十分な記述によって前提とされるそれらの部分の他の性質を固定したとしても、それは B!C 自体において、その十分な記述によって前提とされる性質を必ずしも固定しないであろう。そしてその場合、B の全究極前提を考察するにあたって、これらの前提のどれも、同じ系列のより低い項のうちに含意されているという理由でそこから消えることはないであろうし、したがって矛盾は生じないであろう。

　他方、第190節で提起された反論はこの場合にもあてはまるであろう。決定的対応によって決定される実体の無限系列のそれぞれが、決定的対応によって含意されていない各性質に関してその前提を固定されるためには、随伴の無限系列がなければならないであろうからである。そして第190節で、このような無限系列は受け入れられないという結論にわれわれは達した。

　もしこれが正しいなら、B のすべての部分が無限に至るまで、決定的対応によって決定された性質以外の性質をもつことは不可能であろう、ということが帰結するであろう。しかしこの結果は系列の無限性からのみ帰結する。任意の有限個の階の部分のすべて、あるいはどれかが、決定的対応によって決定されていない性質をもつことは可能であろう。そしてそのような部分のなかには、もちろん、観察の力が無限でないどの観察者によってでさえ観察されうるすべての実体――すなわち、現在われわれにとって何らかの実践的関心をもつすべての実体――が含まれるであろう。

**226**　ここで当然、宇宙のうちに実際に生じる決定的対応の関係が何であるかを見いだすことができるかどうか、という問いが生じる。もし、決定的対応の関係であるような関係はただ一つしかない、あるいは存在するものの本性についてわれわれが達した他の結果とその生起が両立する関係はただ一つしかない、とアプリオリに示すことができれば、その関係が宇宙のうちに実際に生じ、実際に生じる決定的対応の唯一の関係であることがわかるであろう。しかし私は、これをアプリオリに示すことは可能だとは思わない。第5部で経験的な性質の考察を導入するとき、思うに、宇宙のうちに生じ、実際に生じる唯一のものであるようなある決定的対応の関係があると信じる十分な理由を与えることが可能になるであろう。しかしそれまでは、この点は未決定のままでなければならない。

**227**　またわれわれは、私の見るかぎり、実際に生じるどの決定的対応の関係も満たさねばならないさらなる条件を、現在のところ定めることもできない。とりわけ、排除できない二つの重要な可能性がある。第一に、同じ種類の決定的対応が至るところに生じることが必要であると示しうるとは私には思われない。一つより多くの一次全体があるなら、その関係はそのそれぞれにおいて異なるものであるかもしれない、ということは十分可能であるように私には思われる。そして一つの一次全体のうちでさえ、B が C の部分ともつ決定的対応の種類が、D が E の部分ともつそれとも、あるいは B 自身が F の部分ともつそれとも、あるいはさらに G が B の部分ともつそれとも異なりうることを否定する理由はないように思われる。

　しかし、後続する部分の組の無限系列の決定において、最初の段階より後のどの段階にも新しい種類の決定的対応を導入することはできないであろう。最初の段階で、これらの後続する部分の組のすべての成員の十分な記述が含意されていなければならないからである。そしてもし最初の段階で述べられていない新しい種類の対応が後続するどこかの段階で効力をもつなら、そうではないであろう。もちろん、A が、さらなる後続する組の無限系列を生み出すという特性を除いて決定的対応のあらゆる特性をもつ関係によって、後続する組を決定するような部分の組をもつことは可能である。そしてそのようにして決定された組が、そのような系列を生み出すという特性を除いて決定的対応のあらゆる特性をもつ別の関係によって、さらに別の組を決定するかもしれない。これは任意の有限個の組について続くかもしれない。しかしそれは決定的対応ではないであろう。どの関係も組の無限系列を生み出すという特性をもたないであろうからである。最終的には、もとの矛盾が避けられるべきなら、そのような無限系列を生み出す決定的対応の関係に達しなければならない。そしてそのとき、上に挙げた理由から、そのような系列において最初の段階の後に新しい種類の決定的対応を導入することはできない。

**228**　第二に、宇宙全体に、あるいはその一部に及ぶ決定的対応の種が一つより多くありうる可能性を、現在のところ排除することはできない。われわれがまだ見るかぎりでは、宇宙が、どちらの成員も決定的対応によって直接に決定されておらず、しかもどちらかの組のすべての成員の十分な記述から、決定的対応によって、すべての後続する組の成員の十分な記述が帰結するような、二つの部分の組をもつことは可能であるかもしれない。その場合、宇宙は、そのそれぞれがわれわれの定義によって一次部分の組であり、そのそれぞれが宇宙全体に及ぶ決定的対応の体系を始めるような、二つの部分の組をもつであろう。そしてそのような部分の組の数は二つに限られる必要はない。

〔原注〕全体は、どちらも他方に対して後続的でない二つの部分の組に分割されうることを思い起こされたい。たとえばケンブリッジの卒業生の群は、博士の群、修士の群、学士の群から成る一つの部分の組をもつ。それはまた、神学の卒業生の群、法学の卒業生の群などから成る別の組をもつ。これらの組のどちらも他方に対して後続的ではない。

　第5部で経験的な考察を導入するとき、思うに、これら二つの可能性をどちらも退ける十分な理由を見るであろう。上で述べたように、宇宙のうちに実際に生じる決定的対応の関係はただ一つしかないと結論する根拠を見いだすであろうし、また一次部分の組はただ一つしかないと信じる根拠も見いだすであろう。しかし現在のところ、この点についてそれ以上先に進むことはできない。

**229**　その間に、われわれの経験が告げるある種の対応の形を考察し、それらがどこまで決定的対応に必要な条件を満たし、どこまで満たさないかを探究するのは有用かもしれない。そのような議論は、決定的対応の本性をより明らかに悟る助けになるかもしれない。

　まず、決定的対応に属することがわかったある特性を列挙することから始めよう。（1）実体 C と実体 B の部分とのあいだの関係が決定的対応の関係であるのは、C がその関係において B の何らかの部分に立つという事実を含む C のある十分な記述が、問題の B の部分 B!C の十分な記述を内在的に決定するようなものであるときである。（2）決定的対応の関係は、一つの決定項が一つより多くの被決定項を決定しうるような関係である。（3）それは、B!C がただ一つの決定項 C によって決定され、他方 C は、A の多くの部分の直接の決定項でありうるが、B のうちに入る A の部分のうちではただ一つの直接の決定項であるような関係である。（4）それは、少なくともある場合には相互的である。（5）それは、全体が部分の組に分割され、そのそれぞれがまた部分の組に分割され、以下無限に続き、しかもこれらすべての部分の十分な記述が、決定的対応によって、全体の十分な記述によって決定される、ということが可能であるようなものである。

**230**　まず、透明な面に描かれた模様が、その面に対して異なる角度に立つ――どの二枚も同じ角度には立たない――いくつかの板の上にその影を投げかける場合を考察しよう。模様と影とのあいだの関係は、決定的対応に必要な条件のいくつかに実際に合致する。それは第一の条件に合致する。模様の形と、各板が透明な面に対して立つ角度とを知れば、各板の上の影の形を含意する所与をもつことになるからである。それは第二の条件に合致するであろう。一つの模様は異なる板の上に多くの影をもちうるからである。そしてそれは第三の条件に合致するであろう。各影は（模様に対してその角度に置かれた板の上では）ただ一つの模様の影でしかありえず、模様は各板の上にただ一つの影しかもちえないからである。

　しかしそれは第四の条件には合致しないであろう。相互的な決定の可能性はない。模様の部分は模様の影の影ではありえないからである。したがってそれは第五の条件に合致しえない。もし影が無限に部分の中の部分をもつとすれば、それは、模様が、模様と影とのあいだの関係から独立した事実として、無限に部分の中の部分をもつからでしかありえないであろう。そうすると模様は部分の組の無限系列をもち、そのそれぞれはそれに後続するものを前提としつつ、それ自身はそれらによって含意されていたであろう。こうして第23章で説明したしかたで矛盾が生じるであろう。

**231**　あるいはまた、詩集の蔵書が相互参照を排除するある方式で目録化され、目録が何部かあって、各部が異なる色の紙に刷られていると想定しよう。そうすると、ここでもまた最初の三つの条件は満たされるであろう。C の十分な記述は、その巻が B――赤い紙に刷られた目録の部として十分に記述されるであろう――に記載されているという事実を含む、巻の一つのどんな十分な記述でもよいであろう。そしてこれは、目録のその部におけるその本の記載項目の十分な記述 B!C を与える。こうして第一の条件は満たされる。第二の条件は満たされる。一冊の本は目録の多くの部に記載されうるからである。そして各記載項目はただ一冊の本にしか言及せず、各本は各目録にただ一つの記載項目しかもたないであろうから、第三の条件も満たされる。

　しかし第四の条件は満たされない。目録化された本の部分が、目録を目録化する目録の記載項目から成ることはありえないからである。これは不可能である。そのような記載項目から成る本は詩集ではないであろうからである。したがって第五の条件もまた満たされない。一方、本だけが目録化され、その部分は目録化されないなら、目録の記載項目は、目録化されるもののうちの何かに対応する、無限に至る部分の中の部分をもつことはできない。他方、本の部分が目録化されるなら、記載項目のうちにそのような無限系列がありうるのは、目録化される本が独立の事実としてそのような部分の無限系列をもつ場合だけであろう。そしてこれは、前の場合と同じく矛盾に導くであろう。

**232**　しかし場合を変えて、それぞれがそれ自身と、他の目録と、それ自身および他の目録のなかの記載項目とを目録化するような、ある数の目録を取ると想定しよう。最初の三つの条件は前と同じく満たされるであろう。そして第四の条件も満たされるであろう。青い本の記載項目は赤い本の部分であり、赤い本の記載項目は青い本の部分であろうからである。また記載項目の無限系列の十分な記述も含意されるであろう。赤と青の二つの目録があるなら、赤はそれ自身と青の記載項目を含むであろう。それはまた、それ自身のなかのそれ自身と青の記載項目の記載項目、そして青のなかの両方の記載項目の記載項目も含むであろう。そして以下無限に続く。

　しかしそれでも第五の条件は満たされないであろう。青い本の記載項目は、いま述べたように赤い本の部分である。そして青い本のなかの青い本と赤い本の記載項目を記録するさらなる記載項目もまた赤い本の部分である。しかしそれらは赤い本のなかの青い本の記載項目の部分ではない。「青い本」という記載項目が、「青い本のなかの赤い本の記載項目」と「青い本のなかの青い本の記載項目」とをその部分としてもちえないことは明らかである。したがって記載項目の無限系列は、無限に部分へと分割された部分の系列ではなく、第五の条件を満たしたことにはならないであろう。

**233**　次に、B が正であり C が負であって、それらがこの点で自分たちに似るように、それら自身と互いとの部分を決定し、したがって B!C は A の正の部分の負の部分である、と想定しよう。この場合、第一の条件は満たされるであろう。B!C はこのしかたで十分に記述されるであろうからである。第二の条件も満たされるであろう。C は B!C だけでなく C!C をも決定するであろうからである。第三の条件もそうである。B!C は C 以外の何ものにも対応せず、C は B のうちに入る A の部分のうちではただ一つの直接の決定項であるからである。第四の条件も満たされるであろう。B は C の部分を決定し、C は B の部分を決定するであろうからである。最後に、第五の条件も満たされるであろう。第一階の二次部分は四つあるであろう――正の部分の正の部分、正の部分の負の部分、負の部分の正の部分、負の部分の負の部分である。そのそれぞれがまた正と負の部分をもち、以下無限に続く。こうしてすべての条件が満たされる。

　同じ結果は、正と負以外の性質についても起こりうるであろう。そしてこのように組み合わされる性質の数は二つより多くてもよく、したがって一次全体は二つより多くの一次部分を含んでもよいであろう。またそれらのいくつかが相互的に決定する群を形づくるなら、すべての一次部分が他のすべての一次部分を決定する必要もないであろう。

　しかしこのような決定的対応のためには、性質がある特性をもつことが必要である。第一に、それらは互いに両立しないものでなければならない。そうでなければ、B の部分の一方について正であると言い、他方について負であると言うことによって、それらの十分な記述は与えられないであろう。両方の記述が同じ部分に属するかもしれないからである。第二に、それらは全体とその部分が同じ性質をもちうるようなものでなければならない。正の部分が正の部分をもち、負の部分が負の部分をもちうるのでなければ、無限系列は生じないであろうからである。第三に、それらは全体とその部分が異なる性質をもちうるようなものでなければならない。負の部分の正の部分と、正の部分の負の部分とをもつこともまた必要だからである。そしてこれらの特性は、問題の全体が一次部分であれ、第一階の二次部分であれ、他のどの階の二次部分であれ、無限の過程のどの段階においても真でなければならない。

　これらの特性をもつ性質の組が何かあるかどうかは、いまのわれわれにはかかわらない問いである。私は、そのような組があるとも、あるとしても正と負がそのような組であるとも主張しない。

**234**　精神の世界のうちに決定的対応の例を見いだすことはできるであろうか。知識はそのような対応の項でありうるであろうか。まず判断から成る知識を取ろう。真なる判断だけが知識の部分である。真なる判断とは事実に対応する判断であり、判断は知る存在者の心の状態であって実体であり、知られるものはときに実体であるから、実体のあいだの対応であるような知識の場合がある。

〔原注〕すべての真なる判断が知識の部分であると主張するつもりはない。一九一九年のピーターハウス学寮の視察者が司教であったということは真なる判断であるが、もしある人が、その視察者はジブラルタル司教であると信じたためにその判断を下したのなら、彼がこれを知っていると正しく言えるかどうかは、少なくとも疑わしい。

　B は、十分な記述 XYZ をもつ実体が存在することを知っている。十分な記述 XYZ を含み、また B が C についてこの知識をもつという事実も含むこの実体 C の十分な記述は、B の C についての知識の十分な記述を与えるであろうか。

　第一に、それはそうしないであろう。人は同じ事実を二つの異なる時点に知ることが可能だからである。そのとき彼の心の二つの状態があり、そのそれぞれについて「十分な記述 XYZ をもつ実体が存在するという B の知識」という記述が真であろう。したがってこの記述はどちらの状態の十分な記述でもないであろう。それは両方について真だからである。その帰結として、上に定めた第一と第三の条件は満たされないであろう。

　しかし、知る存在者のそれぞれが、そもそも知っているどの実体についてもただ一つの知識の行為しかもたない、という想定がなされるなら、それらは満たされるであろう。そうすると実体は、RST として十分に記述される実体である B の、XYZ として十分に記述される別の実体が存在するという知識、として記述されるなら、十分に記述されるであろう。

　しかしこの予備的な難点が取り除かれても、他の難点が見いだされるであろう。第一に、知識のすべての行為は知る者の部分である――私はこれが真であると信じている――ことを認めるとしても、多くの場合、第四の条件は満たされえないであろう。その場合、B の部分は C によって決定されるであろう。しかし C がそれ自身知る存在者でないなら、この決定は相互的でありえない。私が大ピラミッドを知っているなら、私の心の部分は大ピラミッドについての知識であることによって決定される。しかし大ピラミッドのどの部分も、私の心についての知識であることによって決定されることはありえない。そして第四の条件が満たされないのだから、第五の条件も満たされないにちがいない。

　第二に、B と C が互いを知りうる場合にさえ、第五の条件は満たされないであろう。そのどちらかが一つより多くの実体を知ることは想定の一部ではないからである。またこれでさえ、知識が相互的であると想定し、さらに各知る存在者が自分の知るすべてのものの部分を知ると想定しないかぎり、第五の条件を与えはしないであろう。

　第三に、どの知る存在者の知識の行為もその存在者の完全な部分の組を形づくり、したがって B のすべての部分について決定的対応が与えられることを保証する、ということは想定の一部ではない。

**235**　われわれが考察している知識の種類をさらに特定することによって、これらの難点を避けることはできるであろうか。一次全体の一次部分のそれぞれが知る存在者であり、そのそれぞれが他の一次部分とその部分とを知り、その知識を除いてはまったく何の部分ももたない、としよう。そうすると決定は相互的でありうる。知られる一次部分はまた知ることができ、知られる二次部分は知識の行為でありうるからである。こうして第四の条件は満たされる。そうしてわれわれは B のうちに決定された部分の終わりのない系列をもつ。まず彼自身と C についての彼の知識があるであろう。次に、彼自身と C についての彼の知識についての彼の知識と、彼自身と C についての C の知識についての彼の知識とがある。そして以下無限系列を通じて続く。

　しかしそれでも第五の条件は満たされていない。たしかに一次部分の十分な記述は、そのそれぞれが一次全体の部分であり、また一次部分の一つの部分でもあるような実体の終わりのない系列の十分な記述を内在的に決定する。しかしこの点を越えると、決定される部分は先に決定された部分の部分ではない。それらはすべて判断であり、部分についての判断は全体についての判断の部分ではありえない。したがって相互的な決定は、終わりのない系列を生み出しはするが、部分の中の部分の終わりのない系列を生み出しはしない。

　たとえば上に挙げた場合、BkC（ここで k は「〜についての知識」を表す）は BkCkB と BkCkC を含意する。C のうちには CkB と CkC があり、B は自分の知るすべてのものの部分を知るからである。しかし BkCkB は BkC の部分ではない。両方とも B の部分であり、CkB は C の部分であるにもかかわらず。判断は部分をもつ（もっとも無限に至る部分の中の部分はもたないが）が、判断の部分の組がすべて判断であることはけっしてない。したがって全体についての判断の部分の組が、全体の部分についての判断であることはけっしてありえない。たとえば、私が連合王国について何かを知っているなら、連合王国についての私の判断は、グレートブリテンとアイルランドそれぞれについての二つの判断に分割することはできないであろう。たとえ連合王国についての私の判断が、それはグレートブリテンとアイルランドという二つの部分から成る、というものであっても、その判断は、グレートブリテンについての判断とアイルランドについての判断という二つの判断から成るのではないであろう。

**236**　こうして、知識が判断に限られると取られるなら、知識は決定的対応の例を与えることはできない。しかし判断のほかに、知識と呼ばれる資格をもつものがある。それは知覚である。そして知覚の場合には、いま考察した難点は生じない。部分の知覚が全体の知覚の部分でありうることは、思うに、認めなければならないからである。私が鏡板の表面を全体として知覚し、同時に表面の彫刻の細部を知覚するなら、各特定の細部の知覚は全体としての鏡板の知覚の部分である。

〔原注〕厳密に言えば、もちろん、私は鏡板やその細部を知覚するのではない。私は感覚与件を知覚し、そこから鏡板と細部とを信じるよう導かれるのである。このように細部に関係づけられた感覚与件は、明らかに、このように鏡板に関係づけられた感覚与件の部分であると思われる。そして私の主張は、細部に関係づけられた感覚与件についての私の知覚は、鏡板に関係づけられた感覚与件についての私の知覚の部分である、ということである。（この主題は第5部で論じる。）

　こうして、思うに、一次部分のそれぞれが、他の一次部分とその部分とを知覚し、それ自身はそれらの知覚以外の部分をもたない知覚する存在者であるような一次全体を取ることによって、決定的対応がどのようなものであろうかの例を得ることができる。（われわれはまた、知覚は少なくともある場合には相互的であり、どの知覚者もどの知覚対象についても一つより多くの知覚をもたない、と想定しなければならない。）最初の四つの条件は、判断による知識の場合と同じく満たされるであろう。そして第五の条件もまた満たされるであろう。B についての C の知覚についての B の知覚は、C についての B の知覚の部分であろうから、われわれは部分の中の部分の無限系列をもつことになろうからである。

　このような知覚の経験をわれわれはもたない。われわれの経験は、思うに、正しく分析されるなら、自己は自分自身を知覚することができ、しばしばそうしていることを示す。しかし、ある自己が別の自己を知覚する経験も、したがって自己の相互的な知覚の経験も、われわれはもたない。そしてまた、知覚以外の活動をもたず、知覚以外の部分をもたない知覚する存在者の経験もわれわれはもたない。

　それでもわれわれは知覚がどのようなものかを知っており、このようにして自分自身と互いとその部分とを知覚する自己の社会の概念を形づくることは不可能ではないように思われる。したがって、もしこれが生じたなら、そこに決定的対応の関係が得られるであろう、という結論に達したことは無駄ではない。そしてこの問題は、第5部でふたたび取り上げるまで、ここに置いておかねばならない。

### 第27章　排他的共通性質（続）

〔原注〕簡潔のため、本章の残りでは、「排他的共通性質」を、群の外延の言い直しであるものを含まないように用いる。

**242**　基礎体系の部分でない実体に移ると、その体系に対するそれらの関係によって、それらの実体のある群がそのうちに排他的共通性質をもつであろうと決定できることがわかる。

　第一に、すでに見たように、基礎体系の成員でないどの実体も、その体系の成員である実体へと分割できる。（簡潔のため、これを、すべての外部実体は内部実体へと分割できる、と言うことによって表現してよいであろう。）そしてすべての外部実体は、すべて同じ階の内部実体へと分割できる。たとえば、B と C!D と D!C!E!F から成る実体を取るなら、D!C!E!F は第三階の二次部分であり、B と C!D は同じ階の部分へと分割できるから、外部実体の全体はその階の部分へと分割できるが、それより高いどの階の部分へも分割できない。他の実体は、すべてより高い階である部分へと分割できるであろうし、また別の実体は、より低い階に達したときにはじめてこのしかたで分割できるであろう。

**243**　第二に、すべてではないがある外部実体は、そのどれのすべての部分も、一つより多くの一次全体があるなら、そのうちのある一つの一次全体のうちに入るようなものであろう。そのそれぞれがそのすべての部分を一次全体 A のうちに入れているような外部実体は一つの群を形づくり、そこには、そのすべての部分が一次全体 A のうちに入っているという排他的共通性質があるであろう。そのような各群において、すべてではないがその成員のいくつかは、そのどれか一つのすべての部分がある一つの一次部分のうちに入るようなものであろう。そうすると、そのそれぞれがそのすべての部分を一次部分 B のうちに入れているようなものは一つの群を形づくり、そこには、すべての部分が一次部分 B のうちに入っているという排他的共通性質があるであろう。そして以下無限に続く。

**244**　こうして結果は、基礎体系の成員であるすべての実体は第一の型の排他的共通性質をもつ群の成員であり、そのようなすべての実体は、一次全体を除いて、第二の型の排他的共通性質をもつ群の成員であり、そのようなすべての実体は、一次全体を除いて、第三の型の排他的共通性質をもつ少なくとも一つの群の成員であり、そのようなすべての実体は、一次全体と一次部分を除いて、第四の型の排他的共通性質をもつ少なくとも一つの群の成員である、ということである。そしてさらに、基礎体系の成員でないすべての実体は第五の型の排他的共通性質をもつ群の成員であり、そのうちのいくつかは第六の型の排他的共通性質をもつ一つ以上の群の成員である。そうすると、すべての実体は、その外延の言い直しであるもの以外の排他的共通性質がそのうちにある群の少なくとも一つの成員である。

　しかしこれらの排他的共通性質はすべて関係的性質である。そのそれぞれは何かに対してある関係に立つという性質である。排他的共通本源的性質の生起について何か言うことはできるであろうか。私はできないと思う。われわれは経験的に、ある群には本源的である排他的共通性質があることを知っている。ある実体は幸福であり、ある実体はそうでない。したがって幸福という排他的共通本源的性質をもつ実体の群がある。しかし私の見るかぎり、そのような性質の生起についてアプリオリに何かを決定することは不可能である。そしてとりわけ、すべての実体が排他的共通本源的性質をもつ群の少なくとも一つの成員である、とアプリオリに主張する理由は私には見当たらない。実体の本源的性質についてのわれわれのアプリオリな知識は、ここでも他のところと同じく、その本源的関係についての、したがってその関係的性質についてのわれわれの知識ほど先までわれわれを連れていかない。

**245**　しかし排他的共通性質の生起を――これらの性質が本源的であれそうでないにせよ――証明することによって、われわれは本当に本質的なことをなしたのである。存在するものについての知識の体系を築き上げることができるためには、そのうちに排他的共通本源的性質をもつ群が見いだされる必要はない。何らかの排他的共通性質をもつ群は必要であるが、それが本源的であるか関係的であるかはどちらでもよい。

　排他的共通性質をもつ群がなければ、すべての存在する実体にあてはまるもの以外には、実体についてのいかなる一般的な言明をなすことも不可能であろう。存在する実体についてある数の一般的命題をなすことは論理的には可能であろう。そのような命題のいくつかはすべての存在する実体にあてはまるからである。また特定の存在する実体についての命題をなすことにも論理的な不可能性はないであろう。それぞれが他のどの実体とも共有しない性質によって十分に記述されうるであろうからである。そしてさらに、アプリオリに知りうるような科学的命題に達することも論理的には可能であろう。たとえば、等辺は等角を含意することは、等辺の実体の群が存在しようとしまいと、見てとることができる。

〔原注〕これら三つの可能性は論理的なものにすぎない――つまり、そのような条件のもとでそのような知識をもつことに論理的な不可能性はない、ということである。心理学的な事実としては、思うに、その経験的経験の過程で、自分の知る実体のいくつかに属しながらすべてには属さない性質を見いだすことのできない存在者のうちに、そのような知識、あるいはいかなる知識も生じることは不可能であろう。

　しかし帰納に依存する科学的命題には達しえないであろう。どの科学においても帰納の基礎として、それらに共通で、すべての実体のうちに見いだされるのではない性質をもつ、いくつかの存在する実体の経験を必要とするからである。そしてアプリオリに達せられた科学的命題も、現在それらがもっているのと同じ存在するものへの関連性をもはやもたないであろう。命題の条件が近似的にでさえ実現されている実体の群を何も見いだせないであろうからである。

　たしかにわれわれは、排他的共通性質をそのうちにもつ実体の群があることを確信するのに、この章の議論も、他のいかなる哲学的議論も必要としない。われわれの各人は、そのようなどんな議論よりも短く確実な、自分自身の知覚からの議論によってこの結論に達することができる。私は赤の感覚与件である一つより多くの感覚与件を知覚したことがある。そして赤の感覚与件でない他の感覚与件を知覚したことがある。したがって、赤の感覚与件であるという性質をもつ実体が一つより多くあり、すべての存在する実体がその性質をもつわけではないことは明らかである。そしてこれだけで、排他的共通性質がそのうちにある群が見いだされうることを証明するのに十分である。

　しかしこのような議論は、すべての実体がそのような群に属することをわれわれに証明しえない。したがって、すべての実体にあてはまるもの以外にはいかなる一般的命題もあてはまらないような実体がある、ということはなお可能なままであろう。しかしこの章の議論は、すべての実体が排他的共通性質をもつ群の少なくとも一つに属し、したがってすべての実体が、それに属し、また他のある実体に属しながら、他のすべての実体には属さない性質を少なくとも一つもつ、ということをわれわれに示した。この結果は大きな関心と重要性をもつ。そしてそれは、われわれが確信できる排他的共通性質がすべて本源的でなく関係的であるとしても、重要で関心をひくものである。

　内部実体における第一の型の排他的共通性質の場合には、われわれは性質の型だけでなく性質そのものをアプリオリに決定することができた。そして外部実体における第一の型についても同様であった。しかし他の型は異なる。これらの型の性質は基礎体系のある特定の部分への関係から派生する。それらはそれらの部分が知られる場合にしか知りえない。さて、基礎体系のすべての部分の十分な記述は、アプリオリに知られる原理によって一次部分の十分な記述から帰結する。しかし一次部分の十分な記述をアプリオリに演繹できるしかたはない。それらは、もし知られるとすれば、経験的に知られねばならない。したがってある型の性質は経験的にしか知りえない。そしてすべての実体がそれらの型の排他的共通性質をもつ群の成員であることは示されていないが、一次全体を除くすべての内部実体についてはこのことが示された。

**246**　ある実体を知っているからといって、それがこれら六つの型の一つの排他的共通性質がそのうちにあるどの群に属するかを知ることができる、ということは帰結しない。これを知るためには、基礎体系のうちでのその実体の位置を、あるいはそれがその外にあるなら、その体系のうちでのその部分の位置を知らなければならない。そしてわれわれはこれを知らずにある実体について非常に多くのことを知っているかもしれない。とりわけ、その実体が属する排他的共通性質をもつ何らかの群を知っていながら、排他的共通性質がこれら六つの型のどれかに入るようなどの群にそれが属するかを知らないかもしれない。ケンブリッジのトリニティ・カレッジは、すでに見たように、学寮長の任命権がフェローにないケンブリッジのカレッジであるという排他的共通性質をそのうちにもつ群に属する。しかしわれわれはこれを、それが六つの型のどれかに入るどのような性質をもつかを知ることなしに知ることができる。

### 第28章　宇宙における秩序

**247**　第21章でわれわれは、その時点では宇宙が秩序づけられていると信じる理由はないという結論に達した。われわれは秩序づけられた宇宙を、三つの特性のうち少なくとも一つをもつものと定義した。第一は、部分が一般法則にしたがって互いを決定し合うことであった。これは因果的秩序と呼ばれた。第二は、その部分が、ただ一つの系列を形づくるような関係によって互いに結びついていることであった。これをわれわれは系列的秩序と呼んだ。

　第三をわれわれは分類の秩序と呼んだ。まず、全体の部分が分類体系を形づくると言えるのは、各部分に他の部分との関係で全体のうちの確定した位置を与えるような部分の中の部分の配置があり、しかもその配置によって形づくられる部分の各群が、群の外延の単なる言い直しであるもの以外の何らかの排他的共通性質をもつときである、と述べた。そして、全体が分類の秩序をもつと言えるのは、その部分が、群における排他的共通特性がそれをもつ部分にとって根本的な重要性をもつような本性の分類体系のうちに配置できるときである、と述べた。体系が分類を推し進める程度が大きければ大きいほど、秩序はより完全であろう。

〔原注〕そのような体系はもちろん体系のなかの各部分の排他的記述を与えなければならない。そうでなければそれらは同定できず、どの部分がどの特定の位置にあるかがわからないであろうからである。

　宇宙が系列的秩序をもつかどうかという問いは考察せずに、いまやわれわれは、それが他の二つの特性の両方をもつことを見ることができる。第25章で見たように、因果的決定は、ひょっとするとすべての実体のすべての性質には及ばないにせよ、すべての実体のある性質には及び、しかもそれによって決定されるすべての実体の十分な記述を与えるほどにまで及んでいたからである。

　そしてこれを保証するのと同じ決定的対応の関係が、宇宙が分類の秩序をもつことをも保証する。その関係によって、宇宙の部分は、根本的な重要性をもつ性質に基づく分類体系のうちに配置できるからである。そのような体系を基礎体系と呼んでよいであろう。

**248**　問題の体系は、宇宙をまず一次全体へと分け、次にそのそれぞれをその一次部分へと分け、そのそれぞれを第一階の二次部分へと分け、そのそれぞれを第二階の二次部分へと分け、以下無限に続くような体系である。

〔原注〕この体系の最初の段階は、宇宙が単一の一次全体であることが判明するならもちろん脱落するであろう。一次全体と一次部分とのあいだに、分化群という別の段階が来るべきだと思われるかもしれない。しかしこれらの群は重なり合いうる。たとえば B の分化群は BCD であり、E の分化群は CDF であるかもしれない。したがってこれらの群による区分は、各特定の段階での群分けにおいて、各部分が他のすべての部分と結びつけられるか分けられるかのどちらかであるような、ただ一つの確定した体系のうちに宇宙の部分を配置しないであろう。

　このようにして形づくられる群のそれぞれは、前章で見たように、群の外延の単なる言い直しではない排他的共通性質をそのうちにもつであろう。一次全体の群においては、その排他的共通性質は一次全体であるという性質であろう。一次全体 A のうちに入る一次部分の群においては、排他的共通性質は A のうちに入る一次部分であるという性質であろう。一次部分 B のうちに入る第一階の二次部分の群においては、排他的共通性質は一次部分 B のうちに入る第一階の二次部分であることであろう。B!C のうちに入る第二階の二次部分の群においては、排他的共通性質は第一階の二次部分である B!C のうちに入る第二階の二次部分であることであろう。そして他のすべてについても同様である。

　ここにわれわれは宇宙の内容のすべてを配置する体系をもつ。たしかにそれはすべての実体を成員として含むのではない。B と C が A の全体でない場合の、B と C から成る実体のような実体を成員として含まない。また B!C と C!D!E から成る実体のような実体も成員として含まない。しかし体系はそれらを成員として含まないけれども、それらの部分は成員として含む。

**249**　なぜこの体系が他の分類体系より根本的なものとみなされるべきなのか。第一に、宇宙のこの区分の体系は、そもそも宇宙があるという事実のうちに含まれている。宇宙は実体である。すべての実体は部分の部分へと無限に分割される。そしてこの無限系列のうちにさもなければ含まれるであろう矛盾を避ける唯一のしかたは、宇宙が（一つ以上の一次全体のうちに配置された）一次部分を含み、そのそれぞれの部分が他の一次部分およびその部分と決定的対応にある、ということである。そして一次部分とその部分の互いへのこの関係が、いまわれわれが考察している体系を与えるのだから、その体系は宇宙があるという事実のうちに含意されている。この体系に含意されている体系を除いて、この体系以外の体系がその事実のうちに含意されていることはありえないように思われる。そしてこれは、この体系を宇宙にとってとりわけ根本的なものとみなす資格をわれわれに与えるのに十分である。

　そして第二に、この体系と、それによって含意される他の体系とを除いて、宇宙全体に及ぶ分類体系があるかどうかは確かではない。宇宙の無限に多くの部分は、たしかに無限に多くのしかたで配置することができる。どの二つ以上もいっしょに群にでき、それらの群のどの二つ以上もまた群にでき、以下同様である。しかしそのような配置は、それによって形づくられる部分の各群がその外延の言い直しでない何らかの排他的共通性質をもつのでないかぎり、分類体系ではないであろう。そして私の見るかぎり、いま考察している配置と、それに含意されうるものとを除いて、どの配置がこの性質をもつかもわれわれは知らない。これがこの体系を根本的とみなす第二の理由を与える。

　第三に、われわれが記述した体系は、宇宙のなかのすべての部分を含むのではないにせよ、すでに見たように、すべての部分の部分を含み、したがってそれが含まないすべての部分の存在を含意し、宇宙の部分についてなされうるあらゆる配置（体系的であろうとなかろうと）のあらゆる区分に対して確定した関係をもつ。そしてこれは決定的対応に依存しないどの配置の体系についてもありえない。それは宇宙のすべての部分の部分を含む体系、すなわち無限に至る部分の部分を含む体系についてしかありえないからである。そしてすでに見たように、そのような体系は、決定的対応によって決定されていないかぎり存在しえない。

　これら三つの理由から、われわれはそのような体系を基礎体系とみなし、したがって宇宙のうちに秩序を生み出すものとみなすことができる。そしてそのような体系は、それによって生み出される秩序をより完全にする他の二つの特性をもつ。第一は、その区分が無限に続けられるのだから、それはその区分のどれのうちにも、体系によってさらに決定されえない内容をけっして残さない、ということである。第二は、どの区分を決定した原理も、その区分の下位区分を無限に決定するのと同じ原理――すなわち、同じ種類の決定的対応――である、ということである。

〔原注〕たとえば、人類を人種によって分類し、次に各人種の人々を性別によって分類し、それから同じ人種と性別の人々を年齢によって分類するような体系とは対照的である。

　前の章で見たように、われわれがこれまで進んだかぎりでは、それぞれが宇宙全体に及ぶ決定的対応の二つ以上の独立した体系がありうる、という可能性は排除されていなかった。第5部で導入される考察は、これが実際には事実でないと想定する十分な理由を与えるであろう。しかし、もしそれが事実であっても、宇宙はなお秩序づけられた宇宙であろう。それは、独立ではあるが両立しないのではない、いくつかの分類体系をもち、そのそれぞれが根本的に重要な性質に基づいており、したがってそのそれぞれが、根本的に重要な性質に基づかない分類体系や、そもそも分類体系でない配置に対して、基礎体系と呼べるであろう。

〔原注〕第228節。

**250**　もちろん宇宙の無限に多くの部分の配置は無限に多くある。それらの配置のうち基礎体系から演繹できないものは、分類体系であろうとなかろうと、基礎体系の配置から少なく、あるいは多く離れる程度に応じて、宇宙の根本的な本性を多く、あるいは少なく表現しているものとみなすことができる。

　第一に、基礎体系が分けない群を、その体系に何の変更も加えずに分ける区分がある。たとえば、B の分化群が C、D、E、F であるなら、B の第一階の二次部分は B!C、B!D、B!E、B!F であろう。これら四つの成員は基礎体系のうちで一つの群を形づくり、それと四つの成員それぞれの部分によって形づくられる四つの群とのあいだに、基礎体系は中間の群を与えないであろう。しかしたとえば B!C と B!D が、B!E と B!F によって共有されない排他的共通性質をもつ、ということがたまたまあるなら、二つの中間の群、すなわち B!C と B!D の群と B!E と B!F の群とがあり、それが補足的な体系的配置を与えるであろう。そして排他的共通性質がなかったとしても、これは、体系的でないにせよ、問題の部分の補足的な配置であろう。

　このような場合、配置は基礎体系を補足するが、それから離れるとは言えない。しかし第二に、基礎体系から実際に離れる配置がある。たとえば、B!C!D!E と C!F!G!D とを、何らかのより高い部分の部分の組のただ二つの成員としていっしょにするような配置がそうであろう。そのときこれら二つの部分は、どの二つの部分もありうるかぎり互いに近づけられ、ほかの何ものとも共有しない共通の全体をもつであろうが、基礎体系においては、一次全体より手前には共通の全体をもたず、そのそれぞれは他方よりもはるかに自分に近い実体をもつであろう。

　そうすると、このような配置は基礎体系から離れるであろう。そしてそれは、二つの体系において部分が異なって群分けされる場合の数に応じて、また二つの体系におけるそれらの相対的な位置の違いが大きいか小さいかに応じて、それから多く、あるいは少なく離れるであろう。

**251**　こうしてわれわれは理論的には、基礎体系以外のどの配置も宇宙の根本的な本性を表現している程度の試金石をもつ。それは基礎体系から少なく、あるいは多く離れるのに比例して、多く、あるいは少なくそうするであろうからである。しかしこれが実践的に重要になるのは、判定されるべき配置に含まれる実体の基礎体系のうちでの位置を決定できる場合だけであろう。

　そしてたとえ経験的に知っている実体の基礎体系のうちでの位置を決定できたとしても、われわれの経験的知識の題材を扱うためになす必要があるとわかる分類や区分において、基礎体系が大いに役立つであろう、ということは帰結しないであろう。われわれ自身の何らかの特別な必要に役立つ分類を求めているなら、それが役立たないかもしれないことは明らかである。われわれの必要が扱われるものの根本的な性質に対して単純で確定した関係をもたないなら、われわれの必要に合う分類は、それらの性質の観点からは些細で突飛なものであるかもしれないからである。たとえば、絵画のコレクションをその額縁の金箔の状態によって分類するのは、どんな一般的な立場からも些細で突飛であろう。しかしもし学芸員が額縁の金箔の張り替えのための補助金をどう使うかを決めなければならないなら、そのような分類こそ彼が必要とするものであろう。

　しかし、考慮すべきそのような特別な必要がなく、ただ経験的に知っていることを最もよく理解できるようなしかたで配置したいと望むだけのときでさえ、基礎体系がその分類に大いに役立つであろう、ということは帰結しない。たとえば、宇宙が単一の一次全体であり、その一次部分が物質的原子であったと想定しよう。その場合、ほかには何も存在しないのだから、われわれの一次全体の外のいかなる存在も知らないであろう。そしていかなる一次部分や二次部分の特定の本性についても何も知らないであろう。われわれはいかなる原子とも、いかなる原子のいかなる部分とも経験的に直知していないからである。われわれが経験的に知っているものはすべて、ただ一つのすべてを包む一次全体のうちの一次部分の群であろう。したがって、経験的に知っていることを配置するのに役立ちうる宇宙のなかの唯一の配置は、一次全体のうちの一次部分の配置であろう。そしてそのような配置は基礎体系のうちには見いだされえない。その体系は一次全体からその一次部分の組へと一歩で進むからである。

　たしかに、いずれにせよ一次部分が物質的原子であることはありそうにない――この問題は第5部で論じる。しかし、われわれの各人が経験的に知っている場のある部分において、各一次部分がその場のあまりにも小さな部分を占めるので、それが別々に知られえない、ということは十分ありうるし、その場合には同じ帰結が生じるであろう。

　もちろん、われわれが経験的に知っていることを理解するという目的にとって最善の配置が、単に基礎体系を補足するだけでなく、積極的にそれから離れるようなものでありうるかどうかは、さらなる問いである。しかしその可能性を否定する根拠は私には見当たらない。

**252**　次に別の点に移る。それは、われわれがこの語を用いてきた意味での宇宙の秩序にはかかわらないが、それと十分に近いので同じ章で扱うのが便利である。第21章で見たように、その時点では宇宙が秩序づけられていると信じる理由がないことに加えて、その時点では、われわれがあえて宇宙の木目と呼んだものを見いだせなかったもう一つの点があった。それは、どの実体についても、それが合成の統一と呼ばれるよりも顕現の統一あるいは有機的統一と呼ばれるほうが適切である、あるいはまた、顕現の統一と呼ばれるよりも合成の統一と呼ばれるほうが適切である、と考える理由がなかった、ということである。ある全体についてのわれわれの経験的知識は、部分を全体の顕現として語るよりも全体を部分から合成されたものとして語るほうがはるかに自然に思われるようなものであることをわれわれは見た。また他の場合には、顕現について語るのが合成について語るのと少なくとも同じくらい自然に思われた。しかし二つの類の場合のこの見かけの違いは欺くものかもしれないことをわれわれは見たし、ほかに決め手となるものは何もなかった。われわれは両方の表現がすべての実体について真であることを知っていた。実体の本性の全体が考慮に入れられたとき、一方の表現がその本性に他方より適切であると考える理由はなかった。

**253**　しかしいまやわれわれは異なる立場にある。一次部分と二次部分――すなわち一次全体を除く基礎体系のすべての成員――は、合成の統一よりも顕現の統一と呼ばれるほうが適切であることを見ることができる。というのも、それらのどれか一つのある十分な記述を取るなら、それはその部分の組の十分な記述を含意し、これらの部分のどれか一つの十分な記述はまたその部分の組の十分な記述を含意し、以下無限に続くことがわかるからである。そして全体から部分へのこの含意の連鎖は、各全体はその部分から合成されていると言うよりも、各全体はその部分のうちに顕現していると言うほうを適切にする。

　たしかに、部分の組の各成員の十分な記述もまた全体の十分な記述を決定するであろう。この事実が他方の事実と釣り合い、顕現の統一と合成の統一という表現はひとしく適切になる、と思われるかもしれない。しかし、部分から全体への含意の系列は、全体から部分への含意の系列から離れてそれ自体で妥当な系列ではない、ということを思い起こさなければならない。そのような系列は無限であろう。全体でもないような部分はないからである。そして第23章で見たように、そのような終わりのない系列は、全体から部分への含意の系列もまたあるのでないかぎり悪しきものであろう。全体から部分への系列については、それだけで取られても何の矛盾も含まず、対応する制限はない。したがってこの後者の含意の系列が二つのうちでより特徴的なものとして取られねばならず、基礎体系のうちの部分を顕現の統一として語るほうがより適切である。

　しかしそのような実体のいくつかの場合には、その部分の組の十分な記述を、包含することなしに含意するような全体の十分な記述があることを、われわれは経験的に知っている。たとえば、ある実体が、一八七〇年に標準的であった型のパントマイムの役者の一座である、ということを要素として含む十分な記述をもつかもしれない。そのような記述はその部分の組の十分な記述を含意するであろう。それはその一座が四人の役者を含み、それ以上は含まず、それらがそれぞれ道化、パンタローネ、アルルカン、コロンビーヌであることを含意するであろうからである。そして役者について、たとえば彼がそのような一座の道化である、と言うことは、その十分な記述であろう。一座はすでに十分に記述されており、そのような一座は道化をただ一人しか含まないであろうからである。こうして全体の十分な記述は、そのような型の一座は道化、パンタローネ、アルルカン、コロンビーヌを含み、しかもそれらだけを含む、という経験的にわれわれに知られた法則によって、その部分の組の十分な記述を含意するであろう。そうするとわれわれは、基礎体系の成員でないある実体の十分な記述がその部分の十分な記述を実際に含意することを知っており、他の多くの実体の場合にもこれが起こることは十分ありうるが、それがすべての実体について起こると想定する理由はない。

〔原注〕二つの実体が互いに部分的に重なり合うなら、それらがともに基礎体系の成員であることはないと確信できる。その成員はどれも互いに重なり合うことができないからである。さて、その十分な記述がその部分の十分な記述を含意するある実体は、互いに部分的に重なり合う。たとえば二つのパントマイムの一座は、他の成員は異なっていても、同じ道化をもつことができる。

**255**　こうして、基礎体系の成員でない実体については、二つの表現の形がひとしく適切であることも、合成の統一のほうが好ましいこともありうるが、すべてが基礎体系の成員である一次部分と二次部分については、どの場合にも顕現の統一のほうがより適切な表現であることは確かである。しかし基礎体系は、一次部分と二次部分のほかに一次全体を含む。これらについてはどちらかの表現の形がより適切であろうか。

　一見したところ、一次全体は顕現の統一と呼ばれるほうが適切であるように見えるかもしれない。その部分のすべての十分な記述がそのうちに含意されているような一次部分 B の十分な記述は、B を直接に分化させる他のすべての一次部分の十分な記述を与えるものでなければならないからである。たとえば B が C によって分化されていることを知ることから始めるからこそ、われわれはそれが部分 B!C をもつことを知るのである。そして B の決定項のこれらの十分な記述は、それらの決定項の十分な記述を含まなければならない。C が D によって分化されていることを知らなければ、B が部分 B!C!D をもつことを知らないであろう。したがってわれわれが必要とする B の十分な記述は、それを直接にか間接にか分化させるすべての実体の十分な記述を含まなければならない。これらの実体はすべて B と同じ一次全体のうちに見いだされ、その一次全体の十分な記述で、それらの十分な記述を含むようなものが見いだされうるであろう。こうして、全体の十分な記述はその一次部分の十分な記述に対して、一次部分の十分な記述がその部分の十分な記述に対して立つ関係――すなわち、部分の十分な記述の無限系列全体がそれに依存する、という関係――に立つ、と言われるかもしれない。そして一次部分が顕現の統一と呼ばれるほうが適切であるなら、一次全体についても同じであろうと思われるかもしれない。

　しかしこれは誤りである。たしかに、その部分のすべての十分な記述がそのうちに含意されているような B の十分な記述は、A の他の一次部分の十分な記述を含み、それは A の十分な記述のうちに含めることができるであろう。しかしこの A の十分な記述は、部分として一次部分の十分な記述を含むであろう。それは、A はしかじかの一次部分を含む一次全体であり、これらの一次部分のそれぞれはしかじかの一次部分をその分化群としてもつ、と述べるであろう。したがってそれは一次部分の十分な記述を包含するであろう。しかし一次部分の十分な記述は、その部分の十分な記述を、包含することなしに含意する。こうして一次全体はその部分に対して、一次部分がその部分に対して立つのと同じ関係には立たない。

　他方、一次部分のどんな十分な記述もその一次全体の十分な記述を含意するであろう。したがってそれらの相互関係の本性を最もよく表現する過程は、一次部分から一次全体へのものであってその逆ではなく、一次全体は顕現の統一よりも合成の統一と呼ばれるほうが適切であろう。

　宇宙そのものについても同じであろう。宇宙は一つの一次全体であるか、一つより多くの一次全体から成るかのどちらかである。もしそれが一次全体であるなら、それが合成の統一と呼ばれるほうが適切であることはすでに見た。もしそれがいくつかのそのような全体から成るなら、それらの全体が宇宙との決定的対応によって決定されることはありえないことは明らかである。一次全体の定義によって、そのうちの何ものもその外の何ものとも決定的対応にはないからである。そうすると宇宙は、一次全体がその一次部分から合成された統一と呼ばれるほうが適切であるのと同じ理由で、一次全体から合成された統一として語られるほうが適切であろう。

　もちろん、一次全体の十分な記述がその一次部分の十分な記述を含意し、あるいは宇宙の十分な記述が一次全体の十分な記述を含意することは、パントマイムの一座の十分な記述がその成員の十分な記述を含意したのと同じしかたで――すなわち決定的対応以外の何らかのしかたで――可能である。しかしこれが事実であると信じる理由はなく、もしそうであっても、パントマイムの一座の場合と同じく、それは二つの表現をひとしく適切にしうるだけで、顕現の統一を二つのうちでより適切なものにはしないであろう。

**256**　このすべての結果は、宇宙と一次全体は非常に実在的な統一ではあるが、一次部分は基礎体系のうちで、したがって存在のうちで唯一無二の意義をもつ位置を占める、ということであるように思われる。基礎体系のより低い階のすべての実体と、間接的には他のすべての実体とがそれによって決定される含意の無限系列は、それらから始まるのである。というのも、すでに見たように、どの一次部分 B の部分も、B 以外の何かを持ち込むことによってしか含意されえないが、持ち込まれねばならないのは、B を直接にか間接にか分化させる他の一次部分だけだからである。

　宇宙の真の説明は多元論か一元論か、とときに問われる。答えは、その両方である、でなければならない。宇宙は疑いなく統一であり、疑いなく部分をもつからである。しかしどちらの側面がより根本的かと問われるなら、答えは、多元論のほうがより根本的である、でなければならない。いま見たように、多数性である一次部分がこの唯一無二の意義をもつ位置を占めるからである。宇宙は一次部分から合成されていると言うほうが、それらのうちに顕現していると言うよりも、宇宙と一次部分との関係を――われわれがその関係をアプリオリに決定しうるかぎり――より適切に表現する。そしてこれは天秤を多元論の側に傾けたままにする。

### 第29章　宇宙における法則

**258**　日常生活においてわれわれが受け入れているような知識の構造が妥当であるためには、群の外延の単なる言い直しでない排他的共通性質が宇宙のうちに生じることが不可欠である。これがなければ、宇宙の部分をいかなるしかたでも分類することは不可能であろう。しかし、これは不可欠ではあるが十分ではない。そのような知識の構造が妥当であるためには、宇宙のうちに一般法則があり、それにしたがって宇宙のそのような排他的性質の一つが別の性質を、その決定が宇宙のうちで一度より多く生じるようなしかたで内在的に決定する、ということもまた不可欠である。そしてわれわれがそのような法則を知りうることも不可欠である。

〔原注〕そのような法則はしばしば、性質 X と Y の組み合わせが性質 Z を決定する、という形で表現される。しかし性質 X と Y とはあわせてただ一つの複合性質をなすので、この形は上に挙げた形に還元できる。

　この記述にあてはまらない他の法則もある。どの性質も他のどの性質を内在的に決定するという言明はどれも法則である。そして第一に、決定する性質が宇宙のうちにまったく生じず、したがって決定の関係もまた宇宙のうちに生じない法則がある。フェニックスであるという性質は、同じ実体が空間を占めるという性質をもつことを決定する。これは法則であるが、決定の関係は宇宙のうちに生じない。存在するいかなる実体もフェニックスではないからである。

　第二に、決定の関係が宇宙のうちにただ一度しか生じない法則がある。宇宙であるという性質は、同じ実体が無限分割可能性という性質をもつことを決定する、という法則がそうである。またさらに、もし宇宙についての一神論的な理論が正しいなら、神性という性質が同じ実体のうちの何か他の性質を決定する、という法則はこの類に入るであろう。

　第三に、結びつけられる性質が排他的性質でなく、すべての実体に属するような法則がある。実体であるという性質は、その実体が無限分割可能性という性質をもつことを決定する、という法則がそうである。

　われわれがここで考察している法則は、それを宇宙における法則と呼ぶことによって、これらの類の第一と第二から区別できるであろう。第一の類はそもそも宇宙にあてはまらない。第二の類のそれぞれは宇宙のうちにただ一つの例しかもたず、したがって宇宙の法則と言えるかもしれないが、宇宙における法則と言うのは適切ではないであろう。第三の類からの区別は、われわれが考察している法則を宇宙における排他的法則と呼ぶことによってなされうる。それらが扱う性質は排他的性質だからである。

**259**　そのような法則をアプリオリに知ることは可能であろうか。それらを完全にアプリオリに知ることは可能でない。われわれはそもそも何かが存在することをアプリオリには知らず、したがってどの法則が存在するものにあてはまるかをアプリオリに知ることはできないからである。しかし、何かが存在するなら、そのようないくつかの法則が妥当であることをアプリオリに知ることは可能である。何かが存在するなら、決定的対応の体系がそれにあてはまることをわれわれはアプリオリに知っている。そしてわれわれは、二つの実体 G と H が、それぞれ決定的対応によって決定されているという性質をもち、また、それ自身も決定的対応によって決定されている同じ実体 K の部分であるという性質をもつなら、G と H はそれぞれ同じ決定的対応の関係によって決定されているという性質をもつであろう、ということをアプリオリに知っている。第227節で見たように、後続する部分の組の無限系列の決定において、最初の段階より後のどの段階にも新しい種類の決定的対応を導入することはできないからである。したがって G と H は両方とも、K を決定するその決定的対応の関係によって決定されていなければならない。さて、これは宇宙における法則である。宇宙のうちには決定的対応によって決定されている実体が一つより多くあり、そのどれもが決定的対応によって決定されている部分をもつであろうからである。そしてそれは宇宙における排他的法則である。G と H の位置にあるのはすべての実体ではないからである。たとえば一次全体、一次部分、第一階の二次部分はけっしてその位置にありえない。

〔原注〕たいていの場合、決定的対応によって決定されている実体の最も高い階は第一階の二次部分であり、したがって G と H は第二階、あるいはそれより低いどの階の部分でもありうる。しかしある場合には、第201節で指摘したように、決定的対応によって決定されている実体の最も高い階は第一階より低い何らかの階の二次部分でありうる。

**260**　しかし日常の知識の一見したところの体系を正当化するためには、これ以上のものが必要であろう。その体系は、それらが主張するある性質による別の性質の内在的決定が、いまのところわれわれの見るかぎりアプリオリにはけっして知りえないような法則の妥当性を含むからである。帰納的科学の法則はすべてこの本性のものである。われわれはそれらが真であると考える十分な理由をもっている、あるいはもっていると主張するが、それらはアプリオリには知りえない。それらを信じるわれわれの唯一の根拠は、それら（あるいはそれらがそこから演繹されるより究極的な法則）を非常に多くの場合に検証したので、それらがすべての場合に妥当であると信じることが正当化される、ということである。

　純粋数学を除く科学の全体は、このような法則の妥当性に依存している。そして生活の営みの全体が基づいているのも、このような法則の妥当性の上である。もしそれらが妥当でないなら、石よりもパンを口に入れ、火よりも水に手を入れ、虎よりも猫にすすんで近づく理由はないであろう。

　そうすると一見したところ、宇宙のうちには、われわれがアプリオリには知らない排他的法則がある。しかしこれが真であると主張する哲学的な正当化がわれわれにはあるであろうか。つまり、宇宙があるのだから、そのうちにはその本性がアプリオリには知られない排他的法則がある、ということをアプリオリに示すことは可能であろうか。

**261**　宇宙があるのだから、その宇宙の部分は決定的対応によって結びつけられていなければならないことを、われわれは見た。さて決定的対応は、どの場合にも、宇宙のある特定の部分を他のある特定の部分と結びつけ、どの特定の部分がどの他の部分と結びつけられているかはアプリオリにはわからない。さらに、どの場合にも、二つの部分を結びつけるある特定の決定的対応の関係がなければならない。そして上で（第226節）見たように、この特定の関係が何であるかも、それがどの場合にも同じ関係であるかどうかさえも、アプリオリにはわからない。

　そしてこのことが、アプリオリには知られない法則が宇宙のうちにあると主張することを正当化する。第259節の結果から、実体 C との決定的対応によって決定され、したがって B!C と記述されうるどの実体 K を取っても、この場合の特定の決定的対応の関係が X であるなら、K の部分であるという性質と、C の部分に対して関係 X に立つという性質とを結びつける法則があるであろう、ということが帰結するからである。

　たとえば、C が K を決定する決定的対応の関係が、被決定項による決定項の知覚であると想定しよう。そうすると、K の部分であるという性質をもつものは何であれ、C の部分の知覚であるという性質ももつ、という法則が得られるであろう。あるいは、決定的対応の関係が正か負かに関する類似の関係であるなら、K の部分であるという性質をもつものは何であれ、正か負かに関して C の部分に類似するという性質ももつ、という法則が得られるであろう。

　このような法則は宇宙における排他的法則である。K の部分であることは存在するものの性質であり、それが含む性質もそうである。それらはどちらも排他的性質である。そのどちらもすべての実体によってもたれるのではないからである。そして一方による他方の決定は宇宙のうちで一度より多く生じる。K は一つより多くの部分を――実際、無限に多くの部分を――もつからである。

　そして、宇宙が存在するとすれば、このような法則が真でなければならないことはアプリオリに知っているが、その法則が何であるかはアプリオリにはわからない。どの特定の決定する部分がどの特定の決定される部分を決定するかも、どの特定の決定的対応の関係がそれらのあいだに成り立つかも、アプリオリには知りえないからである。

　同様にして、H が、D との対応によって決定される C の部分との対応によって決定される K の部分であるなら――すなわち、H が B!C!D と記述されうるなら――そして B!C!D と C!D とのあいだの決定的対応の関係が知覚であるなら、H のすべての部分は C!D の部分の知覚であろう、と確信してよい。そして K のどの階のすべての部分についても同様である。

**262**　しかし、H のすべての部分が、D についての C の知覚の部分の知覚であろう、と言ってはならない。すでに見たように、C と B!C とのあいだに成り立つ決定的対応の関係が、C と C!D とのあいだに成り立つそれと異なり、前者が知覚で後者が何か別の関係であることは可能だからである。その場合、C!D の部分の知覚が、B についての C の知覚の部分の知覚であろうとは確信できない。

　しかし、第5部で信じる理由を見いだすように、宇宙のうちに生じる決定的対応の種類はただ一つであり、この関係が知覚であるということが事実であるなら、この反論はもはや成り立たず、H のすべての部分は D についての C の知覚の部分の知覚であり、D についての C の知覚のこの部分は D の部分の知覚であろう、と結論できるであろう。

　そしてまた、宇宙のうちに決定的対応の種類がただ一つしかないという想定の上では、われわれの結論を一次部分の部分にまで拡張できる。たとえば決定的対応の関係が知覚であるなら、C と D から成る決定群をもつどの一次部分 B の部分も、C と D の知覚、および C と D の部分の知覚であろう、という法則があるであろう。そしてこの型のどの特定の法則が宇宙における法則であるかはアプリオリには知りえないであろう。宇宙のうちの決定的対応の種類が何であるかもアプリオリには知りえず、どの特定の一次部分の分化群が何であるかもアプリオリには知りえないであろうからである。

**263**　しかし、宇宙のうちに決定的対応の種類がただ一つしかないという想定なしにでさえ、宇宙における法則の範囲は非常に広いことをわれわれは見いだした。たしかに、存在するすべての実体のすべての性質が宇宙における排他的法則によって決定されている、という結論には達していない。しかし、決定的対応によって決定された実体の部分をなすすべての実体において、何らかの性質がそのような法則によって決定されていることは見いだした。そしてそのような実体は、宇宙の実体的内容の全体を無限回含んでいる。

　そしてこれらの実体のそれぞれの場合に、これらの法則による決定が及ぶ程度は非常に大きい。それがそのそれぞれのすべての性質を決定することはわからないけれども、それがそのそれぞれを、その排他的記述――それが言及する一次部分の十分な記述の助けを借りて十分な記述となるような記述――を与えるのに十分なだけ決定することはわかっているからである。こうして法則は、これらの実体のそれぞれの性質について、それを他のすべての実体から区別するのに十分なだけのことを決定する。

　そしてこれらの法則は、すでに見たように、アプリオリには知りえない。そのそれぞれが、決定的対応の体系と、ある事実――宇宙があること、それがたとえば C との決定的対応によって決定された実体 K を含むこと、そしてこの場合の決定的対応の関係が知覚であること――とをあわせたものから演繹できることは証明されている。さて決定的対応の体系は、すでに見たように、アプリオリに知りうる法則であり、他方問題の事実はアプリオリには知りえないが、法則ではない。しかし二つの要素の組み合わせは、法則であってアプリオリには知りえない何かを与える。

　この章のはじめに述べたように、日常生活において受け入れている知識の構造が妥当であるためには、宇宙のうちに排他的法則があり、われわれがそのような法則を知りうること、しかもアプリオリには知らない場合にそのような法則を知りうることが必要である。いまやわれわれは、アプリオリには知りえないような型の排他的法則が宇宙のうちにあることを見た。この結果は、われわれが事実として、アプリオリに知ることなしにそのようないくつかの法則を知っている、というわれわれの信念の信憑性にどう影響するであろうか。

**264**　アプリオリに達せられない法則は、帰納によってか、帰納によって達せられた何か他の結果からの演繹によってしか達せられえない。さて、どの帰納も、X1、X2、X3 等々が Z1、Z2、Z3 等々に対して関係 Y にあることが見いだされた（ここで X と Z は性質であり、X1、Z1 等々はそれらの性質の異なる生起である）のだから、X のどの生起も、まだそれに立つことが観察されていないとしても、Z のある生起に対して関係 Y に立つ、という形に置くことができる。

　「青酸を飲むことは死を決定する」というような法則の場合、これが事実であることは明らかである。X は青酸を飲むという性質、Z は死んでいるという性質、Y は Z が同じ身体の性質として X の直後に続くという関係である。

　あるいはまた、金の重さはその体積に比例するという法則を取ろう。ここで X は金であるという性質である。Z は、互いにある確定した比率――何立方インチに対して何ポンド――にある体積と重さをもつという複雑性質である。Y は同じ時に同じ実体に属するという関係である。金のさまざまな塊 X1、X2 等々において、Z がつねに同じ時に同じ実体の性質であることを見いだすとき、われわれは Z がつねに X に対してその関係において見いだされると結論する。すなわち、重さは体積に対してある確定した比率にあると結論する――そこからもちろん、それが体積に対して何らかの確定した比率にある、というより広い命題が帰結する。

　またさらに、水の温度の変化はその体積の変化を決定し、温度の変化の大きさがその体積の変化の大きさを決定する、という法則を取ろう。ここで X は温度を変化させている水であるという性質である。そのような温度の変化は量的であるから、そのような変化はすべて確定した大きさをもたねばならないが、すべての大きさの変化がひとしく X の例である。Y は同じ時に同じ実体の性質であるという関係である。Z は、その変化の大きさが、Y によってそれに関係づけられている X のその場合における変化の大きさに対してある確定した比率に立つようなしかたで体積を変化させている水であるという性質である。性質 X が生じるさまざまな場合に、性質 Z がこの関係においてそれに立つことを見いだすとき、われわれは、X が見いだされるときはいつでも Z がこの関係においてそれに立つであろう――すなわち、水の温度のすべての変化はその体積の変化を決定し、後者の変化の大きさは前者の変化の大きさによって決定される――と結論する。

　後の二つのような場合には、帰納がわれわれの定めた型に合致していることは、量的要素を含まない青酸の場合ほど明白ではない。したがって、量を含む法則はその型に合致しない、とときに考えられてきた。しかしこれは誤りである。いま見たように、量的法則はこの型に還元できるからである。こうしてわれわれは、すべての帰納は、ある場合に X の生起が観察によって Z の生起に対して関係 Y に立つことが見いだされたという根拠で、X のすべての生起が Z のある生起に対して関係 Y に立つ、と結論する、と主張する資格がある。（もちろん、Z の不在が観察されたような X の生起が観察されていないことも推論の本質的な条件であろう。）

**265**　どのような条件のもとで、そのような根拠からそのような結論に達することが正当化されるであろうか。まず、Z が X によって内在的に決定されていると考える資格がないかぎり、X のすべての生起が Z の生起を伴うと考える資格はないことは明らかである。何らかのより広い帰納に基づいて、X が Z を内在的に決定しないと信じる十分な理由があるなら、X が Z を伴う場合がいくらあっても、他の場合に X が Z を伴うと主張することを正当化するとは考えられないであろうからである。五港長官が就任した日に毎回例外的な強さの磁気嵐があった、ということがたとえ事実であったとしても、分別のある人は誰も次の長官の就任の際にそのような嵐が起こりそうだとは期待しないであろう。非常に広い経験が、このような特性が内在的決定によって互いに関係していないことをわれわれに確信させているからである。

　さて帰納は、それだけで、アプリオリに達せられたいかなる結果の助けもなしに、ある一つの性質が別の性質を内在的に決定すると信じる十分な理由をわれわれに与えうるであろうか。私にはできるとは思われない。X の生起を百の場合について知っており、そのそれぞれが Z を伴うことを観察によって知っていると想定しよう。これはそれだけで、X が Z を内在的に決定しないという想定を排除するであろうか。

　X が Z を内在的に決定しないなら、観察された場合のそれぞれにおける X と Z の結びつきは単に偶然的と呼んでよいであろう。ある特定の場合に X と Z の結びつきが偶然的であると言うことによって、私は、この特定の場合に X が Z を伴うべき理由がない、という意味で言っているのではなく、X がそれとして、それが生じるところではどこでも Z を伴うべき理由がない、という意味で言っているのである。イングランド王であったチャールズ一世が斬首されるべきであり、同じくイングランド王であったチャールズ二世が斬首されるべきでないことを内在的に決定する事情があったかもしれない。しかしチャールズ二世が斬首されなかったという事実は、イングランド王であることと斬首されることとの結びつきが、それが実際に生じるどの場合にも偶然的であることを示している。

　そうすると、X と Z の結びつきが偶然的であるなら、百の場合のそれぞれにおける X の現前は、その場合に Z が生じることも生じないことも可能なままにしておく。これは非常に多くの可能な組み合わせ――その数は二の百乗――を与える。さてこれらの組み合わせのうち、X の百の場合のそれぞれが Z を伴うものは、他のどの一つよりもありそうでないわけではない――もちろん他のすべてをあわせたものよりは途方もなくありそうでないが。そうすると、もし一方の性質による他方の性質の内在的決定がないなら、これらの組み合わせの一つが生じなければならず、それは偶然的である。そしてもしこの仮説が真であるなら、Z がすべての場合に見いだされる組み合わせが生じることは他のどれよりもありそうでないわけではないのだから、その生起がどうしてこの仮説が真であることをありそうでないものにしうるであろうか。

　この特定の組み合わせは、偶然的に存在しうるけれども、X が Z を内在的に決定するなら存在するであろうし、X が Z を内在的に決定することのほうが、非常に多くの可能な偶然的な組み合わせのうちから、内在的決定によって生み出されるのと同じ結果を生み出すであろうまさにその一つが生じることよりもありそうだ、と論じることはできるであろうか。しかしそのような議論は、宇宙のうちでの内在的決定の生起について前もって何かを知っているのでないかぎり、妥当ではないであろう。これを知らないかぎり、内在的決定と偶然的な結びつきとの相対的な確からしさを判断する手段をわれわれはもたないであろうからである。われわれの知るかぎり、内在的決定はまったくないかもしれない。そしてもしそのような決定が少しでもあるかどうか知らないなら、ある特定の場合に内在的決定と偶然的な結びつきとの相対的な確からしさを見積もることは不可能であろう。

**266**　こうして、何らかの帰納を妥当なものとして受け入れることができる前に、宇宙のうちでの内在的決定の生起について何かを知らなければならないように見える。この結果は、どの二つの性質の結びつきが観察された事例の数によっても影響されないであろう。また、帰納が単純枚挙に基づく代わりに、もし帰納がそもそも妥当であるなら帰納をより確実にするような方法のどれかによって強められたとしても、違いはないであろう。結果が偶然的に生じる可能性と、このことと内在的決定との相対的な確からしさを判断することの不可能性とは依然として残るであろうからである。

　また、帰納が実際にうまくいくことがわかるからといって、帰納を信頼する資格がわれわれにあるわけでもないであろう。もしそうするなら、観察によって検証されていない場合の帰納を、他の場合になされた帰納が観察によって検証されてきたという理由で信じることになろう。いくつかの帰納の正しさから他の帰納の正しさへとこのように論じることは、それ自体帰納の過程であり、帰納一般の擁護として用いられるなら悪循環を含むであろう。

　したがってわれわれは、帰納なしに、ある場合には存在するものの排他的性質が別の性質を、その決定が宇宙のうちで一度より多く生じるようなしかたで実際に内在的に決定している、ということを知りうるのでなければならない。これがなければ、われわれは帰納の基礎をもたないであろう。これがあっても帰納の基礎をもつかどうかは、のちに考察する。

**267**　たしかに、ある類の場合には、そのような内在的決定が実際に起こることを帰納なしに確信するために、決定的対応の理論を待つ必要はない。緑である、あるいは緑に見えるという性質は、空間的である、あるいは空間的に見えるという性質を内在的に決定する、ということをわれわれはアプリオリに知っている。これは経験を必要とせず、語の意味が知られるやいなや明白である。そして私は、帰納によってではなく観察によって、緑である、あるいは緑に見えるという性質が宇宙のうちで一度より多く実際に生じることを知っている。痛みの感じであるという性質と、ある強さをもつという性質についても同様であり、他の多くの性質についても同様である。

　しかしこのような場合はわれわれの助けにならないであろう。それらについてわれわれが内在的決定があることをアプリオリに知っているのは、内在的決定が何であるかをアプリオリに知っているからにすぎない。さて、帰納によって内在的決定を証明しようとするとき、われわれはそのような内在的決定があることをアプリオリには知らない――もし知っていたなら、それを帰納によって証明しようとするのは余計であろう。したがってアプリオリに知られる内在的決定は、われわれの帰納を正当化するのに必要とされるようなものではけっしてありえない。

　また、ある内在的決定――アプリオリに知られるもの――が生じるのだから、他の内在的決定――アプリオリに知られないもの――も同じく生じるであろう、と論じることもできない。これはそれ自体帰納であり、もしすべての帰納の妥当性をそれに基づかせるなら悪循環になるであろうからである。

　そしてたとえ悪循環がないとしても、アプリオリに知られる内在的決定からアプリオリに知られない他の内在的決定への議論は、二つの類の場合のあいだの大きな違いのために非常に不安定であろう。第一の場合には、決定は二つの性質の意味から明白である。第二の場合には、法則そのものについてのわれわれの知識が経験に依存しているだけでなく、経験を離れては、法則が――もし法則があるとして――何であろうかについていかなる確からしさも定めることができない。経験を離れては、チャールズ一世の首を切ることが彼を殺すであろうと想定する理由はない。そしてそれがオリヴァー・クロムウェルやジョージ・ワシントンを殺さないであろうと想定する理由もない。経験を離れては、手を動かそうという私の意志が私の手を動かし、私の足を動かしたり北京を破壊したりはしないであろう、と想定する理由はない。一種類の内在的決定の生起から、これほど重要な特徴においてそれと異なる別の種類へと論じることは、信念にごくわずかな根拠しか与えないであろう。

**268**　したがって帰納の妥当性のためには、帰納の助けなしに、ある場合には存在するものの排他的性質が別の性質を、その決定が宇宙のうちで一度より多く生じ、しかもその決定の本性がアプリオリには知りえないようなしかたで実際に内在的に決定している、ということを知りうることが必要である。そしてこのことを、この章の前半で達した結果の帰結として主張する資格がわれわれにはある。存在するものの排他的性質が、問題の決定がアプリオリに知られえない場合に、他の排他的性質を実際に内在的に決定していることをわれわれは見いだしたからである。そしてこの内在的決定は宇宙全体を通じて非常に広く広がっていることを見いだした。決定的対応によって決定された実体の部分であるすべての実体において何らかの性質がそのように決定されており、したがってそのような性質が生じる実体は宇宙の実体的内容の全体を無限回含み、どの実体もこのしかたで決定された部分をもつことを見いだした。さらに、このように内在的に決定される性質は、どの場合にも、それをもつ実体の十分な記述を与えるのに十分であることを見いだした。

　したがってわれわれは、帰納にわれわれの結論を基づかせることなく、帰納が発見すると主張するような内在的決定が宇宙のうちに多く――実際、無限に多く――実際に生じる、と結論する資格がある。こうしてわれわれは、第265節で述べた帰納の妥当性に対する反論を取り除いた。その反論が基づいていた可能性、すなわち、内在的決定そのものがアプリオリに明白である場合を除いて、ある性質による別の性質の内在的決定はないかもしれない、という可能性を排除したからである。

**269**　しかし帰納の妥当性に対しては、いま論じたものといくらか似た本性の他の二つの反論があり、現在展開されているかぎりでのわれわれの決定的対応の理論は、そのどちらについても役に立たないであろう。第一に、宇宙全体を通じて内在的決定があり、帰納は内在的決定を主張することを認めるとしても、帰納によって達せられると主張される内在的決定が、存在することが証明された決定的対応による内在的決定のどれかであるか、それらから帰結するか、と考えるどんな理由がわれわれにあるであろうか。そしてもしそうでないなら、帰納によって達せられた結果は、決定的対応の確立から何の利益も引き出しえず、以前と同じ立場にある。

　一見したところ、実際、われわれが正当化しようとしている、帰納によってふつう達せられる結論は、決定的対応によって決定されることはおよそありえないように思われるかもしれない。科学においてであれ日常生活においてであれ、帰納によって主張される性質のあいだの関係は決定的対応の関係ではないからである。またそれらが結びつけると考えられる性質も、のちに見るように決定的対応によって結びつけられうると信じる理由のあるようなものではない。

　しかし、第5部と第6部で経験的な考察を導入するとき、科学と日常生活で扱われる性質とそのあいだの関係とは、決定的対応の体系を形づくる性質とそのあいだの関係とをその実在とする見かけであるかもしれない、と示すことが可能かもしれない。そして見かけと実在とのあいだの関係は、実在における法則の妥当性が見かけにおける法則の妥当性を含むようなものである、と示すことが可能かもしれない。

　しかしもしこれが、そのような解決が可能であることの証明以上に進まないなら、それは十分ではないであろう。その場合、帰納において扱われる性質とその関係とが、決定的対応の体系を形づくる性質とその関係との見かけでない、ということもまた可能であろうからである。そしてその場合には、決定的対応の確立はわれわれの助けにならないであろう。

　X が Z とともに百回見いだされ、したがってそれが偶然的に起こる見込みが二の百乗分の一にすぎないとき、それは偶然的に起こったのではなく、いまわれわれが存在することを知っている内在的決定の一つによるほうがはるかにありそうだ、と言われるかもしれない。しかし私には、それがこれらの内在的決定の一つによる見込みを、それが偶然による――疑いなく途方もなく小さい――見込みと確定的に比較できるように見積もることがどうして可能なのかわからない。前者が後者よりありそうかどうかという問いは、そのような内在的決定がそもそもあるかどうかわからなかった第265節の問いよりは確かに確定的である。そして肯定的な答えはいまや未確定の程度だけよりありそうになっている。否定的な答えを含むであろう一つの選択肢――アプリオリに明白なものを除いて内在的決定はまったくない、という選択肢――を排除したからである。しかし私には、それが決定的対応による内在的決定によるという見込みが、どうして、他のある見込みよりも――後者がどれほど小さくても――確定的に大きいと宣言できるほど確定的にされうるのかわからない。

**270**　そしてもしこの反論が克服されたとしても、なお第三の反論があるであろう。百の場合のすべてで X が Z とともに見いだされたという事実に、X は何かを内在的に決定する性質であり、Z は何かによって内在的に決定される性質である、という確実性を付け加えることができたと想定しよう――そのとき、X が Z を内在的に決定する、あるいは Z を内在的に決定する複合性質の何らかの部分である、という結論の基礎をわれわれはもつであろうか。私はもつとは思わない。X は、われわれが観察していなかった W を内在的に決定し、Z は、われわれが観察していなかった Y によって内在的に決定され、われわれが観察した百の場合における X と Y の結びつきは純粋に偶然的であった、ということは可能なままであろう。たしかにこの最後のものの見込みは二の百乗分の一にすぎない。しかし他方、本当の被決定項と決定項とが何らかの理由でわれわれの観察に近づきえない、という可能性がある。そして私には、この可能性が現実でない見込みが、他のある見込みよりも――後者がどれほど小さくても――確定的に大きいと宣言できるほど確定的にされうるとは思われない。

**271**　こうして、帰納の哲学的基礎はまだ見いだされていないように思われる。われわれが考察した三つの反論のうち、第一のものは、すでに見たように、決定的対応の確立によって取り除かれる。第二のものは、ひょっとすると決定的対応の理論の展開によって取り除かれうるかもしれない。しかし第三のものは決定的対応によってはまったく取り除かれえないであろう。

　またそれが他のいかなるしかたで取り除かれうると期待する理由もあまりないように思われる。帰納の助けとして、哲学が、すべての性質が他の性質を内在的に決定し、他の性質によって内在的に決定されていることを示す以上に進むことがどうしてできるのか、見当がつかないからである。そして、たとえ哲学がこれをなしえたとしても――まだそうしてはいないが――それは帰納の哲学的基礎を与えることはできないであろうことを、われわれは見た。

　しかしこの結論をどれほど全面的に受け入れようとも、われわれは皆、帰納の妥当性を受け入れ続けるであろう。他の選択肢となる仮説が偽である見込みが二の百乗対一以上であることを証明することはできない。しかしわれわれはそれをこれよりはるかに大きいとみなさずにはいられない。したがって、それらの仮説の一つを受け入れるか、百の場合における X と Z の随伴は偶然的ではありえないと信じるかのどちらかを選ばねばならないとき、われわれは例外なく後者を受け入れる。もちろん X がそれだけで Z を内在的に決定すると主張するのではない――何か他の性質 V の随伴が必要かもしれない。しかし X は、それだけで Z を内在的に決定するか、Z を内在的に決定する性質の群の成員であるかのどちらかだと、ためらうことなく結論する。われわれの例のように性質が百回いっしょに見いだされたならそうするであろう。そしてもちろん、鉛でできているという性質と水に沈むという性質との随伴や、斬首されるという性質と死んでいるという性質との随伴の場合のように、それらが百回よりはるかに多くいっしょに見いだされた場合もしばしばある。それらの性質が、ある特定の年に聖母受胎告知祭であることと雨であることとがいっしょになりうるのと同じしかたでのみいっしょになる、と想定することは、退けずにはいられないと感じられる結論である。

　これは、われわれのそれぞれに自分自身と自分の利害とを宇宙のなかで実際より重要なものとみなさせがちな衝動や、友人についてはあらゆる善を、敵についてはあらゆる悪を信じさせがちなあの別の衝動に似た、盲目で理不尽な心理的衝動によるのであろうか。それとも、確からしさは実際にわれわれがそう判断しがちなとおりであり、数学的な比率を割り当てることはできないけれども、われわれは実際にそれがそうであると見ているのであろうか。後者が可能であることを否定するのは軽率かもしれない。しかしそれが実際に事実であると主張するのははるかに軽率であろう。そしてそうである以上、帰納の哲学的正当化はまだ見いだされていない、というわれわれの結論を堅持しなければならない。

### 第30章　一次部分の分化

**272**　この部でわれわれはこれまで、決定的対応の体系のなかの二次部分が一次部分との対応によってどのようにして十分に記述されうるか、そしてそれがこれを許す本性をもつことからどのような帰結が生じるかを考察してきた。次に、一次部分そのものが互いにどのようにして識別されうるかを考察しなければならない。何らかのしかたでそれらは識別されなければならない。すでに見たように、すべての実体は、その実体だけにあてはまる十分な記述によって、他のすべての実体から識別されなければならないからである。さらに、二次部分は、一次部分がそれ自身識別されていないかぎり、一次部分との決定的対応によって十分に記述されることはできないであろう。

**273**　第一に、二つの一次部分は、その分化群が異なり、その結果その二次部分が異なる一次部分に対応している、という事実によって互いに区別されうるであろう。たとえば B の分化群が E と F であり、したがってその第一階の二次部分が B!E と B!F であり、C の分化群が G と H であり、したがってその第一階の二次部分が C!G と C!H であるなら、B と C は互いに区別されうるであろう。どの部分の組をもつことも、どの全体の性質でもあり、この性質は B と C とで異なるであろうからである。

〔原注〕群が共通の成員をまったくもたない必要はないであろう。どの二つの群もそのすべての成員を共通にもたなければ十分であろう。

　どの二つの一次部分も同じ分化群をもたない、と考える理由はわれわれにはない――実際、すべての一次部分が同じ分化群をもつという可能性も排除していない。しかし他方、どの二つの一次部分も同じ分化群をもたないことは可能である。

　ある一次部分がこのしかたでのみ互いに識別されることは可能である。しかしすべての一次部分がその分化群の違いによってのみ識別されることは不可能である。これは悪循環か悪しき無限系列かに導くであろうからである。

　B と C とが、一方が E および F と決定的対応をもち、他方が G および H と決定的対応をもつという事実によって識別されるべきなら、これは E、F、G、H の識別を前提とする。E と F が G と H から識別されていなければ、B と C をそれらとのそれぞれの対応によって識別することは不可能であろうからである。

　さて、一次部分を識別する他のしかたがないなら、E、F、G、H は、一次部分のそれらの分化群の違いによってのみ識別され、それらの群の成員はまたそれら自身の分化群の違いによってのみ識別され、以下同様であろう。そしてこれはつねに悪循環か悪しき無限系列かを含むであろう。系列がそれ自身に戻ってきて、B が、B への関係によってしか識別できない項への関係によってしか C から識別できないなら、明らかに悪循環がある。その場合、B は、B の識別が前もって与えられている場合にしか起こりえない過程によってしか識別できないからである。他方、系列がけっしてそれ自身に戻ってこないなら、それは悪しき無限系列である。B の識別は E の識別に依存し、それは K の識別に依存し、以下同様であろうからである。つまり B はこの系列の最後の項なしには識別されえないであろう。そして系列は最後の項をもたないのだから、それはまったく識別されえないであろう。

　こうしてこれはすべての一次部分を識別する唯一のしかたではありえない。しかし上で述べたように、これがある一次部分を識別する唯一のしかたであることは可能なままである。もし B と C がその分化群によって識別され、次に E、F、G、H が、宇宙のなかの他のいかなる実体ももたないような性質あるいは性質の組み合わせをもつことによって識別されるなら、悪循環も無限系列もないであろう。そのとき B と C は十分な記述をもつであろうからである。E と F の十分な記述をそれぞれ X と Y で表すなら、B は、その分化群が十分な記述 X をもつ実体と十分な記述 Y をもつ実体とから成る唯一の一次部分、と記述できる。そしてこれは B の排他的記述であるだけでなく、その十分な記述でもあろう。

**274**　そうすると、一次部分が互いに識別されうる何か他のしかたがなければならない。そしてほかにもいくつかのしかたがある。それらが識別されうる第二のしかたは、それらが他の実体に対して立つ関係――いま論じた、これらの実体をその分化群の成員としてもつという関係以外のもの――によるであろう。B は、E に対して関係 Y に、F に対して関係 Z に立つ唯一の実体であるかもしれない。

　一次部分がそれへの関係によってこのように識別される実体は、一次部分であっても、二次部分であっても、そもそも基礎体系の成員でない実体であってもよいであろう。もちろん、すべての一次部分が他の一次部分へのこの種の関係によってのみ識別されることは不可能であろう。これはふたたび悪循環か悪しき無限系列かを含むであろうからである。しかしそのいくつかはこのしかたでのみ識別されるかもしれない。そしてすべての一次部分が一次部分でない実体への関係によって識別されることも可能であろう。しかしその場合には、問題の実体が、それらが関係している一次部分に依存しないような何らかのしかたで識別されていることが必要であろう。

〔原注〕基礎体系の成員でないものは、すでに見たように、基礎体系の成員である部分から成るであろう。

**275**　第三の可能性は、一次部分のすべてあるいはいくつかが、その本源的性質によって十分に記述される、ということである。その場合、一次部分は、それがほかの何ものもたない何らかの本源的性質をもつという事実によって識別されるであろう。一次部分がもつ唯一無二の性質が単純性質であることも可能である。たとえば、ある一次部分が宇宙のなかの唯一の意識ある実体であるなら、「意識ある実体」がその十分な記述であろう。しかしまた、実体のそのような唯一無二の本源的性質が複合性質や複雑性質であることも可能であり、そのほうがよりありそうに思われるであろう。

〔原注〕われわれは、単純性質のすべての集まりを、どれほどばらばらで異質であっても複合性質に分類したことを思い起こさなければならない。たとえば「スウェーデンボリ派の社会主義者の外交官」は一つの複合性質である。

**276**　第四に、一次部分は、本源的でなく派生的な性質――何かに対してある関係に立つという性質――によって識別されるかもしれない。一次部分が、独立に識別される他の実体に対して立つ関係によって識別される可能性については、すでに論じた。しかしある場合には、独立に識別されていない別の実体に対して立つ関係によって実体を識別することが可能である。関係そのものが唯一無二であったり、ある唯一無二の特徴を示したりすることがありうるからである。A が B を愛しているという事実は、もし宇宙のなかで A 以外の誰も誰かを愛していないなら、あるいは A の B への愛が他のどの愛もけっしてもたない何らかの性質をもつなら、あるいは他のどの愛のそれとも異なる強さの度合いをもつなら、B の十分な記述を必要とすることなしに A の十分な記述を与えるかもしれない。

**277**　そうすると、各一次部分が十分な記述をもち、したがって他のどの一次部分のそれとも異なる本性をもたねばならないという事実には何の難点も含まれないことがわかる。すでに見たように、これが起こりうる可能なしかたはいくつかある。そしてまた、すべての一次部分に共通の性質があることも確かである。すべての実体に属する性質があり、一次部分であるすべての実体に属する他の性質もあるからである。しかしすべての一次部分は、他のいくつかの一次部分とは共有するがすべてとは共有しない性質――一次部分のあいだで共通でありかつ排他的であるような性質――をもつであろうか。

　二つより多くの一次部分があるなら、すべての一次部分はある種類のそのような共通でかつ排他的な性質をもつであろう。そのときすべての一次部分は、他の一つ以上を含み、そのすべては含まない少なくとも一つの群のうちにあるであろうからである。そしてその群の成員であるという性質は、それがもつであろう共通でかつ排他的な性質であろう。しかし先に見たように、そのような性質はたいして重要ではない。より関心をひく問いは、すべての一次部分が、群の外延の単なる言い直しでない共通でかつ排他的な性質をもつかどうかである。

　これがそうでなければならないと想定する理由がわれわれにあるとは私には思われない。もちろん、各一次部分の本性の唯一無二性が、それがさまざまな性質をもち、そのそれぞれが他の一次部分のすべてではないがいくつかと共有され、他方その組み合わせは唯一無二でただ一つの部分にのみ属する、という事実によることは可能である――そしてありそうだと言えるかもしれない。しかしこれは確かではない。ある場合に、あるいはすべての場合に、一次部分の本性が、他のすべての一次部分と共有する共通の性質と、そのどれとも共有しない何らかの性質とからのみ成る、ということは可能であろう。

　たしかに、もし宇宙が一つより多くの一次全体を含むことが確かであるなら、各一次部分が、群の外延の単なる言い直しでない排他的共通性質を少なくとも一つもつことは確かであろう。ある特定の一次全体に属することは一つの性質であり、すべての一次部分は、この仮説の上では、他のいくつかの一次部分とは共有するがすべてとは共有しないこの種の性質をもつであろうからである。またそのような性質は群の外延の単なる言い直しでもないであろう。B の性質は単に、それが他の成員が C、D、E であるような群の成員である、ということではないであろう。B がその成員であるこの B、C、D、E の群がそれ自身一次全体である、ということがその性質の一部であろう。

　しかし宇宙全体がただ一つの一次全体であることも可能であり、そのときその全体に属するという性質は一次部分のあいだで排他的な性質ではないであろう。そしていずれにせよ、一次全体のなかの一次部分のあいだで共通でかつ排他的であるような――すなわち、一次全体のなかの一次部分のいくつかには属するがすべてには属さないような――性質が何かあると信じる理由はないであろう。

　一次部分のそのような排他的共通性質が何かあることは確かではないのだから、ましてや、一次部分の排他的性質が存在する何かの排他的性質によって、その決定が宇宙のうちで一度より多く生じるようなしかたで内在的に決定されるような一般法則が宇宙のうちにある、ということは確かではありえない。もしこれが起こるなら、一次部分の性質は排他的共通性質であろうからである。こうして、一次部分の性質を決定する一般法則が宇宙のうちにあることは確かではない。そのような法則はあるかもしれないが、あると主張する資格はわれわれにはない。

### 第31章　宇宙の統一

**278**　これでわれわれは宇宙のさまざまな部分についてさまざまな結果に達したが、これらすべての部分をひとつに結び合わせる絆の本性は何か、という問いが残っている。言い換えれば、宇宙はどのような種類の統一をもつのか。

　宇宙は、他のすべての実体と同じく、合成の統一であるとともに顕現の統一でもある。全体としてのその本性は、これらの性質から成っていると言えるのと同じく真に、そのさまざまな性質のうちに自らを顕現していると言える。そして、それがその性質に対して立つ関係から、その部分に対して立つ関係へと移ると、宇宙そのものは、その部分から成っていると言えるのと同じく真に、その部分のうちに自らを顕現していると言える。したがってそれは有機的統一である。

　それが顕現の統一および有機的統一とみなしうるという事実は、どの実体についても重要でなくはない。そして上で（第160節）見たように、この事実は宇宙の場合に特別な重要性をもつ。しかしこの統一は宇宙の場合に特別に重要であるとはいえ、それは宇宙のなかのすべての実体がもつのと同じ統一にすぎない。したがってそれは宇宙のうちの統一の量について何も告げない。ある実体の統一はごくわずかだからである。宇宙のなかの実体のどの群も、どれほど恣意的に選ばれ、どれほどわずかにしか結びついていなくても、すでに見たように一つの実体であり、したがって顕現の統一であり、有機的統一である。

　いままでに達した結果から、宇宙がもつ統一についてそれ以上のことを決定することが可能だとは私には思われない。しかし、宇宙の可能な性質ではあるが必然的な性質ではないとわれわれが見たある性質が、実際にその性質であるなら、宇宙にははるかに確定した特徴的な統一を帰することができるかもしれない。そしてこれらの場合のいくつかを詰めてみて、少なくとも可能な想定からどのような結果が帰結するかを見ておく価値がある。

**279**　まず、最も緊密な統一をもたらすであろう一群の想定を考察しよう。宇宙がいくつかの一次全体から成ることも、ただ一つの一次全体から成ることも可能である。それがただ一つの一次全体から成ると想定しよう。宇宙のなかのすべての一次部分が決定項であることも、そのいくつかが決定されるだけで決定項でないことも可能である。それらがすべて決定項であると想定しよう。それらがすべて決定項であるなら、すべての一次部分が他のすべての一次部分の部分を決定することも可能であるが、そうでないことも可能である。そうであると想定しよう。そうすると、この想定がなされるなら、すべての一次部分が他のすべての一次部分の部分を直接に決定することも、ある場合には決定が間接的でしかないことも可能である。それがすべての場合に直接的であると想定しよう。最後に、決定的対応が宇宙全体を通じて同じ種類のものであることも、異なる場合に異なる種類のものであることも可能である。それがつねに同じ種類のものであると想定しよう。宇宙は、これらの想定が正しいならそうであるようなものである、という見解を第一の想定と呼ぶことにしよう。

**280**　この想定の上では、宇宙の統一は多くの点で非常に緊密である。まず、宇宙のなかのすべての一次部分は、各一次部分のうちの部分の決定項である。つまり、各一次部分のうちの部分の決定項は宇宙の部分の組であり、そのすべての内容を含む。そしてこの関係は、全体としての宇宙をその部分のそれぞれにより緊密に結びつけ、全体を通じて、部分を互いにより緊密に結びつける。そして二つの実体のあいだの決定的対応は、決定項の本性の一部による被決定項の本性の内在的決定を含むのだから、一方では宇宙のすべての一次部分の本性と、他方では各一次部分のなかのすべての二次部分の本性とのあいだに、内在的決定の関係――すなわち因果的決定の関係――があるであろう。

　たしかに、二次部分の本性の全体が、それが対応する一次部分の本性の全体によって内在的に決定されているとはかぎらない。二次部分のうちに一次部分のうちの何ものによっても決定されない性質があり、一次部分のうちに二次部分のうちの何ものも決定しない性質があることは可能である。しかし少なくとも、一次部分を他のすべてのものから区別するだけの一次部分の本性が、二次部分をそれが属する一次部分の他のすべての部分から区別するだけの二次部分の本性に対して、この関係に立つのである。

　もちろん、宇宙全体を通じて第一階の各二次部分が、各一次部分のうちの第二階の二次部分に対して同様の関係に立ち、以下無限に続く、ということも帰結するであろう。そして因果関係のこの網の目――現在の想定によらなければそうであったであろうよりもはるかに緊密で包括的な網の目――は、宇宙のうちにかなり多くの統一を持ち込む。

**281**　もう一つの点も考察しなければならない。各一次部分のうちには、各一次部分によって決定される二次部分がある。そしてわれわれの想定によって、決定的対応の特定の関係は宇宙全体を通じての決定的対応のすべての場合に同じである。このことから、どの一次部分 B においても、その第一階の二次部分のすべてが宇宙の一次部分と一対一の対応をもつだけでなく、B のそれらの二次部分のあいだに、宇宙の一次部分のあいだに存在する関係の体系と相同的と呼べるような関係の体系が存在するであろう、ということが帰結する。というのも、これらの二次部分が決定的対応によって決定されるしかたは、そのそれぞれについて三つのこと――それが B の、しかも第一階の二次部分であるという事実、決定的対応の特定の関係がそれがあるところのものであるという事実、そしてその決定項である一次部分がある本性をもつという事実――に依存するであろうからである。そして最初の二つの事実は、われわれの現在の想定の上では、B のうちの第一階のすべての二次部分について同じである。したがって、B のこれらの二次部分の決定された十分な記述のあいだのすべての非類似は、一次部分の決定する十分な記述のあいだの非類似に対応しなければならず、二次部分のこれらの十分な記述のすべてではなくいくつかのあいだに存在するすべての類似は、一次部分の十分な記述のすべてではなくいくつかのあいだの同様の類似に対応しなければならない。そのような非類似と排他的類似とは、問題のすべての二次部分について同じである二つの所与によっては決定されえず、したがって異なる二次部分について変わる唯一の所与――すなわちそれらが対応するさまざまな一次部分――によって決定されなければならないからである。B の第一階の二次部分のあいだの関係の体系は、このようにして宇宙の一次部分のあいだの関係の体系に対応するであろうから、それと相同的と呼んでよいであろう。B の部分が宇宙の部分に対応するだけでなく、それらを結びつける絆のいくつかが、一次部分を結びつける絆のいくつかに対応するであろう。

　しかし、B の二次部分が対応する宇宙の各一次部分の十分な記述が、どの場合にも、その一次部分によってもたれ、ほかの何ものによってももたれない何らかの単純性質にすぎないとしたら、何が起こるであろうか、と問われるかもしれない。その場合、再現されるべき排他的類似はなく、各一次部分が他のすべての一次部分と異なる単純な決定的性質をもつという一様な非類似を除いて、非類似もないであろう。この場合、B の二次部分のあいだに再現されるであろう一次部分のあいだの関係の体系とは何であろうか。

　しかしこの場合でさえ、宇宙のうちの一次部分の関係の体系が、B のうちの第一階の二次部分の関係の体系に対応する、ということはなお真であろう。一次部分の決定する十分な記述は互いにこの関係――そのそれぞれが異なる性質から成り、それらの性質のあいだには排他的類似も排他的共通非類似も見いだされない――をもつであろうからである。そして同じように、B の部分を互いに区別するそれらの決定された十分な記述の部分は、どの場合にも異なる性質であり、それらの性質のあいだには排他的類似も排他的共通非類似も見いだされないであろう。こうして、被決定項の関係の体系は、他の場合と同じく、決定項の関係の体系と相同的であると言えるかもしれない。B の部分のあいだの関係の体系は、たしかにそれらのあいだにわずかな統一しか形づくらないものであろうが、その点で、同じくわずかな統一しか形づくらない一次部分のあいだの関係の体系に対応しているであろう。

**282**　一次部分のあいだの関係が B の二次部分のあいだの関係と相同的である程度を誇張してはならない。決定する各一次部分のすべての性質がその決定する十分な記述のうちに入る、あるいはそこに含意されている必要はないことをわれわれは見た。一次部分は、この特定の十分な記述から独立した他の多くの性質をもちうるし、B の二次部分のうちにそれらに対応するものがあるであろうとか、それらの性質に依存する関係が B の二次部分のあいだのいずれかの関係と相同的であろうとか、想定する理由はない。そしてまた、各二次部分のすべての性質がその決定された十分な記述のうちに入る、あるいはそこに含意されている必要はないことも見た。したがって、これらの性質に依存して、宇宙の一次部分のあいだに生じるいかなる関係とも相同的でない多くの関係があるかもしれない。しかしこれらすべてを考慮に入れても、対応する性質は、一方では各一次部分を宇宙のなかの他のすべてのものから区別するのに、他方では B の二次部分のそれぞれを他のすべてのものから区別するのに十分である、ということは真であり続ける。そして対応する性質は少なくともこれほど網羅的なのだから、相同的な関係が取るに足りないものであることはありえない。

**283**　そうするとわれわれは、B の第一階の二次部分が宇宙の一次部分に対応し、B のこれらの二次部分のあいだのさまざまな関係が宇宙の一次部分のあいだの関係に対応することを確立した。しかし一次部分を、何か抽象的な孤立においてではなく、それらが互いに実際にもつ関係において取るなら、実際にあるがままの宇宙が得られる。そして B の二次部分を同じしかたで取るなら、実際にあるがままの B が得られる。こうしてわれわれは、B と、宇宙の他のすべての一次部分とが、その部分とそれらのあいだの関係とに関して宇宙に対応する、と言う資格がある。

　一次部分の宇宙とのこの対応については、それが派生的なものにすぎない、ということに注意しなければならない。第一次的な事実は第一階の二次部分の一次部分との対応であり、一次部分の宇宙との対応は、すでに見たようにそこから生じるのである。

**284**　そうすると宇宙は、われわれが考察している想定の上では、その部分のある組の各成員が全体としての宇宙と対応するという性質をもつ。この性質を、不適切でない比喩によって、自己反映の性質と呼んでよいであろう。

　自己反映は統一の一形態である。自己反映する全体は、自己反映しないいかなる全体によっても共有されない追加の種類の統一をもつ。自己反映する全体はその部分と特別なしかたで結びついているからである。そしてこれを通じて、問題の部分は互いに特別なしかたで結びついている。そのそれぞれが自分自身の部分のあいだの内的関係の体系をもち、そのすべてが同じ体系に対応し、したがって互いに対応するからである。

　全体がその部分に対してもつ関係のうち、それが有機的統一であるという事実から帰結するものと、それが自己反映する統一であるという事実から帰結するものとを区別しなければならない。有機的統一においては、第20章で見たように、部分が全体を顕現する。しかし全体は、その部分のどれか一つの組の、いっしょに取られたすべての成員のうちにしか顕現しない。それは一つの成員だけのうちには顕現しない。しかし自己反映する統一は、反映が起こる部分の組の各成員のうちに別々に反映される。すべての実体は有機的統一であり、したがって自己反映する統一であるすべての実体は、二種類の統一――有機的統一と自己反映の統一――をもつ。

　自己反映というような語は、宇宙と各一次部分とのあいだの結びつきの緊密さを誇張している、と反論されるかもしれない。一次部分がその内的関係の体系以外の点で宇宙に似ていると想定する理由はないからである。しかしこれは比喩を不適切にはしない。反映は反映される対象の正確な写しではないからである。対象は三次元にあり、反映は二次元にあるかもしれない。対象は山であり、反映は手鏡のなかにあるかもしれない。しかしそのような違いは、一方が他方の反映であることを妨げない。

**285**　宇宙が自己反映する統一であるなら、それによってそれは、すべての実体からではないにせよ、多くの他の実体から区別される。というのも、われわれの議論の道筋は、もしどれかの実体が、決定的対応によって決定された部分へと自己反映し、その対応の帰結として自己反映するような統一であるべきなら、それはただ一つの条件のもとでのみ可能である、ということを示したからである。その条件とは、それが部分の組をもち、その各成員がその群の他のすべての成員を、そしてそれらの成員だけを、その分化群としてもつ、ということである。つまり、そのどの部分もその外の何ものとの対応によって決定されてはならない。さて第24章で見たように、すべての一次部分はその分化群のうちに何か他の一次部分をもたねばならず、したがってそのどの部分の組の少なくともいくつかの成員はそれ自身の外の何かによって決定されるであろう。そしてその帰結として、どの階の二次部分についても同じであろう。

　したがって排除されない唯一の場合は、一次部分の群であって、その各成員がその群のすべての成員を、そしてそれらの成員だけをその分化群としてもつような実体の場合である。しかしもし宇宙が、われわれの現在の想定の上でそうであるように、そのような群であるなら、同じ決定的対応の体系のうちに、そのような群である他の実体はありえない。その場合、すべての一次部分はその分化群のうちに他のすべての一次部分をもち、したがって、どれかの一次部分を排除するような自己反映する群――すなわち、宇宙以外の自己反映する群――の成員ではありえないからである。

　また、宇宙の自己反映は、その一次部分のそれぞれにおける反映に限られない、ということにも注意すべきである。第一階の各二次部分のうちには第二階の二次部分の組があり、そのそれぞれは宇宙の一次部分の一つをその最終決定項としてもつであろう。したがって、一次部分についての議論と類比的な議論によって、第一階の各二次部分はその内的体系に関して宇宙に対応し、したがって宇宙を反映していると言える、ということが帰結するであろう。そして無限に至るすべてのより低い階の二次部分についても同じことが真であろう。

　そして宇宙の自己反映のこの最後の特性――部分の一つの組の成員における自己反映が、後続する組の無限系列の成員における自己反映を含む――は、自己反映が決定的対応に依存しない場合には、どの自己反映する統一によっても共有されえないであろう。部分の一つの組のうちで起こることが後続する組の無限系列のすべてのうちで起こることを含みうるのは、決定的対応によってだけだからである。したがって、もし宇宙が後続する部分の組の無限系列を通じて自己反映しているなら、決定的対応の体系が一つより多くあるのでないかぎり、他のいかなる実体もその性質をもちえないであろう。

**286**　第146節と第147節で見たように、すべての有機的統一に属するとときに主張される性質が二つある。一つは、全体はすべての部分のうちにある、ということである。もう一つは、各部分は全体の本性を表現している、ということである。われわれは、実体が有機的統一であるという事実は、これらの言明のどちらをもその実体について文字どおりには真にしないことを見た。しかしまた、有機的全体の各部分が全体の顕現において唯一無二の機能を果たしているという事実が、これらの表現の使用を、正しくないにせよ不自然ではないものにしていることも見た。

　さて有機的統一がまた自己反映する統一でもあるとき、これらの表現は、依然として正しくはないが、統一が自己反映することなしに有機的である場合よりも適切である。統一が自己反映するものであるなら、全体は各部分のうちにある、と言うのはそれほど不適切でない。全体は、その部分のうちに顕現してはいても、各部分のうちに別々に顕現しているのではないが、自己反映する統一においては全体は反映する部分の組の各部分のうちに別々に反映されているからである。これは全体が各部分のうちにあること――それは不可能である――と同値ではないが、それにある類似をもつ。

　またさらに、統一が有機的であるだけの場合よりも自己反映する場合のほうが、各部分は全体の本性を表現している、と言うのはそれほど不適切でない。全体の本性は、ある特定の実体がそれを顕現する部分の一つであるという事実のうちにはごく部分的にしか表現されていないからである。しかし自己反映する統一においては、反映する部分のそれぞれが、全体のうちに存在する関係の体系と相同的な反映の体系をそのうちにもつ。そしてこれは各部分に全体の本性の全体を表現させはしないけれども、そうでない場合よりもそれに近づく。

**287**　そうすると、われわれの第一の想定は、もし真であるなら、宇宙が確かにもっていることをわれわれが見た統一よりもはるかに緊密な統一を宇宙に与えるであろう。しかしこの想定の上でさえ、宇宙は、統一がその分化よりも根本的である、あるいはその分化と同じほど根本的であるような全体でさえないであろう。われわれの現在の想定のなかには、第256節で、一次部分が基礎体系のうちで、したがって存在のうちで唯一無二の意義をもつ位置を占める、と結論させた議論の力を弱めるものは何もないからである。一次部分の十分な記述は、宇宙のどの十分な記述のうちにも――一次部分の十分な記述をそのうちの要素として実際に含むものを除いて――必ずしも含意されていない。他方、宇宙の一次部分の組のすべての成員のどんな十分な記述も宇宙の十分な記述を含意する。そしてこの理由から、思うに、いま論じてきた想定の上でさえ、宇宙のうちの分化の側面は統一の側面より根本的である、と言わねばならない。

〔原注〕これは、どの全体のどの部分の組のすべての成員のどんな十分な記述もその全体の十分な記述を含意する、という一般原理から帰結する（第187節参照）。含意されるものは、事実として宇宙である実体の十分な記述であろう。この実体が宇宙であるという性質をもつことが必ずしも含意されるわけではないであろう。しかしこれは本文の議論に影響しない。

**288**　これが第一の想定の結果である。しかしすでに述べたように、この想定が事実と一致すると信じる理由はわれわれにはなく、他の想定から何が帰結するであろうかを考察するよう進まなければならない。次に、第一の想定を構成した想定のうち最初の四つは正しいが、第五のものは正しくない、と想定しよう。つまり、宇宙はただ一つの一次全体を形づくると想定しよう。宇宙のなかのすべての一次部分は決定項であると想定しよう。すべての一次部分は他のすべての一次部分のうちの部分を決定し、しかもそれを直接に決定すると想定しよう。しかしもはや決定的対応が宇宙全体を通じて同じ種類のものであるとは想定せず、それが異なる種類のものである可能性を認めよう。この第二の想定の場合には、宇宙の統一についてどのような結論を演繹できるであろうか。

〔原注〕決定的対応の種類は、決定する一次部分によって、あるいは分化される一次部分によって、あるいはその両方によって変わるかもしれない。しかしすでに見たように、決定するどの一次部分 C とその被決定項 B!C とのあいだに成り立つ決定的対応の種類は何であれ、C の部分と B!C の部分とのあいだにも成り立たねばならないであろう。（第227節。）

**289**　第一の想定の場合と同じく、各一次部分が各一次部分のうちに第一階の二次部分を決定し、宇宙のなかの第一階の各二次部分が第一階の各二次部分のうちに第二階の二次部分を決定し、以下無限に続く、ということはなお事実であろう。したがって因果関係の網の目は第一の想定の上でと同じく緊密であろう。

　しかしもはやわれわれは、第一の想定の上で言ったように、各一次部分と、どの階の各二次部分とが、その内的関係に関して宇宙との対応に立ち、したがってそのそれぞれが宇宙を反映していると言える、と言うことはできない。第一の想定の上でこれが起こるという結論にわれわれが達した議論は、それらの二次部分が決定的対応によって決定されるしかたは、そのそれぞれについて三つのこと――それが B の、しかも第一階の二次部分であるという事実、決定的対応の特定の関係がそれがあるところのものであるという事実、そしてその決定項である一次部分がある本性をもつという事実――に依存するであろう、と言うことから始まった。それから続けて、これらの事実の最初の二つは B の第一階のすべての二次部分について同じであり、したがってこれらの二次部分の十分な記述のうちのすべての非類似と排他的類似とは、一次部分の決定する十分な記述のうちの非類似と排他的類似とに対応しなければならない、と指摘した。しかしわれわれの現在の想定の上では、最初の二つの事実がともに各二次部分について必ず同じである、ということはもはや事実ではない。C と B!C とのあいだに生じる決定的対応の種類は、D と B!D とのあいだに生じる決定的対応の種類とまったく異なるかもしれない。したがって、B の部分の決定された十分な記述のうちのすべての非類似と排他的類似とが、一次部分の決定する十分な記述のうちの同様の非類似と類似とに対応するであろう、ということは帰結しない。そのいくつかは決定的対応の異なる種類のうちの非類似と排他的類似とに対応するかもしれない。したがって、B の部分を結びつけ、宇宙の一次部分のあいだのいずれかの関係の体系と相同的であるような関係の体系があると想定する理由はわれわれにはない。

　さて、一次部分がそもそも宇宙に対応すると言うわれわれの唯一の理由は、第一の想定の場合に、各一次部分の部分が、宇宙の一次部分を結びつける体系と相同的な関係の体系によって結びつけられていることを見た、ということであった。そしていまやこれを言う資格がわれわれにはないのだから、一次部分が実際に宇宙に対応するとも、宇宙がそれらのうちに反映されているとも言う資格はない。そして同様の根拠から、どの階の二次部分も宇宙に対応するとも、宇宙がそれらのうちに反映されているとも言う資格はないであろう。

　したがって第二の想定は、第一の想定ほど緊密な統一を宇宙のうちに含意しない。そして第一の想定の上でさえ達せられた結果、すなわち宇宙のうちの多数性は統一よりも根本的である、という結果は、第二の想定の上でも、これから考察しなければならない他の想定の上でもと同じく、ましてや真であろう。

**290**　第三の想定を次のように立てよう。宇宙はただ一つの一次全体を形づくり、宇宙のなかのすべての一次部分は決定項であり、すべての一次部分は他のすべての一次部分のうちの部分を決定する、となお想定しよう。しかしこの決定がどの場合にも直接的であるとはもはや想定しないことにしよう。つまり、B と C とが二つの一次部分であるなら、B が、C をその最終決定項とする何らかのより低い階の部分――B!D!C、B!E!D!C、あるいはそのようなもの――をもつかぎり、部分 B!C をもたない可能性を認めよう。

　この場合、宇宙と一次部分とのあいだの結びつきが前の場合より緊密でないことは明らかである。第二の想定の上では、全体としての一次部分は必ずしも宇宙を反映しなかったが、その部分は宇宙の一次部分と一対一の対応をもっていた。しかしここではそうではないであろう。各一次部分のうちの第一階の二次部分は、もはや必ずしも一次部分と一対一の対応をもたない。宇宙の一次部分が B、C、D、E であったとすれば、B の第一階の二次部分の組がたとえば B!B と B!C であり、C の組が C!B、C!D、C!E であることも可能であろう。またさらに D は第一階の二次部分をまったくもたないかもしれない。それは B との対応によってのみ分化されているかもしれず、したがってその部分の最も高い組は D!B!B と D!B!C であるかもしれない。これらの組のどれも一次部分の組と一対一の対応にはないが、それでも各一次部分のうちには各一次部分によって最終的に決定された部分があるであろう。同じように、第一階の各二次部分のうちの第二階の二次部分も、必ずしも宇宙の一次部分と一対一の対応にはない。

〔原注〕それは B!E!F!…!C でありうる。ここで省略記号で表される段階の数は任意の有限の数でありうる。

　しかしながら、前の二つの想定の上でと同じく、各一次部分は各一次部分の何らかの部分と因果的に関係している、ということはなお事実であろう。それは直接にか間接にか、そのそれぞれのうちの部分を実際に決定するからである。そして因果関係の網の目は、前の二つの想定の上でのように対称的ではないであろうが、この場合にもそれらの場合と同じく、無限に下方へと延長されている。ひとたび C によって直接にか間接にか決定された B の部分が見いだされると（そして想定によって、B のそのような部分がある）、その部分の無限に至るすべての部分は C の部分によって決定されているからである。

　この因果関係が決定的対応を通じて起こるという事実は、因果関係があるという事実によって結びつけられるよりも宇宙をより緊密に結びつけるであろうか。これは真であるかもしれない。しかしこれは、どのような種類の決定的対応が生じたかと、一次部分の特性の本性とに依存するであろう。そしてこれらは次の部まで、したがって次の巻まで延期しなければならない問いである。

　しかし因果的決定はいくらか重要な事柄である。各一次部分がすべての一次部分によって決定された何らかの部分をもつという事実は、各一次部分を他のすべての一次部分（したがって宇宙の部分の一つの組のすべての成員）と内在的決定によって実際に結びつけ、これは、宇宙のすべての部分を結びつけることを先に見た外在的決定による結びつきよりも緊密で生き生きとした絆だからである。他方、ここでの結びつきは直接的である必要がないのだから、ある場合には C によって決定される B の部分がごく小さなものであることは可能である。これが結合の緊密さにどれだけ影響するかは、ここでもまた次の部まで延期しなければならないより具体的な考察に依存するであろう。

**291**　次に第四の想定に来る。宇宙は一つの一次全体を形づくり、すべての一次部分は決定項である、と想定し続けよう。しかし、すべての一次部分が他のすべての一次部分のうちの部分を決定する、というさらなる想定は捨てよう。たとえば、宇宙が六つの一次部分 B、C、D、E、F、G から成ると想定しよう。B と C とが相互に分化させる群を形づくり、したがって B に属する第一階の二次部分は B!B と B!C であり、C のそれは C!B と C!C であるとしよう。D と E も同様に相互に分化させる群を形づくり、F と G の両方の分化群は BDFG であるとしよう。そうすると、宇宙のうちに、K のすべての部分を十分に記述するために K の部分以外の何ものとの決定的対応も持ち込む必要がないような、より小さな群 K を形づくることは可能でないであろう。したがって宇宙のうちには一次全体はなく、宇宙はしたがってただ一つの一次全体であろう。そして各一次部分は少なくとも一つの分化群のうちにあり、したがって決定項である。しかし各一次部分が各一次部分のうちの部分を決定するのではない。D も E も F も G も B や C のうちのいかなる部分も決定しないからである。B と C の部分は B と C の閉じた相互的な群によって決定されており、したがって B と C を除いて、直接的にも間接的にも一次部分をその決定項としてもたない。同じように、B も C も F も G も D や E のうちのいかなる部分も決定しない。

　この想定の上で宇宙の統一について何が言えるであろうか。各一次部分が、決定的対応によってそれらのうちの部分を決定することに関して他のすべての一次部分と結びついている、ということはもはや事実ではない。しかし各一次部分が決定的対応に関して他の各一次部分と結びついている、ということはなお事実である。宇宙はなお一つの一次全体であり、そのことは、宇宙のどれかの部分が排除されているいかなる群も決定的対応に関して自足的ではありえない、ということを意味するからである。そのような群はすべて、群の外の何かを決定するか、それによって決定されるかする何らかの部分をもたねばならない。そしてこれは宇宙のすべての一次部分を――そしてそれらを通じて二次部分を――外在的決定によって結びつけられているよりも緊密に、ただし前の想定の上でそうであろうよりは緊密でなく、結び合わせるであろう。

**292**　第五に、宇宙はただ一つの一次全体を形づくると想定し続けながら、すべての一次部分が決定項であるとはもはや想定しないことができる。そのいくつかが、それ自身は何も決定することなしに決定される、という可能性を認めてもよい。

　この想定の上で生じるであろう宇宙の統一は、前の想定の上で生じるであろうものと同じであろう。いまや、どの一次部分のうちにも部分を決定しないある一次部分があるであろう。しかしこれは、すべての一次部分のうちに部分を決定するわけではない一次部分がある、という前の想定の上で残っていた宇宙の統一を何も破壊しないであろう。

**293**　われわれがなしうる最後の想定は、宇宙が一つより多くの一次全体を形づくる、というものである。これはその統一をさらに減らすであろう。いまや決定的対応に関して互いに独立している宇宙の異なる部分があるからである。もちろんそれらは互いにまったく孤立しているのではない。宇宙のなかのすべてのものは他のすべてのものと関係している。そしてとりわけ、宇宙のなかのすべてのものは他のすべてのものと外在的決定によって関係している。そしてそれらが互いに因果的に関係していることも可能である。決定的対応のそれ以外にも因果関係があるかもしれないからである。しかしわれわれはそのような他の因果関係の生起を確立しておらず、したがって一次全体のあいだに因果関係がまったくないことも可能である。

　注意すべきは、宇宙全体を通じて決定的対応のただ一つの種類しか生じないという想定は、すべての一次部分が他のすべての一次部分のうちの部分を直接に決定するという想定とだけでなく、他の想定のどれとも――それがそのような部分を直接にか間接にか決定する、それはつねに何らかの一次部分のうちの部分の決定項である、それは少なくとも他のすべての一次部分と同じ一次全体のうちにある、そして最後に、それはそのすべてと同じ一次全体のうちにはない、という想定のどれとも――組み合わせうる、ということである。しかしそれは、すべての一次部分がすべての一次部分のうちの部分を直接に決定するという想定と組み合わせた場合を除いて、宇宙のうちの統一の量をそれほど増しはしないであろう、と私は思う。

　これでわれわれの探究の第一の部分――存在するすべてのものに属する特性、あるいは存在全体に属する特性を、できるかぎり決定しようとする試み――を終える。このように決定された宇宙の一般的本性から、経験的にわれわれに知られている存在するもののさまざまな部分について、理論的および実践的な関心を引くどのような帰結が引き出せるか、という考察が残っている。これは、数年のうちに刊行したいと望んでいる第2巻においてその場所を見いだすであろう。
