# ゾロアスターのカルデア神託　作業メモ

ウェストコット編『ゾロアスターのカルデア神託』（『ヘルメス文書集成』第6巻、1895年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の WestcottWWCollectaneaHermeticaVolume06 の OCR テキスト（_djvu.txt、2026年11月4日取得）を `src/oracles_ocr_raw.txt` に置き、柱とページ番号を除いたものを `src/oracles_clean.txt` とした。
- 序論の三つの図式（表）は、note の制約にあわせて入れ子の箇条書きにした。
- 各神託のあとの出典と分類（Z、T、Z または T）は原文どおり残し、略記された書名は日本語にした。読みとれない略記（Jul., Crat.）は「原文のまま」と断った。
- 英訳からの重訳である。ギリシア語原典とは照合していない。
- 日本語訳の有無：検索した範囲では、この版の日本語訳も『カルデア神託』の日本語全訳も見つからなかった。
- 下書き `draft/n1.md`〜`n3.md` と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿1本を生成した。

## 訳の方針

- 神託の本文は「である」調。命令形の教えは「〜せよ」「〜するな」とした。
- 字下げした段落（原文ではイタリック）はサペレ・アウデの注として、そのまま訳した。
- 新プラトン派の用語はカナ書きにした（ヒュパルクシス、シュノケイス、テレタルカイなど）。
