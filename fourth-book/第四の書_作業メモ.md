# オカルト哲学第四の書ほか（ターナー英訳1655年）　作業メモ

ロバート・ターナー英訳『Henry Cornelius Agrippa his Fourth Book of Occult Philosophy』（ロンドン、1655年）のうち、扉・序文・献詩と、「ジオマンシーについて」「オカルト哲学第四の書」「イサゴーゲー」「天文的ジオマンシー」の4篇の全訳の作業記録。note の記事本文には含めない。同じ本の「ヘプタメロン」は `heptameron/`、「アルバテル」は `arbatel/` にある。

## 底本と作業の手順

- Internet Archive の cu31924006718757（コーネル大学図書館蔵。1655年版の複製本）の OCR テキスト（_djvu.txt、2026年11月14日取得）から各篇を切り出して `src/` に置いた。
  - `1655_00_前付_ocr.txt`：扉、序文、献詩（1篇目のジオマンシーのファイル冒頭に、最後の献詩の終わりがかかっている）
  - `1655_01_geomancy_ocr.txt`：pp. 1–31
  - `1655_02_fourth_book_ocr.txt`：pp. 32–72
  - `1655_04_isagoge_ocr.txt`：pp. 108–153 ごろ
  - `1655_05_astro_geomancy_ocr.txt`：pp. 155–177（末尾にアルバテルの冒頭がかかっている）
- スキャンのページ番号（n）と原本のページの対応は、本文の前半では n = ページ + 37。天文的ジオマンシーの156ページは n183。
- 複製本の現代の解説（Stephen Skinner、1978年）は著作権の対象になりうるので、訳していない。1655年の本文だけを訳した。
- 図版は、ページ画像（幅1483px）から切り出して `images/` に置いた。
  - `geo_p3_figures.jpg`：十六の図形と惑星の表（n40）
  - `geo_p6_matres.jpg`・`geo_p6_filiae.jpg`：母たちの打ち出し方と、娘たちの生み出し方の例（n43）
  - `geo_p7_theme.jpg`：ジオマンシーの命式（n44）
  - `geo_p9_example.jpg`：占星術の理による図の例（n46）
  - `fb_p38_heads.jpg`：星・頭・線の表（n75）
  - `fb_p40_good.jpg`・`fb_p41_evil.jpg`・`fb_p42_evil2.jpg`：善霊と悪霊の文字の表（n77〜n79）
  - `ag_p156_figure.jpg`：天文的ジオマンシーの図（n183）
- 序文末尾の日付は OCR が崩れていたので、ページ画像（n29）で「London, ult. Aug. 1654」と確かめた。
- 下書き `draft/n0.md`（扉・序文・献詩）、`n1.md`（ジオマンシー）、`n2.md`（第四の書）、`n3.md`（イサゴーゲー）、`n4.md`（天文的ジオマンシー）と、記事ごとの冒頭 `draft/head_*.md` から、`_build.py` で全訳 `第四の書ほか_全訳.md` と note 用原稿4本を生成した。
- 英訳からの重訳である。ラテン語原典とは照合していない。

## 既訳の確認

- 『オカルト哲学第四の書』本体：大橋喜之訳『アグリッパ儀礼魔術――原典訳『オカルト哲学第四書』』（八坂書房、2025年3月）がある。国会図書館の書誌では、第I部に「オカルト哲学第四書あるいは儀礼魔術について」と「ヘプタメロン」が収められている。
- 「ジオマンシーについて」「イサゴーゲー」「天文的ジオマンシー」：2026年11月14日の検索では日本語訳は見つからなかった（大橋訳の目次にも見当たらない）。
- 既訳のある第四の書本体も、ユーザーの判断（2026年11月14日、「全部訳して全部投稿」）で note に出す。ヘプタメロンを出さなかった方針とは異なるので、記事の書誌欄に大橋訳があることを明記した。

## 訳の方針

- 第四の書は「汝」への教えの文体、イサゴーゲーは対話なので話し言葉にした。
- ジオマンシーの十六の図形は、ラテン語名のカナ書きに意味を添えた（フォルトゥナ・マヨル〔大いなる幸運〕など）。
- 惑星の霊の姿の欄外にあるラテン語（homo mitratus、azurino vestu、buxus、multiceps、caudatus など）は訳さなかった。「cheeslip」は欄外の multiceps からワラジムシと解した。
- 引用されたラテン語の詩（ホラティウス、ウェルギリウス、サクソ・グラマティクス、ルカヌス、ティブルス）は、ラテン語の本文から日本語に訳した。
- 原文の誤りと思われる箇所（家の番号、章番号、人名の綴りなど）は直さず、〔原文のまま〕とした。天文的ジオマンシーに何度か出る「＊R＊」は印刷どおりで、意味がわからないので〔原文のまま〕とした。
