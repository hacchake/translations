# 熟達者たちとともに（フランツ・ハルトマン）　作業メモ

フランツ・ハルトマン『With the Adepts: An Adventure among the Rosicrucians』（1910年改訂版、初版1887年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Global Grey の電子版（1910年改訂第二版にもとづく。付録を含む）を章ごとに `src/c003.txt`〜`c013.txt` に置いた。
- Internet Archive の withadeptsanadv00hartgoog（1910年 Theosophical Publishing Co. 版の Google スキャン）の OCR を `src/w1910.txt` に置き、疑わしい箇所を照合した（第七章の引用符など）。
- 1887年初版（anadventureamon00hartgoog）も確認した。付録は改訂版で加えられたものである。
- 下書き `draft/n1.md`〜`n8.md`（序文と各章、付録と訳注）と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿2本（前編 n1〜n4、後編 n5〜n8）を生成した。
- 日本語訳の有無：2026年11月6日に extended 検索で調べた範囲では見つからなかった。
- 著作権：著者は1912年没。日本・英国・米国で保護期間満了。

## 訳の方針

- 本文は「である」調、熟達者たちの台詞は「です・ます」調。
- cretin は当時の言い方として「クレチン（知的な遅れと発育の障害とをともなう病）」と一度注を添え、以後は「小人」とした。
