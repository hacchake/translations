# セーフェル・イェツィラー（ウェストコット訳）　作業メモ

ウェストコット訳『セーフェル・イェツィラー』第2版（1893年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の sepheryetzirahb00rittgoog（1893年第2版、Google Books 由来）の OCR テキスト（_djvu.txt、2026年11月4日取得）を `src/sy1893_ocr_raw.txt` に置き、Google の透かしとページ番号を除いたものを `src/sy1893_clean.txt` とした。
- 同じ Internet Archive の WestcottWWSepherYetzirah は1996年のクンツ編第4版（著作権あり）なので、底本にも本文の補いにも使っていない。第二十八の小径が後の版で補われたことだけを訳注に記した。
- 本文の上つきの注番号は OCR で崩れているため、注の見出し語から位置を決めて（注N）を入れた。
- 注の中の二つの表（注38、注45）は箇条書きにした。
- 下書き `draft/n1.md`（扉・序・序論）、`n2.md`（本文・三十二の小径）、`n3.md`（注・訳注）と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿1本を生成した。
- 日本語訳の有無：ウェストコット版を底本とする中村心護『セフェル・イェツィラー（形成の書）～カバラの奥義～』（自費出版、書泉などで販売）がある（翻訳後に確認した）。

## 訳の方針

- 本文は「である」調。命令は「〜せよ」。
- ヘブライ語の翻字（ALHIM ChIIM など）はウェストコットの表記のまま残した。
- 英訳からの重訳である。ヘブライ語原典とは照合していない。
