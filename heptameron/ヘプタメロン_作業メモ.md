# ヘプタメロン（伝ピエトロ・ダバノ）　作業メモ

『Heptameron: or, Magical Elements』（ロバート・ターナー英訳、1655年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の cu31924006718757（コーネル大学図書館蔵。1655年版の複製本）の OCR テキスト（_djvu.txt、2026年11月4日取得）から「Heptameron」の部分を切り出して `src/heptameron1655_ocr_raw.txt` とした。
- OCR は霊名とラテン語の祈りの読み誤りがひどいので、ページ画像（n110〜n142、幅1483px）を見開きごとに読んで確かめた。確かめた名の控えは `src/画像で確認した名.md` にある。
- 時刻の天使の表は、惑星時の規則で全表を生成し、日・月・火曜の表をページ画像と照合して一致を確かめた。
- 図版9点（五角形の護符 n117、魔法円 n124、七曜の印章 n125・n127・n129・n132・n134・n136・n138）をページ画像から切り出して `images/` に置いた。
- 複製本の現代の解説は著作権の対象になりうるので、訳していない。1655年の本文だけを訳した。
- 下書き `draft/n1.md`（前置き〜円の図）、`n2.md`（七曜・時刻表・訳注）と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿1本を生成した。
- 日本語訳の有無：検索した範囲では見つからなかった。
- 英訳からの重訳である。ラテン語版とは照合していない。

## 訳の方針

- 英訳本中のラテン語の祈りは日本語に訳し、神名・霊名は原綴のまま残した。
- 主要な七人の天使（ミカエル、ガブリエル、サマエル、ラファエル、サキエル、アナエル、カッシエル）は本文・表でカナ書きにし、一覧の霊名は原綴とした。
