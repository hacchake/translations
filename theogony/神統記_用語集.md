# 神統記　用語集

ヘーシオドス『神統記』の訳で用いた主な訳語。『イーリアス』と共通の神名は ../iliad/イーリアス_用語集.md も見てください。

| Ἔρεβος | エレボス | 闇。 |
| Νύξ | ニュクス | 夜。 |
| Αἰθήρ | アイテール | 澄んだ上空の光。 |
| Ἡμέρη | ヘーメラー | 昼。 |

| Ἐρινύες | エリーニュスたち | 復讐の女神たち。 |
