# デーメーテール讃歌　用語集

| 原語 | 訳語 | 説明 |
|---|---|---|
| Δημήτηρ / Δηώ | デーメーテール／デーオー | 穀物と実りの女神。 |
| Περσεφόνη / Περσεφόνεια | ペルセポネー／ペルセポネイア | デーメーテールの娘。冥界の女王。 |
| Ἀιδωνεύς / Ἀΐδης | アイドーネウス／ハーデース | 冥界の王。 |
| Πολυδέγμων | 多くを受け入れる者 | ハーデースの呼び名。 |
| Πολυσημάντωρ | 多くを支配する者 | ハーデースの呼び名。 |
| Ἑκάτη | ヘカテー | 声を聞きつけ、後にペルセポネーの従者となる女神。 |
| Ἥλιος | ヘーリオス | 太陽神。神々と人間の見張り役。 |
| Ἐλευσίς | エレウシース | アテーナイ近くの町。秘儀の地。 |
| Κελεός | ケレオス | エレウシースの王。 |
| Μετάνειρα | メタネイラ | ケレオスの妻。 |
| Δημοφόων | デーモポーン | ケレオスとメタネイラの幼い息子。 |
| Ἰάμβη | イアンベー | 女神を笑わせた女。 |
| Δωσώ | ドーソー | 女神が名のる偽りの名。 |
| κυκεών | キュケオーン | 大麦とはっかの飲み物。 |
| ὄργια | 秘儀（オルギア） | 女神が教えた儀式。 |
| Τριπτόλεμος | トリプトレモス | 秘儀を授かったエレウシースの王の一人。 |
| Εὔμολπος | エウモルポス | 同じく秘儀を授かった王。後の秘儀の神官家の祖。 |
| ῥοιή | 柘榴 | ペルセポネーが冥界で口にした実。 |
| Ῥάριον | ラーリオンの野 | 最初に穀物が実った野。 |
| Πλοῦτος | プルートス（富） | 女神たちが愛する者に送る富の神。 |
