## タロット・カードのオカルト的な意味

　この短い論考を終える前に、これらの驚くべきタロット・カードの、オカルト的・カバラ的な意味について、少し述べておこう。普通の五十二枚の組が、ある独特な数の意味をもちうることは、昔から知られている。たとえば、

- 一組のカード五十二枚は、一年の五十二週を思わせる。
- 各スートの十三枚は、一年の十三の太陰月、四半期の十三週を思わせる。
- 一組の四つのスートは、一年の四つの季節を思わせる。
- 一組の十二枚の絵札は、一年の十二か月、黄道十二宮を思わせる。

　さらに、次のものを足しあわせると、

| | |
|---|---|
| 四つのスートの数札の目の数 | 220 |
| 十二枚の絵札の目の数 | 12 |
| 十二枚の絵札をそれぞれ10と数えたもの | 120 |
| 各スートのカードの枚数 | 13 |
| 合計＝一年の日数 | 365 |

　一年の日数が得られる。

　だが、タロット・カードは、一見気まぐれで奇妙な図柄の背後に、深遠な象徴の、はるかに込みいった体系を隠している。そこには、十という数に神秘の数四を掛けたものが、二十二文字の原始の象形文字のアルファベットと組み合わされているのが見いだされる。

### レヴィの「トートの書」

　エリファス・レヴィは、その『魔術の歴史』の中でこう言っている。「絶対的な象形文字の学問は、ひとつのアルファベットを基礎としていた。そのアルファベットでは、すべての神々が文字であり、すべての文字が観念であり、すべての観念が数であり、すべての数が完全なしるしであった。

　「この象形文字のアルファベットを、モーセは自分のカバラの大いなる秘密とし、それをエジプト人から取りもどした。というのも、『セフェル・イェツィラー』によれば、それはアブラハムから来たものだからである。このアルファベットこそ、名高い『トートの書』であり、クール・ド・ジェブランは、それがタロットと呼ばれるあの独特なカードの組の形で今日まで保たれているのではないかと推測した。……十の数と二十二の文字とは、カバラで学問の三十二の道と呼ばれるものであり、その哲学的な記述が、『セフェル・イェツィラー』として知られる原始の尊い著作の主題である。この書物は、ピストリウスなどの集成の中に今も見いだされる。トートのアルファベットはわれわれのタロットの原型であるが、ただ形が変わっている。われわれのもっているタロットはユダヤ起源のもので、その図像の型は、シャルル六世の治世より前にはさかのぼれない」。

### 『セフェル・イェツィラー』

　上の引用で触れられている『セフェル・イェツィラー』は、私の友人で、熟練した博識のカバラ研究者であるウィン・ウェストコット博士によって最近翻訳され、今では英語で読めるようになった。私の考えでは、それはたしかにタロットのカバラ的な鍵を与えてくれる。そして、明らかな類比によって、その奇妙な象徴の古く宗教的な起源を、たちどころに示してくれる。それは五章に分けられた三十三の短い節（三十三番目は要約にすぎない）からなり、「道」と呼ばれる三十二のオカルト的な段落によって解き明かされている。実際、それは十と二十二についての論考と呼んでもよい。一から十までの数は、霊、空気、水、火、高さ、深さ、東、西、北、南を象徴するといわれる。二十二の文字は、空気・水・火を指す三つの母字 A・M・SH、七つの惑星などを指す七つの二重字 B・G・D・K・P・R・TH、黄道十二宮などを指す十二の単字 H・V・Z・CH・T・I・L・N・S・O・Tz・Q に分けられる。

　レヴィの弟子クリスティアンは、その魔術についての最近の著作の中で、タロットの二十二の象形文字の説明を、クラタ・レポアというエジプトの秘儀の入門の儀式の一部にしている。

### レヴィが復元した三枚の切り札

　二十二枚のタロットの切り札のうち三枚の象徴は、エリファス・レヴィによって次のように復元された。

**7　戦車**　四本の柱をもつ立方体の戦車で、星をちりばめた紺碧の天蓋をいただいている。戦車の中、四本の柱のあいだに、征服者が立っている。彼は輪の冠をかぶり、そこから金の五芒星が三つ立ちのぼって輝いている。胸甲には三つの直角があり、肩には、満ちていく月と欠けていく月の二つの三日月で象徴されるウリムとトンミムがある。手には、球と正方形と三角形をいただいた王笏を持っている。その姿勢は誇り高く、落ちついている。戦車には、二重のスフィンクス、というよりは、つながった二頭のスフィンクスがつけられている。一頭は頭をめぐらし、二頭とも同じ方向を見ている。もう一頭のほうへ頭を向けているスフィンクスは黒くて威嚇的で、もう一頭は白くて静かである。戦車の正面をなす正方形には、エジプト人の翼のある球をいただいた、インドのリンガが見える。

**10　運命の輪**　七本の輻をもつ車輪で、エゼキエルの宇宙生成の車輪である。一方の側には、犬の頭をした姿（エジプトのメルクリウスであるアヌビス）が昇り、もう一方の側には悪魔（エジプトの悪神テュポン）が降りていく。前者はカドゥケウスを、後者は三叉の矛を持っている。どちらの姿も車輪に縛りつけられている。その上には、車輪の釣りあいの点にスフィンクスがいて、獅子の爪のあいだに抜き身の剣をはさんでいる。

**15　悪魔**　宇宙の上の立方体に、山羊の頭をした、サテュロスのような姿が座している。額には、頂点を上にした五芒星をつけていて、それを光の象徴にしている。一方の手は上の満ちていく月のしるしを、もう一方の手は下の欠けていく月のしるしを指していて、こうして慈悲と正義との永遠の釣りあいを象徴している。それぞれの手は、祝福のしるしを与えるときのように、親指と最初の二本の指を伸ばしている。一方の腕は女のもの、もう一方は男のものである。両の角のあいだには、普遍の釣りあいの魔術の光として、知性の松明が置かれている。生殖器の場所を占めるカドゥケウスは、生命の永遠を意味する。腹は、水を表すために鱗におおわれている。その上の円は大気である。翼は揮発するものの象徴である。そして、ゆがんだ山羊のような足は、大地を踏んでいる。

### むすび

　紙幅がないので、この主題にこれ以上立ち入ることはできない。じつのところ、この主題については、何巻もの書物を書いても書きつくせないだろう。私はただ、この短い論考が、タロット・カードの深遠な意味と、それを占いに使う方法について、読者にいくらかの考えを与えるのに足りることを願うばかりである。

### 訳注

- 原文では「悪魔」の番号が「12」となっているが、序論の表や「各鍵の象徴」の節では15なので、誤りとみなして15とした。
- 365日の計算で、「四つのスートの数札の目の数＝220」は、エースから十までの目の合計55を四倍したもの。「絵札の目の数＝12」は、絵札を一枚1と数えたもの。
- 「トートの書」は、エジプトの知恵の神トート（ギリシアのヘルメース）が書いたとされる伝説の書物。タロットをこれと同一視したのは、クール・ド・ジェブランの協力者ド・メレ伯爵が最初とされる。
- 『セフェル・イェツィラー』（形成の書）は、古代末期から中世初期に書かれたとされる、ユダヤ神秘主義の最古の書物のひとつ。ウィリアム・ウィン・ウェストコット（1848〜1925年）の英訳は1887年に出た。ウェストコットはマサースとともに黄金の夜明け団を創立した。ピストリウス（ヨハン・ピストリウス、1546〜1608年）は、カバラ関係の著作を集めた『カバラの術』（1587年）を編んだ。
- クラタ・レポアは、十八世紀末のドイツで出版された、古代エジプトの秘儀の入門儀式を描いたとする書物。ポール・クリスティアン（1811〜1877年）は、その『魔術の歴史』（1870年）で、タロットの切り札をその儀式の中で説明される絵として語った。マサースはクリスティアンをレヴィの弟子と書いているが、直接の師弟関係があったかどうかははっきりしない。
- ウリムとトンミムは、旧約聖書で大祭司が神意を問うために胸当てに入れていたとされる道具（出エジプト記28章30節）。
- エゼキエルの車輪は、エゼキエル書1章の、ケルビムとともに現れる車輪の幻による。
- テュポンは、ギリシア人がエジプトの神セトと同一視した怪物。
- レヴィの「悪魔」の像は、『高等魔術の教理と祭儀』（1856年）の口絵にあるバフォメットの図として知られている。
