## タロットの遊び方

　これらのタロット・カードは、占いのほかに、普通のカードと同じようにゲームにも使うことができる。そこで、その一般的な規則と遊び方を示しておくのもよいだろう。タロットのゲームは、二人でも三人でも遊べる。七十八枚全部の組を、普通のやり方で切ってカットする。親は、五枚ずつ三つの手に配り、残りの三枚を自分の右側に置く。こうして、二十五枚ずつの手が三つと、ほかに三枚ができる。各プレーヤーは手札を整理し、親は、自分の手のうち最も役に立たない三枚を捨てて、先ほどの三枚と取りかえる。親は、プレーヤーが順番に務める。配り方は、二人で遊ぶときも三人で遊ぶときも同じで、どちらの場合も三つの手を配る。ただし、二人だけで勝負するときは、三つ目の手にはどちらも手をつけない。

　ゲームを決める点数は百点で、クリベッジの盤や紙、あるいは普通のベジークの点数計で記録すればよい。

### 手の中の役

　手札を出して勝負する前に、手札の得点を次のように数える。

　二十二枚の切り札は、すべてが同じ値打ちではない。

　二十一、二十、十九、十八、十七を「五枚の大切り札」と呼ぶ。

　一、二、三、四、五を「五枚の小切り札」と呼ぶ。

　手の中に大切り札を三枚、あるいは小切り札を三枚もっている者は、それで五点を得る。四枚なら十点、五枚全部なら十五点である。どれでも切り札を十枚もっていれば十点、十三枚なら十五点になる。すでに得点した大切り札や小切り札が、その十枚や十三枚の中に含まれていてもかまわない。どの得点も、ほかの組み合わせとは無関係である。さらに、どのカードで得点するにも、得点するときに相手に見せなければならない。この規則はすべての場合にあてはまる。親でない者が先に得点し、先に打ちだす。三人で遊ぶときは、親の左側の者からはじめる。

　七枚のカードが、「タロット切り札」という特別な呼び名をもっている。それは次のとおりである。

　宇宙（二十一）、マットすなわち愚かな男（0）、パガドすなわち手品師または魔術師（一）、王笏の王、杯の王、剣の王、ペンタクルの王。

　プレーヤーは、これらのタロット切り札のうち二枚をもっていれば、相手に三枚目を求めることができる。相手が三枚目のタロット切り札を見せて応じられなければ、求めた者は五点を得る。だが相手が三枚目をもっていれば、それを求めた者に渡さなければならない。その場合、求めた者は得点せず、代わりに値打ちの低いカードを一枚、相手に渡す。実際に手の中にもっているタロット切り札三枚ごとに、もち主は十五点を記録する。

　切り札、あるいは同じスートのカードの続き番号（シークエンス）も数える。続き番号四枚ごとに五点、七枚ごとに十点、十枚で十五点である。これらの得点をなすカードは、すべて相手に見せなければならない。

### 札の出し方

　0の「愚かな男」は、手札を出して勝負するときには、組の中で最も低いカードである。どのスートのカードも取ることができず、どのスートのカードに対しても出すことができる。たとえば、相手が王を打ちだし、自分の手にはそのスートの女王しか残っていないが、0ももっている場合、女王の代わりにこれを出して、女王が取られるのを防ぐことができる。カットで王が出たら、それをカットした者に五点が入る。どのスートでも王が最も高く、次に女王、騎士、ジャック、十、九、というように続き、エースが最も低い。エースは0しか取ることができない。切り札は、最も高い二十一から、最も低い一まで数える。出せるなら同じスートを出さなければならない。出せなければ切り札を出してもよい。取ったトリック（一回ごとの勝負で取った札の組）は、後で数えるために、それぞれ分けておくこと。もちろん、プレーヤーがいちばん気をつけるべきことは、自分の大事なカードを守り、相手の大事なカードを取ることである。トリックを取った者が次に打ちだす。手札を全部出しおえたら、双方のトリックを次のように数える。

　タロット切り札の入ったトリックごとに五点（0はもとの持ち主に数え、パガド〔一〕は、それを取った者に数える）。女王の入ったトリックごとに四点、騎士なら三点、ジャックなら二点、そのほかのトリックごとに一点。

　各回の終わりに、各プレーヤーの得点を別々に合計し、少ないほうを多いほうから引いて、運のよかったほうのプレーヤーの超過点だけを記録する。毎回同じようにして、こうして先に百点に達した（あるいは最後の回で百点を超えた）プレーヤーが、ゲームに勝つ。

### 得点表

　読者の便宜のために、得られる得点の表をつけておく。

| 手の中で得点するもの | 点 |
|---|---|
| 大切り札を3枚もっている | 5 |
| 大切り札を4枚もっている | 10 |
| 大切り札を5枚全部もっている | 15 |
| 小切り札を3枚もっている | 5 |
| 小切り札を4枚もっている | 10 |
| 小切り札を5枚全部もっている | 15 |
| 切り札を10枚もっている | 10 |
| 切り札を13枚もっている | 15 |
| タロット切り札2枚で三枚目を求め、相手が応じられない | 5 |
| タロット切り札を実際に3枚もっている | 15 |
| 4枚の続き番号ごとに | 5 |
| 7枚の続き番号ごとに | 10 |
| 10枚の続き番号ごとに | 15 |

| 勝負の中で得点するもの | 点 |
|---|---|
| カットで王が出た | 5 |
| タロット切り札の入ったトリックごとに | 5 |
| 女王の入ったトリックごとに | 4 |
| 騎士の入ったトリックごとに | 3 |
| ジャックの入ったトリックごとに | 2 |
| 普通の札二枚のトリックごとに | 1 |

　三人で勝負するときは、もちろん、三人目のプレーヤーがゲームのもうひとつの要素になる。その場合、同じ回で三人がそれぞれの得点をくらべたら、いちばん多い者だけが得点し、それも二番目の者を上まわった分だけを得点する。ほかのプレーヤーはまったく得点しない。

### 訳注

- クリベッジとベジークは、どちらも十九世紀のイギリスで広く遊ばれたトランプ・ゲーム。クリベッジは穴のあいた板にピンをさして得点を数え、ベジークには専用の点数計があった。
- このゲームは、イタリアやフランスで遊ばれていたタロッキ（タロック）の遊び方を、簡略にしたもの。本来のタロットは、占いよりも前に、何世紀にもわたってこのようなトリック・テイキング・ゲームのカードとして使われていた。
