# 仕事と日　用語集

ヘーシオドス『仕事と日』の訳で用いた主な訳語。神名は ../theogony/神統記_用語集.md も見てください。

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ἔργα καὶ Ἡμέραι | 仕事と日 | 書名。「仕事」は農作業を中心とする労働、「日」は月の日ごとの吉凶。 |
| Πέρσης | ペルセース | ヘーシオドスの弟。 |
| Ἔρις | エリス（争い） | 悪い争いと、よい競争心の二つがあるとされる。 |
| δίκη / Δίκη | 正義／ディケー | 正しい裁き。擬人化された女神。 |
| ὕβρις | 傲慢（ヒュブリス） | 度を越した無法なふるまい。 |
| αἰδώς / Αἰδώς | 慎み、恥じらい／アイドース | 人を正しく保つ恥の感覚。擬人化もされる。 |
| νέμεσις / Νέμεσις | 義憤／ネメシス | 不正に対する怒り。 |
| ἀρετή | 徳（アレテー） | すぐれていること。汗の先にあるとされる。 |
| κακότης | 悪（カコテース） | たやすく手に入る悪いあり方。 |
| πίθος | 甕（ピトス） | パンドーラーが開けた大きな貯蔵甕。 |
| Ἐλπίς | エルピス（希望） | 甕の中に残ったもの。 |
| γένος | 種族、時代 | 黄金・銀・青銅・英雄・鉄の五つ。 |
| ἡμίθεοι | 半神（ヘーミテオイ） | 英雄の種族。 |
| μακάρων νῆσοι | 至福の者たちの島々 | 英雄たちが住む大地の果ての島。 |
| δαίμονες | ダイモーン（神霊） | 黄金の種族の死後の姿。 |
| Πληιάδες | プレイアデス（すばる） | 刈り入れと耕作の時を告げる星団。 |
| Σείριος | シリウス | 夏の暑さの星。 |
| Ἀρκτοῦρος | アルクトゥーロス | 春と秋の時を告げる星。 |
| Ὠαρίων | オーリーオーン | 脱穀とぶどうの収穫の時を告げる星座。 |
| Ληναιών | レーナイオーンの月 | 冬の最も寒い月。 |
| ἄροτρον | 犂 | 牛に引かせて畑を耕す道具。 |
| καιρός | 時宜（カイロス） | ちょうどよい時。 |
| φήμη | うわさ（ペーメー） | 神ともされる、人々の言いならわし。 |
