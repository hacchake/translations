# 名高きマカリア王国の記（ガブリエル・プラッツ）　作業メモ

[Gabriel Plattes]『A Description of the Famous Kingdome of Macaria』（1641年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Project Gutenberg 第55269番の本文を `src/pg55269.txt` に置いた。
- 下書き `draft/n1.md`（扉・議会への献辞・対話）と解説 `draft/head.md` から、`_build.py` で全訳と note 用原稿1本を生成した（約1万字）。
- 図版：グーテンベルク版には飾り罫しかなく、1641年版の扉の画像も見つからなかったので、図版は入れていない。
- 対話の話者は原文の Traveller / Schollar を「旅人」「学者」とした。原文で「学者」の発言が二度続く箇所は、そのまま訳して〔　〕で示した。
- 原文のまま訳したところ：「grat facilitie」（great の誤植）。ヒエロニムスのラテン語の引用は訳し、〔原文はラテン語〕と示した。
- 作者：刊行時は無署名。長くハートリブの作とされたが、チャールズ・ウェブスターらの研究によりプラッツの作とされている。解説にはこの通説を書いた。
- 日本語訳の有無：2026年11月7日に extended 検索と国立国会図書館サーチで調べた範囲では見つからなかった（田村秀夫『イギリス革命とユートウピア』に論及がある）。
- 著作権：プラッツは1644年没。日本・英国・米国で保護期間満了。
