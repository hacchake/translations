# 哲学者の天ほか（パラケルスス）　作業メモ

ウェイト英訳『The Hermetic and Alchemical Writings of Paracelsus』第一巻（1894年）の巻頭五篇（『哲学者の天』『哲学者のチンキについての書』『金属の階梯』『錬金術師のための宝の中の宝』『金属と膠剤との変成』）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の Google 版 `hermeticandalch00paragoog` の djvu.txt を主に使い（コーネル大学版 `cu31924092287121` の OCR は右端が欠けるページがある）、3〜47ページを `src/pc.txt` に切り出した（.gitignore で除外。全文は `../_para/` に置き、これも除外）。
- コーネル版のページ画像は n = ページ + 21。扉（n8）を `images/title-1894.jpg` として切り出した。注の崩れた出典名（De Colica、De Aridura、Explicatio Totius Astronomiae、De Caduco Matricis、De Icteritiis、De Membris Contractis、De Morbis Vermium、De Praeparationibus Lib. I Tract 2）、「hearty」「Kybrick」「Aliocosoph」「Iamen」はページ画像で確かめた。サファイアの注の「clay-like hue」は Google 版 OCR の「day-like」とコーネル版画像の行頭「cl」から読んだ。
- ウェイトの注（本文の下の *、† など）は各下書きの末尾に〔注1〕〜〔注41〕として通し番号で訳した。〔注27〕は『ヘルメスの黙示』の全文で、数ページの脚注にまたがって組まれているのをつないだ。
- 原文のままとして注記した箇所：第六の規範で処女宮が二度、第七の規範でウェヌスが二度出る。『宝の中の宝』の「水と土」（前の工程からは「水と空気」）。不詳の語「thucia」「Zifferbrunnen」「or -er Quartal」「Iamen」「Alumen Aochi」「Isteris of Blood」。
- 下書き `draft/n1.md`〜`n4.md` と解説 `draft/head.md` から、`_build.py` で全訳と note 用原稿2本を生成した。
- 日本語訳の有無：2026年11月9日に Web 検索（extended）と NDL サーチで調べた範囲では、これら五篇の邦訳は見つからなかった。既刊のパラケルスス訳（工作舎『奇蹟の医書』『奇蹟の医の糧』、ホメオパシー出版『アルキドクセン』など）は別の著作。
- 著作権：パラケルススは1541年没、ウェイトは1942年没。日本・英国・米国で保護期間満了。
