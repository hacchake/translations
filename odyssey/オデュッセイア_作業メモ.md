# オデュッセイア　作業メモ

ホメロス『オデュッセイア』のギリシア語原典からの全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- 底本：Homer, The Odyssey, with an English translation by A. T. Murray, 2 vols., Loeb Classical Library（1919年）のギリシア語本文。
  - ペルセウス計画のデジタル版（TEI XML）を使った。
  - 入手先：https://github.com/PerseusDL/canonical-greekLit の tlg0012.tlg002.perseus-grc2.xml
  - XML の編者欄は Augustus Taber Murray。マレーは1940年没で、日本でも米国でも保護期間が満了している。
- 作業の手順：
  - XML から歌ごとに行番号つきの本文を書き出した。全24歌、12,107行。
  - 1歌ずつ下書き（`draft/b01.md`〜）に訳した。
  - 4歌ずつまとめて全訳ファイル（`オデュッセイア_0N_第…歌.md`）と note 用原稿（`note用/`）を `draft/_build.py` で生成する。

## 構成と note への投稿

- 『イーリアス』と同じく、4歌ずつ6本の記事にまとめる。
  - 第一〜四歌、第五〜八歌、第九〜十二歌、第十三〜十六歌、第十七〜二十歌、第二十一〜二十四歌。
- 最後に、各歌の要約と各記事へのリンクをまとめた記事を1本作る。
- 投稿の状況：
  - 第一〜四歌：未投稿（note の1日の投稿数の上限に達していたため。下訳と記事原稿は完成）。
  - 第五〜八歌：未投稿（同じ理由。下訳と記事原稿は完成）。
  - 第九〜十二歌：未投稿（同じ理由。下訳と記事原稿は完成）。

## 訳の方針

- 『イーリアス』の訳と同じ方針をとった。
- **原典から直接訳す**：既存の日本語訳は参照していない。
- **文体**：「である」調の散文訳。韻文の行分けはしない。
  - 段落の頭に［1］などの形で原典の行番号を付けた。
  - 段落は、話者の交代と場面の区切りで分けた。
  - 会話は、話し手と相手の関係に合わせて口調を変えた（テーレマコスは目上には「です・ます」、求婚者には「だ」調など）。
- **決まり文句（エピテトン）**：「きらめく目の女神アテーナー」「思慮深いテーレマコス」「ばら色の指の曙」など、繰り返しを含めて省かずに訳した。
- **繰り返しの場面**：同じ言葉の繰り返し（第一歌のアテーナーの助言と第二歌のテーレマコスの言葉、第三歌と第四歌のテーレマコスの頼みなど）も省略せず、毎回同じ訳文で訳した。
- **固有名詞**：ギリシア語の発音に近い片仮名で、長音を示した。日本語で定着している名は慣用に従った（ゼウス、トロイア、ホメロスなど）。『イーリアス』の訳と表記をそろえた。
- **歌の題と小見出し**：原典にはない。訳者が付けた。

## 判断した箇所

- 第一歌1行の πολύτροπος：「多くの方向に向く」の意で、「さまよい歩いた」とも「機略に富む」とも取れる語。直後に「多くの地をさまよった」が続くので、重ならないよう「機略に富む」とした。
- 第一歌320行の ἀνόπαια：「天窓から」「上へ」「見えないように」、あるいは鳥の名など、意味が定まらない。場面に合う「天窓から」をとり、訳注で他の説にふれた。
- 第二歌・第一歌の ἔεδνα（贈り物・結納）：花婿が花嫁の家に贈るものか、花嫁の家が持たせるものか、解釈が分かれる。原文の「いとしい娘に添えてやる」に従って訳した。
- 第三歌304〜305行：底本では行の順序が入れ替わっている（305行が先）。底本の並びのまま訳した。
- 第四歌1行の κητώεσσα：「谷の多い」とした。「海獣の多い」とする古い解釈がある。
- 第四歌221行の νηπενθές：「悲しみを消す」とした。後世の「ネペンテ」の語源。

- 第五歌281行の ῥινός：「盾のように」とした。「皮」「牛皮の盾」の意で、霧の中に浮かぶ島の形のたとえと取った。
- 第七歌107行：「目のつまった亜麻布からオリーブ油がしたたる」の意味は確定しない。原文の字面のまま訳し、訳注で二つの解釈にふれた。
- 第八歌111行以下の若者の名：船と海にちなむ名がほとんどなので、訳文では片仮名にとどめ、訳注で意味を示した。

- 第九歌366行の Οὖτις：名を「ダレデモナイ」と訳し、仲間のキュクロープスの返事（μή τις）を「誰でもないのが」として、言葉遊びが日本語でも通じるようにした。訳注で原語にふれた。
- 第十一歌134行の ἐξ ἁλός：「海から離れて」と取った。「海から来る（死）」とする解釈もあり、訳注で両方にふれた。
- 第十一歌568〜627行（冥界の裁きと罰を受ける者たち）：後の挿入とする説が古くからあるが、底本にあるので省かずに訳し、訳注で説にふれた。
