# オデュッセイア　用語集

ホメロス『オデュッセイア』の訳で用いた主な訳語と人名・地名の一覧。『イーリアス』と共通する語は、『イーリアス』の訳と同じ訳語を用いた。

## 人名（人間）

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ὀδυσσεύς | オデュッセウス | イタケーの王。トロイア戦争ののち、十年さまよう。 |
| Τηλέμαχος | テーレマコス | オデュッセウスの息子。添え名は「思慮深い」（πεπνυμένος）。 |
| Πηνελόπεια | ペーネロペイア | オデュッセウスの妻。イーカリオスの娘。添え名は「思慮深い」（περίφρων）。 |
| Λαέρτης | ラーエルテース | オデュッセウスの父。町を離れて野で暮らす。 |
| Εὐρύκλεια | エウリュクレイア | テーレマコスの乳母。オープスの娘。 |
| Ἀντίνοος | アンティノオス | 求婚者の頭の一人。エウペイテースの子。 |
| Εὐρύμαχος | エウリュマコス | 求婚者の頭の一人。ポリュボスの子。 |
| Μέντωρ | メントール | オデュッセウスの友。アテーナーがその姿を借りる。 |
| Μέντης | メンテース | タポス人の首領。第一歌でアテーナーがその姿を借りる。 |
| Φήμιος | ペーミオス | イタケーの歌い手。求婚者たちのために歌わされている。 |
| Μέδων | メドーン | イタケーの伝令。 |
| Ἁλιθέρσης | ハリテルセース | 鳥占いにすぐれた老人。 |
| Νοήμων | ノエーモーン | プロニオスの子。テーレマコスに船を貸す。 |
| Νέστωρ | ネストール | ピュロスの老王。添え名は「ゲレーニアの騎士」。 |
| Πεισίστρατος | ペイシストラトス | ネストールの末の息子。テーレマコスに付き添う。 |
| Μενέλαος | メネラーオス | スパルテーの王。アガメムノーンの弟。添え名は「金髪の」。 |
| Ἑλένη | ヘレネー | メネラーオスの妻。ゼウスの娘。 |
| Ἀγαμέμνων | アガメムノーン | ミュケーネーの王。帰国してすぐに殺される。 |
| Αἴγισθος | アイギストス | アガメムノーンを殺した男。添え名は「悪だくみの」。 |
| Ὀρέστης | オレステース | アガメムノーンの息子。父の仇を討つ。 |
| Κλυταιμνήστρη | クリュタイムネーストラー | アガメムノーンの妻。 |

## 神々・海の老人

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ἀθήνη | アテーナー | ゼウスの娘。オデュッセウスとテーレマコスを守る。添え名は「きらめく目の」（γλαυκῶπις）。 |
| Ποσειδάων | ポセイダーオーン | 海の神。息子ポリュペーモスの目をつぶされたことで、オデュッセウスに怒っている。 |
| Ἑρμείας | ヘルメイアース | 神々の使者。添え名は「アルゲイポンテース」。 |
| Καλυψώ | カリュプソー | アトラースの娘のニンフ。オーギュギエーの島にオデュッセウスを引きとめる。 |
| Πρωτεύς | プローテウス | 姿を変えて逃れる海の老人。「偽りを言わぬ海の老人」。 |
| Εἰδοθέη | エイドテエー | プローテウスの娘。メネラーオスを助ける。 |
| Ἠώς | 曙（エーオース） | 朝の女神。「朝早く生まれる、ばら色の指の曙」は定型の句。 |

## 地名・民族名

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ἰθάκη | イタケー | オデュッセウスの国の島。 |
| Ὠγυγίη | オーギュギエー | カリュプソーの島。 |
| Πύλος | ピュロス | ネストールの国。添え名は「砂の多い」。 |
| Σπάρτη / Λακεδαίμων | スパルテー／ラケダイモーン | メネラーオスの国。 |
| Αἴγυπτος | アイギュプトス | エジプト、またナイル川。 |
| Φάρος | パロス | エジプト沖の島。メネラーオスがプローテウスを捕らえる。 |
| Ἠλύσιον πεδίον | エーリュシオンの野 | 大地の果ての楽園。 |
| Ἀχαιοί / Ἀργεῖοι / Δαναοί | アカイア人／アルゴス人／ダナオイ人 | いずれもギリシア人の総称。原文のとおりに訳し分けた。 |
| Τάφιοι | タポス人 | タポス島の人々。「櫂を好む」。 |

## そのほかの語

| 原語 | 訳語 | 説明 |
|---|---|---|
| μνηστῆρες | 求婚者たち | ペーネロペイアに求婚して、オデュッセウスの家に入りびたる若者たち。 |
| νόστος | 帰国 | この作品の中心となる語。 |
| ξεῖνος | 客人 | 客人をもてなし、贈り物を交わす間柄。「父の代からの客人」は、家どうしの代々のつきあい。 |
| κρητήρ | 混酒器 | ぶどう酒を水で割るための大きな器。 |
| ἑκατόμβη | 百頭の供物 | 多くの牛を供える大きな供犠。 |
| πεπνυμένος | 思慮深い | テーレマコスの定型の添え名。 |
| ὄσσα | 噂（オッサ） | 人々のあいだに広まる、ゼウスから来るとされる噂。 |
| νηπενθές | 悲しみを消す（薬） | ヘレネーがぶどう酒に入れたエジプトの薬。 |
