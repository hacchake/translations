# アーリア人の知恵（アラン・ベネット）　作業メモ

Allan Bennett (Ananda M.)『The Wisdom of the Aryas』（1923年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の `wisdomofaryas00anan`（1923年初版、プリンストン神学校図書館蔵本のスキャン）から、OCRテキスト `src/djvu.txt` とPDF `src/scan.pdf` を取った。`_clean.py` で柱と頁番号を除き、段落ごとに整形して `src/clean.txt` にした。柱が段落の中に残ったところは訳すときに読み飛ばした。第七章の見出しはOCRで落ちていたので、目次に従って補った。
- 扉の画像（`images/title-1923.jpg`）はPDFの7頁目から切り出した。
- 下書き：`draft/n1.md`（献辞・序論）、`n2.md`〜`n8.md`（第一章〜第七章）。解説は `draft/head.md`。`_build.py` で全訳と note 用原稿3本（第一回 n1〜n3、第二回 n4〜n6、第三回 n7〜n8）を生成した。
- 仏教の用語は、パーリ語の片仮名表記と漢訳の術語とを併記した（例：アニッチャ（無常）、ジャーナ（禅那）、四梵住）。原文の Aryan は「アーリアの」「アーリア人」と訳し、四聖諦は「四つのアーリアの真理」とした。著者がアーリヤ（聖なる）と人種論の「アーリア人種」とを重ねて論じているため。
- 当時の人種観・女性観を含む記述は原文どおりに訳し、解説でふれた。
- 原文のまま訳し、〔原文 X〕などと示したところ：序論の「utteily」「underest ood」「Train-cells」「lusus nature?」「repetional」、第一章「tir」「impassionate」「wTesiern」「Tire」、第二章「soliptic」「immensly」「Lane」、第三章「三百万キロメートル」（実際は三十万）「Hither」「Sign at a」「prefect」、第四章「Ko」「sejf-same」「^ee」「shoit」、第五章「froyn」「tenative」「sympton」「wonder」「object」「comp1 ex」、第六章「ovei whelming」「overcast that which had been set up」「awfogravitational」「正の電子」「Ecstacy」「erst-while while」、第七章「he」「Thompson」「Na ca So ; na ca Anno」。
- 引用：エドウィン・アーノルド『アジアの光』の四行（第三章）は訳者が訳した。燃焼経、七仏通戒偈、大般涅槃経の引用はベネットの英訳から訳した。
- 日本語訳の有無：2026年11月7日に extended 検索と国立国会図書館サーチで調べた範囲では見つからなかった。
- 著作権：ベネットは1923年没。日本・英国・米国で保護期間満了（原著1923年刊、米国でも保護期間満了）。
