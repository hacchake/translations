# 宇宙意識　作業メモ

リチャード・モーリス・バック『宇宙意識』（1901年初版、底本は1905年版）の全訳の作業記録。原本との照合、判断が必要だった箇所、注意点をまとめる。note の記事本文には含めない。

## 底本と作業の手順

- 底本：Internet Archive の1905年版スキャン（cosmicconsciousn01buck）。同サイトの文字起こし（djvu テキスト）を基本とし、文字起こしが崩れている箇所はページ画像（`page/n{番号}_w600.jpg`、印刷ページ＋23 が画像番号）で確認した。
- 1905年版は1901年初版と同じ組版の再刷とみられる（扉裏の著作権表示は1901年）。
- 訳は部・章ごとに下書き（`draft/`）を作り、最後に部ごとの完成版（`宇宙意識_0N_第N部.md`）と note 用原稿（`note用/`）を生成した。

## 文字起こし（OCR）の問題と、画像で確認した箇所

- **第二部第二章の図と表**：色の名と色の感覚を示す図（画像 n53）と、心の能力の出現時期を示す表（十三項目、画像 n66）は、OCR では読めなかったため、画像から起こした。
- **第三部の四十三事例の表**（画像 n90〜92）：画像から起こした。
- **欄外の注釈**：原著では、引用を本文側に、バックの対照箇所や注釈を欄外の別欄に組んだページが多い（第四部第八章のイエペス、第九章のベーコンのソネット、第十章のベーメ、第十一章のブレイク、第十二章のバルザック、第五部の多くの章）。OCR では両者が行単位で混ざっているため、内容から切り分け、注釈を〔　〕に入れて対応する引用の後に置いた。
- **ソネット第五十三番**：OCR では詩の本文が第五十五番の注釈の後に来ていたが、原著の配置どおり第五十三番の位置に戻した。
- **ゴシック体の飾り文字**：第五部第十章（ガーディナー大佐）と第十一章（スヴェーデンボリ）の神の言葉は OCR で崩れていたため、一般に伝わる文言から訳した。
- **引用書目録の1〜27番**：OCR で番号と書名が分かれていたため、内容から番号を当てた（13番は原著でも見当たらない）。
- **献辞**：目次には「献辞（v ページ）」とあるが、底本のスキャンには該当ページがない。扉の前にバックの肖像写真と自筆署名があるだけである。

## 原文の誤りと思われる箇所（訳で改めたもの・訳注で示したもの）

- 第五部第八章、パスカルの生没年 "1623-1772" → 1662 に改めた。
- 第四部第七章、セビリャ攻略の年「一二五二年」（実際は一二四八年）→ 原文のまま訳し、訳注で指摘。
- 第四部第九章、要約の "Hawley" → ローリー（Rawley）と読んだ。
- 第六部、照明の季節の事例数（「十七例」）が第一部・第四部の数字（二十例中十五例）と合わない → 本文は原文の構文を生かして訳し、訳注で指摘。
- 聖書の参照番号の誤り：たとえば第四部第十一章の［14、12:50］（実際はヨハネ）、［16、15:18］（実際はローマ）、［12、9:48］（実際はマルコ）。目録の番号（11 出エジプト記、12 士師記、14 マタイ、15 マルコ、16 ルカ、17 ヨハネ、18 使徒言行録、19 ローマ、20 コリント一、21 コリント二、22 ガラテヤ、23 エフェソ、24 フィリピ、25 コロサイ、26 テサロニケ一、27 黙示録）と照らして、訳注で指摘した。
- 第六部、ギュイヨン夫人の出典［180］は目録ではティンダルの著作であり、番号の誤り。
- ホイットマンの句の出典［197］［102］など、明らかに［193］の誤植とみられるものは訳注で指摘した。

## 判断が必要だった箇所

- **聖書・コーランなどの引用**：バックは英語改訂訳聖書（1881〜85年）とパーマー英訳コーラン（1880年）などから引いている。日本語の既存の聖書訳（口語訳、新共同訳、聖書協会共同訳など）やコーラン訳は著作権のあるものが多いため、それらの文言を用いず、原著の英文から新たに訳した。定まった言い回しに近づきすぎないよう、語句を選んだ。
- **詩の引用**：ホイットマン、シェイクスピアのソネット、ダンテ（ノートン英訳）、ワーズワース、テニスン、プーシキン（デイナ英訳）、十字架の聖ヨハネ（ルイス英訳）、老子（レッグ英訳）なども、既存の日本語訳を用いず、原著の英文から訳した。原語の原典からの訳ではない。
- **第四部第四章プロティノスの「フラックスへの手紙」**：ヴォーンが『神秘家たちとの時間』で創作した書簡で、プロティノス自身のものではない。訳注で指摘した。
- **第四部第九章のベーコン＝シェイクスピア説**：今日の学界では支持されていない説だが、バックの議論として忠実に訳し、訳注で学界の現状を示した。
- **人種・障害・遺伝についての記述**：第一部〜第三部、第六部などに、人種の序列づけ、「白痴」「痴愚」などの語、両親の気質と遺伝についての推測など、今日では受け入れられない記述がある。原著の歴史的な性格を示すものとして忠実に訳し、訳注で批判的に注記した。
- **ステイントン・モーゼズの浮揚現象**（第六部）：心霊研究の報告からの引用として訳し、訳者はその真偽について立場をとらない。
- **第五部の頭文字の人物**：J・B・B、C・M・C などの人物の特定は、一般によく知られているもの（J・W・W＝J・W・ウォレス、C・P＝ケイレブ・ピンク）を除いて試みなかった。

## 表記の方針

- 文体はである調。原語は初出に（　）で示した。
- バックの対照箇所・注釈は〔　〕、バック自身の脚注は（注n）、各章末に「訳注」を置いた。
- 人名は原語に近い日本語の慣用表記に統一した（フアン・デ・イエペス、ヤーコプ・ベーメ、ムハンマド、スヴェーデンボリなど）。原文の英語化された綴り（John Yepes、Behmen、Mohammed）は用語集に示した。
- 原文の角かっこ内の参照番号［番号、ページ］はそのまま残した。番号は前付けの引用書目録に対応する。

## 残っている課題

- 一部の引用の出典（目録にない番号［76a］［125a］など）は特定できていない。
- 欄外の注釈の位置は内容から推定したもので、ページ画像と一行ずつ照合したわけではない。
