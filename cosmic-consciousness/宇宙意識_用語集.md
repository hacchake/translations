# 宇宙意識　用語集

リチャード・モーリス・バック『宇宙意識』（1901年）の訳で用いた主な訳語と人名の一覧。

## 中心となる用語

| 原語 | 訳語 | 説明 |
|---|---|---|
| Cosmic Consciousness | 宇宙意識 | 本書の主題。宇宙（コスモス）の生命と秩序を直接に意識する、自己意識より一段高い意識。 |
| Cosmic Sense | 宇宙的な感覚 | 宇宙意識をもたらす新しい能力を、感覚の一つとして呼ぶときの語。 |
| Self Consciousness | 自己意識 | 自分を一個の存在として意識する、人間に固有の意識。 |
| Simple Consciousness | 単純意識 | 身のまわりの物事と自分の体を意識する、高等動物と共通の意識。 |
| Cosmos | 宇宙（コスモス） | 生きた秩序ある全体としての宇宙。 |
| illumination | 照明 | 宇宙意識が訪れる出来事。 |
| the illumined / illuminati | 照明された人々、照明者 | 宇宙意識に入った人々。 |
| subjective light | 主観的な光 | 照明の際に本人が体験する、内から来る光。 |
| moral elevation | 道徳的な高揚 | 照明に伴う道徳的な高まり。 |
| intellectual illumination | 知的な照明 | 照明に伴う知性の高まり。 |
| sense of immortality | 不死の感覚 | 永遠の生命をすでにもっているという感覚（信仰とは区別される）。 |
| transfiguration | 変貌 | 照明の際の外見の変化。福音書のイエスの変貌にちなむ。 |
| Brahmic Splendor / Brahmic Bliss | ブラフマンの輝き／ブラフマンの至福 | 宇宙的な見神とその喜び。『アヌギーター』の英訳から取った語。 |
| Nirvana | 涅槃 | バックは宇宙意識の仏教での名とみなす。 |
| Arahatship | 阿羅漢の境地 | 同じく仏教での宇宙意識の呼び名とみなされる。 |
| kingdom of God / of heaven | 神の国／天の国 | バックは宇宙意識のキリスト教での呼び名とみなす。 |
| Christ | キリスト | パウロの用法として、宇宙的な感覚を指すとバックは解する。 |
| specialism / specialist | スペシャリズム／スペシャリスト | バルザック『ルイ・ランベール』の語（spécialité）。バックは宇宙意識と同一視する。 |
| abstraction / instinct | 抽象／本能 | 同じくバルザックの語。それぞれ自己意識・単純意識に当たる。 |
| twilight | 薄明 | 宇宙意識の手前の、光は届くが太陽が昇らない状態（第五部）。 |
| duplex personality | 二重の人格 | 自己意識の自己と宇宙意識の自己が一人の中に並ぶこと。 |
| the other I am | もう一人の私 | ホイットマンの句。 |
| devolution | 退化 | 新しい能力から順に失われていくこと（第二部第三章）。 |
| percept / recept / concept | 知覚／受容表象／概念 | ロマーニズの心理学の用語。 |
| alalus homo | 言葉をもたない人（ホモ・アラルス） | 言語以前の人類の祖先。 |
| parallel passages | 対照箇所 | 原著で欄外や小さい活字で示される比較の引用。訳では〔　〕に入れた。 |
