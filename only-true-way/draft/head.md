# 【全訳】『唯一の真の道』（1677年、『ヘルメス博物館』所収、ウェイト英訳）

著者不詳／全訳

![『唯一の真の道』の扉（『ヘルメス博物館』英訳第一巻、1893年）](images/title-1893.jpg)

- 原題：The Only True Way; or, An Useful, Good, and Helpful Tract, pointing out the Path of Truth（1677年。ラテン語訳 Via Veritatis Unicae が1678年の『ヘルメス博物館』〔Musaeum Hermeticum〕増補版に収められ、A・E・ウェイトが1893年の英訳第一巻に収めた）
- 内容：作者は長年、尿・塩・明礬・毛髪・卵・強水などで石を作ろうとして失敗した経験を語り、「溶解・凝固・昇華・腐敗・循環」といった錬金術の用語は、じつはみな「おだやかな熱による煮熟」という一つの単純な過程の別名にすぎないと説く。「メルクリウス」は湿り気（液体）、「硫黄」は元素の火、黒・白・赤の色は黒い煙・白い煙・完全な煮熟を指すにすぎない、と古人たちの寓意をことごとく読みほどき、植物・動物・金属の違いを「煮熟の度合い」で説明する。同時代のパラケルスス派の編者アダム・フォン・ボーデンシュタインを名指しで批判するのも特徴である
- 作業の基にした本文と扉：Internet Archive 所蔵の1893年英訳第一巻のスキャン（OCR を画像と照合した）
- 著作権：原典は十七世紀、ウェイトは1942年に死去。日本・米国・英国で保護期間が満了している
- 訳者：人工知能（Claude Opus 5.5）
- 訳の性格：全文を訳した。訳者の調べたかぎりでは、日本語訳は出ていない

## この本について

　この小論は、『ヘルメス博物館』の一六七八年の増補版のために新たに加えられた文書の一つで、扉には一六七七年とある。作者の名は伝わらない。

　錬金術の文書の多くが、わざと曖昧な寓意で真理を隠すのに対して、この作者は「寓意の曖昧さからできるだけ自由な文体」で書くと宣言し、古人たちの比喩を一つずつ散文に置き換えていく。そのため、錬金術の用語の「種明かし」として読むことができる。もっとも、作者もまた「誓いによって」はっきりとは語れないと言い、肝心の「一つの物質」が何であるかは最後まで明かさない。

　本サイトで訳した『賢者の石についての黄金論文』『賢者たちの水石』『迷える錬金術師への自然の論証』と同じく、偽錬金術師への批判と「自然に従え」という教えが中心にある。そのなかでこの小論は、色の変化さえ寓意として退ける点で、もっとも徹底して「単純さ」を説いている。
