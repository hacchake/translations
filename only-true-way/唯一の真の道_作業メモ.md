# 唯一の真の道　作業メモ

『The Only True Way』（1677年、『ヘルメス博物館』英訳第一巻所収）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の `b24927363_0001`（The Hermetic Museum, vol. 1, 1893）の djvu.txt から本篇（149〜164ページ）を `src/otw.txt` に切り出した（.gitignore で除外）。扉（n164、「1677」とある）を `images/title-1893.jpg` として切り出した。
- OCR で崩れた副題は目次と扉の画像から復元した（An Useful, Good, and Helpful Tract, pointing out the Path of Truth）。
- 下書き `draft/n1.md` と解説 `draft/head.md` から、`_build.py` で全訳と note 用原稿1本を生成した。
- 原文の「(of perfection ?)」は英訳者の補いと疑問符をそのまま示した。
- 日本語訳の有無：2026年11月8日に extended 検索で調べた範囲では見つからなかった。
- 著作権：原典は17世紀、ウェイトは1942年没。日本・英国・米国で保護期間満了。
- 同じ巻のフラメル「A Short Tract, or Philosophical Summary」は既訳がある可能性が高い（有田忠郎訳『象形寓意図の書』白水社に「賢者の術概要」が入っていると記憶している。未確認）ので見送った。
