# ルーメン・デ・ルーミネ　作業メモ

トマス・ヴォーン『ルーメン・デ・ルーミネ』（Lumen de Lumine, 1651年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- 本文：Text Creation Partnership（EEBO-TCP）の電子テキスト A64767（GitHub textcreationpartnership/A64767、CC0、2026年11月4日取得）。TEI XML からテキストを取りだして `src/lumen_tcp.txt` に置いた。電子テキストで判読できなかった文字（gap）は〔欠〕と示されている。
- 扉絵「魔術の学校の図」（Scholae Magicae Typus、ロバート・ヴォーン彫版）は、ウェルカム・コレクション所蔵の初版本（b30340160、パブリックドメイン）のIIIFスキャンの50コマ目から切りだして `images/scholae_magicae_typus.jpg` に置いた。
- 日本語訳の有無：検索した範囲では見つからなかった。
- 下書き `draft/e1.md`〜`e8.md` と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿2本（前編 e1〜e3、後編 e4〜e8）を生成した。

## 本文の状態と訳の方針

- ヴォーンがラテン語原文と自分の英訳とを並べて掲げている引用（R・Cの兄弟たちの書簡、「真珠の川」の達人の描写、ルルスの引用など）は、英訳のほうだけを訳し、本文中でそう断った。ヴォーンが訳を添えていないラテン語（ボドリーへの詩、メクッバリームのあかし、魔術の箴言など）は、訳者がラテン語から訳した。
- ギリシア語・ヘブライ語の語句は電子テキストでほとんど欠けている。文脈から推定できるものは補い、できないものは〔欠〕とした。
- ボドリーへの詩は欠けた文字が多いが、ラテン語の韻律と文脈から補って訳した。
- 「である」調。タリアの言葉は「です・ます」調。献辞は「です・ます」調。
- 夢物語の部分と、原著で見出しのない部分には、訳者が小見出しを付けた。原著の見出し（The First Matter など）はそのまま訳した。
