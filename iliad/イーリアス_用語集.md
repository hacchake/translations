# イーリアス　用語集

ホメロス『イーリアス』の訳で用いた主な訳語と人名・地名の一覧。

## 民族名・地名

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ἀχαιοί | アカイア人 | ギリシア軍を指す最も一般的な呼び名。 |
| Δαναοί | ダナオイ人 | ギリシア軍の別名。伝説の王ダナオスにちなむ。 |
| Ἀργεῖοι | アルゴス人 | ギリシア軍の別名。 |
| Τρῶες | トロイア人 | トロイアの住民。援軍の諸民族とは区別されることがある。 |
| Ἴλιος | イーリオス | トロイアの町の名。作品の題『イーリアス』はここから。 |
| Τροίη | トロイア | 町、またその周りの土地。 |
| Πέργαμος | ペルガモス | トロイアの城山。アポローンの社がある。 |
| Σκαιαὶ πύλαι | スカイア門 | トロイアの西の門。多くの場面の舞台となる。 |
| Ἴδη | イーデー山 | トロイアの東南の山。ゼウスが戦場を見下ろす場所。 |
| Ὄλυμπος | オリュンポス | 神々の住む山。 |
| Σκάμανδρος / Ξάνθος | スカマンドロス川／クサントス川 | トロイア平野の川。神々の呼び名がクサントス。第二十一歌でアキレウスと戦う。 |
| Σιμόεις | シモエイス川 | トロイア平野のもう一つの川。 |
| Ἑλλήσποντος | ヘッレースポントス | 今のダーダネルス海峡。 |

## 神々

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ζεύς | ゼウス | 神々と人間の父。「雲を集める」「雷を投げる」などの決まり文句をもつ。 |
| Ἥρη | ヘーラー | ゼウスの妻。ギリシア方の味方。「白い腕の女神」。 |
| Ἀθήνη / Παλλὰς Ἀθήνη | アテーナー／パラス・アテーナー | ギリシア方の味方。「きらめく目の女神」。 |
| Ἀπόλλων / Φοῖβος | アポローン／ポイボス | トロイア方の味方。「銀の弓の神」「遠矢射る神」。 |
| Ἀφροδίτη | アプロディーテー | 愛の女神。パリスとアイネイアースを守る。 |
| Ἄρης | アレース | 軍神。トロイア方につく。 |
| Ποσειδάων | ポセイダーオーン | 海の神（一般にはポセイドーン）。ギリシア方の味方。「大地を揺るがす神」。 |
| Ἑρμείας / Ἀργεϊφόντης | ヘルメイアース／アルゲイポンテース | 神々の使い（一般にはヘルメース）。第二十四歌でプリアモスを導く。 |
| Ἥφαιστος | ヘーパイストス | 鍛冶の神。アキレウスの新しい武具を作る。 |
| Θέτις | テティス | 海の女神。アキレウスの母。 |
| Ἶρις | イーリス | 虹の女神。神々の使い。 |
| Ὕπνος / Θάνατος | 眠り／死 | 双子の兄弟神。 |
| Μοῖρα / αἶσα | 運命 | 人の定め。神々も容易には逆らえない。 |
| Κῆρ | 死の定め | 死をもたらす運命の霊。 |

## ギリシア方の人物

| 原語 | 訳語 | 説明 |
|---|---|---|
| Ἀχιλλεύς / Πηλεΐδης | アキレウス／ペーレウスの子 | ミュルミドーン人の王。物語の主人公。「足速い」。 |
| Ἀγαμέμνων / Ἀτρεΐδης | アガメムノーン／アトレウスの子 | ミュケーナイの王。ギリシア軍の総大将。「民の王」。 |
| Μενέλαος | メネラーオス | アガメムノーンの弟。ヘレネーの夫。 |
| Πάτροκλος | パトロクロス | アキレウスの親友。第十六歌で戦死する。 |
| Ὀδυσσεύς | オデュッセウス | イタケーの王。「知恵の多い」「忍耐強い」。 |
| Αἴας (Τελαμώνιος) | アイアース（大アイアース） | テラモーンの子。アキレウスに次ぐ勇士。大きな盾をもつ。 |
| Αἴας (Ὀϊλῆος) | アイアース（小アイアース） | オイーレウスの子。ロクリス人の将。 |
| Διομήδης / Τυδεΐδης | ディオメーデース／テューデウスの子 | アルゴスの王。第五歌で神々をも傷つける。 |
| Νέστωρ | ネストール | ピュロスの老王。昔語りの多い助言者。「ゲレーニアの騎士」。 |
| Φοῖνιξ | ポイニクス | アキレウスの育ての親。第九歌の使節の一人。 |
| Ἰδομενεύς | イードメネウス | クレータの王。 |
| Μηριόνης | メーリオネース | イードメネウスの従者。 |
| Ἀντίλοχος | アンティロコス | ネストールの子。パトロクロスの死をアキレウスに知らせる。 |
| Μαχάων | マカーオーン | 医術の神アスクレーピオスの子で、軍医。 |
| Κάλχας | カルカース | 予言者。 |
| Θερσίτης | テルシーテース | 第二歌で王たちをののしり、オデュッセウスに打たれる兵。 |
| Βρισηΐς | ブリーセーイス | アキレウスの戦利品の女。アガメムノーンに奪われる。 |

|---|---|---|
| Ἕκτωρ | ヘクトール | プリアモスの長子。トロイア第一の勇士。「輝く兜の」。第二十二歌で戦死する。 |
| Πρίαμος | プリアモス | トロイアの老王。 |
| Ἑκάβη | ヘカベー | プリアモスの妃。ヘクトールの母。 |
| Ἀνδρομάχη | アンドロマケー | ヘクトールの妻。 |
| Ἀστυάναξ / Σκαμάνδριος | アステュアナクス／スカマンドリオス | ヘクトールの幼い息子。 |
| Ἀλέξανδρος / Πάρις | アレクサンドロス／パリス | プリアモスの子。ヘレネーを連れ去り、戦争の原因を作った。 |
| Ἑλένη | ヘレネー | メネラーオスの妻。パリスとともにトロイアにいる。 |
| Αἰνείας | アイネイアース | アプロディーテーとアンキーセースの子。 |
| Σαρπηδών | サルペードーン | ゼウスの子。リュキア人の将。第十六歌で戦死する。 |

| Πουλυδάμας | プーリュダマース | ヘクトールの同年の友で、慎重な助言者。 |
| Πάνδαρος | パンダロス | 弓の名手。第四歌で誓いを破る矢を射る。 |
| Δόλων | ドローン | 第十歌の斥候。 |
| Χρύσης / Χρυσηΐς | クリューセース／クリューセーイス | アポローンの祭司とその娘。 |

## 主な語

| 原語 | 訳語 | 説明 |
|---|---|---|
| μῆνις | 怒り | 作品の最初の一語。アキレウスの、神々の怒りにも比べられる重い怒り。 |
| κλέος | 名声、誉れ | 歌い継がれる名。英雄が命と引き換えに求めるもの。 |
| τιμή | 名誉 | 身分と贈り物で示される名誉。アキレウスの怒りはこれを傷つけられたことによる。 |
| γέρας | 褒美、戦利品の取り分 | 戦の功に応じて与えられる取り分。 |
| ἄποινα | 身代金 | 捕虜や死体を取り戻すための代価。第一歌と第二十四歌の枠をなす。 |
| ξεῖνος / ξενίη | 客人、客人の縁 | もてなしで結ばれた家どうしの関係。第六歌のディオメーデースとグラウコス。 |
| θυμός | 心、胸 | 感情や意志の宿るところ。 |
| ψυχή | 魂 | 死ぬと体を離れて冥界へ行くもの。 |
| ἄτη | 迷い | 神々が人の心に送る判断の狂い。第十九歌のアガメムノーンの弁明。 |
| αἰγίς | アイギス | ゼウスとアテーナーのもつ、恐怖を起こす房飾りの盾。 |
| ἑκατόμβη | 百頭の牛の生け贄 | 大がかりな生け贄。 |
| τάλαντον | タラントン | 金などの重さの単位。またゼウスの運命の秤。 |
| ἐπίθετον | 決まり文句（エピテトン） | 「足速いアキレウス」「薔薇色の指の曙」など、人や物に繰り返し付く形容句。訳では省かずに訳した。 |
