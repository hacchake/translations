# イーリアス　作業メモ

ホメロス『イーリアス』のギリシア語原典からの全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- 底本：Homeri Opera, ed. D. B. Monro & T. W. Allen, 3rd ed., Oxford（1908〜1920年）。
  - ペルセウス計画のデジタル版（TEI XML）を使った。
  - 入手先：https://github.com/PerseusDL/canonical-greekLit の tlg0012.tlg001.perseus-grc2.xml
- 作業の手順：
  - XML から歌ごとに行番号つきの本文を書き出した。全24歌、15,693行。
  - 1歌ずつ下書き（`draft/b01.md`〜）に訳した。
  - 4歌ずつまとめて全訳ファイル（`イーリアス_0N_第…歌.md`）と note 用原稿（`note用/`）を生成した。

## 構成と note への投稿

- note の記事は4歌ずつ6本にまとめる（ユーザーの指示）。
  - 第一〜四歌、第五〜八歌、第九〜十二歌、第十三〜十六歌、第十七〜二十歌、第二十一〜二十四歌。
- そのほかに、各歌の要約と各記事へのリンクをまとめた記事を1本作る。

## 訳の方針

- **原典から直接訳す**：ギリシア語原典から直接訳した。既存の日本語訳は参照していない。
- **英訳との照合**：意味の取りにくい箇所は、保護期間の切れた英訳（S. バトラー訳1898年、A. T. マリー訳1924年）と照らし合わせることにした。
- **文体**：「である」調の散文訳。韻文の行分けはしない。
  - 段落の頭に［1］などの形で原典の行番号を付け、原文と照らし合わせられるようにした。
  - 段落は、話者の交代と場面の区切りで分けた。
- **決まり文句（エピテトン）**：「足速いアキレウス」「白い腕の女神ヘーラー」「薔薇色の指の曙」など、繰り返しを含めて省かずに訳した。
- **繰り返しの場面**：同じ言葉の繰り返し（使者が命令をそのまま伝える場面など）も省略せず、毎回訳した。
- **固有名詞**：ギリシア語の発音に近い片仮名で、長音を示した。
  - 例：アガメムノーン、ヘーラー、ポセイダーオーン。
  - ただし、日本語で定着している名は慣用に従った（ゼウス、トロイア、ホメロスなど）。
- **民族名の訳し分け**：「アカイア人」「ダナオイ人」「アルゴス人」は、原文の使い分けのとおりに訳し分けた。
- **歌の題**：原典にはない。各歌の主な出来事から、訳者が付けた。
