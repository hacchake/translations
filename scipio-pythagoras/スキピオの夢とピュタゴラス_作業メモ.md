# スキピオの夢／ピュタゴラスの黄金の詩句と象徴　作業メモ

ウェストコット編『ヘルメス文書集成』第5巻（1894年）の全訳の作業記録。note の記事本文には含めない。

## 底本と作業の手順

- Internet Archive の WestcottWWCollectaneaHermeticaVolume05 の OCR テキスト（_djvu.txt、2026年11月4日取得）を `src/vol5_ocr_raw.txt` に置き、柱とページ番号を除いたものを `src/vol5_clean.txt` とした。
- 下書き `draft/p1.md`（扉・スキピオの夢）、`p2.md`（その注・L・Oの論考）、`p3.md`（黄金の詩句と注）、`p4.md`（ピュタゴラスの象徴）と解説 `draft/head.md` から `_build.py` で全訳と note 用原稿2本（前編 p1+p2、後編 p3+p4）を生成した。
- 『象徴』のラテン語は OCR の誤りが多いため通行の綴りに直した。第六十八の後半は判読できず補っていない。
- 原文の聖書箇所やヘロドトスの巻数の誤りは本文を改めず、訳注で断った。
- 英訳からの重訳である。ラテン語・ギリシア語原典とは照合していない。
- 日本語訳の有無：『スキピオの夢』（キケロ『国家について』第6巻）と『黄金の詩句』には既訳があるが、この版（L・O論考、A・E・A注、S・Aの象徴注解）の日本語訳は見つからなかった。

## 訳の方針

- 戒めは「〜せよ」「〜するな」。注解は「である」調。
- 注者の略号（S.A.、L.O.、N.O.M.、A.E.A.）は原文どおり残した。A・E・A、N・O・Mの実名は推定しない。
